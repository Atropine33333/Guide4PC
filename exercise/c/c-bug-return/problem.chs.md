（濠梁之上，庄子与惠子临水而坐。）

惠子：我有一算：自一乘二，递乘至九，积得三十六万二千八百八十。如何？

庄子：数是对的。你把它放在哪里了？

惠子：就在我手里握着。

庄子：握在手里，便是没有交出来。算完了不交，与没算何异？

惠子：那该如何？

庄子：从哪儿取的，就递回哪儿去。

**人话**：读入一个整数 `n`，输出 `n` 的阶乘。`starter.c` 里的 `factorial` 已经把乘积算出来了，却没有把结果交回去；补上这一处，程序就对了。

**输入**：一行一个整数 `n`（`0 ≤ n ≤ 12`）。

**输出**：一行，`n!` 的值。

### 示例

输入：

```text
5
```

输出：

```text
120
```

### 约定

- `0!` 与 `1!` 都等于 `1`。
- `12! = 479001600`，在 `int` 范围内。
- 只改 `factorial` 里坏掉的那一处，输入输出的格式保持不变。
- 输出一行，末尾换行。
