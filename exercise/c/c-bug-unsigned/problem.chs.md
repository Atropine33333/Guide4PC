《十三号楼楼道须知》

一、本楼自上而下编号：最高一级是 `n`，最低一级是 `1`。
二、每下一级，报出脚下的编号。编号之间空一格。
三、报出 `1` 之后即可停步，换行，不必回头。
四、编号没有零，也没有负数。若有人一直往下走却始终踩不到底，说明他数过了头。
五、若听见脚步声从 `n` 一直响下去，不要跟着数。

**人话**：读入 `n`，按 `n, n-1, ..., 1` 的顺序在一行内输出，数字之间用单个空格分隔，行末换行。`starter.c` 的循环用 `unsigned` 计数，`i >= 0` 永远成立，数到 `1` 之后也停不下来；把这个条件改对。

**输入**：一行一个整数 `n`（`1 ≤ n ≤ 1000`）。

**输出**：一行，从 `n` 递减到 `1` 的整数序列，用单个空格分隔。

### 示例

输入：

```text
5
```

输出：

```text
5 4 3 2 1
```

### 约定

- `n` 至少为 `1`，不会出现零级或负级。
- 最后一个数字后面直接换行，行末不要有多余空格。
- 只改坏掉的那一处，输入输出的格式保持不变。
