读入两个 0 到 127 之间的整数 `a`、`b`，看看一个 `char` 参加加法之后变成了什么类型。

**人话**：先把 `a`、`b` 各自转成 `char` 再相加，输出这个和的整数值；再输出 `sizeof(a + b)` 的值；最后输出 `(unsigned char)300` 的值。三项写在同一行，用单个空格分隔。

**输入**：一行两个整数 `a`、`b`，满足 `0 ≤ a, b ≤ 127`。

**输出**：一行三个整数，依次为：

1. `(char)a + (char)b` 的值；
2. `sizeof(a + b)` 的值；
3. `(unsigned char)300` 的值。

### 示例

输入：

```text
100 50
```

输出：

```text
150 4 44
```

`(char)100` 与 `(char)50` 在相加之前都会提升为 `int`，所以和是 150，不会在 8 位里回绕；这个和表达式的类型是 `int`，在本机占 4 字节，`sizeof` 取到 4；`300` 塞进 8 位的 `unsigned char` 只留下低 8 位，`300 - 256 = 44`。

### 约定

- 两个操作数都在 `0` 到 `127` 之间，`char` 是否有符号都不影响结果。
- `sizeof` 的结果可以转成 `int` 再打印。
- 本机的 `int` 占 4 字节、`unsigned char` 占 1 字节，与常见平台一致。
- 输出行末不要有多余空格。
- 不要输出题面之外的文字。
