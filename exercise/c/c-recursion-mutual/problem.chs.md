《齐物论：奇偶》

蒙叟坐于濠上，弟子问曰：「数有奇偶乎？」

叟曰：「欲知偶者，先问其奇；欲知奇者，先问其偶。偶减一为奇，奇减一为偶，如环相生，无有端始。」

弟子曰：「至零则如何？」

叟曰：「零，偶也。问偶而得偶，不复再问。」

弟子曰：「千，何如？」

叟曰：「以偶问奇，以奇问偶，层层相减，终至于零而止。千次之问，犹一问也。」

**人话**：实现两个互相调用的函数。`is_even(0)` 返回 `1`，`is_even(n)` 返回 `is_odd(n - 1)`；`is_odd(0)` 返回 `0`，`is_odd(n)` 返回 `is_even(n - 1)`。读入 `n`，`n` 为偶数输出 `even`，否则输出 `odd`。

**输入**：一行一个整数 `n`，满足 `0 ≤ n ≤ 1000`。

**输出**：一行，`even` 或 `odd`。

### 示例

输入：

```text
7
```

输出：

```text
odd
```

### 约定

- 两个函数必须互相调用；`is_odd` 里调用 `is_even`，`is_even` 里调用 `is_odd`。
- 递归深度不超过 `1001` 层，可以直接递归。
- `0` 按偶数处理。
- 输出小写，行末不要有多余空格。
