从头读到尾，一次把字符、行、词都数出来。

**输入**：若干行，至少一行，总长度不超过 `10000`；只含可打印 ASCII 字符、空格与换行，最后一行以换行结束。

**输出**：一行三个整数，依次为字符数、行数、单词数，用单个空格分隔。

- 字符数：包括空格与换行在内的所有字符个数。
- 行数：换行符的个数。
- 单词数：连续的非空白字符算一个单词；标点紧贴单词时算作单词的一部分。

### 示例

输入：

```text
the quick fox
```

输出：

```text
14 1 3
```

这一行有 `13` 个可见字符，加上行末的换行是 `14` 个字符；一共 `1` 行、`3` 个单词。

### 约定

- 用 `getchar` 循环读到 `EOF`。
- 空白指空格、制表符与换行。
- 行数按换行符计，输入的最后一行也带换行。
- 行末不要有多余空格。
