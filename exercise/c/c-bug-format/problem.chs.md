`starter.c` 里的程序要打印一张平方表，现在每一行都挤在同一行里，列也没有对齐。

表有 `n` 行，第 `i` 行先打印 `i`，再打印 `i * i`。两个数各占固定的列宽，都往右对齐：`i` 占 `4` 列，`i * i` 占 `6` 列，两列紧挨着，每行末尾换行。

请把输出格式改对。

**人话**：读入 `n`，打印 `n` 行；第 `i` 行是 `i` 和 `i * i`，分别占 `4` 列和 `6` 列，右对齐，每行末尾换行。

**输入**：一行一个整数 `n`（`1 ≤ n ≤ 100`）。

**输出**：`n` 行，第 `i` 行（`i` 从 `1` 到 `n`）为 `i` 与 `i * i`，前者占 `4` 列、后者占 `6` 列，均右对齐，两列之间不再另加空格。

### 示例

输入：

```text
3
```

输出：

```text
   1     1
   2     4
   3     9
```

第一行里，`1` 前面有 3 个空格；它后面紧跟 5 个空格，再是平方数 `1`。

### 约定

- 右对齐用 `printf` 的列宽写法，不要手工拼空格。
- 每一行末尾都要换行，最后一行也一样。
- 只改输出的那一处，读入部分保持不变。
