哦，我的朋友，你可算来了。站到灯底下来，别害臊——这条街上的人都在说，你能把字母一个挨一个地摞起来，摞成一座金字塔。

听好，事情是这样的。最上头只站一个 `A`。往下第二层，从左往右念过去是 `ABA`：两边各站一个 `A`，中间那位是 `B`。第三层是 `ABCBA`，第四层是 `ABCDCBA`。再往下就照这个规矩一层层接上去，字母从 `A` 起顺着一路往上爬，爬到这一层的正中间那位，再顺着原路倒回来。每一层都得端端正正地摆在中轴线上，左边空出够用的位置，右边一个空格都不许留，上帝作证，一位都不许。

**人话**：读入整数 `n`，输出 `n` 行字符金字塔。第 `i` 行（`i` 从 `1` 数起）有 `2i-1` 个字母：从 `A` 顺写到第 `i` 个字母，再倒写回来；整行前面补 `n-i` 个空格，行末不留空格。

**输入**：一行，一个整数 `n`，`1 ≤ n ≤ 9`。

**输出**：共 `n` 行，第 `i` 行按上面的规矩排好。

### 示例

输入：

```text
3
```

输出：

```text
  A
 ABA
ABCBA
```

### 约定

- `n` 不超过 `9`，最底层的中间字母最大是 `I`，不会绕回 `A`。
- 第 `i` 行前面的空格数恰好是 `n-i`。
- 行末不要多余空格，最后一行下面不要多出空行。
