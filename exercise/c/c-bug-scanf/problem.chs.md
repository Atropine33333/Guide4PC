`starter.c` 里的程序读入两个整数，要输出它们的和。现在第二个整数没有被读进来：`scanf` 收到的是 `b` 的值，而它需要的是 `b` 的地址，读入落到了别处。把参数改对。

**输入**：一行两个整数 `a`、`b`，满足 `-10^9 ≤ a, b ≤ 10^9`，用单个空格分隔。

**输出**：一行，`a + b` 的值。

### 示例

输入：

```text
12 30
```

输出：

```text
42
```

### 约定

- 两个数都在 `int` 范围内，和也在 `int` 范围内，不会溢出。
- 只改坏掉的那一处，输入输出的格式保持不变。
- 输出一行，末尾换行。
