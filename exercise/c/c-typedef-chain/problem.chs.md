`score` 是分数的类型名。有人嫌 `int` 太直白，给它起了别名：

```c
typedef int score;
typedef score *score_ptr;
```

`score_ptr` 指向一个分数，`*score_ptr` 读出来又是 `score`。别名套着别名，念起来像绕口令，编译器却认得清清楚楚。

**人话**：读入 `n` 个分数，让 `score_ptr` 指向下标 `n / 2` 的元素，输出 `sizeof(score)` 与 `*p`，中间用一个空格隔开。

**输入**：第一行一个整数 `n`（`1 ≤ n ≤ 1000`）；第二行 `n` 个整数，每个都在 `-10^6` 到 `10^6` 之间，表示分数。

**输出**：一行两个整数，依次为 `sizeof(score)` 与 `*p`，用一个空格分隔。

### 示例

输入：

```text
5
10 20 30 40 50
```

输出：

```text
4 30
```

`n / 2` 为 `2`，下标 `2` 的元素是 `30`。

### 约定

- 先写 `typedef int score;`，再写 `typedef score *score_ptr;`，让指针类型也走一遍别名。
- 本环境里 `int` 占 4 字节，`sizeof(score)` 就是 `4`；输出时用 `%zu`。
- 指针自身占几个字节不在输出之列。
- 下标从 `0` 开始，`n / 2` 向下取整。
- 输出行末不要有多余空格。
