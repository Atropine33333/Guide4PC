《读入律》

第一条（起读）凡读整数者，先读一枚，再论其余。故一枚未读之前，律已行过一次。

第二条（止读）所读之数为零，即止；零不入账。

第三条（计枚）非零之数，读一枚，计一枚。

第四条（累加）非零之数，读一枚，加入总和。总和以长整数记，虽千枚、每枚十亿，亦不溢出。

第五条（空卷）第一枚即零者，计零枚，和为零。

第六条（裁断）读毕，先报枚数，后报总和，同处一行，以单个空格分隔。

**人话**：反复读入整数，读到 `0` 就停止；`0` 本身不算，输出前面非零整数的个数与总和（先个数、后总和）。循环体至少执行一次。

**输入**：一行若干整数，以 `0` 结尾；`0` 之前最多 `1000` 个，每个的绝对值不超过 `10^9`。

**输出**：一行两个整数，依次为个数与总和，用单个空格分隔。

### 示例

输入：

```text
3 5 -2 0
```

输出：

```text
3 6
```

### 约定

- 用 `do`-`while` 写循环：先读一枚，再判断是否该停，所以第一枚无论是什么都读过了。
- 输入以 `0` 结尾；`0` 不计入个数，也不计入总和。
- 总和可能超过 `int` 的范围，用 `long long` 保存。
- 输出行末不要有多余空格。
