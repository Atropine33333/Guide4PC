读入一个 `0` 到 `255` 之间的整数，把这个数的 8 个二进制位原样交给一个 `signed char`，输出它读出来的值。

**输入**：一行一个整数 `n`，满足 `0 ≤ n ≤ 255`。

**输出**：一行一个整数，即把 `n` 的 8 个位按补码解释为有符号 8 位整数时的值。

### 示例

输入：

```text
200
```

输出：

```text
-56
```

`200` 的 8 个位是 `11001000`，最高位为 `1`，按补码读作 `200 - 256 = -56`。

### 约定

- `0` 到 `127` 保持原值；`128` 到 `255` 减去 `256`。
- 输出用十进制，负数带负号，不加前缀。
- 不要输出题面之外的文字。
