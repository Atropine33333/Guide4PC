`starter.c` 里的程序要输出从 `1` 到 `n` 的整数，用单个空格隔开。现在它每次都多输出一个数：读入 `5`，它打出 `1 2 3 4 5 6`。请把这一处改对。

**人话**：读入 `n`，把 `1` 到 `n` 依次打印出来，数字之间用一个空格隔开。`starter.c` 里的循环多走了一步，改掉它。

**输入**：一行一个整数 `n`（`1 ≤ n ≤ 30`）。

**输出**：一行，从 `1` 到 `n` 的整数，按顺序排列，相邻两个数之间用一个空格分隔，行末不要有多余空格。

### 示例

输入：

```text
5
```

输出：

```text
1 2 3 4 5
```

### 约定

- 只改坏掉的那一处，输入输出的格式保持不变。
- `n` 至少为 `1`，不必考虑空输入。
- 输出一行，末尾换行。
