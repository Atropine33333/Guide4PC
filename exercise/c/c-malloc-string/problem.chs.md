字符串在 C 里没有自己的住处。你手里只有一个 `const char *`，它指向的那片内存随时可能被收回或改写。想把一段文字留住，就得自己申请一块地，把字一个一个搬进去，再从这块地的首地址读回来。

**人话**：写 `dup_str`，按 `strlen(s) + 1` 个字节申请内存，把 `s` 连同结尾的 `'\0'` 一起复制进去并返回首地址；`free_str` 负责把这块内存还回去。

**接口**：

```c
char *dup_str(const char *s);
void free_str(char *s);
```

- `dup_str(NULL)` 返回 `NULL`。
- 申请不到内存时返回 `NULL`。
- 返回的副本是一块新内存，与 `s` 不重叠；改副本里的字符，原文保持不变。
- 副本保留全部字符，长度再长也不截断。
- `free_str(NULL)` 什么也不做；`free_str` 只接受 `dup_str` 返回的指针。

### 示例

```c
char *p = dup_str("hello");   /* p 指向 "hello"，与字面量不重叠 */
p[0] = 'H';                   /* 字面量 "hello" 不受影响 */
free_str(p);
```

### 约定

- 只需要实现这两个函数，不要写 `main`。
- 只用标准库里的 `malloc`、`free` 一类设施，不使用变长数组或全局缓冲区。
- 一个副本只归还一次。
