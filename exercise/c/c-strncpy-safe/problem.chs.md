把源字符串搬进目标缓冲区，最多写到容量允许的位置，并在末尾补上 `\0`。目标缓冲区容量有限、源串长度未知时，不论源串多长，都不会写到目标缓冲区之外，结果始终是一个合法的 C 字符串。

**人话**：把 `s` 复制进 `dst`，最多写 `cap - 1` 个字符，并在末尾补 `\0`；`cap` 为 `0` 时一个字节都不写。

**接口**：

```c
void copy_name(char *dst, size_t cap, const char *s);
```

- `cap` 为 `0`：什么也不做，连结尾的 `\0` 也不写，`dst` 保持原样。
- `cap` 大于 `0`：最多写入 `cap - 1` 个字符，再补一个 `\0`；源串多出来的字符直接舍弃，不报错。
- `cap` 放得下整串时，效果与整串复制相同。
- `cap` 以字节计，包含结尾 `\0` 占的那一个位置；目标缓冲区里第 `cap` 个字节及其后的内容不会被改动；源串自身不受影响。

### 示例

```c
char a[16];
copy_name(a, 8, "0123456");   // a 变成 "0123456"

char b[16];
copy_name(b, 5, "abcdefgh");  // b 变成 "abcd"

char c[8];
copy_name(c, 1, "abc");       // c 变成 ""
```

### 约定

- 只实现这个函数，不要写 `main`；这些函数会被直接调用。
- 只写 `dst` 的前 `cap` 个字节，`cap` 之后的字节保持原样。
- 源串以 `\0` 结尾，函数读到这里就停，不读它后面的内容。
