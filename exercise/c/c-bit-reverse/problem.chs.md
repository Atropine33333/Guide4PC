《三十二位守则》

一、这扇门只认 `0` 到 `4294967295` 的整数。进来时它按 32 位无符号存放，一位不多，一位不少。

二、位从 `0` 数起：第 `0` 位最靠右，第 `31` 位最靠左。

三、把 32 位整个翻过来：第 `0` 位搬到第 `31` 位，第 `31` 位搬到第 `0` 位，其余各位照此对折。

四、`1` 只有第 `0` 位亮着；翻过来只剩第 `31` 位亮着，读作 `2147483648`。

五、`0` 的 32 位都不亮，翻过来还是 `0`。这一条没有例外。

六、`4294967295` 的 32 位全亮，翻过来还是全亮，仍是 `4294967295`。

七、若你把翻过来的数塞进有符号的 `int` 再直接打印，第四条里的 `2147483648` 会显示成 `-2147483648`，第四条便暂时作废；改用无符号读出，第四条立刻重新成立。

八、守则一至六对所有合法输入都成立；只有第七条会因你读出结果的方式而作废或成立。

**人话**：读入一个整数，把它的 32 个二进制位首尾颠倒，输出得到的新整数。

**输入**：一行一个整数 `x`，满足 `0 ≤ x ≤ 4294967295`。

**输出**：一行一个整数，为 `x` 的 32 位二进制逆序后的值，按无符号十进制输出。

### 示例

输入：

```text
1
```

输出：

```text
2147483648
```

`1` 只有最低位为 `1`；翻过来只剩最高位为 `1`，即 `2^31`。

### 约定

- 固定按 32 位颠倒，高位的 `0` 也参与，结果仍在 `0` 到 `4294967295` 之间。
- 用 `uint32_t` 保存输入与结果，不要用有符号类型保存中间结果。
- 输出用无符号十进制，不带正号，不补前导零。
- 不要输出题面之外的文字。
