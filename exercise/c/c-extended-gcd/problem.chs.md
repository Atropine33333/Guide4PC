> 甲帮乙帮各列阵，
> 以少减多余数现；
> 余尽人齐教头出，
> 再配调度凑一船。

江湖上，甲帮有 `a` 人，乙帮有 `b` 人。两帮要并成一支巡山队，每排站同样多的人，且每排人数越多越好：这个每排人数 `g`，就是两帮人数的最大公约数。老盟主嫌光有 `g` 还不够，又传下一道调度令：甲帮出 `x` 队、乙帮出 `y` 队，两队人数相加恰好凑成 `g`，如此巡山队才算点齐。

**人话**：求 `a` 与 `b` 的最大公约数 `g`，并给出一组整数 `x`、`y`，使 `a x + b y = g`。为了答案唯一，规定 `x` 取满足 `0 ≤ x < b / g` 的那一个，再按 `g x y` 的顺序输出。

**输入**：一行两个正整数 `a`、`b`（`1 ≤ a, b ≤ 10^9`），用单个空格分隔。

**输出**：一行三个整数 `g`、`x`、`y`，用单个空格分隔。

### 示例

输入：

```text
12 8
```

输出：

```text
4 1 -1
```

`12` 与 `8` 的最大公约数是 `4`；`12 × 1 + 8 × (-1) = 4`，且 `1` 落在 `0 ≤ x < 8 / 4 = 2` 之内。

### 约定

- `g` 是 `a` 与 `b` 的最大公约数。
- `x` 取满足 `0 ≤ x < b / g` 的那一个解，`y` 由 `(g - a x) / b` 得出。
- 中间乘积 `a x` 不超过 `10^18`，用 `long long` 保存。
- 两个数都不小于 `1`，不会出现除以零。
- 输出行末不要有多余空格。
