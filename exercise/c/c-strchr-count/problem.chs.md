「字符的点名」

一行文字里，某个字符出现了几次？把这一行读进来，再读一个字符，从行首走到行尾，点到一次名就记一笔。

**人话**：读入一行文字和一个字符，数出这个字符在这一行里出现了多少次，打印这个次数。

**输入**：

- 第一行一段文字，长度在 `1` 到 `200` 之间，可以含空格，行内没有换行符。
- 第二行一个可见字符，不是空格、制表符或换行。

**输出**：一行一个整数，表示该字符在文字行中出现的次数。

### 示例

输入：

```text
hello world
l
```

输出：

```text
3
```

`hello world` 里的 `l` 一共出现三次。

### 约定

- 用 `strchr` 从当前位置往后找，找到一个就把指针挪到它后面接着找。
- 区分大小写，`a` 与 `A` 算两个不同的字符。
- 空格是文字的一部分，照常保留；要数的字符本身不是空白字符。
- 输出行末不要有多余空格。
