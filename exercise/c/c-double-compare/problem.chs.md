双精度比较仪 G4 型 使用说明书

一、用途

本机比较两个双精度浮点数，依次给出两项读数，每项一行。

二、安装

无需安装。把两个数送进来，机器就开始工作。

三、第一项读数（容差比较）

取两数之差的绝对值。绝对值小于 `1e-9` 时判为相等，读数 `1`；否则读数 `0`。

四、第二项读数（自检）

机器计算 `0.1 + 0.2`，再用 `==` 与 `0.3` 比较。相等读数 `1`，否则读数 `0`。这一项只反映双精度的表示误差，与送进来的两个数无关。

五、读数顺序

第一项在上，第二项在下，各占一行，每行一个 `0` 或 `1`。

六、注意

- 送进来的两个数不要用 `==` 直接比较。
- 求差的绝对值时自己判符号即可，不必依赖额外的数学库。
- 输入可以是负数、零或小数，两数的绝对值都不超过 `10^9`。

**人话**：读入两个 `double`，第一行输出 `|a - b| < 1e-9` 的结果（`1` 或 `0`），第二行输出 `0.1 + 0.2 == 0.3` 的结果（`1` 或 `0`）。

**输入**：一行两个十进制小数 `a`、`b`，用单个空格分隔，绝对值不超过 `10^9`。

**输出**：两行，每行一个整数 `0` 或 `1`。第一行是容差比较的结果，第二行是自检的结果。

### 示例

输入：

```text
1.0 1.0000000005
```

输出：

```text
1
0
```

两数相差约 `5e-10`，小于 `1e-9`，第一项读数为 `1`；`0.1 + 0.2` 的双精度结果是 `0.30000000000000004`，与 `0.3` 不相等，第二项读数恒为 `0`。

### 约定

- 容差比较用 `<`，差恰好等于 `1e-9` 时读数 `0`。
- 第二项读数与输入无关，恒为 `0`。
- 输出只有两行，行末换行，不要有空行。
- 不要输出题面之外的文字。
