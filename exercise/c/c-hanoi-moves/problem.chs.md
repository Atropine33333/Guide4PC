甲：说三根柱子，`n` 个盘子从小到大摞在第一根上。

乙：要都搬到第三根去。

甲：一回只能搬一个，大盘不能压在小盘上。最少几步？

乙：先把上面 `n - 1` 个挪到中间那根，把最大的挪到第三根，再把那 `n - 1` 个从中间挪过去。

甲：这么算，一步变两步，还多一步？

乙：对，`T(n) = 2T(n - 1) + 1`；只有一个盘子时恰好一步，解开就是 `2^n - 1`。

甲：得，报个数，看官自己算去吧。

**人话**：读入 `n`（`1 ≤ n ≤ 30`），输出把 `n` 个盘子全部搬到第三根所需的最少步数，即 `2^n - 1`。

**输入**：一行一个整数 `n`（`1 ≤ n ≤ 30`）。

**输出**：一行一个整数，最少步数。

### 示例

输入：

```text
3
```

输出：

```text
7
```

三个盘子：小盘挪到第三根，中盘挪到第二根，小盘挪到第二根，大盘挪到第三根，小盘挪到第一根，中盘挪到第三根，小盘挪到第三根，共七步。

### 约定

- `2^30 - 1 = 1073741823`，用 `int` 放得下，用 `long long` 更稳妥。
- 只输出步数，不用输出每一步的搬法。
- 输出行末不要有多余空格。
