（甲、乙二人上台，桌上放一块醒木。）

甲：我这儿有个规矩：谁开口，先喊一声。

乙：喊什么？

甲：对得上，就喊「OK」；对不上，就喊「FAIL:行」，把犯事的哪一行也报出来。

乙：嚯，还带行号的。

甲：那可不。可这行号不能乱报，得按写下的位置报。我在前头压一句 `#line 40`，底下的两次比较就从第 40 行、第 41 行起数。

乙：那要是头一行就不对呢？

甲：先喊 `FAIL:40`，再喊第二声。

乙：两行都不对？

甲：那就 `FAIL:40`、`FAIL:41`，一声不落。

乙：得，您这规矩我记住了。

**人话**：定义 `CHECK(cond)` 宏：条件成立时输出 `OK`，不成立时输出 `FAIL:<行号>`，行号取宏调用处的 `__LINE__`。读入两个整数 `a`、`b`，依次检查 `a < b` 和 `a == b`，每个检查输出一行。

**输入**：一行两个整数 `a`、`b`，满足 `-1000 ≤ a ≤ 1000`、`-1000 ≤ b ≤ 1000`。

**输出**：两行。第一行是 `CHECK(a < b)` 的结果，第二行是 `CHECK(a == b)` 的结果；成立输出 `OK`，不成立输出 `FAIL:<行号>`。

### 示例

输入：

```text
3 5
```

输出：

```text
OK
FAIL:41
```

`3 < 5` 成立，第一声是 `OK`；`3 == 5` 不成立，第二声报出第 41 行。

### 约定

- 宏体放进 `do { ... } while (0)`，每次调用末尾写分号。
- 条件只求值一次，不要把它写两遍。
- 行号取自 `__LINE__`；两次调用位于 `#line 40` 之后的两行，所以分别是 40 和 41。
- 不要把两次调用挪到别的行，也不要改动 `#line 40`。
- 输出行末不要有多余空格。
