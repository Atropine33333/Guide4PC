**人话**：实现 `IntVec` 的三个函数。`vec_init` 把它置为空；`vec_push` 在尾部追加一个整数，容量不够时扩容（新容量至少是旧容量的两倍），成功返回 `0`，失败返回 `-1` 且已有数据不变；`vec_free` 释放内存并把 `size` 置 `0`。

**接口**：

```c
typedef struct {
    int *data;
    size_t size;
    size_t cap;
} IntVec;

void vec_init(IntVec *v);
int vec_push(IntVec *v, int value);
void vec_free(IntVec *v);
```

### 示例

| 调用 | 结果 |
| --- | --- |
| `vec_init(&v)` | `size == 0`，`cap == 0`，`data == NULL` |
| `vec_push(&v, 7)`、`vec_push(&v, 9)` | 都返回 `0`，`size == 2`，`data[0] == 7`，`data[1] == 9` |
| 接着追加 98 个整数 | 都返回 `0`，`size == 100`，`cap >= 100`，值按追加顺序排列 |
| `vec_free(&v)` | 内存归还，`size == 0` |

### 约定

- `vec_init` 之后 `size == 0`、`cap == 0`、`data == NULL`。
- 容量为 `0` 时的第一次扩容，新容量至少为 `1`。
- 只要发生扩容，新容量至少是旧容量的两倍；任何时刻都有 `cap >= size`。
- 扩容后旧元素按原顺序保留，一个都不能丢。
- `vec_push` 在分配失败时返回 `-1`，`size` 和已有元素保持不变。
- `vec_free` 在从未追加过元素时也能安全调用；调用后 `size == 0`。同一个 `IntVec` 只释放一次。
- 内存用 `malloc`/`realloc` 取得，所有权归 `IntVec`，由 `vec_free` 归还。
- 不要写 `main`。
