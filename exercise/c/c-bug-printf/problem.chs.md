`starter.c` 里的程序读入两个实数，要输出它们的和，保留两位小数。现在它用 `%d` 打印 `double` 类型的结果，屏幕上的数字完全对不上。把格式改对。

**输入**：一行两个实数 `a`、`b`，各最多两位小数，绝对值不超过 `10000`，用单个空格分隔。

**输出**：一行，`a + b` 的值，保留两位小数。

### 示例

输入：

```text
1.25 2.50
```

输出：

```text
3.75
```

### 约定

- 用 `double` 读入和计算，用 `%.2f` 输出。
- 只改坏掉的那一处，输入输出的格式保持不变。
- 输出一行，末尾换行。
