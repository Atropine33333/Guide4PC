**柜台一号：自动编号机**

> 排号排到一半，机器失忆，客人重号？
> 本机不答应。按一次，出一个号；再按一次，接着往下数。`1`、`2`、`3`……一个不重，一个不漏。
> 换班了？摁下复位键，从 `1` 重新来过。手重连摁两下，也不多不少，仍旧从 `1` 起。
> 取号不限次数，随按随取，柜台永不打烊。

**人话**：实现两个函数。`next_id` 每次调用返回一个比上次大 `1` 的编号，第一次调用返回 `1`；`reset_ids` 把编号归零，让下一次 `next_id` 重新从 `1` 开始。编号要在两次调用之间留在原地。

**接口**：

```c
int next_id(void);
void reset_ids(void);
```

- `next_id`：返回 `1`、`2`、`3`……依次递增，返回值用 `int` 装得下。
- `reset_ids`：把计数器归零；紧接着调用 `next_id` 得到 `1`。连续调用多次与调用一次效果相同。

### 示例

先调用三次 `next_id`，得到 `1`、`2`、`3`；再调用一次，得到 `4`。调用 `reset_ids` 之后，`next_id` 又返回 `1`。

### 约定

- 计数器要活过函数返回：用静态存储期的变量（函数内的 `static` 局部变量，或文件作用域的 `static` 变量）。
- 只需要实现这两个函数，不要写 `main`。
- 编号在 `int` 范围内递增，从复位到复位之间不会溢出。
