一行文字里混着字母、数字、空格和其他符号。给每个字符找到它该去的类别，再数清每一类各有多少个。

**人话**：读入一行文字（可能为空），统计其中字母、数字、空白字符和其他字符的个数，依次输出四个整数。

**输入**：一行，长度在 `0` 到 `1000` 之间，可以包含字母、数字、空格、制表符和可见标点，不含换行符。

**输出**：一行四个整数，依次为字母数、数字个数、空白字符数、其他字符数，用单个空格分隔。

### 示例

输入：

```text
Hello123
```

输出：

```text
5 3 0 0
```

`H`、`e`、`l`、`l`、`o` 是字母，`1`、`2`、`3` 是数字，没有空白和其他字符。

### 约定

- 字母指 `A`–`Z` 与 `a`–`z`，数字指 `0`–`9`。
- 空白字符指空格和制表符。
- 空行输出 `0 0 0 0`。
- 输出行末不要有多余空格。
- 不要输出题面之外的文字。
