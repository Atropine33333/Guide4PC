【清仓告示 · 只此一支】

本店最后一个小数，正挂在门口的价签上。

小票价：保留两位小数，末尾的零照留，收银机跳出来的就是这一串。
抹零价：只留整数位，小数部分按店里的规矩舍入，老板心里记的就是这个数。

舍入的规矩只有一条：小数部分恰好是一半时，向最近的偶数靠；其余情况按平常的四舍五入。

两个价并排写在一行，中间空一格。数量有限，售完即止。

**人话**：读入一个 `double`，先用 `%.2f` 打印保留两位小数的值，再用 `%.0f` 打印取整后的值，两个值用单个空格分隔，输出一行。

**输入**：一行一个十进制小数，可以带负号，绝对值不超过 `10^9`。

**输出**：一行两个值，依次为保留两位小数的结果与取整结果，用单个空格分隔。

### 示例

输入：

```text
19.99
```

输出：

```text
19.99 20
```

两位小数原样保留；整数位上 `19.99` 离 `20` 更近，抹零价就是 `20`。

输入：

```text
2.5
```

输出：

```text
2.50 2
```

小数部分正好是一半，向最近的偶数靠，`2.5` 取整为 `2`；`3.5` 同样是一半，取整为 `4`。

### 约定

- `%.2f` 与 `%.0f` 各自按 `printf` 的规矩舍入，小数位不足时补零。
- 恰好一半时按当前舍入模式处理，也就是向最近的偶数靠。
- 负数照常带负号，`-0.6` 的抹零价是 `-1`。
- 输出行末不要有多余空格。
- 不要输出题面之外的文字。
