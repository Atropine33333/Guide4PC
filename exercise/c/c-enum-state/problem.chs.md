《状态号说明书》

§1 用途
本页说明一台控制器上报的状态号码怎么读成名字。

§2 号码表

```c
enum State {
    IDLE = 0,
    RUN  = 2,
    DONE = 5
};
```

号码是挑着给的，中间留着空档：`0` 是空闲，`2` 是运行，`5` 是完成。

§3 读数规则
拿到一个整数，就照号码表查：

| 号码 | 名字 |
| ---- | ---- |
| `0`  | `IDLE` |
| `2`  | `RUN` |
| `5`  | `DONE` |
| 其他 | `UNKNOWN` |

编号从 `0` 开始，负数也是合法读数，按其他处理。

§4 输出
名字写在一行里，全大写，行末只留一个换行。

**人话**：读入一个整数，按 `enum State` 的取值输出 `IDLE`、`RUN` 或 `DONE`；不是 `0`、`2`、`5` 时输出 `UNKNOWN`。

**输入**：一行一个整数，`-10^9 ≤ 值 ≤ 10^9`。

**输出**：一行，状态名或 `UNKNOWN`。

### 示例

输入：

```text
2
```

输出：

```text
RUN
```

`2` 在表里对应运行状态，所以读出 `RUN`。

### 约定

- 只认 `0`、`2`、`5` 三个号码，其余一律 `UNKNOWN`。
- 空档里的号码（如 `1`、`3`、`4`）不算任何状态。
- 名字全大写，不要加引号或空格。
