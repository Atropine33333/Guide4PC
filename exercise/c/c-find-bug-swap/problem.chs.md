下面的程序读入两个整数，交换它们的值，再把结果打印出来；可它打出来的还是原来的顺序。请找出并修正 `swap` 里的错误。

**输入**：一行，两个整数 `a` 和 `b`，用一个空格分隔，绝对值都不超过 `10^9`。

**输出**：一行，两个整数，即交换值之后的结果，用一个空格分隔。

### 示例

输入：

```text
3 7
```

输出：

```text
7 3
```

### 提示

- `swap` 收到的两个参数本身就是指针，函数里直接改动它们，改的只是形参这份拷贝。
- 两个数相等时，交换前后的输出应当一样。
- 不要改变输入输出格式，也不要重写整题；只需修复 `starter.c` 中 `swap` 的逻辑错误。
