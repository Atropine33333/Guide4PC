`starter.c` 里的程序要算 `1 + 2 + ... + n`。读入 `n`，把输出的错误改掉，让结果正确。

现在的程序对任何 `n` 都恰好少加一项，算出来的结果比正确答案少 `n`。

**输入**：一行一个整数 `n`（`1 <= n <= 1000000`）。

**输出**：一行，`1` 到 `n` 的和。

### 示例

输入：

```text
10
```

输出：

```text
55
```

### 约定

- 和最大为 `500000500000`，超出 32 位整数范围，用 `long long` 保存。
- 只改坏掉的那一处，不要改变输入输出的格式。
- 输出一行，末尾换行。
