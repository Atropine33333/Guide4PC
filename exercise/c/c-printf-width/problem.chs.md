读入若干行姓名与分数，按固定的列宽排成一张表，表头也用同一套列宽。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 50`）。
- 接下来 `n` 行，每行一个姓名和一个整数分数，中间用一个空格分隔。姓名只含小写字母，长度在 `1` 到 `8` 之间；分数在 `-9999` 到 `9999` 之间。

**输出**：

第一行是表头：`name` 左对齐占 `8` 列，`score` 右对齐占 `5` 列，两段之间没有额外的分隔空格，姓名补出来的空格就是间隔。随后按输入顺序输出 `n` 行，列宽与表头相同：姓名左对齐占 `8` 列，分数右对齐占 `5` 列。

### 示例

输入：

```text
3
alice 120
bob -42
cara 7
```

输出（为了看清空格，下面用 `·` 表示一个空格）：

```text
name····score
alice·····120
bob·······-42
cara········7
```

实际输出中 `·` 是普通空格。

### 约定

- 表头也按 `%-8s` 与 `%5s` 的列宽写出，不要手写固定空格。
- 姓名正好 `8` 个字符时不再补空格，分数仍然按 `5` 列右对齐。
- 分数正好占满 `5` 列（例如 `-9999`）时前面不补空格。
- 除每行末尾的换行外，不要输出空行；行末不要有多余空格。
