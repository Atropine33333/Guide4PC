墙上挂着八盏小灯，编号 `0` 到 `7`，一开始全灭。命令一条条过来：`set k` 点亮第 `k` 盏，`clear k` 熄灭第 `k` 盏，`toggle k` 把它拨到相反的状态，`test k` 只问它亮不亮。八盏灯的状态合起来，正好是一个 8 位掩码。

**人话**：维护一个从 `0` 开始的掩码，第 `k` 位对应第 `k` 盏灯。`set k` 把这一位置 `1`，`clear k` 置 `0`，`toggle k` 取反，`test k` 不改动掩码，只报告这一位是 `0` 还是 `1`。

**输入**：若干行，每行是 `set k`、`clear k`、`toggle k`、`test k` 之一，其中 `0 ≤ k ≤ 7`，命令数为 `1` 到 `1000`，读到输入结束为止。

**输出**：每条命令输出一行。`set`、`clear`、`toggle` 输出执行后的掩码（十进制）；`test` 输出当前掩码、一个空格、该位的 `0` 或 `1`。

### 示例

输入：

```text
set 3
set 0
test 3
clear 3
toggle 7
test 2
```

输出：

```text
8
9
9 1
1
129
129 0
```

### 约定

- 初始掩码为 `0`，全部熄灭。
- 掩码只有低 8 位，最大为 `255`，用 `unsigned int` 保存即可。
- `test` 不改变掩码；重复 `set` 同一位置、重复 `clear` 已经为 `0` 的位都要照常输出。
- 输出行末不要有多余空格。
