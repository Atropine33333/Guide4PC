惠子谓庄子曰：“鹏之徙于南冥也，水击三千里，抟扶摇而上者九万里。今有一群小鸟，各衔一词，词皆小写之字，长短不齐。欲令其列阵而飞，先者在前，后者在后，按字典之序，一鸟一行，当何以处之？”

庄子曰：“子不见夫风乎？风一举而众窍齐鸣，大者大鸣，小者小鸣，各得其位，不待一一相校也。排序亦有长风，名曰 `qsort`：借其力者，一呼而众词自序；两词相较，则付之 `strcmp`，孰先孰后，一言而决。”

惠子曰：“然则同词者何以处之？”

庄子曰：“同词者并肩而列，各占一行，不必去也。”

**人话**：读入 `n` 个只含小写字母的单词，按字典序从小到大排好，每行输出一个；相同的单词都保留，各占一行。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 200`）。
- 接下来 `n` 行，每行一个单词，长度在 `1` 到 `20` 之间，只含小写字母 `a`–`z`，不含空格。

**输出**：`n` 行，每行一个单词，按字典序从小到大排列。

### 示例

输入：

```text
5
pear
apple
fig
apple
banana
```

输出：

```text
apple
apple
banana
fig
pear
```

### 约定

- 排序必须调用 `qsort`，两个单词的比较必须调用 `strcmp`，不要手写排序。
- 字典序就是 `strcmp` 给出的顺序；单词全为小写字母时，它与通常的字典序一致。
- 相同的单词不去重，出现几次就输出几行。
- 每行只输出单词本身，行末不要有多余空格。
