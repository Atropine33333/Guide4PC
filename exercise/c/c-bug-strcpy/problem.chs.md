《LX-24 标签机使用说明书》

一、用途
本机把货物名与货号拼成一枚标签，或把一段引文连同方括号写进标签。

二、标签格式
货物标签为 `名字#货号` 的连写；引文标签为 `[引文]`。

三、容量
每条标签写进一块容量为 `cap` 字节的缓冲区，最后一个字节留给结尾的 `'\0'`，可见字符最多 `cap - 1` 个。

四、放不下时
从尾部截断：前面放得下的字符照写，末尾补 `'\0'`。不做提示，不换行，不补空格。

五、返回值
返回实际写下的可见字符数，不含 `'\0'`。`cap` 为 1 时什么都不写，返回 0。

六、注意
随附的示例程序不看容量：它用 `strcpy`、`strcat` 一路抄下去，名字一长就写穿缓冲区，把相邻的内存踩坏。请按本说明书修正。

**人话**：实现两个函数。`label_make` 把 `name`、`#`、`code` 依次拼进 `out`；`label_quote` 把 `text` 用方括号括起来写进 `out`。两者最多写 `cap - 1` 个字符，末尾补 `'\0'`，返回写下的字符数。`starter.c` 里的版本不看 `cap`，请把它改对。

**接口**：

```c
#define LABEL_CAP 24

int label_make(char *out, int cap, const char *name, const char *code);
int label_quote(char *out, int cap, const char *text);
```

### 示例

`label_make(buf, 24, "A7", "B2")` 得到 `A7#B2`，返回 `5`。

`label_quote(buf, 24, "ok")` 得到 `[ok]`，返回 `4`。

### 约定

- `cap` 是 `out` 的容量，包含结尾的 `'\0'`，且至少为 `1`。
- 截断只发生在尾部，前面的字符原样保留。
- 返回值与实际写入的可见字符数一致。
- 这些函数会被直接调用，不要写 `main`。
- 拼接与截断都要守住 `cap`，不要动态分配。
