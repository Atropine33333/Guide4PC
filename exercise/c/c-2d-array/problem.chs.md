一张两维的席子要铺在内存里。C 没有现成的二维数组可以按行申请，只能先申请一排行指针，再给每一行单独划一块地方。席子铺好时每个格子都是 `0`；格子之间各管各的，改动一行不会碰到另一行。

**人话**：`make2d(rows, cols)` 先申请 `rows` 个 `int *`，再为每一行申请 `cols` 个 `int` 并全部置 `0`；`sum2d` 把整张席子的元素加起来；`free2d` 按申请的反向逐行归还。

**接口**：

```c
int **make2d(int rows, int cols);
long long sum2d(int **grid, int rows, int cols);
void free2d(int **grid, int rows);
```

- `rows` 或 `cols` 不是正数时，`make2d` 返回 `NULL`。
- 申请失败时返回 `NULL`，已经申请到的部分要全部归还。
- 每一行的内存单独申请，行与行之间不共享存储。
- `sum2d` 用 `long long` 返回总和，避免相加溢出 `int`；`grid` 为 `NULL` 时返回 `0`。
- `free2d` 先逐行归还，再归还行指针数组；`grid` 为 `NULL` 时什么也不做。

### 示例

```c
int **g = make2d(2, 3);   /* 2 行 3 列，六个格子都是 0 */
g[0][0] = 7;
g[1][2] = -2;             /* 只改各自的格子 */
long long s = sum2d(g, 2, 3);   /* 5 */
free2d(g, 2);
```

### 约定

- 只需要实现这三个函数，不要写 `main`。
- 每一行单独申请，不用一整块连续内存冒充多行。
- 一个席子只归还一次；归还之后可以再申请新的席子。
