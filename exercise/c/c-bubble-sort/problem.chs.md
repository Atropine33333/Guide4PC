一堆整数挤在一行里，大小参差。冒泡排序的规矩：从左到右两两相比，前面的大就换到后面去；走完一趟，最大的落在末尾，再走一趟，第二大的也落了位，如此重复，整列便成升序。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 1000`）。
- 第二行 `n` 个整数，相邻两个用一个空格分隔，每个都在 `-10^9` 到 `10^9` 之间。

**输出**：一行 `n` 个整数，从小到大排列，相邻两个用一个空格分隔。

### 示例

输入：

```text
5
5 1 4 2 8
```

输出：

```text
1 2 4 5 8
```

### 约定

- 相同的数都保留，出现几次就输出几次。
- 输出行末不要有多余空格。
- `n` 至少为 `1`，不会出现空输入。
