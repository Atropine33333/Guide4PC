# 倒着点名

（小剧场。台上两张凳子，甲乙各坐一张。）

甲：今儿说个学堂。先生点名向来从前往后，这一天忽然说：倒着点。

乙：那就从队尾点起呗。

甲：可队伍里每人只记得后头站着谁，前头是谁，一概不知道。

乙：哟，那得重新搭一遍。

甲：先生从队头走起。走到谁，就让谁把手搭回刚才那位的肩上。

乙：一位一位这么搭过去？

甲：搭到队尾，最后那位就成了排头；原先的排头身后空了，成了队尾。

乙：队伍还是那几个人，只是朝向换了。

甲：空队呢？

乙：没人可点，点完还是空。

甲：只站着一位呢？

乙：他转过身，还是他自己。

**人话**：把一个单链表的链接方向整个掉过来：原来的头变成尾，原来的尾变成头；节点不新建，也不删除。

**接口**：

```c
typedef struct Node {
    int value;
    struct Node *next;
} Node;

Node *list_reverse(Node *head);
```

`head` 是链表头，返回反转后的新头；空链表返回 `NULL`。

### 示例

`1 → 2 → 3` 反转后是 `3 → 2 → 1`。

### 约定

- 只实现 `list_reverse`，不要写 `main`。
- 只改 `next` 指针，不新建节点，不改 `value`。
- 链表没有环。
