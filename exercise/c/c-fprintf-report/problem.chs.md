把编号与分数按固定格式写进一个已经打开的文件。

**接口**：

```c
void report(FILE *f, int id, int score);
```

- 往 `f` 里写一行：`id=` 接十进制的 `id`，一个空格，`score=` 接十进制的 `score`，行末一个换行符。
- 数值不补前导零、不补空格、不加千分位；负数带减号，零就写 `0`。
- 每次调用只写这一行，不写别的文字；不要关闭 `f`，也不要回绕它。
- 这个函数会被直接调用，不需要写 `main`。

### 示例

`report(f, 7, 93)` 之后，`f` 里多出一行：

```text
id=7 score=93
```

再调用 `report(f, -1, -5)`，下一行是：

```text
id=-1 score=-5
```

### 约定

- 行末有且只有一个换行符。
- 连续调用写出的内容依次追加，每次一行。
- 两个数值都在 `int` 范围内，都可以为负。
- 用 `fprintf` 写入。
