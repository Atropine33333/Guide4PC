评书《排好队再找》

话说这一日，校场上点了一千号人，按个头从矮到高站成一排，谁也不许插队。堂上吩咐下来：「找一个数，它在队里站着，就报他的位置；找不着，回一句 `-1`。」

从头到尾挨个问过去，一千号人问一遍也成。偏生这队伍排得整整齐齐，老书童便教了一招：先问正当中那位，比要的数大，就往左半边寻；比要的数小，就往右半边寻。一巴掌拍下去，人数减半，三问两问便见分晓。这一招，名唤 `bsearch`。

**人话**：读入一个严格递增的整数数组和一个 `key`，用 `bsearch` 查找，输出 `key` 的下标（从 `0` 开始）；找不到输出 `-1`。

**输入**：

- 第一行一个整数 `n`（`1 <= n <= 1000`）。
- 第二行 `n` 个整数，严格递增，每个都在 `int` 范围内。
- 第三行一个整数 `key`。

**输出**：一行一个整数：找到时是 `key` 的下标，找不到时是 `-1`。

### 示例

输入：

```text
5
1 3 5 7 9
5
```

输出：

```text
2
```

`5` 排在第三位，下标是 `2`。

### 约定

- 数组严格递增，同一个值最多出现一次，下标唯一。
- 必须调用 `bsearch`，比较函数按 `int` 值比较。
- 下标从 `0` 开始。
- 输出行末不要有多余空格。
