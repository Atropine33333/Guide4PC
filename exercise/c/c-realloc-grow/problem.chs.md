（深空货运站。舷窗外一片黑，舱里只剩一排货格。）

甲：这排货格眼下是空的，一格也没占。第一批货到了，你打算怎么放？

乙：先腾出四格。四格都满了，就把整排扩成八格，原来那四件货原样留在前四格里，一件也不挪位。

甲：八格又满了呢？

乙：八格变十六格，十六变三十二，每回翻一倍。旧货的位置一个不动。

甲：要是站里腾不出地方，扩不了呢？

乙：那就报一声失败，货格、件数、格数全保持原样，等下一趟再试。旧货一件也不能丢。

甲：记下了。题面我念给你听。

**人话**：实现 `append`，把 `v` 追加到动态数组末尾。数组由 `*a`（首地址）、`*n`（已用个数）、`*cap`（容量）描述；满了就扩容，旧元素保持原值和顺序。

**接口**：

```c
int append(int **a, int *n, int *cap, int v);
```

- 初始可以是 `*a = NULL`、`*n = 0`、`*cap = 0`，也可以是已经分配好、装着若干元素的数组。
- `*n < *cap`：把 `v` 写到下标 `*n`，`*n` 加一，返回 `0`。
- `*n == *cap`：新容量取 `*cap == 0 ? 4 : *cap * 2`；扩容成功后写入，更新三个值，返回 `0`。
- 扩容失败：返回 `-1`，`*a`、`*n`、`*cap` 都不动，原有元素仍然可以访问。
- 成功一律返回 `0`。

### 示例

初始为 `NULL`、`0`、`0`，依次追加 `5`、`6`、`7`、`8`：此时容量是 `4`。再追加 `9`，容量翻到 `8`，下标 `0` 到 `3` 仍是 `5`、`6`、`7`、`8`，下标 `4` 是 `9`，`*n` 为 `5`。

### 约定

- 只实现这个函数，不要写 `main`。
- 扩容用 `realloc`，旧元素必须保留。
- 容量为 `0` 时首次分配 `4` 格，此后每次翻倍。
- `*n` 始终等于已存元素个数，`*cap` 始终不小于 `*n`。
- 调用者最后用 `free` 归还整块内存。
