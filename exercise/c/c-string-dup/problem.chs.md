实现 `dup_string`：用 `malloc` 复制一个以 `\0` 结尾的字符串，返回新字符串的首地址。

**接口**：

```c
char *dup_string(const char *s);
```

### 示例

| 调用 | 结果 |
| --- | --- |
| `dup_string("hello")` | 一块新内存里的 `"hello"` |
| `dup_string("")` | 一块新内存里的空串，首字节为 `'\0'` |

### 约定

- `s` 以 `'\0'` 结尾；`s` 的长度为 `0` 时也要返回一块可以 `free` 的内存，不能返回 `NULL`。
- 返回值由调用方 `free`，不能返回 `s` 本身。
- 复制完成后，修改 `s` 指向的内容不影响副本。
- 内存不够时返回 `NULL`。
- 不要写 `main`。
