规则怪谈：值域候检室

你在一间候检室门口捡到一张《比较守则》，纸边卷起，字迹却很清楚：

第一条　进门之前，把身上的符号留在架子上。
第二条　负数换上一件无符号的外衣，外衣上的数字是原数加 2 的 32 次方。
第三条　换好外衣再排队，队里只认无符号的大小。
第四条　出门时照抄两样东西：谁排在前面（是记 `1`，否记 `0`），以及你那件外衣上的数字。
第五条　`-1` 穿上外衣是 `4294967295`，它比 `1` 大，别吃惊。

**人话**：读入 `int a` 与 `unsigned b`，输出两样东西——`(a < b)` 的真假（真为 `1`，假为 `0`）和 `(unsigned)a` 的十进制值，用一个空格隔开。

**输入**：一行两个整数 `a`、`b`，满足 `-2147483648 ≤ a ≤ 2147483647`、`0 ≤ b ≤ 4000000000`。

**输出**：一行两个整数，依次为 `(a < b)` 的真假值与 `(unsigned)a`，用一个空格分隔。

### 示例

输入：

```text
-1 1
```

输出：

```text
0 4294967295
```

`-1` 转成无符号后是 `4294967295`，它不比 `1` 小，所以第一项为 `0`；第二项照抄外衣上的数字。

### 约定

- 本环境的 `unsigned` 是 32 位，取值范围 `0` 到 `4294967295`。
- 负数转无符号按模 `2^32` 回绕，结果有确定的值。
- 读 `b` 时用 `%u`，读 `a` 时用 `%d`。
- 输出行末不要有多余空格。
