【金字招牌】位置由您定，宽度由您报，一个铜板也不多收。

本店承接招牌排版：把宽度与价码一并交来，照 `printf("%*d", width, n)` 的规矩排进方框。宽度为正，数字靠右；宽度为负，数字靠左；宽度窄过数字本身，数字整段顶出框外，一个字符也不删。

**人话**：读入两个整数 `width` 与 `n`，输出一行：左方括号、按宽度排好版的 `n`、右方括号。

**输入**：一行两个整数 `width`、`n`，满足 `-30 ≤ width ≤ 30`、`-100000 ≤ n ≤ 100000`。

**输出**：一行，形如 `[` + 排版结果 + `]`；排版结果与 `printf("%*d", width, n)` 打印出来的那一段完全相同，`width` 为 `0` 时不填充。方括号原样保留，用来看清这一行的首尾。

### 示例

输入：

```text
6 -42
```

输出：

```text
[   -42]
```

`-42` 占三个字符，宽度 `6` 还差三个，空格补在左边。

### 约定

- 宽度为正补在左边（右对齐），为负补在右边（左对齐），填充字符是空格。
- 数字本身比宽度还长时原样输出，不截断。
- 行末不要有空格；方括号里的空格要如实输出。
