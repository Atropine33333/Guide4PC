> 数来不问姓与名，
> 只报多少便可行；
> 逐一取来合一处，
> 零个也算总数清。

《九章》少广之遗术：置数若干，不列其名，只报其数。术曰：先问其数之多少，后逐一取之，合而计之，即得总和；若其数曰零，则无所取，总和亦零。

今有术士袖中藏数，先报个数 `count`，再依次报出这些整数，问合数几何？

**人话**：实现 `int sum_ints(int count, ...)`，它接受 `count` 个 `int`，返回它们的和；`count` 为 `0` 时返回 `0`。

**接口**：

```c
int sum_ints(int count, ...);
```

- `count` 是后面实参的个数，范围 `0` 到 `8`。
- 返回值是这些整数的和，负数照常参与相加。
- 只需实现这一个函数，不要写 `main`。
- 这些函数会被直接调用，每个实参都按 `int` 传入。

### 示例

`sum_ints(3, 4, -1, 2)` 返回 `5`；`sum_ints(0)` 返回 `0`；`sum_ints(2, -7, -8)` 返回 `-15`。

### 约定

- 用 `<stdarg.h>` 里的 `va_list`、`va_start`、`va_arg`、`va_end` 取参数。
- 每个参数按 `int` 类型取出。
- `count` 不会为负。
- 不要借助数组或全局变量暂存参数。
