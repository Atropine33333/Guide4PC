星舰「远望号」的终端日志还在往下滚。补给舱重启之后，配置表被冲回成一堆原始行：有的行前面挂着注释，有的行只剩一片空白，有的键和值两边都沾着空格。值班员只想要一段干净的回声——每一条真正生效的配置，按它出现的顺序列出来。

**人话**：读入 `n` 行配置日志，跳过空行与注释行；对剩下的每一行，按第一个 `=` 拆成键和值，去掉两端的空白，再输出成 `key: value`。重复的键不用合并，照常逐条输出。

**输入**：

第一行一个整数 `n`（`1` ≤ `n` ≤ `100`）。

随后 `n` 行配置日志，每行不超过 `200` 个字符，至少含一个 `=`。

**输出**：

每个有效行输出一行 `key: value`，冒号之后恰好一个空格；有效行按它们出现的顺序输出。

### 示例

输入：

```text
4
# 补给舱重启
  port = 8080
# 频道已校准
mode=巡航
```

输出：

```text
port: 8080
mode: 巡航
```

### 约定

- 一行去掉首尾空白后为空，视为空行，跳过。
- 一行去掉首尾空白后，第一个字符是 `#`，整行视为注释，跳过。
- 空白包括空格和制表符；键与值分别去掉各自两端的空白。
- 一行若有多个 `=`，只在第一个 `=` 处拆分；值里保留其余的 `=`。
- 有效行的键与值去掉空白后都非空。
- 重复的键逐条输出，不覆盖、不去重。
