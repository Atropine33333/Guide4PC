给指针的槽位配一个规规矩矩的归还动作：槽位里放着地址时，把地址指向的内存还回去，再把槽位清成空；槽位本来就是空的，或者槽位本身不存在，就什么也不做。

**人话**：实现 `safe_free`。参数是指针变量的地址；`p` 为 `NULL` 或 `*p` 为 `NULL` 时直接返回，否则归还 `*p` 指向的内存并把 `*p` 置为 `NULL`。

**接口**：

```c
#include <stddef.h>

void safe_free(void **p);
```

- `p == NULL`：什么也不做。
- `*p == NULL`：什么也不做。
- 其他情况：归还 `*p` 指向的内存，再把 `*p` 置为 `NULL`。
- 归还过的槽位再传进来，看到的是 `NULL`，调用什么也不做。
- 两个槽位各管各的，归还一个不影响另一个。

### 示例

```c
void *p = malloc(32);
safe_free(&p);    /* p 变成 NULL */
safe_free(&p);    /* 什么也不做 */
safe_free(NULL);  /* 什么也不做 */
```

### 约定

- 只实现这个函数，不要写 `main`。
- 只归还 `malloc`、`calloc`、`realloc` 一类设施给出的内存。
- 只处理传进来的这个槽位，不去追查别处是否还存着同一个地址。
- 归还之后原来的地址不再使用。
