外层先有一个 `x`，它的值由输入给定。进入一层花括号之后，再声明一个同名的 `x`，让它比外层那个大 `1`。在这一块范围里，说话算数的是新的 `x`；退出花括号，外层那个 `x` 又回来了，值一点没变。

要把两个值都报出来：先内层，后外层。

**人话**：读入一个整数 `x`；在块里声明同名变量并令它等于外层值加 `1`，输出内层值，再输出块外的外层值，两个数用单个空格分隔。

**输入**：一行一个整数 `x`，满足 `-1000000 ≤ x ≤ 1000000`。

**输出**：一行两个整数，依次为内层值与块外的外层值。

### 示例

输入：

```text
5
```

输出：

```text
6 5
```

### 约定

- 内层块结束后，外层 `x` 保持读入时的值。
- 直接写 `int x = x + 1;` 时，右边那个 `x` 指的就是刚声明的变量，它还没有值；先把外层值存进另一个变量，再声明同名变量。
- 输出行末不要有多余空格。
