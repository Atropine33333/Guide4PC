话说罗马城里有个刻碑的匠人，手边只有七个字母：`I` 当一，`V` 当五，`X` 当十，`L` 当五十，`C` 当一百，`D` 当五百，`M` 当一千。

他刻数有个讲究：平常由大到小一字排开，值相加；碰上四、九这类数，就把小字刻在大字左边，值相减。一千九百八十七，他刻作 `MCMLXXXVII`。

看官要问：随便报一个数，这匠人该如何下刀？

**人话**：读入一个 `1` 到 `3999` 的整数 `n`，输出它的罗马数字写法，全部用大写字母。

**输入**：一行一个整数 `n`（`1 ≤ n ≤ 3999`）。

**输出**：一行，`n` 的罗马数字写法，由 `I`、`V`、`X`、`L`、`C`、`D`、`M` 组成。

### 示例

输入：

```text
1987
```

输出：

```text
MCMLXXXVII
```

`M` 是一千，`CM` 是九百，`LXXX` 是八十，`VII` 是七，合起来正好一千九百八十七。

### 约定

- 相减的写法只有 `IV`、`IX`、`XL`、`XC`、`CD`、`CM` 六种。
- 同一个字母最多连写三次，例如 `III`、`XXX`、`CCC`、`MMM`。
- `n` 不超过 `3999`，千位最多三个 `M`，不会出现表示五千的写法。
- 输出行末不要有多余空格。
