字符常量在 C 里就是整数，只是写出来像一个字符。`'A'` 的值是 `65`；`'\n'` 是换行符的编码 `10`；`'\x41'` 用十六进制写出同一个 `A`；`'\\'` 是反斜杠，值为 `92`；`'0'` 是字符零，值为 `48`。

**人话**：读入 `k`，输出一行五个整数，依次为 `'A' + k`、`'\n'`、`'\x41'`、`'\\'`、`'0'` 的值。

**输入**：一行一个整数 `k`，满足 `0 ≤ k ≤ 25`。

**输出**：一行五个整数，用单个空格分隔。

### 示例

输入：

```text
2
```

输出：

```text
67 10 65 92 48
```

### 约定

- 五个值都用 `%d` 输出。
- `'A' + k` 的结果是 `int`，`k` 取 `0` 到 `25` 时落在 `A` 到 `Z` 之间。
- `'\x41'` 与 `'A'` 的值相同，`'\\'` 才是反斜杠本身。
- 输出行末不要有多余空格。
