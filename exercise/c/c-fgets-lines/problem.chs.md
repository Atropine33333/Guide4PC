用 `fgets` 一行一行地取，去掉行尾的换行，再在行首补上编号。

**输入**：若干行，`1` 到 `20` 行，每行不超过 `200` 个字符，行内可含空格与标点；每一行以换行结束。

**输出**：每行写成 `[<行号>] <原行>`，行号从 `1` 开始，方括号与原行之间一个空格；原行为空时只写 `[<行号>]`，方括号后面不再补空格。

### 示例

输入：

```text
alpha
beta
```

输出：

```text
[1] alpha
[2] beta
```

### 约定

- 用 `fgets` 逐行读，读到文件末尾为止。
- 去掉行尾的换行符；行尾如果带回车符，也一并去掉。
- 原行开头的空格保留，不要删。
- 行末不要有多余空格。
