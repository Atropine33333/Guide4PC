（醒木一拍。）

话说河间府有个账房，姓周，人送外号周算盘。这一日掌柜的抱来一摞单子，说要盘一盘流水。

周算盘拨着算珠，一笔一笔往下加：“十贯、百贯、千贯……”加到末了，抬头报了个数。

掌柜的一听就急了：“怎么是负的？我这一摞单子，莫非还倒欠你不成？”

周算盘低头一瞧，原来是那只旧算盘只认得九位数，一过二十亿就翻了个个儿，账自然对不上。换了新算盘，十万贯的流水才有个准数。

**人话**：`starter.c` 里的程序读入 `n` 笔金额并求和。它用 `int` 累加，总额一过二十亿就翻成负数，输出全错。把累加与输出改用 `long long`。

**输入**：第一行一个整数 `n`（`1 ≤ n ≤ 1000`）；第二行 `n` 个整数，每个在 `0` 到 `10^9` 之间，用单个空格分隔。

**输出**：一行，这 `n` 笔金额的总和。

### 示例

输入：

```text
10
1000000000 1000000000 1000000000 1000000000 1000000000 1000000000 1000000000 1000000000 1000000000 1000000000
```

输出：

```text
10000000000
```

### 约定

- 总和最大接近 `10^12`，用 `long long` 保存。
- 只改坏掉的那一处，输入输出的格式保持不变。
- 输出一行，末尾换行。
