从 `1` 数到 `n`，遇到 `3` 的倍数就跳过，其余的加进同一个和里。和一旦超过 `100`，立刻收手，后面的数一概不再看。

**人话**：读入 `n`，按 `1`、`2`、……、`n` 的顺序累加所有不被 `3` 整除的数；累加过程中和一旦大于 `100` 就立即停止；输出最后的和。

**输入**：一行一个整数 `n`，满足 `0 ≤ n ≤ 1000`。

**输出**：一行一个整数，即累加得到的和。

### 示例

输入：

```text
6
```

输出：

```text
12
```

`1 + 2 + 4 + 5 = 12`，`3` 和 `6` 被跳过。

输入：

```text
17
```

输出：

```text
108
```

加到 `17` 时和第一次超过 `100`，于是停在 `108`。

### 约定

- 跳过用 `continue`，收手用 `break`；判断是否超过 `100` 要在加完之后立刻进行。
- `n = 0` 时一个数也不加，输出 `0`。
- 和超过 `100` 后就不再增加，`int` 足够。
- 输出行末不要有多余空格。
