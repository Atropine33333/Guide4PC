`starter.c` 里有两个和指针打交道的函数，都有毛病。

`swap_ints` 本该把两个整数换过来，现在两个数一动不动。`max_ptr` 本该返回指向数组中最大元素的指针，现在它总是指向最后一个元素：它拿地址比大小，忘了比地址里的值。

请把这两处改对。

**人话**：`swap_ints` 要交换指针所指的两个 `int`；`max_ptr` 要在数组里找到最大值，返回指向它的指针，最大值重复出现时返回第一次出现的位置。

**接口**：

```c
void swap_ints(int *a, int *b);
int *max_ptr(int *a, int n);
```

- `swap_ints`：交换 `*a` 与 `*b`。两个指针指向同一个变量时，调用前后该变量的值不变。
- `max_ptr`：返回指向 `a[0]` 到 `a[n-1]` 中最大元素的指针；最大值出现多次时，返回第一次出现的那个位置。
- `n` 在 `1` 到 `1000` 之间，`a` 指向至少 `n` 个有效的 `int`。

### 示例

```c
int x = 3;
int y = 7;
swap_ints(&x, &y);           /* x 为 7，y 为 3 */

int data[4] = {2, 9, 4, 9};
int *p = max_ptr(data, 4);   /* p 指向 data[1] */
```

### 约定

- 只改这两个函数的实现，不要写 `main`。
- 函数收到的指针都指向有效的 `int`，不需要处理空指针。
- 结果要从指针写回去：`swap_ints` 返回 `void`，交换后的两个值只能落在 `*a` 与 `*b` 里。
