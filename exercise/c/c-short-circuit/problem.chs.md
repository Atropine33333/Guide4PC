两扇门并排立在路口，左边一扇挂着 `&&`，右边一扇挂着 `||`。

`&&` 的门卫很省事：左边的人没过关，后面的人他连问都不问，直接拦住。`||` 的门卫同样省事：左边的人过关了，后面的人他也不问，直接放行。

现在门口来了两个数 `a` 和 `b`，要算两件事：`b` 不为零、并且 `a` 除以 `b` 的商大于 `2`；`b` 为零、或者 `a` 除以 `b` 的商大于 `2`。除数是零时，那道除法要是真算下去，程序就倒了；靠门卫的省事，它根本轮不到上场。

**人话**：读入 `a`、`b`，分别输出 `(b != 0 && a / b > 2)` 与 `(b == 0 || a / b > 2)` 的真假值，真写 `1`，假写 `0`，用单个空格分隔。`b` 可能是 `0`。

**输入**：一行两个整数 `a`、`b`，满足 `-10^9 ≤ a ≤ 10^9`、`-10^9 ≤ b ≤ 10^9`。

**输出**：一行两个 `0` 或 `1`，依次为第一个、第二个表达式的值。

### 示例

输入：

```text
10 2
```

输出：

```text
1 1
```

`10 / 2 = 5`，比 `2` 大，两个表达式都为真。

再如：

```text
10 0
```

输出：

```text
0 1
```

`&&` 在 `b != 0` 处就停了，`||` 在 `b == 0` 处就停了，两处都没有走到除法。

### 约定

- 直接写两个表达式，靠 `&&` 与 `||` 的求值顺序避开除零，不要先用 `if` 把 `b` 分情况绕开。
- 商向零截断，`a`、`b` 都在 `int` 范围内，`a / b` 不会溢出。
- 输出行末不要有多余空格。
