（小剧场。台上一张八仙桌，桌上八副碗筷。）

甲：今儿说个铺子。铺子里只有八副碗筷，客人一来摆一副，坐满为止。

乙：先来的先坐。

甲：坐满了又来人呢？

乙：门口拦着，回一句“满了”，一副也添不进去。

甲：走一位呢？

乙：收走一副，空出的位子给下一位。

甲：我瞧您这摆法有意思：摆到第八副，再摆一副，手又绕回第一副了。

乙：对喽。八副碗筷围成一圈，摆到第八副就回到头一副，这叫绕。

甲：那您怎么记账？总不能每回都从头数一遍。

乙：记两样就够：头一副在哪儿、眼下摆了几副。添一副，尾往后挪一格，挪到头就绕回零；收一副，头往后挪一格，挪到头也绕回零。满了不再添，空了不再收。

甲：空了呢？

乙：回一句“空了”，碗筷原样摆着，别动。

甲：得嘞，题面我给您念念。

**人话**：实现一个容量为 8 的环形缓冲区：`ring_push` 从队尾写入，`ring_pop` 从队头取出，满或空时返回 `-1`。

**接口**：

```c
#define RING_CAP 8

typedef struct { int data[RING_CAP]; int head; int size; } RingBuf;

void ring_init(RingBuf *r);
int ring_push(RingBuf *r, int value);
int ring_pop(RingBuf *r, int *out);
int ring_peek(const RingBuf *r, int *out);
int ring_size(const RingBuf *r);
```

- `ring_init`：把缓冲区置为空。
- `ring_push`：没满就写到队尾并返回 `0`；已经放满 8 个时返回 `-1`，原有元素保持不动。
- `ring_pop`：不为空就把队头写进 `*out`、移走它并返回 `0`；为空返回 `-1`，`*out` 不动。
- `ring_peek`：不为空就把队头写进 `*out` 但不移走，返回 `0`；为空返回 `-1`，`*out` 不动。
- `ring_size`：返回当前元素个数，取值在 `0` 到 `8` 之间。

### 示例

依次写入 `1`、`2`、`3`，队头是 `1`；取一次得 `1`，再取一次得 `2`，再取一次得 `3`；此时缓冲区为空，再取返回 `-1`。连续写满 8 个之后再写，返回 `-1`。

### 约定

- 容量由 `RING_CAP` 决定，固定为 8，不要动态分配。
- 写满 8 个之后再写必须返回 `-1`，已经写进去的 8 个元素顺序保持不变。
- 绕回：队尾走到 `data` 末尾之后回到下标 `0` 继续写，队头也一样绕。
- 只需要实现这些函数，不要写 `main`。
