读入 `n` 个字节值，把每个值输出为两位大写十六进制数。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 256`）。
- 第二行 `n` 个整数 `v`（`0 ≤ v ≤ 255`）。

**输出**：`n` 行，每行恰好两个大写十六进制字符。小于 `16` 的值要补一个前导 `0`。

### 示例

输入：

```text
5
0 15 16 127 255
```

输出：

```text
00
0F
10
7F
FF
```

### 约束

- 输出的字母必须大写。
- 每行必须是两位，不能把 `0` 输出成空行或单个字符。
- 值始终在 `0`–`255` 内，可以用 `unsigned char` 保存。
