今有方阵二：甲阵 `n` 行 `p` 列，乙阵 `p` 行 `q` 列，诸数皆以整数书之。问二阵相乘，得阵几何？

术曰：取甲阵第 `i` 行，取乙阵第 `j` 列，逐位相乘，同列相加，置于新阵第 `i` 行第 `j` 列。列尽则换次列，行尽则换次行。新阵凡 `n` 行 `q` 列，其数曰 `C[i][j] = sum(A[i][k] * B[k][j])`，其中 `0 ≤ k < p`。所得之数，同一行者以空一格隔之，行末不加空格。

今有算者，取乙阵时混其行列：乙阵本 `p` 行 `q` 列，他偏把列数当行数来取。故所得之数不与术合。请正其二下标。

**人话**：读入矩阵 `A`（`n × p`）与 `B`（`p × q`），输出乘积 `C = A * B`（`n × q`），每行 `q` 个整数，用单个空格分隔。`C[i][j]` 是 `A` 的第 `i` 行与 `B` 的第 `j` 列逐项相乘之和。starter 访问 `B` 时把 `[k][j]` 写错，修好它，不要改变输出格式。

**输入**：

- 第一行三个整数 `n`、`p`、`q`（`1 ≤ n, p, q ≤ 50`）。
- 接下来 `n` 行，每行 `p` 个整数，表示矩阵 `A`（`n × p`）。
- 再接下来 `p` 行，每行 `q` 个整数，表示矩阵 `B`（`p × q`）。

**输出**：

- `n` 行，每行 `q` 个整数，表示 `C = A * B`；同一行相邻整数用一个空格分隔。
- `C[i][j] = sum(A[i][k] * B[k][j])`，其中 `0 ≤ k < p`。

### 示例

输入：

```text
2 2 2
1 2
3 4
5 6
7 8
```

输出：

```text
19 22
43 50
```

### 约束

- 元素在 `[-100, 100]` 内；乘积之和在 `int` 范围内。
- starter 里有一个下标错误，请修好它，不要改变输入输出格式。
- 不要输出多余的空格或行。

### 提示

检查内层循环访问 `B` 时使用的两个下标：`B` 的行数是 `p`、列数是 `q`。
