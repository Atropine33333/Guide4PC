读入一个用十六进制写成的 32 位值，它可能是某个 `float` 的位模式。把它的符号位、指数域和尾数域拆出来，并判断它属于哪一类。

### 输入

一行，一个由 1 到 8 个十六进制数字组成的字符串（大小写均可），没有 `0x` 前缀。例如 `3F800000` 表示值 `1.0f`。

### 输出

一行四个字段，用单个空格分隔：

```
<类别> <符号> <指数域> <尾数域>
```

- 类别按下面的顺序判定：指数域为 `255` 时，尾数域为 `0` 输出 `inf`，否则输出 `nan`；指数域为 `0` 时，尾数域为 `0` 输出 `zero`，否则输出 `subnormal`；其余输出 `normal`。
- 符号输出 `0`（正）或 `1`（负），负零也是 `1`。
- 指数域是第 23–30 位的原始无偏值（`0`–`255`），不做减 `127`。
- 尾数域是第 0–22 位的原始值（`0`–`8388607`），不要补隐含的最高位。

### 示例

| 输入 | 输出 |
| --- | --- |
| `3F800000` | `normal 0 127 0` |
| `BF800000` | `normal 1 127 0` |
| `00000001` | `subnormal 0 0 1` |
| `7F800000` | `inf 0 255 0` |
| `7FC00000` | `nan 0 255 4194304` |

### 约束

- 输入的十六进制串至少 1 位、至多 8 位，可能有前导零。
- 输出只用小写字母和十进制数字，行末一个换行。
