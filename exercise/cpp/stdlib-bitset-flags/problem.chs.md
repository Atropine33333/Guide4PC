维护一个 64 位的标志寄存器，初始时 64 个位全部为 0。读入若干条命令，按顺序执行。

命令格式如下：

- `set i`：把第 `i` 位置 1。
- `reset i`：把第 `i` 位清 0。
- `flip i`：翻转第 `i` 位。
- `test i`：输出第 `i` 位的值（`0` 或 `1`）。
- `count`：输出当前为 1 的位数。
- `first`：输出最低的、值为 1 的下标；如果没有，输出 `-1`。
- `last`：输出最高的、值为 1 的下标；如果没有，输出 `-1`。
- `any`：如果至少有一位为 1，输出 `1`，否则输出 `0`。
- `fill`：把所有位都置 1。

下标 `i` 满足 `0 <= i < 64`，第 0 位是最低位。

### 输入

第一行一个整数 `n`（`1 <= n <= 1000`），表示命令数。

接下来 `n` 行，每行一条上述命令。

### 输出

对每条会输出结果的命令，按执行顺序各输出一行。`test`、`count`、`first`、`last`、`any` 有输出；`set`、`reset`、`flip`、`fill` 没有输出。

### 示例

输入：

```text
8
set 0
set 63
test 0
test 63
test 1
count
first
last
```

输出：

```text
1
1
0
2
0
63
```

### 约束

- 命令和下标之间恰好一个空格。
- 可以使用 `std::bitset<64>`，也可以自己维护一个 64 位无符号整数。
- 只输出结果，不要回显命令。
