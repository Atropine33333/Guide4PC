读入两个整数，按顺序输出五行布尔值，用来观察逻辑运算符的短路行为。

**输入**：一行两个整数 `a b`（`|a|, |b| ≤ 10^9`）。

**输出**：五行，每行是 `true` 或 `false`，依次表示：

1. `a < b`
2. `a == b`
3. `a % 2 == 0 && b % 2 == 0`（两个数都是偶数）
4. `a != 0 && b / a >= 2`
5. `a == 0 || b % a == 0`

### 示例

输入：

```text
2 3
```

输出：

```text
true
false
false
false
false
```

### 约束

- 第 4、5 行必须利用 `&&` 与 `||` 的短路：`a == 0` 时不能执行 `b / a` 或 `b % a`。
- 第 4 行的除法是 C++ 的整数除法（向零截断）。
- 用 `std::boolalpha` 或等价方式得到小写的 `true`/`false`。
