**成绩分档条例**

第一条 凡修业者之试卷所得，以整数记之，满分为一百。

第二条 边界之数，归入较高一档：九十、八十、七十、六十，皆从其高，不得下推。

第三条 逾界之数不在本条例所辖，不必理会。

第四条 输入者一个分数，输出者一个大写字母，别无他物。

第五条 一数只归一档，档与档之间不容并立，亦不设中间地带。

第六条 本例自公布之日起施行，解释权归教务处。

**人话**：读入一个整数 `score`，按分档表查出对应的大写字母等级，输出这一个字符。

**输入**：一行一个整数 `score`（`0 ≤ score ≤ 100`）。

**输出**：一个大写字母。

| 分数 | 等级 |
| --- | --- |
| 90–100 | `A` |
| 80–89 | `B` |
| 70–79 | `C` |
| 60–69 | `D` |
| 0–59 | `F` |

### 示例

输入：

```text
89
```

输出：

```text
B
```

### 约束

- 不需要处理 `0`–`100` 之外的分数。
- `90`、`80`、`70`、`60` 这些边界值属于较高的一档。

### 附则

本例所列各档，皆经教务处复核：`89` 归 `B`，`90` 归 `A`，其余依此类推。
