读入一个整数分数，按分档表输出对应的大写字母等级。

**输入**：

- 一行一个整数 `score`（`0 ≤ score ≤ 100`）。

**输出**：一个大写字母。

| 分数 | 等级 |
| --- | --- |
| 90–100 | `A` |
| 80–89 | `B` |
| 70–79 | `C` |
| 60–69 | `D` |
| 0–59 | `F` |

### 示例

输入：

```text
89
```

输出：

```text
B
```

### 约束

- 不需要处理 `0`–`100` 之外的分数。
- `90`、`80`、`70`、`60` 这些边界值属于较高的一档。
