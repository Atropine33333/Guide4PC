计算 `a` 的 `b` 次方对 `m` 取模的结果。

**输入**：一行三个整数 `a b m`（`0 ≤ a ≤ 10^9`，`0 ≤ b ≤ 10^18`，`1 ≤ m ≤ 10^9`）。

**输出**：一行一个整数，即 `a^b mod m`。

### 示例

输入：

```text
2 10 1000
```

输出：

```text
24
```

### 约束

- 指数可以达到 `10^18`，逐个相乘会超时，要用二进制快速幂。
- `b = 0` 时结果是 `1 mod m`；`a = 0` 且 `b > 0` 时结果是 0。
- 中间乘积最大约为 `(10^9)^2 = 10^18`，用 `long long` 计算即可；每次乘法后立刻取模。
