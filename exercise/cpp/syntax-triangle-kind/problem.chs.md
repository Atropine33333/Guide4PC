读入三条边的长度（整数），判断它们能组成哪一种三角形。

**输入**：一行三个整数 `a b c`（`1 ≤ a, b, c ≤ 10^9`）。

**输出**：下面四种之一：

- `NOT_TRIANGLE`：无法组成三角形（包括两边之和恰好等于第三边的退化情况）。
- `EQUILATERAL`：三边相等。
- `ISOSCELES`：恰好有两边相等。
- `SCALENE`：三边互不相等。

### 示例

输入：

```text
3 4 5
```

输出：

```text
SCALENE
```

### 约束

- 任意两边之和都必须严格大于第三边，只检查一对是不够的。
- 边长之和可能超过 `int` 范围，用 64 位整数判断。
- 先判断能否组成三角形，再判断边的相等关系。
