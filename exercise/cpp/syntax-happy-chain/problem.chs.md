把一个正整数 `n` 反复替换成它十进制各位数字的平方和。

例如从 `19` 出发：`19 → 82 → 68 → 100 → 1`，共 4 次替换后到达 1。
从 `2` 出发会进入 `4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4` 的循环，永远到不了 1。

求到达 1 所需的替换次数；如果永远到不了 1，输出 `-1`。

**输入**：

- 一行一个整数 `n`（`1 ≤ n ≤ 10^12`）。

**输出**：

- 一个整数：到达 1 的替换次数，或 `-1`。

### 示例

输入：

```text
19
```

输出：

```text
4
```

### 约束

- `1` 的替换次数为 `0`。
- 只需要判断链是否进入循环，不需要输出路径。
- 平方和最大不超过 `12 × 81 = 972`，用 `long long` 保存输入即可。
