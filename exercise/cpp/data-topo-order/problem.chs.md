拓扑序列条例

第一章　总则

第一条　给定一张有向图。凡有边 `u v`，即前驱 `u` 指向后继 `v`；顶点自 1 编号，共 `n` 个，边共 `m` 条。

第二条　本图之拓扑序，指 `n` 个顶点的一个排列，其中任一条边均自较前者指向较后者。一图可有多条合法排列，本条例只认字典序最小者。

第二章　输入与输出

第三条　输入首行为 `n m`（`1 ≤ n ≤ 10^5`，`0 ≤ m ≤ 2·10^5`）；其后 `m` 行，每行 `u v`（`1 ≤ u, v ≤ n`），为一条自 `u` 指向 `v` 的边。

第四条　若存在拓扑序，输出 `n` 行，每行一个顶点编号；若不存在，只输出一行 `cycle`。

第三章　细则

第五条　取序列时，每次只从入度为零的顶点中挑编号最小者，以最小堆维护，不得随意挑选。

第六条　重边使入度累加，须逐条计数，不得合并为一条。

第七条　自环与有向环，一律按第四条后半办理。

第八条　图可不连通；孤立顶点入度为零，照章输出，不得遗漏。

本条例自公布之日起施行。

**人话**：给一个有向图，输出字典序最小的拓扑序；有环就输出 `cycle`。第一步读 `n m` 与 `m` 条边，顶点编号 1 到 n；序列中每条边都必须从较前的顶点指向较后的顶点。合法序列可能有很多，要求字典序最小——每次从当前入度为 0 的顶点里取编号最小的那个，用最小堆维护。重边会让入度增加多次，必须按边逐条计数；自环也会成环；图可能不连通，孤立顶点也要输出。读 stdin，写 stdout。

**输入**：

- 第一行两个整数 `n m`（`1 ≤ n ≤ 10^5`，`0 ≤ m ≤ 2·10^5`）。
- 接下来 `m` 行，每行两个整数 `u v`（`1 ≤ u, v ≤ n`），表示一条从 `u` 指向 `v` 的有向边。

**输出**：

- 若存在拓扑序：输出 `n` 行，每行一个顶点编号。
- 若不存在：只输出一行 `cycle`。

### 示例

输入：

```text
4 4
1 2
1 3
2 4
3 4
```

输出：

```text
1
2
3
4
```

### 约束

- 拓扑序中每条边都从较前的顶点指向较后的顶点。
- 同样合法的序列可能有很多个，本题要求字典序最小：每次从当前入度为 0 的顶点中选编号最小的那个，用最小堆维护。
- 重边会让入度增加多次，必须按边逐条计数；自环也会形成环。
- 图可能不连通，孤立顶点也要输出。
