给定一个有向图，输出字典序最小的拓扑序；若图中有环，输出 `cycle`。

**输入**：

- 第一行两个整数 `n m`（`1 ≤ n ≤ 10^5`，`0 ≤ m ≤ 2·10^5`）。
- 接下来 `m` 行，每行两个整数 `u v`（`1 ≤ u, v ≤ n`），表示一条从 `u` 指向 `v` 的有向边。

**输出**：

- 若存在拓扑序：输出 `n` 行，每行一个顶点编号。
- 若不存在：只输出一行 `cycle`。

### 示例

输入：

```text
4 4
1 2
1 3
2 4
3 4
```

输出：

```text
1
2
3
4
```

### 约束

- 拓扑序中每条边都从较前的顶点指向较后的顶点。
- 同样合法的序列可能有很多个，本题要求字典序最小：每次从当前入度为 0 的顶点中选编号最小的那个，用最小堆维护。
- 重边会让入度增加多次，必须按边逐条计数；自环也会形成环。
- 图可能不连通，孤立顶点也要输出。
