统计一段文本的行数、单词数，以及除换行符以外的字符数。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 50`）。
- 接下来 `n` 行文本。每行只包含小写字母、数字和空格，可能有空行，也可能在行首或行尾有空格。

**输出**：一行三个整数，依次为行数、单词数、字符数（不含换行符），用单个空格分隔。

单词是最长的一段连续非空格字符。空行算一行，但不贡献单词。行首、行尾和单词之间的空格都计入字符数。

### 示例

输入：

```text
2
hello world
foo
```

输出：

```text
2 3 14
```

### 提示

`std::cin >> word` 会跳过所有空白，无法区分空行和空格数。应当用 `std::getline` 逐行读取，再逐字符统计。
