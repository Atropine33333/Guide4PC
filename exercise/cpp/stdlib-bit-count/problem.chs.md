欢迎来到无符号走廊第 32 号房间。

这里的每一条规则都是真的。你只需要决定，要不要把你那套关于符号的常识留在门外。

规则一：本房间的每个数都是 32 位无符号整数，取值范围 0 到 4294967295。这里没有负数，也没有符号位。

规则二：`4294967295` 的二进制是 32 个 1。若哪位访客把它读进有符号 `int`，规则一对他作废，后果由他自负。

规则三：要数的是每个数二进制表示里 1 的个数。`0` 里有 0 个 1。这件事叫 popcount。

规则四：读入 `n` 个数，按输入次序每行输出一个 popcount 值。不要输出别的东西。

规则五：走廊的门从外面开。你可以使用 `<bit>` 里的 `std::popcount`，也可以自己逐位统计。先读入 `unsigned long long`，再转成 `std::uint32_t`，是最稳妥的走法。

如果你开始觉得这些规则很正常，请回到开头，重读第一句。

**人话**：读入 `n` 个 32 位无符号整数，分别输出每个数二进制中 `1` 的个数（popcount）。输入值可能超过 32 位有符号 `int` 的正数范围，建议先用 `unsigned long long` 读入，再转成 `std::uint32_t`；可以使用 `std::popcount`，也可以自己逐位统计。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 20`）。
- 第二行 `n` 个整数 `v`（`0 ≤ v ≤ 4294967295`）。

**输出**：`n` 行，每行一个整数，表示对应值的二进制中 `1` 的位数（popcount）。

### 示例

输入：

```text
2
0 4294967295
```

输出：

```text
0
32
```
