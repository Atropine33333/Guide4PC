这一题不读 stdin，也不写 stdout。实现统计逆序对的函数，测试在隐藏的 harness 里。

```cpp
long long count_inversions(const std::vector<int>& values);
```

逆序对是满足 `i < j` 且 `values[i] > values[j]` 的下标对 `(i, j)`。

规则：

- 空序列和只有一个元素的序列都返回 0。
- 相等元素不构成逆序对，只统计严格大于。
- 值可能是负数，也可能重复；长度最多 100000。
- 结果可能超过 `int` 范围，返回类型是 `long long`。
- 不要写 `main`。

### 提示

暴力两重循环在 100000 个元素时会超时。可以用归并排序顺带统计，或者用树状数组配合离散化。注意在合并时，右边取一个元素会让左边所有剩余元素都与它构成逆序对。
