**牌阵**

问卜者洗牌三次，横着摊开一列，牌面就是这些数字。解牌人看过，说道：

“牌的位置在此，牌面在彼。前一张的牌面大于后一张，便算一对错位；错位越多，事情的结越乱。牌面相等的两张，只当是同一张牌照了两次镜子，算不得错位。”

问：这一列里，错位的对子共有几对？牌可以有十万张，牌面可正可负，也可重复；数目大了，账要用 `long long` 记。切勿自写 `main`。

**人话**：实现函数 `count_inversions`，统计满足 `i < j` 且 `values[i] > values[j]` 的下标对 `(i, j)` 的个数；空序列与单元素序列返回 0，元素相等不计，长度最多 100000。

```cpp
long long count_inversions(const std::vector<int>& values);
```

### 规则

- 空序列和只有一个元素的序列都返回 0。
- 相等元素不构成逆序对，只统计严格大于。
- 值可能是负数，也可能重复；长度最多 100000。
- 结果可能超过 `int` 范围，返回类型是 `long long`。
- 不要写 `main`。

### 提示

暴力两重循环在 100000 个元素时会超时。可以用归并排序顺带统计，或者用树状数组配合离散化。注意在合并时，右边取一个元素会让左边所有剩余元素都与它构成逆序对。
