《CSV 字段书写与解析法典》

第一条（适用范围）本法典规定一行 CSV 中单个字段的书写与整行的解析。所需接口如下。

```cpp
#include <string>
#include <vector>

std::string csv_quote(const std::string& field);
std::vector<std::string> csv_split(const std::string& line);
```

第二条（免于加引号）字段中不含逗号 `,`、双引号 `"` 和换行 `\n` 三者之一者，原样返回。

第三条（加引号）字段含上述任一字符者，两端各加一个双引号；字段内原有的每个双引号，改写作两个双引号。

第四条（分隔）解析之时，逗号分隔字段；两个逗号之间的内容（可以为空）即为一个字段。

第五条（引号模式）以双引号开头的字段进入引号模式，其中逗号不作分隔；连续两个双引号表示一个真正的双引号。

第六条（空字段）空行解析出一个空字段；行尾的逗号解析出一个空字段。

第七条（附则）输入保证是第二条、第三条所能产生的合法格式，未闭合的引号不必处理。

**人话**：实现 `csv_quote` 与 `csv_split`：前者按需给字段加引号并把内部双引号写成两个，后者按逗号与引号模式切出一行中的所有字段。

### 示例

| 调用 | 结果 |
| --- | --- |
| `csv_quote("abc")` | `abc` |
| `csv_quote("a,b")` | `"a,b"` |
| `csv_quote("say \"hi\"")` | `"say ""hi"""` |
| `csv_split("a,b,c")` | 三个字段 `a`、`b`、`c` |
| `csv_split("\"a,b\",c")` | 两个字段 `a,b`、`c` |
| `csv_split("a,")` | 两个字段 `a`、空串 |

### 提示

写出时先判断“是否需要引号”，再逐字符拼接；解析时用一个 `in_quotes` 状态，遇到引号时先看下一个字符是否为引号。
