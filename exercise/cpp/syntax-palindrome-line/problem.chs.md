甲：您给瞧瞧这串儿——“A man, a plan, a canal: Panama”。

乙：瞧什么呀？

甲：瞧它回不回文。

乙：嗐，回文我懂，正着念倒着念一个样。可您这串儿里头有逗号、有冒号，还有空格，这怎么算？

甲：那些个一概不理会。ASCII 字母、数字留下，其余全当没看见；大小写也不分，`A` 与 `a` 同宗。

乙：那要是整串儿一个字母一个数字都没有呢？

甲：也算回文。空串也算。

乙：得，您这规矩倒是宽。可写起来有个坑：判断字符类别得先把 `char` 转成 `unsigned char`，不然碰上高位字符，`<cctype>` 那几个函数爱闹脾气。

**人话**：实现函数 `is_palindrome(text)`，跳过非字母数字字符、忽略大小写后判断整串是否回文。

```cpp
bool is_palindrome(const std::string& text);
```

**规则**：

- 只考虑 ASCII 字母和数字，其他字符（空格、标点、制表符）全部跳过；
- 比较字母时忽略大小写；
- 空串，或者没有任何字母和数字的串，视为回文；
- 不要写 `main`。

### 提示

用两个下标从两端向中间扫描，遇到非字母数字字符就跳过。判断字符类别时记得把 `char` 转成 `unsigned char` 再传给 `<cctype>` 的函数。
