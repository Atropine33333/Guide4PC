读入 `n` 个小数，把每个数舍入到最接近的整数。恰好位于两个整数中间时，采用“向偶数舍入”（银行家舍入）：选择两个相邻整数中为偶数的那个。

例如：

- `2.5` 舍入为 `2`，`3.5` 舍入为 `4`。
- `-2.5` 舍入为 `-2`，`-3.5` 舍入为 `-4`。
- `2.4999` 舍入为 `2`，`2.5001` 舍入为 `3`。

### 输入

第一行一个整数 `n`（`1 <= n <= 1000`）。

第二行 `n` 个小数，每个数在 `-1000000` 到 `1000000` 之间，最多带 3 位小数。

### 输出

`n` 行，每行一个整数，依次是每个输入舍入后的结果。不要把 `-0` 输出成带负号的零：结果为零时输出 `0`。

### 示例

输入：

```text
4
0.5 1.5 2.5 -2.5
```

输出：

```text
0
2
2
-2
```

### 约束

- 不要使用 `std::round`，它在恰好一半时远离零舍入。
- 可以用 `std::nearbyint`，默认舍入模式就是向最近偶数舍入；也可以自己判断小数部分。
- 只使用标准库，不要输出多余文字。
