给定一个整数序列，找出出现次数严格超过一半的元素；如果不存在这样的元素，输出 `none`。

“严格超过一半”指出现次数 `> n / 2`（向下取整）。例如长度为 `4` 的序列，元素必须出现至少 `3` 次；长度为 `5` 时也必须出现至少 `3` 次。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 200000`）。
- 第二行 `n` 个整数，相邻整数用一个空格分隔，每个整数在 `[-10^9, 10^9]` 内。

**输出**：

- 一行：多数元素的值，或者 `none`。

### 示例

输入：

```text
5
2 2 1 2 3
```

输出：

```text
2
```

### 约束

- 序列长度最大为 `200000`，建议使用线性时间、常数空间的算法。
- 不存在多数元素时输出小写 `none`。
- 即使某个元素出现次数正好等于 `n / 2`，它也不是多数元素。
