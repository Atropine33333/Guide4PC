读入一个 32 位无符号整数 `x`，按字节拆开并输出字节翻转后的结果。

### 输入

一行一个十进制整数 `x`，满足 `0 <= x <= 4294967295`。

### 输出

两行：

1. `x` 的四个字节，从最低有效字节到最高有效字节，用十进制表示，字节之间用一个空格分隔。
2. 把四个字节的顺序完全颠倒后得到的 32 位整数，写成 `0x` 加 8 位小写十六进制数字；不足 8 位时在高位补 `0`。

### 示例

输入：

```text
16909060
```

输出：

```text
4 3 2 1
0x04030201
```

`16909060` 的十六进制是 `0x01020304`，最低有效字节是 `0x04`，最高有效字节是 `0x01`；翻转后得到 `0x04030201`。

### 约束

- 输入一定在 32 位无符号整数范围内。
- 只用标准库，不要使用平台相关的字节序函数或联合体类型双关。
- 输出必须为小写十六进制，并且恰好 8 位数字。
