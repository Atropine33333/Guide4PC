读入一个奇数 `n`，用星号画一个高度为 `n` 的菱形。

菱形的第 `i` 行（`0 ≤ i < n`）有 `2 * min(i, n - 1 - i) + 1` 个星号，并且在这 `n` 个字符宽的区域内居中：左侧补空格，右侧不补。

**输入**：一行一个奇数 `n`（`1 ≤ n ≤ 51`）。

**输出**：`n` 行，每行由空格和 `*` 组成。最宽的一行从第 1 列开始，没有前导空格；其它行前面补 `(n - 星号数) / 2` 个空格。行尾不要输出多余的空格。

### 示例

输入：

```text
5
```

输出：

```text
  *
 ***
*****
 ***
  *
```

### 约束

- `n` 一定是奇数，不需要处理偶数。
- 最中间一行恰好有 `n` 个星号。
- 上半部分和下半部分对称；可以写成两层循环，也可以先算每行的空格数与星号数再输出。
- 行末空格会被忽略，但行首空格必须正确。
