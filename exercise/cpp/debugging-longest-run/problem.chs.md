读入一行字符，输出最长的一段连续相同字符的长度。

**输入**：

- 一行文本，可能包含空格；长度在 `0` 到 `1000` 之间。
- 行尾的换行符不属于文本内容。

**输出**：

- 一个整数：最长连续相同字符的长度。
- 空行输出 `0`。

### 示例

输入：

```text
aabbbbcc
```

输出：

```text
4
```

### 约束

- 字符区分大小写；空格也是普通字符。
- starter 给出了一个错误实现，请修好它，不要改变输入输出格式。
- 只需要修改计算逻辑，不需要重写输入输出。

### 提示

starter 只在“字符发生变化”时更新答案，因此会漏掉位于行尾的连续段。想一想什么时候还应该更新一次答案。
