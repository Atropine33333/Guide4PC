主持人：朋友们，看这个 `sum_all`！传一个 `char`，它加；传两个 `int`，它加；传五个 `long long`，它照样加！

画外音：BUT WAIT, THERE'S MORE!

主持人：没错，还有更多！参数包没有上限，一个不嫌少，十个不嫌多！

主持人：空的呢？空的它返回 0！所有实参一律按 64 位有符号整数累加，`char` 按数值算，`'a'` 就是 97！

主持人：结果是负的？没关系！只要别用 `int` 存总和，它就稳稳当当！

画外音：这还没完！它连 `main` 都不要你写！

主持人：对，不要 `main`，不要钱，只要一个折叠表达式！

（切广告。）

**人话**：实现可变参数函数模板 `sum_all`，把全部实参按 64 位有符号整数求和，无参数返回 0；`char` 按数值参与相加。

```cpp
template <typename... Args>
long long sum_all(Args... args);
```

规则：

- 把所有实参按 64 位有符号整数相加并返回。
- 不传参数时返回 0。
- 实参可以是 `char`、`short`、`int`、`long`、`long long` 等整型，也可能混合出现。
- `char` 按它的数值参与相加（例如 `'a'` 是 97），不要当作文本。
- 结果可能为负；不要用 `int` 作为累加类型。
- 不要写 `main`。

### 提示

C++17 的折叠表达式最方便：`return (0LL + ... + static_cast<long long>(args));`。空参数包时这个折叠的结果是 0。
