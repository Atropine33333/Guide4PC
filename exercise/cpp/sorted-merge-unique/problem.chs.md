**第一章**

耶和华晓谕摩西说：

“你数点两支队伍。第一支行 `n` 人，第二支行 `m` 人，各按自己的次序站好，数目从少到多，不可乱。你要将两队并成一队，仍按从少到多数点；数目相同的，只留一人，不可重复记名。若两队都空，就在册上写 `empty`。”

摩西便照耶和华所吩咐的行了。

**人话**：读入两个非递减整数数组，合并成一个非递减数组，并去掉重复的数值；输出一行，相邻两个数用一个空格分隔。两个数组都为空时，只输出 `empty`。可以拼接后排序再用 `std::unique` 去重，也可以像归并排序那样用双指针前进；空数组时不要输出多余的空行。

**输入**：

- 第一行一个整数 `n`（`0 ≤ n ≤ 500`）。
- 第二行 `n` 个整数，非递减排列。若 `n = 0`，这一行是空行。
- 第三行一个整数 `m`（`0 ≤ m ≤ 500`）。
- 第四行 `m` 个整数，非递减排列。若 `m = 0`，这一行是空行。

**输出**：一行，按非递减顺序输出合并去重后的所有整数，相邻两个数用一个空格分隔。如果结果为空（两个数组都为空），输出 `empty`。

### 示例

输入：

```text
3
1 3 5
3
2 3 6
```

输出：

```text
1 2 3 5 6
```

### 提示

可以先把两个数组拼在一起排序，再用 `std::unique` 去重；也可以像归并排序那样双指针前进。注意空数组时不要输出多余的空行。
