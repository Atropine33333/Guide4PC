读入一个正整数 `n`，按 Collatz 规则反复变换：偶数除以 2，奇数变成 `3n + 1`，直到得到 1。输出到达 1 所需的变换次数，以及过程中出现过的最大值（包括初始的 `n` 和最后的 1）。

**输入**：一行一个整数 `n`（`1 ≤ n ≤ 10^6`）。

**输出**：一行两个整数，用单个空格分隔：变换次数与过程中的最大值。

### 示例

输入：

```text
6
```

输出：

```text
8 16
```

序列是 `6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1`，共 8 次变换，最大值为 16。

### 约束

- `n = 1` 时不需要变换，次数为 0，最大值为 1。
- 中间值可能超过 32 位整数范围，请用 64 位有符号整数保存。
- 输出只包含两个十进制整数和一个空格。
