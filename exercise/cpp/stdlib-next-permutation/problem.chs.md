读入 `n` 个整数，按字典序输出它们的**下一个排列**。如果当前已经是最后一个排列（从大到小），下一个排列就是第一个排列（从小到大）。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 20`）。
- 第二行 `n` 个整数，每个在 `-10^9` 到 `10^9` 之间，可能重复。

**输出**：一行 `n` 个整数，是下一个排列，相邻整数用一个空格分隔。

### 示例

输入：

```text
3
1 2 3
```

输出：

```text
1 3 2
```

### 约束

- 排列按整个序列的字典序比较，不是按元素个数。
- 重复元素按位置参与排列；比如 `1 1` 的下一个排列还是 `1 1`。
- 必须让相等的元素也保持“下一个”的定义：不能通过先排序再去重来跳过重复排列。
- 可以调用标准库的 `std::next_permutation`，也可以自己实现。
