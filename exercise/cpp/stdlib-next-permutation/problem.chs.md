今有列数 `n` 枚，自左至右，各记其值。问：依字典之序，此列之后一列何如？

术曰：自右向左，寻第一处前数小于后数者。若得之，复自右向左寻第一个大于前数者，交换二数，再将前数之后诸数反转，即得后一列。若遍寻不得，此列已自大至小，是末列也，则反转为自小至大，复归首列。

问者又曰：数可重复，当何以处之？答曰：重复之数，各安其位，`1 1` 之后仍是 `1 1`。不可先排序去重，以避重复之列。

**人话**：读入 `n` 个整数，按字典序输出它们的下一个排列；若当前已是最后一个排列（从大到小），下一个排列就是第一个（从小到大）。排列按整个序列的字典序比较，与元素个数无关；重复元素按位置参与，相等的元素也照“下一个”的定义走。可以调用 `std::next_permutation`，也可以自己实现。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 20`）。
- 第二行 `n` 个整数，每个在 `-10^9` 到 `10^9` 之间，可能重复。

**输出**：一行 `n` 个整数，是下一个排列，相邻整数用一个空格分隔。

### 示例

输入：

```text
3
1 2 3
```

输出：

```text
1 3 2
```

### 约束

- 排列按整个序列的字典序比较，与元素个数无关。
- 重复元素按位置参与排列；比如 `1 1` 的下一个排列还是 `1 1`。
- 必须让相等的元素也保持“下一个”的定义：不能通过先排序再去重来跳过重复排列。
- 可以调用标准库的 `std::next_permutation`，也可以自己实现。
