浮点转整数条例

第一条 本条例规范 `double` 到 `int` 的精确转换，其函数式如左：

```cpp
bool to_int_exact(double value, int& out);
```

第二条 准予转换者，须三事俱全：`value` 为有限值；`value` 等于某个整数；该整数在 `-2147483648` 到 `2147483647` 之间。三事俱全者，写入 `out`，返回 `true`。
第三条 其余情形一律返回 `false`，`out` 保持原值。
第四条 `NaN`、正无穷、负无穷，概不准入。`-0.0` 准入，结果为 `0`。
第五条 先转换后检查者，逾界之时已生未定义行为，本条例不予承认。`2147483648.0` 必须驳回。
第六条 不得书写 `main`。

附则 审查次序：先验 `std::isfinite(value)`，再验 `value == std::trunc(value)`，末与 `int` 上下界相较。先转换、后比较，次序一倒，即入第五条之列。

**人话**：实现一个精确转换函数：`double` 是有限值、正好等于某个整数、且该整数落在 `int` 范围内时，写入 `out` 返回 `true`；其余情况返回 `false` 且不碰 `out`。
