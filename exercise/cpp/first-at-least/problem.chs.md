给定一个按非递减顺序排列的数组，回答若干查询：第一个大于等于给定值 `x` 的元素在第几位？

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 200000`）。
- 第二行 `n` 个整数，非递减排列，每个数的绝对值不超过 `10^9`。
- 第三行一个整数 `q`（`1 ≤ q ≤ 200000`）。
- 接下来 `q` 行，每行一个整数 `x`，绝对值不超过 `10^9`。

**输出**：对每个查询输出一行。若存在最小的 `i` 使 `a[i] ≥ x`，输出 `i`（从 1 开始）；若不存在，输出 `n + 1`。

### 示例

输入：

```text
5
1 3 3 7 10
3
3
4
0
```

输出：

```text
2
4
1
```

### 提示

`std::lower_bound` 正好做这件事。注意它返回迭代器，需要减去 `begin()` 并加 1；数组里可能有重复值，二分本身会落到最左的一个。
