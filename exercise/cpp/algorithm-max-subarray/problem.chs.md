读入一个整数序列，求它的最大子段和。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 200000`）。
- 第二行 `n` 个整数，每个数的绝对值不超过 `10^9`。

**输出**：一行一个整数，表示所有非空连续子段中最大的元素和。

### 示例

输入：

```text
7
1 -2 3 4 -1 2 -5
```

输出：

```text
8
```

取子段 `3 4 -1 2`，和为 8。

### 约束

- 子段必须非空；当所有数都是负数时，答案是其中最大的那个负数，而不是 0。
- 一个子段最多包含 200000 个 `10^9`，总和可能超出 32 位，使用 64 位整数。
- 需要 `O(n)` 的 Kadane 算法，不能枚举所有子段。
