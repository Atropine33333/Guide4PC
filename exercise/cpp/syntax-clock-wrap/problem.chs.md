话说这一日，钟楼里来了位老匠人，接下一桩差事：造一座不惧午夜的钟。

列位看官，寻常的钟走到 23:59:59 便歇了；这一座不同，再走一秒，它自会翻回 00:00:00，仿佛什么事也没发生。您若要它倒着走，它也照走不误：退一秒，正是 23:59:59。往前多走一日，它便多绕一圈，钟面上看不出痕迹。

老匠人说：“钟面上只有三个数——时、分、秒；钟肚里也只存一个数，从零时起算的秒数。两个数目，说的是同一刻。”

**人话**：实现一个按 24 小时循环的 `Clock` 类，构造与走动都自动跨午夜回绕。

实现 `Clock`：

- `Clock(int hour, int minute, int second)`：三个分量可以是任意整数（包括负数）；构造后必须归一化到 `00:00:00`–`23:59:59`。
- `void advance(int seconds)`：向前走 `seconds` 秒；`seconds` 可以为负。
- `int hour() const`、`int minute() const`、`int second() const`：返回归一化后的分量。
- `int total_seconds() const`：返回从 `00:00:00` 起经过的秒数，范围是 `[0, 86399]`。
- `bool operator==(const Clock& other) const`：表示同一时刻时返回 `true`。

所有运算都按 24 小时循环进行。例如 `-1` 秒是 `23:59:59`，`25:00:00` 是次日 `01:00:00`。不要写 `main`。

### 示例

| 调用 | 结果 |
| --- | --- |
| `Clock(25, 0, 0)` | `01:00:00` |
| `Clock(0, 0, -1)` | `23:59:59` |
| `Clock(12, 30, 0).advance(86400)` | 仍是 `12:30:00` |

### 提示

先把三个分量并成总秒数，用取模归一到 `[0, 86399]`；处理负数时，C++ 的 `%` 会得到负余数，需要再加一个周期。
