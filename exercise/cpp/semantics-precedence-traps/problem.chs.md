读入表达式编号 `q` 和三个正整数 `a`、`b`、`c`，计算下面第 `q` 个表达式的值。这些表达式故意省略了括号，请严格按 C++ 的优先级与结合性计算。

```text
1: a + b * c
2: (a + b) * c
3: a << b - 1
4: a & b ^ c
5: a < b == c > a
6: -a * -b
7: a - b - c
8: a ? b : c
```

### 输入

一行四个整数 `q a b c`，满足 `1 <= q <= 8`，`1 <= a, b, c <= 9`。

### 输出

一行，第 `q` 个表达式的值。

### 示例

输入：

```text
4 2 3 4
```

输出：

```text
6
```

### 约束

- 所有中间结果都在 `int` 范围内，不会溢出。
- `a << b - 1` 中的 `b - 1` 在 0 到 8 之间，不会产生未定义行为。
- 只使用标准库；不要输出题面之外的文字。
