“哦，老天爷，”制片人把烟按进烟灰缸，“这份报表谁看得懂？通篇是数字，一栏压着一栏。”

“您别急，我亲爱的，”绘图员抖开一张纸，“咱们给它画成横条。第几行就标几号，从 1 起，后面跟一个冒号、一个空格，再排下 `#`；哪一行是零，就画一根短横 `-`，别让那行空着。”

“序号自 1 起算，莫从 0 起。”制片人补了一句，“行末不许拖空格，观众的眼睛尖得很。”

“这才像话。”他把纸卷起来，“午夜前送到。”

**人话**：读入 `n` 个非负整数，按输入顺序画一张横向条形图，每行以“序号 + 冒号 + 空格”开头，后面是下标个数的 `#`，数值为零时改画一个 `-`。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 50`）。
- 第二行 `n` 个整数 `v`（`0 ≤ v ≤ 40`）。

**输出**：`n` 行。第 `i` 行先输出序号（从 1 开始）、冒号和一个空格，再输出 `v_i` 个 `#`；若 `v_i = 0`，输出一个 `-` 代替条形。

### 示例

输入：

```text
3
3 0 5
```

输出：

```text
1: ###
2: -
3: #####
```

### 约束

- 每行末尾不要多输出空格。
- 序号从 1 开始，起始值取 1。
