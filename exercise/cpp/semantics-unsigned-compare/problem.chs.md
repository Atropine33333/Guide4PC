读入一个有符号整数 `a` 和一个无符号整数 `b`，按数学上的大小关系比较它们，而不是直接使用 C++ 的隐式转换结果。

**输入**：

- 第一行一个整数 `a`，范围是 `-9223372036854775808` 到 `9223372036854775807`。
- 第二行一个整数 `b`，范围是 `0` 到 `18446744073709551615`。

**输出**：一行两个 `0` 或 `1`，用一个空格分隔：第一个表示 `a < b` 是否成立，第二个表示 `a == b` 是否成立（都按数学值比较）。

### 示例

输入：

```text
-1
0
```

输出：

```text
1 0
```

### 约束

- 直接用 `a < b` 或 `a == b` 会把 `a` 转换成无符号数，负数会变成很大的值，结果不对。
- `a` 为负数时一定小于任何非负的 `b`。
- 不要用浮点数比较，`b` 已经超出 `double` 的精确表示范围。
