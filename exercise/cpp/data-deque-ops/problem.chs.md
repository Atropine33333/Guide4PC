模拟一个双端队列的指令流。队列初始为空，请你按顺序执行指令。

**输入**：

- 第一行一个整数 `m`（`1 ≤ m ≤ 1000`），表示指令条数。
- 接下来 `m` 行，每行是一条指令，格式为以下之一：
  - `push_front x`：把整数 `x` 放到队头；
  - `push_back x`：把整数 `x` 放到队尾；
  - `pop_front`：弹出队头；
  - `pop_back`：弹出队尾；
  - `size`：查询队列长度。

`x` 的绝对值不超过 `10^9`。

**输出**：对每条 `pop_front` 或 `pop_back`，输出被弹出的整数；若此时队列为空，输出 `EMPTY`。对每条 `size`，输出当前元素个数。每个答案独占一行，其余指令不产生输出。

### 示例

输入：

```text
6
push_back 1
push_back 2
push_front 0
size
pop_front
pop_back
```

输出：

```text
3
0
2
```

### 约束

- 指令可能在任何时刻对空队列执行弹出。
- `std::vector` 的 `pop_back` 很方便，但它不支持在头部高效删除；请使用 `std::deque`。
- 队列中的元素可能重复，不要假设互不相同。
