读入两个整数 `a` 和 `b`，输出 C++ 取模运算的结果，以及一个非负余数。

**输入**：一行两个整数 `a` 和 `b`（`b ≠ 0`，`|a| ≤ 10^9`，`|b| ≤ 10^9`）。

**输出**：一行两个整数，用单个空格分隔：

- 第一个是 C++ 表达式 `a % b` 的值。结果非零时，符号与被除数 `a` 相同。
- 第二个是满足 `0 ≤ r < |b|` 且 `a - r` 能被 `b` 整除的余数 `r`。

### 示例

输入：

```text
-7 3
```

输出：

```text
-1 2
```

`-7 / 3` 向零取整得到 `-2`，所以 `-7 % 3` 是 `-1`；要落到非负区间，还需要加一个 `|b|`。

### 约束

- `b` 可以是负数，但不会是 0。
- 不要使用浮点数计算余数。
