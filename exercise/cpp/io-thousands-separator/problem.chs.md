读入 `n` 个整数，按千位分隔符格式输出。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 100`）。
- 接下来 `n` 行，每行一个整数 `x`（`-10^15 ≤ x ≤ 10^15`）。

**输出**：`n` 行。每行是 `x` 的十进制表示，从右往左每三位插入一个逗号 `,`。负号放在最前面，不参与分组；`0` 输出 `0`。

### 示例

输入：

```text
3
1234567
-9876543
0
```

输出：

```text
1,234,567
-9,876,543
0
```

### 约束

- 不能使用固定的数字位数，输入可能有 16 位。
- 不要输出前导零；`-0` 应输出 `0`。
- 分组之间不能有空格。
