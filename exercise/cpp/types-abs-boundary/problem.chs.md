《绝对值使用须知》

一、本须知适用于一切 64 位有符号整数。
二、对任意 `x`，其绝对值记作 `|x|`，以十进制输出，不加前导零，不加正号。例如 `-42` 的绝对值是 `42`。
三、`long long` 的最小值为 `-9223372036854775808`，它的绝对值是 `9223372036854775808`。
四、第 3 条恒为真。该数比 `long long` 能表示的最大正数还大 1。
五、因此，对最小值直接写 `-x` 会触发有符号整数溢出，属未定义行为；第 2 条在此处照旧生效。
六、若你假定结果总能放回 `long long`，第 2 条对你作废：你交出的将是一个负数，或更糟。
七、本须知只负责指出上述各条同时为真，不负责替你选容器。

**人话**：读入 `n` 个 64 位有符号整数，逐行输出每个数的绝对值。绝对值可能超出 `long long` 的正数上限，所以要么用无符号 64 位整数，要么把十进制数字当字符串处理。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 100`）。
- 第二行 `n` 个整数，相邻整数用一个空格分隔，每个整数都在 `[-2^63, 2^63 - 1]` 内。

**输出**：

- `n` 行，每行一个非负整数，表示对应输入的绝对值。

### 示例

输入：

```text
3
-7 0 9223372036854775807
```

输出：

```text
7
0
9223372036854775807
```

### 约束

- 不能假设绝对值一定能放进 `long long`。
- 对最小负数直接写 `-x` 会触发有符号整数溢出，是未定义行为。
- 输出使用十进制，不要加前导零或正号。
