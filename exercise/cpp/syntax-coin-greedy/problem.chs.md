**第二十章**

天国好像一个家主，清早出去雇人进他的葡萄园作工。他与人讲定一天一钱银子，又吩咐管事的说：“凡来领工价的，先取最大的银钱，再取次大的，直到付清，一枚也不许多给。”

管事的便取出八种银钱：二百、一百、五十、二十、十、五、二、一。他每回都先抓最大的，抓不动了才换小的。家主数了数他手里的枚数，说：“这人取法称心。”

**人话**：实现 `greedy_coin_count(amount)`，按面额从大到小的贪心规则清点金额，返回取走的硬币总枚数。

```cpp
long long greedy_coin_count(long long amount);
```

**规则**：

- 硬币面额为 `200, 100, 50, 20, 10, 5, 2, 1`（单位：分）。
- `amount` 是非负整数，`0 ≤ amount ≤ 10^18`。
- 从左到右处理面额：每次取走尽可能多枚当前面额的硬币，再处理下一个面额。
- 返回取走的硬币总枚数。
- 不要写 `main`。

### 示例

`greedy_coin_count(388)` 取一枚 `200`、一枚 `100`、一枚 `50`、一枚 `20`、一枚 `10`、一枚 `5`、一枚 `2`、一枚 `1`，共 8 枚。

### 提示

对每个面额 `coin`，取 `amount / coin` 枚，然后 `amount %= coin`。总和也要用 `long long`：`10^18` 分全部用 200 分硬币需要 `5·10^15` 枚，`int` 存不下。
