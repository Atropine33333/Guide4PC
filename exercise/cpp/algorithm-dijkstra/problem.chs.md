话说那一夜，图上起了风波。列位看官，且听我道来：有城 `n` 座，编号自零至 `n-1`；有路 `m` 条，条条单向，脚程或长或短，却没有倒着走的。

说书人手里一块醒木，往零号城上一拍：“零号城，脚程零。”随即遣一名探马，把这城所通之处一一记下。探马回来报：某城可近，某城尚远。醒木再拍，取脚程最近的一座城，定为已到，再从它往外探；哪条绕道反而更近，便把旧账改作新数。如此一拍一探，直到无城可探，各城脚程俱定。至于路断不通之城，只报一个“无”字，写作 `-1`。

**人话**：给定 `n` 个结点、`m` 条边的有向图，边权非负，求从结点 `0` 到每个结点的最短路径长度；不可达的结点输出 `-1`。用 Dijkstra 算法配优先队列，距离用 64 位整数。

### 输入

第一行两个整数 `n` 和 `m`（`1 <= n <= 2000`，`0 <= m <= 10000`）。

接下来 `m` 行，每行三个整数 `u v w`（`0 <= u, v < n`，`0 <= w <= 1000000000`），表示一条从 `u` 到 `v` 的边，权值为 `w`。

图中可能有重边和自环。

### 输出

一行 `n` 个整数，依次是结点 `0` 到结点 `0, 1, ..., n-1` 的最短距离；不可达输出 `-1`。相邻整数之间用一个空格分隔。

### 示例

输入：

```text
3 3
0 1 10
0 2 1
2 1 2
```

输出：

```text
0 3 1
```

直接到结点 `1` 的距离是 10，经过结点 `2` 的距离是 `1 + 2 = 3`。

### 约束

- 边权非负，因此可以使用 Dijkstra 算法。
- 路径长度可能超过 32 位有符号整数范围，请使用 64 位整数。
- 只使用标准库。
