下面的程序统计 `n` 个字符里元音字母的个数，但它有错误。请找出并修正这些错误，使程序通过所有测试。

元音字母是 `a`、`e`、`i`、`o`、`u` 以及它们的大写形式。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 1000`）。
- 第二行 `n` 个字符，用空格分隔。字符是 ASCII 字母。

**输出**：一个整数，表示元音字母的个数。

### 示例

输入：

```text
5
H e l l o
```

输出：

```text
2
```

`e` 和 `o` 是元音。

### 提示

- 注意循环是否检查了全部 `n` 个字符；
- 注意大小写；
- 不要改变输入输出格式，也不要重写整题；只需修复 `starter.cpp` 中的逻辑错误。
