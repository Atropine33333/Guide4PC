# 语法讲义写作规范（给写作者）

## 目标

写一份**期末/期中复习用**的 C++ 基础语法讲义，覆盖基础语法与常用技巧；读者是学过一遍、需要系统梳理的人。

- 讲清楚：规则、为什么、边界情况；
- 可验证：每个可运行例子都必须能编译、能跑、输出与文中一致；
- 多讲坑：给反例、给"看起来对但错"的写法。

## 文件与标题

- 每人只写自己的分片文件：`grammar/parts/<编号>.md`（编号由任务指定）。
- 文件开头直接是二级标题，例如 `## 7. 指针`，不要写一级标题、不要写目录。
- 子标题用 `###`；更细一层用 `####`。
- 小节顺序按任务指定的章节号写。

## 可运行例子（强制）

每个 `cpp` 代码块必须是**完整程序**（自带 `#include` 和 `main`），并且**紧跟**一个 `text` 块写它的精确输出：

````markdown
### 指针与数组的区别

```cpp
#include <iostream>
int main() {
    int a[3] = {1, 2, 3};
    std::cout << sizeof(a) / sizeof(a[0]) << '\n';
}
```

输出：
```text
3
```
````

规则：

- 输出块只放 stdout，不含 stderr、不含提示符；行尾空格去掉；末尾不空行。
- 程序必须确定性、只用 ASCII 输出；不读 stdin（除非该小节专门讲输入，并同时给出输入说明）。
- 禁止：异常（throw/try）、线程、原子操作、文件、网络、随机数、系统调用、动态库。
- 允许：`<iostream> <string> <vector> <array> <map> <set> <algorithm> <numeric> <cmath> <cstring> <cstdint> <iomanip> <climits> <cstddef> <utility> <tuple> <queue> <stack> <deque>` 等标准库。
- 用 C++20；编译命令：`clang++ -std=c++20 -Wall -O0 文件.cpp`；要求无 warning。
- **可运行例子不得依赖 stdin**：演示 `cin` 时用 `std::istringstream` 提供固定输入（需 `#include <sstream>`），保证 `程序 </dev/null` 也能逐字重现 text 输出；不要写需要人工输入的程序。
- 不可单独运行的片段（声明、签名、结构示意）不要用 ```cpp，改用 ```cpp-fragment，不要跟 text 块。

## 讲解要求

- 每节以"这是什么、什么时候用"开头，2–4 句，不铺垫。
- 优先用表格对比易混点（如 指针 vs 引用、`char[]` vs `std::string`、`sizeof` 数组 vs 指针）。
- 每个"坑"用「❌ 错误 / ✅ 正确」或"注意"标出，并说明后果（编译错、UB、静默错误）。
- 多维数组、指针、引用要画内存布局（用 ASCII 或表格）。
- 篇幅：普通节 800–1800 汉字 + 2–5 个可运行例子；指针/多维数组/引用 1500–2500 汉字 + 4–6 个例子。
- 例子之间要有承接，不要堆砌互不相关的代码。

## 自检

写完逐个例子：

1. 保存为临时 `.cpp`，`clang++ -std=c++20 -Wall` 编译；
2. 运行，核对输出与 `text` 块逐字节一致；
3. 确认没有 warning、没有未定义行为（越界、悬垂、未初始化）。

如果环境里没有可用的 shell/编译器，就在每个例子旁标注 `<!-- unverified -->` 并在回复里说明，不要假装验证过。
