一个整数摆在桌上，要用三种写法各抄一遍：十六进制、八进制，还有一格一格数出来的二进制。

**人话**：读入一个非负整数 `n`，分三行输出它的十六进制、八进制和二进制写法，三种写法都不带 `0x`、`0` 这类前缀。

**输入**：一行一个整数 `n`，满足 `0 ≤ n ≤ 1000000000`。

**输出**：三行。

- 第一行：`n` 的十六进制，小写字母，不带前缀。
- 第二行：`n` 的八进制，不带前缀。
- 第三行：`n` 的二进制，最高位在前，没有前导零；`n` 为 `0` 时写 `0`。

### 示例

输入：

```text
45
```

输出：

```text
2d
55
101101
```

45 写成十六进制是 `2d`，写成八进制是 `55`，二进制是 `101101`。

### 约定

- `n` 在 `int` 范围内，十六进制与八进制用 `printf` 的转换说明就能写出来。
- 二进制要自己从高位到低位逐位写，并且去掉前导零。
- 行末不要有空格，也不要输出题面之外的文字。
