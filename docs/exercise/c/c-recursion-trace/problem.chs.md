阶乘写成递归，最像一串脚印：算 `n!`，先迈一步去算 `(n-1)!`，再往前迈一步……一直走到 `0!`，然后踩着原来的脚印一步一步退回来，每退一步就乘上一个数。

现在要你在函数里数脚印：每进入一次 `fact`，就把计数器加一，包括最后停在 `0` 的那一次。

**人话**：读入 `n`，用递归算出 `n!`，同时数出一共调用了多少次递归函数；输出阶乘值与调用次数。`fact(0)` 只调用一次，所以 `n = 0` 时输出 `1 1`。

**输入**：一行一个整数 `n`，满足 `0 ≤ n ≤ 12`。

**输出**：一行两个整数，先阶乘值，后调用次数，用单个空格分隔。

### 示例

输入：

```text
3
```

输出：

```text
6 4
```

`fact(3)` 调用 `fact(2)`，再调用 `fact(1)`，再调用 `fact(0)`，一共四次。

### 约定

- `fact` 以 `n == 0` 为出口，返回 `1`。
- `n = 12` 时 `12! = 479001600`，用 `int` 装得下；用 `long long` 更稳妥。
- 调用次数就是递归树的结点数：`n ≥ 0` 时为 `n + 1`。
- 输出行末不要有多余空格。
