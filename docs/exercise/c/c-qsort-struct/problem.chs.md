《塔罗牌阵：按分排座》

占卜师把几张牌洗开，每张写着一个名字和一个分数。

「坐席只有一排，」她说，「分数高的坐前头；分数一样的，名字在字典里靠前的坐前头。」

她把牌递给你：「照这个规矩排好，一张一行念出来。念的时候，名字在前，分数在后。」

**人话**：读入 `n` 个学生的姓名与分数，用 `qsort` 按分数从高到低排序；分数相同则按姓名从小到大排；排好后每行输出 `name score`。

**输入**：

- 第一行一个整数 `n`（`1 <= n <= 100`）。
- 接下来 `n` 行，每行一个姓名和一个整数分数，用单个空格分隔；姓名只含小写字母，长度在 `1` 到 `20` 之间；分数在 `0` 到 `1000` 之间。

**输出**：`n` 行，每行一个姓名和一个分数，中间用单个空格分隔。

### 示例

输入：

```text
4
dan 80
alice 90
cara 80
bob 70
```

输出：

```text
alice 90
cara 80
dan 80
bob 70
```

`alice` 分数最高，坐第一；`cara` 与 `dan` 都是 `80`，`cara` 的名字在前，先坐；`bob` 分数最低，坐最后。

### 约定

- 必须用 `qsort` 排序；姓名比较用 `strcmp`，分数比较用整数。
- 分数高的在前；同分时姓名字典序小的在前。
- 姓名互不相同，不会出现同名同分。
- 输出行末不要有多余空格。
