少室山下，老掌门把一盏茶推到你面前。

“你若要催动 `b` 分真气去闯 `e` 重关，一掌一掌地推，关没走完，人先脱力。”

他把掌一分为二：“看好了。掌力折半，威力自乘；关数折半，余数记账。关数逢双，只把掌力自乘一遍；关数逢单，先记你这一掌，再折半。六十重关，也不过换手数十回。”

你依言而行，一路行至关底，真气落在 `m` 块石板上，余下几分，便是答案。

**人话**：求 `b` 的 `e` 次方对 `m` 取余，即 `b^e mod m`。

**输入**：一行三个整数 `b`、`e`、`m`（`0 ≤ b < m`，`0 ≤ e ≤ 10^18`，`1 ≤ m ≤ 10^9`）。

**输出**：一行一个整数，即 `b^e mod m`，取值在 `0` 到 `m - 1` 之间。

### 示例

输入：

```text
2 10 1000
```

输出：

```text
24
```

### 约定

- `e = 0` 时输出 `1 % m`：`m = 1` 时为 `0`，否则为 `1`。
- `m = 1` 时任何指数都输出 `0`。
- `e` 最大到 `10^18`，逐个相乘会超时；按二进制拆指数，每乘一次取一次模，约六十轮即可。
- 中间乘积最大约为 `(10^9)^2 = 10^18`，用 `long long` 计算；每次乘法后立刻取模。
- 输出行末不要有多余空格。
