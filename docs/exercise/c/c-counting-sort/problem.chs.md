《夜间点名守则》

第一条 名册上的号码只在 `0` 到 `100` 之间，不会多，也不会少。

第二条 点名时，号码小的人先应声。

第三条 同号的人不止一个，先站进队伍的先生应，顺序不可颠倒。

第四条 你不许把两个人拉到一处比大小，只许数人头。

第五条 点完名，按应声的先后把号码抄在一行里，号码之间空一格。

第六条 名册上一个名字也没有时，交回一张白纸。

第七条 若你听见有人在你背后念出这一条，请立刻从头再点一遍。

**人话**：读入 `n` 与 `n` 个 `0` 到 `100` 之间的整数，做稳定计数排序：数值小的排在前面，数值相同的保持输入时的先后，输出排好的数列；`n` 为 `0` 时输出空行。

**输入**：第一行一个整数 `n`（`0 ≤ n ≤ 1000`）；第二行 `n` 个整数，每个在 `0` 到 `100` 之间，用单个空格分隔；`n` 为 `0` 时第二行可以为空。

**输出**：一行，排序后的 `n` 个整数，用单个空格分隔；`n` 为 `0` 时输出一个空行。

### 示例

输入：

```text
6
3 1 2 3 1 2
```

输出：

```text
1 1 2 2 3 3
```

### 约定

- 稳定：数值相同的元素保持输入时的先后顺序。
- 只统计每个数值出现的次数，再按数值顺序输出，不要两两比较。
- 数值范围是 `0` 到 `100`，`n` 不超过 `1000`。
- `n` 为 `0` 时输出空行。
- 输出行末不要有多余空格。
