《塔罗牌阵：进制的钥匙》

占卜师洗开一张牌，牌上刻着一串记号：有时是一串数字，有时前面还压着 `0x` 两个字母。

「门有两重，」她说，「一重认十，一重认十六。先看牌面起头的那两个字母，钥匙便自己选好了。」

你抽到的牌写着 `0x1F`。报出门后的十进制数。

**人话**：读入一个不带空格的整数记号（`0x` 开头的十六进制，或普通十进制），用 `strtol(s, NULL, 0)` 转成数值，再按十进制打印。

**输入**：一行一个记号，长度在 `1` 到 `30` 之间，只含数字、字母、可选的 `+`/`-` 号与 `0x`/`0X` 前缀，不含空格。

**输出**：一行一个十进制整数。

### 示例

输入：

```text
0x1F
```

输出：

```text
31
```

`0x` 说明这是十六进制，`1F` 即 `1 * 16 + 15 = 31`。

### 约定

- 进制由前缀决定：`0x`/`0X` 开头按十六进制，其余按十进制。
- 十六进制里的字母大小写都认，`0xAbCd` 与 `0xABCD` 相同。
- 结果保证在 `int` 范围内，不会溢出。
- 输出行末不要有多余空格。
