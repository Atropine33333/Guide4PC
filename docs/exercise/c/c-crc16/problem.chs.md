《校验的印章》

电报从海边出发，一路要过七道关口。每道关口都有人问：这串字符，还是原来那串吗？

现在有了「CRC16 校验印章」。无论多长的 ASCII 串，盖一次章，只留下四个十六进制数字。收信的人再盖一次，两枚章对得上，字符就一个没少。

印章的规矩只有三条：

- 初值 `0xFFFF`；
- 多项式 `0x1021`；
- 从最高位往最低位推，每个字节推八次。位序不翻转，末尾也不再异或。

空格也算正文，行尾的换行不算。四个数字按大写写出，不足四位在前面补零。

**人话**：读入一行 ASCII 文本，按 CRC-16/CCITT-FALSE 计算校验值，输出 `CRC16=0x` 加四位大写十六进制数字。初值 `0xFFFF`，多项式 `0x1021`；对每个字节，先把它与 CRC 的高八位异或，再左移八次，每次最高位为 `1` 时异或多项式。

**输入**：一行 ASCII 文本，长度在 `0` 到 `200` 之间，字符的编码在 `0x20` 到 `0x7E` 之间；行末可以有换行，也可以没有。空行也是合法输入。

**输出**：一行，`CRC16=0x` 后面跟四位大写十六进制数字，例如 `CRC16=0x29B1`。

### 示例

输入：

```text
123456789
```

输出：

```text
CRC16=0x29B1
```

### 约定

- 每个字符按它的 ASCII 码当作一个字节；行末的 `\n` 与 `\r` 不计入。
- 空行的校验值为 `0xFFFF`。
- 先把字符转换成 `unsigned char` 再参与运算，避免有符号 `char` 带来的符号扩展。
- CRC 始终按 16 位无符号数处理，移位后只保留低 16 位。
- 输出不足四位时在前面补 `0`，字母用大写。
- 输出行末不要有多余空格。
