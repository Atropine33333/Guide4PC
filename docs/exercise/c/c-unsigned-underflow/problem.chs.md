两个无符号数相减，结果仍然是无符号数。读入 `a`、`b`，先按 `unsigned` 算出 `a - b`，再把同一个结果转换成 `int`，两项用单个空格写在一行。

**人话**：`a - b` 不够减的时候向高位借位，无符号结果按 2^32 取模；第二项就是把回绕后的这个无符号结果当成 32 位有符号整数来读，最高位为 1 时读作负数。

**输入**：一行两个整数 `a`、`b`，满足 `0 ≤ a, b ≤ 100`。

**输出**：一行两个数，依次为 `a - b` 的无符号结果与 `(int)(a - b)` 的结果，用单个空格分隔。

### 示例

输入：

```text
3 5
```

输出：

```text
4294967294 -2
```

`3 - 5` 不够减，回绕成 `2^32 - 2 = 4294967294`；这个值按 32 位补码读作有符号整数，就是 `-2`。

### 约定

- 无符号减法按 `2^32` 取模，差的绝对值不超过 `100`，不会连续回绕多圈。
- 第一项用 `%u` 打印，第二项用 `%d` 打印。
- 本机的 `unsigned` 与 `int` 都是 32 位，转换后最高位为 1 时结果为负。
- 输出行末不要有多余空格。
- 不要输出题面之外的文字。
