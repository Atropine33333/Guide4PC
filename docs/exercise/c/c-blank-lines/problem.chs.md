《空行守则》

一、每一条空行都算数。
二、只含空格或制表符的一行，同样算空行。
三、连着出现的空行，只许留下一条。
四、开头的空行一条不留。
五、结尾的空行一条不留。
六、留下的那一条，行内一个字符都不许有。

**人话**：逐行读入整段文本，读到输入结束为止；把连续空行压成一条，去掉首尾的空行，其余各行原样输出。

**输入**：若干行文本，每行不超过 1000 个字符，总行数不超过 1000。输入可能为空。

**输出**：处理后的文本；其余各行原样返回，空行输出成真正的空行。

### 示例

输入：

```text
alpha


beta
```

输出：

```text
alpha

beta
```

两条连续的空行压成一条；开头或结尾若还有空行，一并不留。

### 约定

- 行内其他字符原样保留，不增不减。
- 只含空格或制表符的行按空行处理，输出成真正的空行。
- 全部都是空行时，输出为空。
- 行末不要补空格。
