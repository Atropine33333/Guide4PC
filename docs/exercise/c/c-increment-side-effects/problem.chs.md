甲：账房先生，账本上就一个数 `i`，您怎么记三笔？

乙：头一笔 `a = i++`：先把此刻的 `i` 记给 `a`，再让 `i` 长一岁。

甲：先记账，后添岁。

乙：第二笔 `b = ++i`：先把岁添上，再把添完的 `i` 记给 `b`。

甲：先添岁，后记账。

乙：第三笔 `c = i--`：先把 `i` 记给 `c`，再让它退一岁。

甲：这三笔过完，账上还剩多少？

乙：那得看 `i` 自己了。

**人话**：读入整数 `i`，按顺序执行 `a = i++;`、`b = ++i;`、`c = i--;`，输出 `a`、`b`、`c` 与这三句之后的 `i`，用单个空格分隔。

**输入**：一行一个整数 `i`（`-1000 ≤ i ≤ 1000`）。

**输出**：一行四个整数，依次为 `a`、`b`、`c` 和最终的 `i`。

### 示例

输入：

```text
5
```

输出：

```text
5 7 7 6
```

### 约定

- 三条语句各占一行，先后顺序固定，语句之间不要合并。
- 前缀与后缀的差别只在取值的时刻：一个先取值再改，一个先改再取值。
- 不要在同一个表达式里对 `i` 改动两次。
- 输出行末不要有多余空格。
