译制片：宽字符的候场室

（放映机咔哒一响，银幕上打出一行字幕。）

配音员甲：哦，听我说，老伙计，这一行里的字符要被逐个点名了。
配音员乙：点名？它们只是一串 ASCII 字符。
配音员甲：在宽字符的世界里，每个字符都带着自己的编号，一个也不能少。
配音员乙：那就按顺序念：`H` 是 `72`，`i` 是 `105`。
配音员甲：念完一个，空一格，再念下一个。
配音员乙：要是这行是空的呢？
配音员甲：那就一个也不念，银幕上只留一行空白。

（音乐起，字幕缓缓上移。）

**人话**：读入一行 ASCII 字符，把每个字符当成 `wchar_t`，输出它的十进制值，值与值之间用一个空格隔开。

**输入**：一行，长度在 `0` 到 `1000` 之间，只含可见 ASCII 字符（`0x20` 到 `0x7E`），末尾带换行。

**输出**：一行，按顺序写出每个字符的 `wchar_t` 十进制值，用单个空格分隔；空行只输出一个换行。

### 示例

输入：

```text
Hi
```

输出：

```text
72 105
```

`H` 的编码是 `72`，`i` 的编码是 `105`。

### 约定

- ASCII 范围内的字符，其 `wchar_t` 值等于字符的编码，也就是常见的 ASCII 码。
- 行末换行不参与点名；行中与行末的空格照点，值为 `32`。
- 输出行末不要有多余空格。
