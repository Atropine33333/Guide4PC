《四张牌》

占卜师把四张牌摊在桌上，牌面依次是 `+`、`-`、`*`、`max`。每张牌底下压着两个整数 `a` 与 `b`。

问卜的人先报出抽到的牌名，占卜师照着牌面算一次：`+` 牌把两数相加，`-` 牌用前一个数减后一个数，`*` 牌求两数之积，`max` 牌留下较大的那个。若报出的牌名根本不在桌上，占卜师只推回一张空白的 `?`。

**人话**：读入牌名 `op` 与两个整数 `a`、`b`；`op` 为 `+`、`-`、`*`、`max` 时按对应运算输出结果，其他牌名输出 `?`。

**输入**：一行，`op` 与 `a`、`b`，之间用空格分隔。`op` 是不含空格的短字符串，长度不超过 `15`；`|a| ≤ 10^6`，`|b| ≤ 10^6`。

**输出**：一行一个结果：对应运算的值，或牌名不认识时的 `?`。

### 示例

输入：

```text
* 6 7
```

输出：

```text
42
```

抽到的是 `*` 牌，两数之积为 `42`。

### 约定

- `max` 比较的是数值大小，负数一样比较：`max -9 -2` 得 `-2`。
- 乘积可能超过 `int`，结果用更宽的整数类型保存后打印。
- 输出只有一个整数或一个 `?`，行末不要空格。
- 牌名按完整字符串比较，`+` 与 `max` 各算一张。
