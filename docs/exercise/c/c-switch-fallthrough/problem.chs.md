《天梯掉落法》

第一条（适用范围）凡自第 `n` 级沿天梯逐级落至第 1 级、把途经各级的级数累加者，皆依本法。

第二条（入口）由 `switch` 的 `case n` 进入，不得从更低的级闯入。

第三条（掉落）每落到一级，就把该级级数加进总和；加完不停，继续落向下一级，级与级之间不设 `break`。

第四条（落地）落到 `case 1` 并把它加完之后，方可 `break` 离梯。

第五条（次序）掉落自高向低，一级一次，每级只加一次。

第六条（结果）输出累计所得的总和，单独一行。

**人话**：读入 `n`，用 `switch` 从 `case n` 一路掉到 `case 1`，把途经的级数相加，输出总和。

**输入**：一行一个整数 `n`（`1 ≤ n ≤ 9`）。

**输出**：一行一个整数，即 `1 + 2 + … + n` 的和。

### 示例

输入：

```text
4
```

输出：

```text
10
```

### 约定

- 只用 `switch` 的掉落完成累加，不要改用循环或求和公式。
- 除 `case 1` 外，各级都不写 `break`。
- 每一级只累加一次，不要重复加。
- 输出行末不要有多余空格。
