「自搬自」搬家服务——广告

还在为搬家发愁？「自搬自」推出一项新服务：把一列整数从左往右挪 `k` 个位子，空出来的后 `k` 个位置一律补零。

- **重叠搬运**：前后两块地方挨着，甚至叠在一起，`memmove` 一次搞定，绝不先踩坏还没搬走的数。
- **一位起搬，整列也搬**：`k` 从 `0` 到 `n` 都接。
- **搬空之后**：末尾补零，账目清楚。

**人话**：把数组 `a` 的前 `n` 个元素整体左移 `k` 位，`a[i]` 取原来的 `a[i + k]`，末尾空出的 `k` 个位置填 `0`；搬运用 `memmove` 处理重叠。

**接口**：

```c
void shift_left(int *a, int n, int k);
```

- `n >= 0`，且 `0 <= k <= n`。
- `k` 为 `0`：数组原样不动。
- `k` 等于 `n`：前 `n` 个元素全部变成 `0`。
- 其余情况：前 `n - k` 个元素左移，后 `k` 个填 `0`。

### 示例

```c
int a[6] = {1, 2, 3, 4, 5, 6};
shift_left(a, 6, 2);
// a 变成 {3, 4, 5, 6, 0, 0}
```

### 约定

- 只实现这个函数，不要写 `main`；这些函数会被直接调用。
- 前后区域重叠时，从低到高逐个赋值会先读到自己刚写下的数；这件事交给 `memmove` 一次完成。
- 只改前 `n` 个元素，`a[n]` 及其后的内存保持原样。
- 不要动态分配。
