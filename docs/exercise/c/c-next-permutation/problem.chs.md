（濠水桥上，庄子与惠子看鱼。）

惠子把几枚竹片排成一列：“这一列有先后。换一种排法，就是另一列。”

庄子说：“列有尽，意无穷。你把竹片排到极处，再往下一列，就跨过去了。”

惠子问：“跨过去是什么？”

庄子说：“空处。列到尽头，只余空处，再也写不出下一列。”

**人话**：读入 `n` 与 `1..n` 的一个排列，输出按字典序紧排在它后面的那个排列；若它已经是最后一个，输出 `none`。

**输入**：第一行一个整数 `n`（`1 ≤ n ≤ 1000`）；第二行 `n` 个整数，是 `1..n` 的一个排列，用单个空格分隔。

**输出**：一行，下一个排列，数字之间用单个空格分隔；若不存在，输出 `none`。

### 示例

输入：

```text
3
1 2 3
```

输出：

```text
1 3 2
```

`1 2 3` 之后依次是 `1 3 2`、`2 1 3`……；`3 2 1` 是最后一个，它就没有下一个。

### 约定

- 字典序逐位比较：先比第一个不同的数。
- 下一个排列是全部排列中恰好排在当前排列后面的那一个。
- 若当前排列从左到右严格递减，它已是最后一个，输出小写 `none`。
- 输出各数之间用单个空格分隔，行末不要有多余空格。
