**产品说明书**

**品名**：字段拆分器
**型号**：`split_fields`
**适用**：一行以逗号分隔的文本

**一、用途**

把一行文本按逗号切成若干段，去掉每段首尾的空格，空段丢弃，留下的段依次装进调用方准备好的格子里。

**二、操作**

调用方准备一排格子 `out`，每格 `FIELD_LEN` 字节，最多提供 `max` 格；把整行 `line` 交给 `split_fields`，函数返回真正装进格子的段数。

**三、示例**

`"  alpha ,, beta  , gamma "` 拆出三个字段：`alpha`、`beta`、`gamma`。

`"one,two,three,four,five"` 在 `max = 3` 时只装下 `one`、`two`、`three`，返回 `3`。

**人话**：按逗号切分一行文本，去掉每段首尾空格，跳过空段，按顺序写入 `out` 并返回字段数；有效字段多于 `max` 时只写前 `max` 个，返回 `max`。

**接口**：

```c
#define FIELD_MAX 32
#define FIELD_LEN 64

int split_fields(const char *line, char out[][FIELD_LEN], int max);
```

### 约定

- 分隔符只有逗号 `,`；每段只去掉首尾的 ASCII 空格 `' '`，段内部空格原样保留。
- 去掉空格后为空的段直接跳过：不写进 `out`，也不计入返回值。
- 保留下来的字段按原顺序写入 `out[0]`、`out[1]`……，每个字段以 `'\0'` 结尾。
- 一个字段超过 `FIELD_LEN - 1`（即 63）个字符时，只保留前 63 个字符，末尾补 `'\0'`；它仍然算一个字段。
- 有效字段多于 `max` 时，只写前 `max` 个，后面的格子保持原样，返回 `max`。
- `max` 不大于 `0` 时返回 `0`，不碰 `out`；`max` 不超过 `FIELD_MAX`。
- 整行为空、或整行只有逗号与空格时返回 `0`。
- 不要写 `main`；不需要动态分配内存。
