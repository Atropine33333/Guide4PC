《拼句机使用说明书》

型号：SENTENCE-1
用途：把姓名与年龄拼成一行标签。

一、安装

把机器接在标准输入上，装好 `snprintf`，再备一只足够大的缓冲区接住成品。缓冲区小了，机器会把句子截断；这一次的活计，`80` 个字节够用。

二、上料

左边料斗放姓名，右边料斗放年龄，两者之间留一个空格。姓名不得超过 `32` 个字符，且不得含空格；年龄取 `0` 到 `150` 的整数。

三、操作

按下按钮，机器按固定模子拼句：

```text
name=<姓名>; age=<年龄>
```

`name=` 之后原样放进姓名，接着是分号、一个空格、`age=`，最后是年龄的十进制写法。

四、下料

成品占一行，行末换行。分号后头那个空格不能省，等号两边不能加空格，姓名的字符一个不改。

五、注意

- 模子里的小写字母、分号、空格都要照抄。
- 先用 `snprintf` 拼进缓冲区，再把整行输出。
- 年龄为 `0` 时照常写出 `age=0`。

**人话**：读入一个不含空格的姓名和一个年龄，用 `snprintf` 拼出 `name=<姓名>; age=<年龄>`，输出一行。

**输入**：一行，姓名与年龄用一个空格隔开。姓名长度 `1` 到 `32`，不含空格；年龄是 `0` 到 `150` 的整数。

**输出**：一行，格式为 `name=<姓名>; age=<年龄>`，行末换行。

### 示例

输入：

```text
Alice 30
```

输出：

```text
name=Alice; age=30
```

### 约定

- `name=`、`; age=` 全部小写，分号后面恰好一个空格。
- 姓名的字符原样照抄，不增不减。
- 年龄按十进制整数写出，不加前导零。
- 输出行末不要有多余空格。
- 不要输出题面之外的文字。
