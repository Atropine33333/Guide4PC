把一块动态分配的数组收小：只保留前 `n` 个元素，容量从 `*cap` 改成 `n`。`n` 等于当前容量时什么都不用做；`n` 为 `0` 时整块归还；`n` 小于容量时缩容并保留前 `n` 个值；`n` 为负或超过容量时拒绝，原数组不动。

**人话**：实现 `trim_to`，把动态数组的容量从 `*cap` 缩到 `n`，保留下标 `0` 到 `n-1` 的元素；`n` 为 `0` 时归还整块内存；`n` 为负或大于当前容量时返回 `-1`，什么都不改。

**接口**：

```c
int trim_to(int **a, int *cap, int n);
```

- `*a` 是数组首地址，`*cap` 是当前容量，下标 `0` 到 `*cap - 1` 可读写。
- `0 < n < *cap`：把容量缩到 `n`，下标 `0` 到 `n-1` 的元素保持原值和顺序，返回 `0`。
- `n == *cap`：容量不变，返回 `0`。
- `n == 0`：归还整块内存，`*a` 置为 `NULL`，`*cap` 置为 `0`，返回 `0`。
- `n < 0` 或 `n > *cap`：返回 `-1`，`*a`、`*cap` 和所有元素都不动。
- 缩小失败：返回 `-1`，原数组仍然可用。

### 示例

容量为 `8`，里面依次是 `0` 到 `7`。`trim_to(&a, &cap, 4)` 返回 `0`，容量变成 `4`，下标 `0` 到 `3` 仍是 `0`、`1`、`2`、`3`。再调用 `trim_to(&a, &cap, 0)`，容量归零，`a` 成为 `NULL`。

### 约定

- 只实现这个函数，不要写 `main`。
- 缩小用 `realloc`；前 `n` 个元素必须原样保留。
- 归还整块内存之后，调用者手里的指针已经是 `NULL`。
- 函数返回 `0` 时 `*cap` 一定等于 `n`；返回 `-1` 时三个值都不变。
