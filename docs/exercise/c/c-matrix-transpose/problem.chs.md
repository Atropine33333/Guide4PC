# 翻个面

**人话**：读入一个 `n` 行 `m` 列的整数矩阵，输出它的转置：共 `m` 行 `n` 列，原第 `i` 行第 `j` 列的数出现在新第 `j` 行第 `i` 列。

**输入**：第一行两个整数 `n`、`m`（`1 ≤ n, m ≤ 50`）。接下来 `n` 行，每行 `m` 个整数，每个整数的绝对值不超过 `1000`。

**输出**：`m` 行，每行 `n` 个整数，用单个空格分隔，行末不留空格。

### 示例

输入：

```text
2 3
1 2 3
4 5 6
```

输出：

```text
1 4
2 5
3 6
```

原来横着的三列，转过来成了竖着的三行。

### 约定

- 行数与列数互换：新矩阵是 `m` 行 `n` 列。
- 不要输出题面之外的文字。
- 每行末尾不要多打空格。
