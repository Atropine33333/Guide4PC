一行字里常常藏着看不见的字符：制表、回车、反斜杠、双引号。逐个点名，把它们写成看得见的记号。

**输入**：一行，长度不超过 `1000`，可以含空格；行尾的换行不算内容。

**输出**：一行记号，按原字符顺序排列，相邻记号之间用一个空格分隔。

- 换行写成 `\n`，制表符写成 `\t`，回车写成 `\r`。
- 反斜杠写成 `\\`，双引号写成 `\"`。
- 其余字符原样照抄。
- 空行没有字符可点名，输出一行空行。

### 示例

输入：

```text
a"b
```

输出：

```text
a \" b
```

### 约定

- 空格是普通字符，原样输出；它两侧各有一个分隔空格，所以看起来是一串空格。
- 读整行时把空格一并读进来，行尾的换行去掉。
- 行末不要有多余空格。
- 不要输出题面之外的文字。
