《商余法条》

第一条（适用范围）凡问 `a` 除以 `b` 的商与余数者，皆依本法条。

第二条（截断）商 `q` 取 `a / b`，向零截断：能整除时即精确商；不能整除时舍去小数部分，既不四舍五入，也不向负无穷取整。

第三条（余数）余数 `r` 取 `a % b`，恒满足 `a = q * b + r`，且 `|r| < |b|`。

第四条（符号）余数的符号与被除数 `a` 一致：`a` 为正时 `r` 不为负，`a` 为负时 `r` 不为正。除数为负，此条不改。

第五条（除尽）`a` 能被 `b` 整除时，`r` 为 `0`；`0` 不分正负。

第六条（小数被除数）`|a| < |b|` 时，`q` 为 `0`，`r` 等于 `a`。

第七条（输出）商与余数写在同一行，先后有序，以单个空格分隔。`b` 永不为 `0`。

**人话**：读入两个整数 `a`、`b`，按 C 的截断除法输出商 `a / b` 与余数 `a % b`，用单个空格分隔。

**输入**：一行两个整数 `a`、`b`，满足 `-10^9 ≤ a ≤ 10^9`、`-10^9 ≤ b ≤ 10^9`，且 `b ≠ 0`。

**输出**：一行两个整数，依次为商与余数，用单个空格分隔。

### 示例

输入：

```text
-7 3
```

输出：

```text
-2 -1
```

商向零截断为 `-2`；`-2 * 3 = -6`，故余数为 `-1`，与 `-7` 同号。

### 约定

- 商向零截断，余数与被除数同号。
- 输出行末不要有多余空格。
- `a`、`b` 均在 `int` 范围内，且 `b ≠ 0`，计算不会溢出。
- 不要输出题面之外的文字。
