《枚举编号条例》

第一条（适用范围） 本条例只管一个枚举：`enum E { A, B = 5, C, D = 2 };`

第二条（起算） 没有写赋值式的枚举量，其数值等于前一个枚举量加一；排在最前的那个从 `0` 起算。

第三条（明写） 写了赋值式的枚举量，其数值就是写下的那个数，与前一个的数值无关。

第四条（接续） 明写之后，再往后的枚举量沿着这个新数依次加一。

第五条（查询） 送进来一个由 `A`、`B`、`C`、`D` 组成的词，按字母出现的先后逐个给出它们的数值。

第六条（写法） 数值都是十进制整数，同一行内用单个空格分隔；第一个字母之前、最后一个字母之后不加空格。

第七条（篇幅） 词长为一到四，同一个字母可以重复出现。

**人话**：按上面的枚举规则算出 `A`、`B`、`C`、`D` 各自的整数值，再按输入字母的顺序把它们输出，用单个空格分隔。

**输入**：一行一个由 `A`、`B`、`C`、`D` 组成的词，长度为 `1` 到 `4`。

**输出**：一行若干个整数，个数与词的字母数相同，依次为每个字母对应枚举量的值，用单个空格分隔。

### 示例

输入：

```text
ABCD
```

输出：

```text
0 5 6 2
```

`A` 排在最前，从 `0` 起算；`B` 明写为 `5`；`C` 没写，接在 `5` 后面为 `6`；`D` 明写为 `2`，把接续的链改到了 `2`。

输入：

```text
DCBA
```

输出：

```text
2 6 5 0
```

### 约定

- 枚举量的值由声明顺序与赋值式共同决定，与字母表顺序无关。
- 明写的数值会打断加一，明写之后的枚举量从新数接着加。
- 输出行末不要有多余空格。
- 不要输出题面之外的文字。
