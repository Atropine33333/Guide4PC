【一条语句，两笔答案！】

还在为「从 1 加到 `n` 是多少、一共加了几项」写两段循环吗？

逗号运算符来了：它从左到右依次求值，只把最后一个式子的值留下。于是 `for` 的步进处可以同时办三件事——把这一项加进和、把项数添一、走到下一项。

一条语句收工，和与项数同时到手。

**人话**：读入 `n`，用逗号表达式在一条 `for` 语句里累加 `1` 到 `n` 的和并数出项数，输出和与项数。

**输入**：一行一个整数 `n`（`0 ≤ n ≤ 1000000`）。

**输出**：一行两个整数，用单个空格分隔：先和，后项数。

### 示例

输入：

```text
100
```

输出：

```text
5050 100
```

### 约定

- 和可能超过 `int` 的范围，用 `long long` 保存，打印用 `%lld`。
- `n` 为 `0` 时和与项数都是 `0`。
- 加法与计数放在同一个逗号表达式里，顺序从左到右。
- 输出行末不要有多余空格。
