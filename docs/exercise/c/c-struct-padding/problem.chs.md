轨道站的舱壁按字节分格。工程师把两块样品封进对齐舱：样品 A 是一格字符加一格整数，样品 B 在整数后面又多了一格字符。舱壁会在成员之间塞入看不见的垫块，好让每个 `int` 从四的倍数处开始。测量仪只肯报四个读数：A 占多少字节、B 占多少字节，以及 `i` 在 A 中、`d` 在 B 中的起始偏移。读数不出来，舱门就不开。

**人话**：定义 `struct A { char c; int i; }` 与 `struct B { char c; int i; char d; }`，输出 `sizeof(struct A)`、`sizeof(struct B)`、`offsetof(struct A, i)`、`offsetof(struct B, d)`，一行四个整数。

**输入**：无输入。

**输出**：一行四个整数，用单个空格分隔。

### 示例

输出：

```text
8 12 4 8
```

### 约定

- `char` 占 1 字节，`int` 占 4 字节，且 `int` 从 4 的倍数处开始。
- 空隙会出现在 `c` 与 `i` 之间，也会出现在 `d` 之后；`sizeof` 把这些空隙算进整体大小。
- 用 `<stddef.h>` 里的 `offsetof` 取成员偏移，用 `%zu` 输出四个值。
- 输出行末不要有多余空格。
