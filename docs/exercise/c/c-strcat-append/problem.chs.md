有两段文字：一段已经待在缓冲区里，另一段要接到它的尾巴上。缓冲区有固定的字节数，接得下就接，接不下就保持原样。

**人话**：实现 `append_str(buf, cap, s)`，把字符串 `s` 接到 `buf` 的末尾。容量够就接上并返回 `0`，结尾保留 `'\0'`；容量不够就返回 `-1`，`buf` 一个字也不改。

**接口**：

```c
#include <stddef.h>

int append_str(char *buf, size_t cap, const char *s);
```

- `buf` 里已经是一段以 `'\0'` 结尾的字符串，`cap` 是整个缓冲区的字节数，至少为 `1`。
- `s` 是以 `'\0'` 结尾的字符串，可以为空。
- 接得上（`strlen(buf) + strlen(s) + 1 <= cap`）：把 `s` 接在末尾，结果以 `'\0'` 结尾，返回 `0`。
- 接不上：`buf` 保持原样，返回 `-1`。

### 示例

`char buf[10] = "cat";` 之后调用 `append_str(buf, 10, "s")`，返回 `0`，`buf` 变成 `"cats"`。

`char buf[4] = "cat";` 之后调用 `append_str(buf, 4, "s")`，返回 `-1`，`buf` 仍是 `"cat"`：三个字符加结尾的 `'\0'` 再加一个 `s` 需要 `5` 个字节。

### 约定

- 只实现这个函数，不要写 `main`。
- 用 `strlen` 量出两段文字的长度。
- 成功时结果必须以 `'\0'` 结尾；失败时缓冲区内容不变。
- 不要输出任何文字。
