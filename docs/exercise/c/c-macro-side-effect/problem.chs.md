宏在预处理时只是把文本搬过去，括号落在哪里，搬完之后就是谁跟谁结合。`SQ(v)` 写成 `((v) * (v))`，于是 `SQ(x + 1)` 展开成 `((x + 1) * (x + 1))`，`SQ((x) + 1)` 展开成 `(((x) + 1) * ((x) + 1))`，两者结果相同。函数 `square` 先把参数算成一个值，再把这个值平方，结果同样是 `(x + 1) * (x + 1)`。

**人话**：读入 `x`，依次输出 `SQ(x + 1)`、`SQ((x) + 1)`、`square(x + 1)` 三个值，一行三个整数。

**输入**：一行一个整数 `x`，满足 `-100 ≤ x ≤ 100`。

**输出**：一行三个整数，用单个空格分隔。

### 示例

输入：

```text
2
```

输出：

```text
9 9 9
```

### 约定

- `#define SQ(v) ((v) * (v))`；`square` 是普通函数，签名为 `int square(int v)`。
- 宏体自带的括号让 `x + 1` 整体参与乘法；若宏体写成 `v * v`，`SQ(x + 1)` 就会展开成 `x + 1 * x + 1`。
- 宏对参数求值两次，函数只求值一次；本题的实参没有副作用，两边结果一致。
- 输出行末不要有多余空格。
