（牌师洗好一副牌，在桌上摆成方阵。她翻开第三张，女皇斜倚在宝座上；又翻开第十三张，死神提着镰刀。）

牌师说：“今晚只请皇后入座。方阵有几行，就请几位皇后，每位占一格；同一列、同一条斜线上不许有第二位，不然她们的眼光会撞在一起。”

她把牌收走，只留下一张空白方阵：“数一数，皇后们各安其位，一共能摆出多少种坐法。”

**人话**：读入 `n`，输出 n 皇后问题的解数，即 `n` 位皇后在 `n × n` 棋盘上两两不同行、不同列、不同对角线的摆法总数。

**输入**：一行一个整数 `n`（`1 ≤ n ≤ 10`）。

**输出**：一行一个整数，摆法总数；没有摆法时输出 `0`。

### 示例

输入：

```text
4
```

输出：

```text
2
```

四位皇后在 4 × 4 棋盘上恰好有两种互不攻击的摆法。

### 约定

- 每行恰好放一位皇后，所以摆法数量由列的选择决定。
- 皇后不能同行、同列，也不能在同一条主对角线或副对角线上。
- `n` 在 `1` 到 `10` 之间；答案最大为 `724`。
- 无解时输出 `0`。
- 输出行末不要有多余空格。
