（小剧场。台上摆着一排席子，甲蹲在边上看。）

甲：您这席子铺得齐整，一张挨一张，上头看着都干净。

乙：新到的货。要几张，报个数，我给您铺几张；铺出来张张干净，半点灰也没有。

甲：我自个儿拿货，可不敢保证干净。上一回铺开一领，底下印着上一位客人的脚印。

乙：您用 `malloc` 那路数，货是空的，灰还留在上头。我这儿用 `calloc`，交货之前先扫一遍，连缝里的灰都扫掉。

甲：那要是我说“来零张”呢？

乙：零张就没有席子。我给您个空手，您回头把空手还给我，我也不记账。

甲：听着不亏。那我要四千零九十六张呢？

乙：照样铺，张张干净，各占各的位置，互不串门。

甲：得嘞，题面我给您念念。

**人话**：实现 `zeros(n)`：申请 `n` 个 `int` 的位置，把每一格都置为零，返回首地址；`n` 为 `0` 时返回 `NULL`。用完之后由调用者 `free`。

**接口**：

```c
#include <stddef.h>

int *zeros(size_t n);
```

- `n > 0`：返回指向 `n` 个 `int` 的指针，每个元素都是 `0`；分配失败返回 `NULL`。
- `n == 0`：返回 `NULL`。
- 归还时对返回值调用 `free`；`free(NULL)` 什么也不做。

### 示例

`int *p = zeros(4);` 之后 `p[0]` 到 `p[3]` 都是 `0`；`zeros(0)` 得到 `NULL`。

### 约定

- 只实现这个函数，不要写 `main`。
- 使用标准库的动态分配，不要用固定大小的数组顶替。
- 返回的每一格都可读可写，写入一格不影响同一块里的其他格。
- 两次申请到的块互不相通，改动其中一块不会改到另一块。
