两个整数写得很长，长到 `long long` 也装不下。从最低位开始逐位相加，把进位一路往高位带，和就出来了。

**输入**：两行，每行一个非负十进制整数，只含数字，长度在 `1` 到 `1000` 之间；除了单独的 `0`，不含前导零。

**输出**：一行，两个数的和，不含前导零。

### 示例

输入：

```text
999999999999999999999
1
```

输出：

```text
1000000000000000000000
```

### 约定

- 输入不带正负号，只有数字。
- 两个数的位数可以不同。
- 和最多 `1001` 位；和为 `0` 时输出 `0`。
- 输出行末不要有多余空格。
- 不要用浮点数近似，也不要依赖 `long long`。
