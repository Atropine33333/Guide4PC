话说这一日，演武场上摆开一溜石锁，从第一尊到第 `n` 尊，尊尊相隔一丈，整整齐齐排成一行。

教头唤来两个伙计：一个守着第一尊，一个守着最后一尊。教头问：“你二人相隔几何？”

伙计甲拱手：“回教头，从第一尊到最后一尊，中间隔着 `n` 减一丈。”

教头把令旗一摆：“再取当中那尊，报上刻的号来。”

（惊堂木一拍，且听下回分解。）

**人话**：读入 `n` 与 `n` 个整数，输出两个值——`&arr[n - 1] - &arr[0]`（两个指针相减，得到相隔的元素个数）与 `arr[n / 2]`，中间用一个空格隔开。

**输入**：第一行一个整数 `n`（`1 ≤ n ≤ 100`）；第二行 `n` 个整数，每个都在 `-10^6` 到 `10^6` 之间。

**输出**：一行两个整数，依次为两个指针的距离与 `arr[n / 2]` 的值，用一个空格分隔。

### 示例

输入：

```text
5
10 20 30 40 50
```

输出：

```text
4 30
```

首尾两尊相隔 `5 - 1 = 4` 个位置；`n / 2` 为 `2`，下标 `2` 的石锁刻着 `30`。

### 约定

- 指针相减得到 `ptrdiff_t`，它的值是元素个数，打印时用 `%td`。
- 两个指针都指向同一个数组里的元素，相减结果不会溢出。
- 下标从 `0` 开始，`n / 2` 向下取整。
- `n` 为 `1` 时首尾是同一尊，距离为 `0`。
- 输出行末不要有多余空格。
