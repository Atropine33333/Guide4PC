一行字符串摆在面前，里面的整数要你亲手取出来。规则和标准库的 `atoi` 一样：跳过开头的空格，认一个可选的正负号，然后从左往右读连续的数字，读到第一个不是数字的字符就收手，后面的内容一概不管。一个数字都没读到时，结果是 `0`。

**人话**：把输入行开头的整数部分转成一个整数打印出来，转换规则与 `atoi` 相同。

**输入**：一行字符串，长度在 `1` 到 `200` 之间，行内可能含空格、字母和其他符号。

**输出**：一行一个整数，即按上述规则取到的值。

### 示例

输入：

```text
   -42abc
```

输出：

```text
-42
```

开头两个空格被跳过，`-` 是负号，接着读到 `42`，再往下遇到字母 `a` 便停下，后面的 `abc` 不再理会。

### 约定

- 取到的值保证落在 `int` 范围内，即 `-2147483648` 到 `2147483647`。
- 前导零不保留，`007` 与 `7` 是同一个值。
- 可以调用 `atoi`，也可以逐字符自己解析；两种做法结果一致。
- 输出行末不要有多余空格。
