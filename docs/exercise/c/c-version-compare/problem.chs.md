两个版本号并排摆在终端里。比较按段进行：从左往右，第一个不同的段决定大小；哪一段缺席，就当它写的是 `0`。段内的数字按十进制数值比较，`10` 比 `9` 大。

**输入**：两行，每行一个版本号。版本号只含数字和 `.`，由 `1` 到 `4` 段组成，段与段之间用一个 `.` 分隔；每段是 `0` 到 `1000000000` 的整数，允许前导零。

**输出**：一行，为 `-1`、`0` 或 `1` 之一：第一行小于、等于、大于第二行时分别输出 `-1`、`0`、`1`。

### 示例

输入：

```text
1.2
1.2.0
```

输出：

```text
0
```

输入：

```text
1.10
1.9
```

输出：

```text
1
```

### 约定

- 比较时把版本号看成 4 段，缺少的段补 `0`。
- 每段按整数大小比较，不能按字符串比较。
- 版本号只含数字和 `.`，不会出现空段、负号或其它字符。
- 行末可以有换行，也可以没有。
- 输出的行末不要有多余空格。
