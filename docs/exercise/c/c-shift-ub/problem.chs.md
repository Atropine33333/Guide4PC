《移位值班须知》

第一条 本机房只认无符号数。做左移之前，先把被移的数写成 `1u`。

第二条 移位数 `k` 限于 `0` 到 `31`。写到 `32` 或更大，这条须知就管不到你的结果了。

第三条 有符号的 `1` 移进最高位时，请重读第二条：结果不在本须知的担保之内。

第四条 每次值班抄两行数：第一行写 `1u << k` 与 `(1u << k) - 1`，用一个空格隔开；第二行写 `1u << 31` 的值。

**人话**：读入 `k`，第一行输出 `1u << k` 和 `(1u << k) - 1`，第二行输出 `1u << 31` 的值，也就是 `2147483648`。

**输入**：一行一个整数 `k`，满足 `0 ≤ k ≤ 31`。

**输出**：两行。第一行两个无符号十进制数，依次为 `1u << k` 与 `(1u << k) - 1`；第二行一个无符号十进制数，为 `1u << 31` 的值。

### 示例

输入：

```text
5
```

输出：

```text
32 31
2147483648
```

### 约定

- `1u` 是 `unsigned int` 字面量，`1u << 31` 得到 `2147483648`，能正常保存并输出。
- 有符号的 `1 << 31` 会移进符号位，左移量达到或超过 `32` 同样不可用；这两种写法都不要写进程序。
- `k` 为 `0` 时，`(1u << 0) - 1` 为 `0`。
- 用 `%u` 输出无符号十进制，行末不要有多余空格。
