读入若干行姓名与分数，按固定列宽排成一张表。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 50`）。
- 接下来 `n` 行，每行一个姓名和一个整数分数，中间用一个空格分隔。姓名只含小写字母，长度在 `1` 到 `10` 之间，不含空格；分数在 `-9999` 到 `9999` 之间。

**输出**：

第一行是表头 `name      score`。随后按输入顺序输出 `n` 行，每行的列宽与表头相同：

- 姓名左对齐，至少占 `8` 列，不足时在右侧补空格；
- 姓名之后空 `2` 列；
- 分数右对齐，占 `5` 列，不足时在左侧补空格。

姓名超过 `8` 个字符时原样输出，不截断，分数仍紧跟在两个空格之后。行末不要有多余空格。

### 示例

输入：

```text
3
alice 120
bob -42
cara 7
```

输出（为了看清空格，下面用 `·` 表示一个空格）：

```text
name······score
alice·······120
bob·········-42
cara··········7
```

实际输出中 `·` 是普通空格。

### 约定

- 表头同样按上述列宽排布：`name` 左对齐占 `8` 列，空 `2` 列，`score` 右对齐占 `5` 列。
- 姓名正好 `8` 个字符时，其后仍要空 `2` 列再写分数。
- 分数正好占满 `5` 列时不再补空格。
- 使用 `printf` 的字段宽度控制对齐，不要手工拼空格。
- 除每行末尾的换行外，不要输出空行。
