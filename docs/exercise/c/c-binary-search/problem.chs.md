一本按升序排好的号码簿，要找的号若在其中，就翻到它所在的那一页；不在，便报一个 `-1`。簿子很厚，逐页翻太慢，于是每次翻到正中间：要找的比中间小，就只往左半本看；比中间大，就只往右半本看。范围一次减半，几步就见了分晓。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 200000`）。
- 第二行 `n` 个整数，严格递增，相邻两个用一个空格分隔，每个都在 `-10^9` 到 `10^9` 之间。
- 第三行一个整数 `key`，同样在 `-10^9` 到 `10^9` 之间。

**输出**：一行一个整数：`key` 在数列中的下标（从 `0` 开始）；若数列中没有 `key`，输出 `-1`。

### 示例

输入：

```text
7
1 3 5 7 9 11 13
9
```

输出：

```text
4
```

`9` 排在第五个，下标为 `4`。

### 约定

- 数列严格递增，没有重复元素，所以下标唯一。
- 下标从 `0` 开始。
- 找不到时只输出 `-1`，不要输出别的内容。
- `n` 最多 20 万，二分把比较次数压到二十次上下。
- 输出行末不要有多余空格。
