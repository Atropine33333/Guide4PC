一串整数排成一行，你要报出两件事：它们的总和，以及其中最大的那个。数字可能全是负数，也可能重复，最大的那个只报一次。

**人话**：读入整数 `n`，再读入 `n` 个整数，输出这 `n` 个数的总和与最大值，用一个空格分隔。

**输入**：第一行一个整数 `n`（`1 ≤ n ≤ 1000`）；第二行 `n` 个整数，每个满足 `-10^6 ≤ a[i] ≤ 10^6`。

**输出**：一行两个整数，先是总和，再是最大值，用一个空格分隔。

### 示例

输入：

```text
5
3 -1 7 7 2
```

输出：

```text
18 7
```

五个数加起来是 `18`，最大的是 `7`（出现两次，只报一次）。

### 约定

- `n ≥ 1`，数组里至少有一个元素。
- 总和可能超过 `int` 的范围，用足够宽的整数类型保存。
- 从第一个元素开始逐个访问到最后一个，边界不要多走一步。
- 行末不要再输出空格。
