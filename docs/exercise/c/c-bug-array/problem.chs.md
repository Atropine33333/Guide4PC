`starter.c` 里有两个读数组的函数，边界都多算了一格。

`sum_array` 该把 `a[0]` 到 `a[n-1]` 加起来，现在会多读一个 `a[n]`，和因此偏大。`last_value` 该返回最后一个元素 `a[n-1]`，现在返回的是紧跟在数组后面的那个数。

请把这两处改对。

**人话**：`sum_array` 求数组前 `n` 个元素的和，`n` 为 `0` 时返回 `0`；`last_value` 返回下标 `n-1` 处的元素。两个函数都只能碰 `a[0]` 到 `a[n-1]` 这 `n` 个元素。

**接口**：

```c
int sum_array(const int *a, int n);
int last_value(const int *a, int n);
```

- `sum_array`：返回 `a[0] + ... + a[n-1]`；`n` 为 `0` 时返回 `0`，这时一个元素也不读。
- `last_value`：返回 `a[n-1]`；调用时 `n` 至少为 `1`。
- `a` 后面紧跟的那一格不属于这个数组，读它没有意义。

### 示例

```c
int data[5] = {3, 1, 4, 1, 5};
sum_array(data, 5);   /* 14 */
last_value(data, 5);  /* 5 */
```

### 约定

- 只改这两个函数的实现，不要写 `main`。
- `n` 在 `0` 到 `1000` 之间，元素的绝对值不超过 `1000`。
- 每个元素最多加一次，不要重复计数。
