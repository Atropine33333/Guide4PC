话说大营夜半拔寨，文书官接了一桩差：照抄 `n` 个字。

点卯先验令箭：文书没到（`s` 为空指针），或字数是个负数，便是差事不成，当即收兵回营。

差事办成，也得留后路：中途粮草不济（内存不够），同样收兵回营，绝不把半截营帐丢在野地里。

营门只留一处：所有退路都走同一个 `goto cleanup`，到了那里，该放的放、该还的还，干干净净。

**人话**：实现 `dup_n`——`s` 为空指针或 `n < 0` 时返回 `NULL`；否则申请 `n + 1` 字节，复制至多 `n` 个字符，遇到源串结束就停，末尾补 `'\0'`，返回这块新内存。

**接口**：

```c
char *dup_n(const char *s, int n);
```

- `s` 为空指针，或 `n` 为负数：返回 `NULL`，不申请内存。
- 申请失败：返回 `NULL`。
- 成功：返回以 `'\0'` 结尾的新字符串，长度不超过 `n`，内容取自 `s` 的前缀。

### 示例

`s` 为 `"hello"`、`n` 为 `3` 时，返回的新字符串是 `"hel"`；`n` 为 `5` 时是 `"hello"`；`n` 为 `8` 时仍是 `"hello"`，因为抄到源串结束就停。

### 约定

- 复制时不得越过源字符串的 `'\0'`，也不得修改源字符串。
- 成功返回的内存由调用者用 `free` 释放。
- 所有失败退路汇到同一处清理，再返回 `NULL`。
- 这些函数会被直接调用，请只实现 `dup_n`，不要写 `main`。
