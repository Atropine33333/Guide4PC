《三目评级器 使用说明》

一、用途　把百分制分数折成 A、B、C、D、F 五档。

二、操作　在输入口送入一个 `0` 到 `100` 的整数，按一次回车，屏幕上即出现对应的档位字母。

三、刻度　`90` 及以上为 A；`80` 到 `89` 为 B；`70` 到 `79` 为 C；`60` 到 `69` 为 D；`60` 以下为 F。

四、内部结构　机身里只有一条嵌套三目表达式，从高档往低档依次判断，第一个成立的条件就是结果。

五、注意　边界值归入较高的那一档：`90` 是 A，`89` 是 B，其余照此类推。

**人话**：读入一个 `0` 到 `100` 的分数，用嵌套三目表达式判断档位，输出一个大写字母。

**输入**：一行一个整数 `score`（`0 ≤ score ≤ 100`）。

**输出**：一行一个大写字母，取值为 `A`、`B`、`C`、`D`、`F`。

### 示例

输入：

```text
89
```

输出：

```text
B
```

### 约定

- 用一条嵌套三目表达式完成判断，分支条件从高到低排列。
- 每一档包含它的下界，不包含上一档的下界。
- 输出只有一个字母和换行，行末不要有多余空格。
