《只读测量接口说明书》

§1 用途
本接口量一条以 `'\0'` 结尾的字符序列有多长。量的时候只看，不改。

§2 原型

```c
size_t str_len(const char *s);
```

§3 参数
`s` 指向待测序列的首字符。调用方允许传入 `NULL`，也允许传入字符串字面量。

§4 返回值
从 `s` 起数到第一个 `'\0'` 之前的字符个数；`s` 为 `NULL` 时返回 `0`。

§5 只读承诺
实现不得通过 `s` 写入任何字符。字面量、`const` 数组、普通数组都可以直接传进来，调用方不必另外复制一份可写缓冲区。

§6 调用方式
这些函数会被直接调用，请只实现函数，不要写 `main`。

**人话**：实现 `size_t str_len(const char *s)`，返回字符串的长度；`s` 为 `NULL` 时返回 `0`，且全程不修改 `s` 指向的内容。

**接口**：`size_t str_len(const char *s);`

### 示例

```c
str_len("hello")                 // 5
str_len("")                      // 0
str_len(NULL)                    // 0
char buf[4] = "abc"; str_len(buf) // 3，buf 仍是 "abc"
```

### 约定

- 只统计 `'\0'` 之前的字符，`'\0'` 本身不算。
- `NULL` 必须先判掉，再去访问首字符。
- 不写 `main`，这个函数不需要任何输入输出。
- 只用标准库，不需要动态分配。
