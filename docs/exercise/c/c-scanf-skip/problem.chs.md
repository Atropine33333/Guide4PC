一行里塞着两段赋值，空格和逗号随手乱放。别去数它们的位置，让 `scanf` 自己跳过这些噪音，把两个整数读出来相加。

**输入**：一行，形如 `a=<整数> b=<整数>`。字母 `a`、`b` 与等号之间允许有空格，等号与数字之间也允许有空格；两段赋值之间的分隔符是一个及以上空格或逗号，两者可以混用。两个整数都可以为负，绝对值不超过 `10^9`。

**输出**：一行一个整数，等于两个整数之和。

### 示例

输入：

```text
a = 12 , b = -30
```

输出：

```text
-18
```

### 约定

- 用一次 `scanf` 调用把两个整数都读进来。
- 分隔符的数量与种类都不固定，不要在格式串里写死几个空格或几个逗号。
- 两个数的和也在 `int` 范围内，不会溢出。
- 行末不要有多余空格，也不要输出题面之外的文字。
