有人收果子，一筐一筐地记。筐里可能装着两件，可能只装了一件，也可能一件没有；他只想知道：这一回到底收成几件。

**人话**：写一个函数 `read_pair`，从字符串 `s` 里按整数的样式读最多两个数，返回真正读到的个数。读到的值写进 `a`、`b`；没读到的那个位置保持原样。

**接口**：

```c
int read_pair(const char *s, int *a, int *b);
```

- 返回 `0`、`1` 或 `2`，表示成功读入的整数个数。
- 两个整数之间用空白分隔，前后多余的空白要跳过。
- 只有成功读到的值才写入 `*a`、`*b`；没读到的那一个不写，调用者原来的值保持不变。
- `s` 是 `NULL` 时返回 `0`，两个位置都不动。

### 示例

`read_pair("12 34", &a, &b)` 返回 `2`，`a` 得 `12`，`b` 得 `34`。

`read_pair("42", &a, &b)` 返回 `1`，`a` 得 `42`，`b` 保持原值。

`read_pair("apple", &a, &b)` 返回 `0`，两个位置都不动。

### 约定

- 用 `sscanf` 完成读入；一个数都没读到时它可能返回负值，要把这个结果归一成 `0`。
- 只需要实现这一个函数，不要写 `main`。
- 这些函数会被直接调用，用编译好的代码检查返回值与写出的值。
