**人话**：`starter.c` 里的程序要读入 `n` 个整数并输出它们的和。它每次都漏掉最后一个数，所以结果偏小。把这一处改对，让输出正确。

**输入**：第一行一个整数 `n`（`1 ≤ n ≤ 200000`）；第二行 `n` 个整数，每个的绝对值不超过 `10^9`，用单个空格分隔。

**输出**：一行，这 `n` 个数的和。

### 示例

输入：

```text
3
2 -5 10
```

输出：

```text
7
```

### 约定

- 和可能超出 32 位整数范围，用 `long long` 保存。
- 只改坏掉的那一处，输入输出的格式保持不变。
- 输出一行，末尾换行。
