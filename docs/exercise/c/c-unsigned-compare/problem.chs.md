《下行守则》

夜里的楼只剩下行。守则四则，贴在楼梯口：

一、纸条上有一个整数 `n`，`1 ≤ n ≤ 10`。没有纸条，就不要下楼。
二、从 `n` 开始向下报数：`n`、`n-1`，一直报到 `1`，一个也不许漏。
三、相邻两个数之间只隔一个空格，报完 `1` 立刻停。楼里没有 `0` 层。
四、第四条不要读。你已经在往下走了。

**人话**：读入整数 `n`，从 `n` 递减到 `1` 依次输出，数字之间用一个空格分隔。

**输入**：一行一个整数 `n`，`1 ≤ n ≤ 10`。

**输出**：一行，从 `n` 到 `1` 的数字，相邻两个之间用一个空格分隔，行末不留空格。

### 示例

输入：

```text
5
```

输出：

```text
5 4 3 2 1
```

### 约定

- `n` 至少为 `1`，所以 `1` 一定会被报到。
- 行末不要再输出空格。
- 除这一行数字外，不要输出别的内容。
