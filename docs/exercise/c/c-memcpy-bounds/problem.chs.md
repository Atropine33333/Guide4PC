（货场边，一辆小车停着，车斗里一格一格隔开。）

甲：这车能装几格？

乙：车斗里一共 `cap` 格，最后一格得空着放封条，所以货最多占 `cap - 1` 格。

甲：货有 `n` 件呢？

乙：装得下多少装多少。货比地方多，就装到封条前一格；货比地方少，就全装。装完在下一格打上封条。

甲：要是连一格都没有呢？

乙：那就不动手，一件也不装，封条也不贴。

**人话**：实现 `copy_capped(dst, cap, src, n)`，从 `src` 复制 `n` 字节到 `dst`，最多复制 `cap - 1` 字节，末尾写一个 `'\0'`，返回复制的字节数（不含 `'\0'`）。`cap` 为 `0` 时一个字节也不写，返回 `0`。

**接口**：

```c
#include <stddef.h>

size_t copy_capped(char *dst, size_t cap, const char *src, size_t n);
```

- `dst` 至少有 `cap` 字节可写，`src` 至少有 `n` 字节可读。
- `cap == 0`：返回 `0`，`dst` 一个字节也不改。
- `cap > 0`：复制 `min(n, cap - 1)` 个字节，紧接着写一个 `'\0'`，返回复制的字节数。
- 复制按字节进行，`src` 中间的 `'\0'` 照抄，复制到第 `n` 字节就停。
- `dst` 下标 `cap` 及其后面的内容不改动。

### 示例

```c
char dst[4];
size_t r = copy_capped(dst, 4, "abcdef", 6);
/* dst 的前四个字节是 'a'、'b'、'c'、'\0'，r 为 3 */
```

容量是 `4`，封条占最后一格，货只能占三格；货有六件，只搬前三件。

### 约定

- 只实现这个函数，不要写 `main`。
- 只用标准库设施。
- 不越界写 `dst`：最多写到下标 `cap - 1`。
- 不越界读 `src`：最多读到下标 `n - 1`。
- 返回值为 `size_t`，等于实际复制的字节数。
