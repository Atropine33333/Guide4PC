`int arr[10]` 是一把固定长度的尺子：往里放几个数，它都还是十格。读入若干整数放进这把尺子，再报出它有几格、每格多宽。

**输入**：一行，先是一个整数 `n`（`1 ≤ n ≤ 10`），随后是 `n` 个整数，依次放进 `int arr[10]` 的前 `n` 格。

**输出**：一行两个整数，用单个空格分隔：`sizeof(arr) / sizeof(arr[0])` 的值，以及 `sizeof(int)` 的值。

### 示例

输入：

```text
3 5 -1 0
```

输出：

```text
10 4
```

### 约定

- 数组的格数由声明决定，与这次填了几个数无关。
- 只在 `arr` 仍是数组的地方用 `sizeof`，不要把它传进函数再量。
- 两个结果都转成 `int` 再用 `%d` 打印。
- 本题的输出按 `int` 占 4 字节的平台给出；别的平台上第二个数会随编译器变化。
- 输出行末不要有多余空格。
