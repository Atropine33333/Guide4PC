一个八位无符号累加器，初值为 `0`。依次读入 `n` 个整数，每读入一个就加到累加器上。累加器只能存 `0` 到 `255`：结果超过 `255` 时高位被丢弃，数值从 `0` 重新开始（即对 `256` 取模）。每加完一个数，输出当前的累加值。

**输入**：第一行一个整数 `n`（`1` ≤ `n` ≤ `1000`）。随后是 `n` 个整数，每个在 `0` 到 `255` 之间，用空白分隔，可以写在一行或多行。

**输出**：共 `n` 行。第 `i` 行是加上第 `i` 个数之后的累加值，范围 `0` 到 `255`，十进制，不带前导零。

### 示例

输入：

```text
3
200 100 56
```

输出：

```text
200
44
100
```

### 约定

- 累加变量必须用 `uint8_t`，初值 `0`。
- 每次加法在赋回 `uint8_t` 时按 `256` 取模；例如 `200 + 100 = 300`，赋回后是 `44`。
- 每个累加值单独一行，行末换行。
- 不补前导零，不加正负号。
