读入 `n` 对整数，逐对求它们的和。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 100`）。
- 接下来 `n` 行，每行两个整数 `a` 和 `b`，用单个空格分隔。两数都可以为负，绝对值不超过 `10^9`。

**输出**：`n` 行，每行一个整数，等于对应那一对的 `a + b`。

### 示例

输入：

```text
3
2 3
-5 -7
0 12
```

输出：

```text
5
-12
12
```

### 约定

- 每行只输出一个和，行末不要有多余空格。
- 和的绝对值不超过 `2 × 10^9`；用能容纳这个范围的整数类型保存即可。
- 输出顺序与输入行一一对应。
- 不要合并相同的和，也不要跳过任何一行。
