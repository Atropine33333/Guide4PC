把 32 位无符号整数打包成四个字节，有两种排法：小端把最低有效字节放在最前面，大端把最高有效字节放在最前面。本题按小端打包：先读入一个十进制无符号整数，再用移位与掩码把它的四个字节拆开，从低到高依次输出，每个字节写成两位大写十六进制。

**输入**：一行一个十进制无符号整数 `n`，满足 `0 ≤ n ≤ 4294967295`。

**输出**：一行四个两位大写十六进制字节，按小端次序排列，用单个空格分隔：最先输出最低有效字节，最后输出最高有效字节。

### 示例

输入：

```text
305419896
```

输出：

```text
78 56 34 12
```

`305419896` 等于 `0x12345678`：最低字节 `0x78` 在最前，最高字节 `0x12` 在最后。

### 约定

- 用 `uint32_t` 保存读入的值，用 `SCNu32` 宏拼出 `scanf` 的格式串。
- 第 `i` 个输出的字节（`i` 从 `0` 到 `3`）等于 `(value >> (8 * i)) & 0xFF`。
- 每个字节用 `%02X` 输出，至少两位，字母大写。
- 本题按小端规则显式打包，结果与机器本身是大端还是小端无关；不要通过指针读取内存里的字节。
- 输出行末不要有多余空格。
