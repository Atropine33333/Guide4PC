两个 `int` 摆在一起做乘法，结果先按 `int` 的宽度算，装不下的高位就丢了。想留住每一位，得请 `long long` 出场。

**人话**：读入两个整数，输出它们的乘积。乘积按 64 位有符号整数计算，中间结果不要停在 `int` 的宽度上。

**输入**：一行两个整数 `a`、`b`，满足 `-10^9 ≤ a ≤ 10^9`、`-10^9 ≤ b ≤ 10^9`。

**输出**：一行一个整数，即 `a * b` 的精确值。

### 示例

输入：

```text
100000 100000
```

输出：

```text
10000000000
```

`10^10` 已经超出 32 位 `int` 的范围，乘法要用 64 位来算。

### 约定

- 先把 `a` 转成 `long long` 再乘：`(long long)a * b`。
- 乘积最大到 `10^18`，`long long` 装得下。
- 输出用 `%lld`。
- 输出行末不要有多余空格。
