【远程补给站 · 值班日志】

补给站只剩一块八位的货舱编号牌，牌子被切成三格：

舱门一位，`0` 是开，`1` 是锁。
人数档两位，`0` 到 `3`。
氧气五位，`0` 到 `31`。

三格从低位往高位排：舱门占最右一位，人数档接在后面两位，氧气占最左五位，加起来正好八位。

登记员只做两件事：把三格写进编号牌，或者按牌上的八位把三格读回来。牌子之外多出来的位一律退回，原牌不动。

**人话**：实现下面这组函数，把三个位域字段（1 位、2 位、5 位）按声明顺序打包成一个 8 位数，也能把这个 8 位数拆回三个字段；越界的值一律拒绝。

**接口**：

```c
#define FLAGS_WORD_MAX 0xFFu

typedef struct {
    unsigned int a : 1;
    unsigned int b : 2;
    unsigned int c : 5;
} Flags;

void flags_init(Flags *f);
int flags_set(Flags *f, char which, unsigned value);
unsigned flags_get(const Flags *f, char which);
unsigned flags_pack(const Flags *f);
int flags_unpack(Flags *f, unsigned word);
```

- `flags_init`：三个字段全部清 `0`。
- `flags_set`：`which` 取 `'a'`、`'b'`、`'c'`，分别接受 `0..1`、`0..3`、`0..31`；写入成功返回 `0`。值越界或字段名不认识时返回 `-1`，结构体保持原样。
- `flags_get`：返回字段当前的值；字段名不认识时返回 `0`。
- `flags_pack`：把三个字段按 `a` 在第 0 位、`b` 在第 1 到 2 位、`c` 在第 3 到 7 位的次序拼成一个 8 位数返回。
- `flags_unpack`：`word` 不超过 `FLAGS_WORD_MAX` 时按同样的位序写进三个字段并返回 `0`；超过时返回 `-1`，结构体保持原样。

### 示例

依次写入 `a = 1`、`b = 2`、`c = 5`，打包得到 `1 + 4 + 40 = 45`；再拆 `45`，读回来正是 `a = 1`、`b = 2`、`c = 5`。

把 `b` 写到 `4` 会被退回，打包结果仍是 `45`。

### 约定

- 结构体声明与函数签名保持原样，这些函数会被直接调用。
- 三个字段共用一块存储，位宽依次为 1、2、5，按声明顺序从低位往高位排。
- 打包结果只占低 8 位，高位一律不收。
- 越界写入不改变结构体里原有的值。
- 只使用标准库，不要写 `main`。
