一行里有 `x=...` 和 `y=...` 两段赋值，逗号与空格的位置不固定。先把整行读成字符串，再用 `sscanf` 从这串里把两个整数抠出来。

**输入**：一行，形如 `x=<整数>,y=<整数>`。字母 `x`、`y` 与等号之间，等号与数字之间，逗号两侧，都允许有空格，也可以完全没有；逗号必须有。两个赋值按 `x` 在前、`y` 在后的顺序出现。

**输出**：一行一个整数，等于 `x + y`。

### 示例

输入：

```text
x = -4 , y = 9
```

输出：

```text
5
```

### 约定

- 先用 `fgets` 把整行读成字符串，再用 `sscanf` 解析。
- 空格可多可少，字母、等号、逗号的先后顺序固定。
- 两个数都在 `int` 范围内，和也在 `int` 范围内。
- 行末不要有多余空格。
