一个 `m` 行 `n` 列的矩阵，大部分格子是 `0`。只记非零的位置：每个非零元素写成一行三元组 `行 列 值`，行列都从 `0` 开始编号。转置之后，原来的第 `r` 行第 `c` 列，变成新矩阵的第 `c` 行第 `r` 列，值不变。

**输入**：第一行三个整数 `m`、`n`、`k`，依次为行数、列数与非零元素个数。随后 `k` 行，每行三个整数 `r c v`，表示第 `r` 行第 `c` 列的值为 `v`。

**输出**：第一行三个整数 `n`、`m`、`k`，依次为转置后的行数、列数与非零元素个数。随后 `k` 行，每行三个整数 `c r v`：新行号、新列号、值。所有三元组按新行号升序排列，同一新行内按新列号升序排列。

### 示例

输入：

```text
3 4 4
0 1 5
1 3 -2
2 0 7
2 2 9
```

原来的 `0` 行 `1` 列是 `5`，转置后落在 `1` 行 `0` 列；原来的 `1` 行 `3` 列是 `-2`，落在 `3` 行 `1` 列；`2 0 7` 与 `2 2 9` 分别落在 `0 2` 与 `2 2`。

输出：

```text
4 3 4
0 2 7
1 0 5
2 2 9
3 1 -2
```

### 约定

- `1 ≤ m, n ≤ 500`，`0 ≤ k ≤ 1000`。
- 输入里的三元组不保证有序；同一个 `(r, c)` 最多出现一次。
- `v` 不为 `0`，且 `|v| ≤ 10^9`。
- 输出行末不要有多余空格，也不要输出题面之外的文字。
