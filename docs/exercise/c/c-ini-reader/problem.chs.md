一份简化的配置文件，形如 `键=值`，每行一条。读入之后要丢掉注释与空行，抹平键和值两边的空白，重复的键只留最后一次的值，最后按键的字典序输出。

**输入**：

- 从标准输入读到文件结束，每行一个条目，可能带行首行尾的空格或制表符。
- 行首第一个非空白字符是 `#` 的行是注释，整行跳过。
- 没有 `=` 的行跳过。
- 在第一个 `=` 处切成键与值；键或值两边剩下的空格与制表符都去掉。
- 键为空的行跳过。
- 同一个键出现多次时，以最后一次的值为准。
- 有效条目最多 100 条，键最多 31 个字符，值最多 63 个字符，单行最多 200 个字符。

**输出**：

- 每条有效条目一行，写成 `键=值`。
- 按 `strcmp` 对键升序排列。
- 值可以为空，此时行尾就是 `=`。
- 没有任何有效条目时，什么都不输出。

### 示例

输入：

```
# 备注
b = 2
a = 1
a = 7
```

输出：

```
a=7
b=2
```

### 约定

- 只使用标准库，用 `fgets` 逐行读入。
- 键与值分别存进固定大小的数组，不要动态分配。
- 输出只包含条目行，每行以换行收尾。
