> 洛书出而九宫定，
> 纵横斜路十五同；
> 一自中宫南面起，
> 右上升阶莫撞锋。

古有洛书：一居下中，九居上顶，纵横斜三路，其和皆十五。今有方阵一区，边长 `n`，欲以 `1` 至 `n²` 之数各居其一，使每行、每列、两对角线之和相等。

**人话**：实现函数 `magic_square(n)`，返回按行展开的 `n × n` 幻方；`n` 为正奇数时构造任意一个合法幻方，其余情况返回空数组。

```cpp
#include <vector>

std::vector<int> magic_square(int n);
```

返回按行展开的 `n × n` 方阵：包含 `1` 到 `n²` 的每个整数恰好一次，并且每一行、每一列、两条主对角线的和都相等。

**要求**：

- `n` 为正奇数时，构造任意一个合法的幻方。
- `n` 为负数、`0` 或偶数时，返回空的 `std::vector<int>`。
- 返回值的长度必须恰好是 `n * n`，按行主序排列。
- 不要写 `main`。

### 示例

`n = 3` 时一种结果是：

```text
8 1 6
3 5 7
4 9 2
```

### 约束

- `0 ≤ n ≤ 15`，但题目约定只对正奇数构造幻方。
- 幻方的行和等于 `n × (n² + 1) / 2`，在 `int` 范围内。

### 术曰

可以用 Siamese 方法：把 `1` 放在第一行中间，之后每次向右上走一格，越界就回绕；如果目标格已被占用，则改为从当前格向下一格放置。
