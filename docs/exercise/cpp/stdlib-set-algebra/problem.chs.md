给定两个非递减的整数序列，它们可能含有重复元素。把每个序列看成集合，输出并集、交集和差集（第一个序列减去第二个序列），结果按升序去重。

### 输入

- 第一行两个整数 `n` 和 `m`（`0 ≤ n, m ≤ 100000`），分别是两个序列的长度。
- 第二行 `n` 个非递减整数，构成序列 A。
- 第三行 `m` 个非递减整数，构成序列 B。

当长度为 0 时，对应行是空行。

### 输出

三行，依次是并集、交集、A 减 B 的结果。每行内的整数按升序排列，相邻两个之间用一个空格分隔。如果结果为集合空，输出 `empty`。

### 示例

输入：

```
3 3
1 3 5
2 3 4
```

输出：

```
1 2 3 4 5
3
1 5
```

### 约束

- 两个序列都已经按非递减顺序给出。
- 同一个序列中可能有重复值，输出中每个值只出现一次。
- `n, m` 之和可能达到 `200000`，不要对每一对元素逐一比较。
