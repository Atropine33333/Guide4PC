（深夜，古堡书房。老管家捧来一只天鹅绒盒子，盒里恰好两个位置。）

管家：哦，我亲爱的先生，这是给两位客人预备的盒子。左边一位，右边一位，谁也不能坐错。

主人：老天爷，就两个位置，还分左右？

管家：当然，先生。您把左边那位请出来，那个位置就空着；要换位置，我们另备一只盒子，请两位对调，原来那只盒子纹丝不动。

主人：要是两位客人一模一样呢？

管家：哦，那他们就相等，先生。相等的人坐哪边都一样，可我们仍旧要照规矩说一声“相等”。判断相等，两个位置都得比过。

主人：盒里的人能读，能改吗？

管家：能读，也能改，先生。盒面上写着 `first()` 与 `second()`，各备两把钥匙：一把给寻常客人，一把给只许观看的客人。

主人：空盒子呢？

管家：空盒子也生得出来，先生。两个位置先摆上默认的值，等客人来了再坐。

**人话**：实现类模板 `Pair<T>`，按下列条款提供默认构造、带两个值的构造、`first()` / `second()` 的 `const` 与非 `const` 版本、`swapped()` 和 `operator==`。

- `Pair()`：两个元素值初始化。
- `Pair(const T& first, const T& second)`：按给定值构造。
- `T& first()` / `const T& first() const`：访问第一个元素，两个重载都要有。
- `T& second()` / `const T& second() const`：访问第二个元素，两个重载都要有。
- `Pair<T> swapped() const`：返回一个新数对，两个元素交换位置，原数对不变。
- `bool operator==(const Pair<T>& other) const`：两个元素都相等时返回 `true`。

`T` 会是 `int`、`std::string` 或 `Pair<int>`；`const` 对象也必须能读取元素。
