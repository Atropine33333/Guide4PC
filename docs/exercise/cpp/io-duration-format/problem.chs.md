**人话**：实现 `std::string format_duration(long long total_seconds)`，把秒数格式化成 `H:MM:SS`；`H` 不补前导零，`MM`、`SS` 恰好两位，`total_seconds` 保证非负。

### 示例

- `0` 输出 `0:00:00`
- `3599` 输出 `0:59:59`
- `3600` 输出 `1:00:00`
- `86399` 输出 `23:59:59`
- `360000` 输出 `100:00:00`

### 约束

- `H` 可以超过 99，不补前导零。
- `MM` 和 `SS` 必须是恰好两位，不足补 `0`。
- 不要写 `main`。
