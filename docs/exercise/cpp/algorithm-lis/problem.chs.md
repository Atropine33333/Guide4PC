这一题不读 stdin，也不写 stdout。求一个整数序列的最长严格上升子序列长度，测试在隐藏的 harness 里。

```cpp
#include <vector>

int lis_length(const std::vector<int>& values);
```

规则：

- 子序列不要求连续，但要保持原顺序。
- 严格上升：后一个元素必须严格大于前一个，相等不算上升。
- 空序列返回 0，单元素序列返回 1。
- 序列长度可以达到 `2·10^5`，`O(n^2)` 的写法会超时，请用 `O(n log n)` 的解法。
- 不要写 `main`。

### 示例

| 调用 | 结果 |
| --- | --- |
| `lis_length({10, 9, 2, 5, 3, 7, 101, 18})` | `4` |
| `lis_length({1, 2, 3})` | `3` |
| `lis_length({2, 2, 2})` | `1` |

### 提示

维护一个数组 `tails`，其中 `tails[k]` 是所有长度为 `k + 1` 的上升子序列里最小的结尾值。`tails` 本身严格递增，对每个元素用 `std::lower_bound` 找到第一个不小于它的位置并替换，答案就是 `tails` 的长度。
