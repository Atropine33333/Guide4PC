《C++ 运算符优先级法典》

第一条（目的）为明确省略括号时各运算符的结合次序，制定本法典。

第二条（乘法）在 `a + b * c` 中，乘法先于加法，等价于 `a + (b * c)`。

第三条（括号）在 `(a + b) * c` 中，括号内的加法先行。

第四条（移位与减法）在 `a << b - 1` 中，减法先于左移，等价于 `a << (b - 1)`。

第五条（位与、异或）在 `a & b ^ c` 中，位与先于异或，等价于 `(a & b) ^ c`。

第六条（关系与相等）在 `a < b == c > a` 中，关系运算先于相等比较，等价于 `(a < b) == (c > a)`。

第七条（一元负号）在 `-a * -b` 中，一元负号先于乘法，等价于 `(-a) * (-b)`。

第八条（减法结合性）在 `a - b - c` 中，减法左结合，等价于 `(a - b) - c`。

第九条（条件运算符）在 `a ? b : c` 中，条件运算符右结合；本题只含一个条件运算符。

第十条（附则）本法典未规定之处，以 C++ 标准为准。各表达式不得擅自添加括号，亦不得援引其他语言的习惯。

**人话**：读入 `q a b c`，按 C++ 的运算符优先级和结合性，算出第 `q` 个表达式的值；不要自己加括号。所有中间结果都在 `int` 范围内，不会溢出。

### 输入

一行四个整数 `q a b c`，满足 `1 <= q <= 8`，`1 <= a, b, c <= 9`。

### 输出

一行，第 `q` 个表达式的值。

### 示例

输入：

```text
4 2 3 4
```

输出：

```text
6
```

### 约束

- 所有中间结果都在 `int` 范围内，不会溢出。
- `a << b - 1` 中的 `b - 1` 在 0 到 8 之间，不会产生未定义行为。
- 只使用标准库；不要输出题面之外的文字。
