**第一章**

那时，有人来到记分的人面前，说：「给我记上四分。」记分的人便写了四分。那人又来，说：「再记六分。」记分的人把六分加在四分之上，册上写着十分。天国好像一个忠心的记分人：同一个人来几回，账就累几回，一分也不短少。

又有人问：「两个人总分相同，谁坐首座？」经上说：名字在前的那位先受召。并列之时，取字典序最小的名字；总分更高的，才谈得上首座。

又有人问：「册子空空，首座是谁？」记分的人回答：「册上无名，首座便无。你不可凭空捏一个出来。」于是返回 `false`。

至于册上有几人，照名字的数目报；同一个名字来多少回，只算一人。

**人话**：实现 `ScoreBoard` 的成员函数：`add` 对同一玩家累加分数；`score` 取出总分，玩家不存在时返回 `false`；`players` 返回不同玩家数；`leader` 返回总分最高者的名字，并列取字典序最小，记分板为空时返回 `false`。starter 有几处行为不符约定，逐一修好；不改成员函数签名，不写 `main`。

这一题不读 stdin，也不写 stdout。测试在隐藏的 harness 里。

约定的行为：

- `void add(const std::string& player, int points)`：给玩家加分。同一个玩家多次加分应当**累加**。`points` 为正数。
- `bool score(const std::string& player, int& out) const`：玩家存在时把总分写入 `out` 并返回 `true`，否则返回 `false`。
- `int players() const`：返回出现过的玩家数量。
- `bool leader(std::string& out) const`：把总分最高的玩家名字写入 `out` 并返回 `true`；总分并列时选字典序最小的名字；记分板为空时返回 `false`。

只修改 `ScoreBoard` 的实现，不要改变成员函数的签名，也不要写 `main`。
