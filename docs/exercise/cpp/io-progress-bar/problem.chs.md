给定完成百分比和进度条宽度，画一个文本进度条。

进度条总宽度固定为 `width` 个格子。完成的格子数按下面的整数运算计算：

```text
filled = percent * width / 100      （向下取整）
```

左边 `filled` 个格子用 `#` 表示，其余格子用 `-` 表示，两端用方括号包住，后面空一格写百分比数字和 `%`。

**输入**：

- 一行两个整数 `percent` 和 `width`，用一个空格分隔。
- `0 ≤ percent ≤ 100`，`1 ≤ width ≤ 50`。

**输出**：

- 一行，形如 `[###-------] 30%`，其中恰好有 `width` 个格子和一个百分号。
- 不要在行尾输出多余空格。

### 示例

输入：

```text
30 10
```

输出：

```text
[###-------] 30%
```

### 约束

- 使用向下取整，而不是四舍五入：`99 10` 只填 `9` 个格子。
- `width = 1` 时，只有 `percent = 100` 才会显示 `#`。
- 百分比按输入原样输出，不要补前导零。
