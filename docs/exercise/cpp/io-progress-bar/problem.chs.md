甲：听说您会画进度条？

乙：会啊。给我百分比和宽度，我给您画一个 `[###-------] 30%` 这样的东西。

甲：格子怎么数？

乙：`filled = percent * width / 100`，整除，往下抹。三十个百分点、十格，填三个 `#`，余下七个 `-`，两边方括号一扣，后头空一格，写百分比加 `%`。

甲：那九十九个百分点、十格呢？

乙：您猜十个？错啦。九十九乘十得九百九，除一百得九点九，抹下去就是九。十个格子里留一个 `-`，这才叫规矩。

甲：那宽度一格的？

乙：只有百分之百才给一个 `#`，其余全是空跑。

甲：百分比要补零吗？

乙：不补。输入写 `30` 就印 `30`，别自作主张写成 `030`。行尾也不许拖空格。

**人话**：读入 `percent` 与 `width`，按 `filled = percent * width / 100` 向下取整，输出 `[`、`filled` 个 `#`、其余 `-`、`] `、`percent%`，行尾不留空格。

```text
filled = percent * width / 100      （向下取整）
```

**输入**：

- 一行两个整数 `percent` 和 `width`，用一个空格分隔。
- `0 ≤ percent ≤ 100`，`1 ≤ width ≤ 50`。

**输出**：

- 一行，形如 `[###-------] 30%`，其中恰好有 `width` 个格子和一个百分号。
- 不要在行尾输出多余空格。

### 示例

输入：

```text
30 10
```

输出：

```text
[###-------] 30%
```

### 约束

- 一律向下取整，勿作四舍五入：`99 10` 只填 `9` 个格子。
- `width = 1` 时，只有 `percent = 100` 才会显示 `#`。
- 百分比按输入原样输出，不要补前导零。
