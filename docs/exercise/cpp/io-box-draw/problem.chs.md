**文档司文件〔2026〕7 号**

**关于统一文本外框绘制规格的通知**

各科室、各直属单位：

为规范来文的呈现形式，现就外框绘制事项通知如下。

一、来文先报送行数 `n`（`1 ≤ n ≤ 50`），其下 `n` 行为正文；每行可以为空，可以含空格，长度不超过 40 个字符。

二、外框共 `n + 2` 行。首行与末行由 `+`、若干 `-`、`+` 组成，其中 `-` 的个数为“最长行长度 + 2”。

三、中间各行一律写作 `| `、正文、补齐的空格、` |`。正文左对齐，右侧补空格，使所有正文行宽度等于最长行长度。

四、若全部正文皆为空，则最长行长度为 0，外框为 `+--+`，每一内容行为 `|  |`。

五、首行 `n` 之后尚余一个换行符，须先消耗，再逐行读入正文。

以上规格请照此执行。

抄送：档案室。

**人话**：读入 `n` 行文本，把它们放进一个左对齐的矩形边框里，按上述规格输出 `n + 2` 行。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 50`），表示文本行数。
- 接下来 `n` 行，每行是一段文本，可能为空，可能包含空格；长度不超过 40。

**输出**：画好的边框，共 `n + 2` 行：

- 第一行和最后一行是 `+`、若干个 `-`、`+`，其中 `-` 的个数是“最长行长度 + 2”。
- 中间每一行是 `| `、文本、若干补齐的空格、` |`，让所有文本行的宽度都等于最长行长度。

### 示例

输入：

```text
3
cat
hi
dog
```

输出：

```text
+-----+
| cat |
| hi  |
| dog |
+-----+
```

### 约束

- 所有文本行都左对齐，右侧用空格补齐。
- 如果所有行都是空的，最长行长度为 0，边框是 `+--+`，每个内容行是 `|  |`。
- 第一行 `n` 后面还有换行符，读取文本行前要把它消耗掉。
