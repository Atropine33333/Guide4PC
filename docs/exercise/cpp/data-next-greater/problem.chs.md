对序列中的每个位置，找它右边第一个严格大于它的元素。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 10^5`）。
- 第二行 `n` 个整数 `a[i]`（`|a[i]| ≤ 10^9`）。

**输出**：一行 `n` 个整数，第 `i` 个数是 `a[i]` 右边第一个严格大于 `a[i]` 的元素；不存在时输出 `-1`。相邻整数用一个空格分隔。

### 示例

输入：

```text
5
2 1 2 4 3
```

输出：

```text
4 2 4 -1 -1
```

### 约束

- “严格大于”意味着相等不算更大：全为 `3` 的序列输出全是 `-1`。
- 从右向左扫描，维护一个单调栈保存“还没找到更大元素的候选下标”，每个元素最多进出栈一次。
- 朴素的两重循环在 `n = 10^5` 时可能超时，但也能得到正确答案。
