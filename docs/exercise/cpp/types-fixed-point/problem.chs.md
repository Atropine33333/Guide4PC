天国又好像一个家主，叫仆人们来算账。

头一个上前说：「主啊，我欠一两一钱。」第二个说：「我欠二两二钱。」第三个说：「我欠三分。」家主说：「把每一笔都化作『分』，再拿来相加。银子用秤称，莫用眼睛估。」

门徒问：「主啊，为何不用浮点数？」家主说：「`0.1` 加 `0.2` 在浮点里得不着 `0.3`，末了一位要晃。一分之差，账就不平；账不平，人就不安。」

**人话**：读入 `n` 笔金额，把每笔解析成整数「分」，用 `long long` 累加，最后按 `元.分` 输出总和，恰好两位小数。总和为 0 时输出 `0.00`，不要出现 `-0.00`。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 1000`）。
- 接下来 `n` 行，每行一个金额：可选的负号、若干数字，后面可以跟一个小数点和 1–2 位小数。金额的绝对值不超过 `10^9`。

**输出**：一行，把总和格式化为恰好两位小数（例如 `-0.50`、`3.30`、`1000000000.00`）。总和为 0 时输出 `0.00`，不要输出 `-0.00`。

### 示例

输入：

```text
2
1.10
2.20
```

输出：

```text
3.30
```

### 约束

- 不要用 `double` 累加：`0.1 + 0.2` 这类值不能精确表示，输出可能差一分。
- 把每个金额解析成整数「分」，用 `long long` 累加，最后再把分格式化成 `元.分`。
- 小数部分可能只有一位（`0.1` 表示 `0.10`），也可能没有（`3` 表示 `3.00`）。
