甲：我这儿有台计数器，能加能减，就是有一样脾气——减到零就趴下，再也不肯往下。

乙：哦，那叫“不落负数”。

甲：它还有两个自增的做派。前置的 `++c`，先把自个儿加一，再把自个儿递给你；后置的 `c++`，先把旧值的副本递给你，回头才偷偷加一。

乙：一个递身子，一个递影子。

甲：`+=` 收负数，减过头就按零算，完事也把自个儿递回来。听着不难，写起来十个人里八个把后置的返回类型写成引用。

乙：那可就递了个假影子。

甲：所以本题就考这个：前置返 `Counter&`，后置返 `Counter`，一字之差。还有，拷贝一台计数器，得是另一台新的，各自记各自的数。

**人话**：实现计数器类 `Counter`：默认构造为 0，起点为负也取 0；`increment` 加一，`decrement` 减一且不低于 0，`reset` 归零，`value` 读数；前置 `++` 加一后返回自身引用，后置 `++` 返回加一之前的**值**、返回类型为 `Counter`（不带引用），`+=` 接受负数并把结果夹在 0 以上、返回自身引用。

```cpp
class Counter {
public:
    Counter();
    explicit Counter(int start);

    void increment();
    void decrement();
    int value() const;
    void reset();

    Counter& operator++();
    Counter operator++(int);
    Counter& operator+=(int amount);
};
```

### 规则

- 默认构造的计数器为 0；`Counter(start)` 在 `start < 0` 时也取 0。
- `increment` 加 1；`decrement` 减 1，但不会减到 0 以下。
- `value` 返回当前值；`reset` 把值置 0。
- 前置 `++` 先加 1，再返回自身的引用。
- 后置 `++` 返回加 1 之前的**值**（返回类型为 `Counter`，不带引用），然后把自身加 1。
- `+=` 允许负数；结果小于 0 时取 0，返回自身的引用。
- 拷贝一个计数器会得到独立的值。
- 不要写 `main`。

### 提示

后置 `++` 用一个临时对象保存旧值并返回它。返回引用与返回值，二者务必分清。
