读入 `n` 个非负整数，按输入顺序画一张横向条形图。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 50`）。
- 第二行 `n` 个整数 `v`（`0 ≤ v ≤ 40`）。

**输出**：`n` 行。第 `i` 行先输出序号（从 1 开始）、冒号和一个空格，再输出 `v_i` 个 `#`；若 `v_i = 0`，输出一个 `-` 代替条形。

### 示例

输入：

```text
3
3 0 5
```

输出：

```text
1: ###
2: -
3: #####
```

### 约束

- 每行末尾不要多输出空格。
- 序号从 1 开始，不是从 0 开始。
