惠子谓庄子曰：“我有一树，名曰二叉搜索。凡入一个数，小于当前结点者往左，大于者往右，同者不收。树上结点，各据一位。”

庄子曰：“树有几层，君可自数乎？”

惠子曰：“空树为零，独一根为一。可我若按升序一一投进去，树就歪成一条长链，层数恰等于结点数。这又如何？”

庄子曰：“歪也是它，直也是它，层数总得一层一层数。你从根上问下去：‘你这棵子树有多高？’根答道：‘我比左右两边高的那一边，再高一层。’叶子答道：‘我一层不欠。’问到叶，数便出来。数数这件事，本来就是把自己这棵树，交给自己左右两棵子树去数。”

惠子曰：“我还想把树上的数按次序报出来。”

庄子曰：“中序便是。左边的报完，报自己，再报右边。报完了，这一棵树也就走完了一遍。”

**人话**：实现一个存储 `int` 的二叉搜索树 `IntBST`，不读 stdin、不写 stdout，测试在隐藏的 harness 里。`insert` 插入新值返回 `true`，已存在返回 `false`；`contains` 查找；`size` 返回结点数；`height` 返回层数，空树为 0、只有根为 1；`inorder` 把升序结果追加到 `out` 末尾，不先清空。不允许重复值；自己管理结点内存，析构时释放全部结点；不要写 `main`。递归插入与递归求高度都很自然，树退化成一条链（例如按升序插入）是允许的，此时高度等于结点数。

实现：

```cpp
class IntBST {
public:
    IntBST();
    ~IntBST();
    IntBST(const IntBST&) = delete;
    IntBST& operator=(const IntBST&) = delete;

    bool insert(int value);   // 新值返回 true；已存在返回 false
    bool contains(int value) const;
    int size() const;
    int height() const;       // 空树为 0，只有根为 1
    void inorder(std::vector<int>& out) const;  // 追加升序结果
};
```

要求：

- 不允许重复值；
- `height()` 返回结点层数，空树为 0，只有一个根结点时为 1；
- `inorder` 把中序遍历结果追加到 `out` 末尾，不先清空它；
- 自行管理结点内存，析构时释放全部结点；不要写 `main`。

提示：递归插入和递归求高度都很自然。树可能退化成一条链（例如按升序插入），此时高度等于结点数，这是允许的。
