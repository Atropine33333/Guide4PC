读入一整行文本（可能包含空格，也可能为空），对它做百分号编码后输出。

编码规则：只保留下列字符原样输出：

- 大写字母 `A`–`Z`、小写字母 `a`–`z`
- 数字 `0`–`9`
- `-`、`_`、`.`、`~`

其余字符的每个字节都写成 `%` 加两位大写十六进制（例如空格是 `%20`，`+` 是 `%2B`）。

### 输入

一行文本，行末的换行符不属于内容。输入只包含可打印 ASCII 字符。

### 输出

编码后的一行，末尾换行。

### 示例

输入：

```
a b/c?
```

输出：

```
a%20b%2Fc%3F
```

### 约束

- 区分大小写：十六进制字母必须大写。
- 不要输出多余的空格或提示。
