> 方田一块要铺砖，
> 砖边多长不剩边？
> 更相减损减到等，
> 等数就是砖的边。
>
> 甲鼓三拍乙五拍，
> 两鼓何时一齐来？
> 从头数到相逢处，
> 同声一响笑开怀。

《九章》有术：以少减多，更相减损，求其等也。

今有方田，广 `a` 步，从 `b` 步，里正欲以正方砖铺满，问砖边最长几何？又置二鼓：甲鼓每 `a` 刻一鸣，乙鼓每 `b` 刻一鸣，二鼓于零刻同响，问此后初同鸣于第几刻？

**人话**：每组给定两个整数 `a`、`b`，求它们的最大公约数（砖边）和最小公倍数（同鸣之刻），按这个顺序输出。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 1000`），表示共有 `n` 组田与鼓。
- 接下来 `n` 行，每行两个整数 `a`、`b`（`0 ≤ a, b ≤ 10^9`）。

**输出**：`n` 行，每行两个整数，用单个空格分隔：砖边（最长正方砖边长）与二鼓初同鸣之刻。

### 示例

输入：

```text
2
12 18
7 5
```

输出：

```text
6 36
1 35
```

### 约束

- 若 `a = 0` 或 `b = 0`，视作田缺一边、一鼓不鸣：砖边取非零的那个数；两数都为 0 时砖边为 0。
- 只要有一个数为 0，初同鸣之刻记作 0。
- 初同鸣之刻可能接近 `10^18`，请用 64 位整数保存。
- 计算时先除后乘，避免中间结果溢出。
