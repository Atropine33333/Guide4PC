读入若干对整数，对每一对输出最大公约数和最小公倍数。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 1000`）。
- 接下来 `n` 行，每行两个整数 `a`、`b`（`0 ≤ a, b ≤ 10^9`）。

**输出**：`n` 行，每行两个整数，用单个空格分隔：`a` 和 `b` 的最大公约数、最小公倍数。

### 示例

输入：

```text
2
12 18
7 5
```

输出：

```text
6 36
1 35
```

### 约束

- `gcd(0, 0) = 0`。
- 只要有一个数为 0，最小公倍数就是 0。
- 最小公倍数可能接近 `10^18`，请用 64 位整数保存。
- 计算 `lcm` 时先除后乘，避免中间结果溢出。
