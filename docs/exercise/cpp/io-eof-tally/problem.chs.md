（铺开桌布，洗牌，切牌。）

问卜的人不说话，只把牌一张一张推过来。牌面朝上，全是整数，绝对值不超过 `10^9`。牌不按行发，也没人告诉你一共几张——你只能一张接一张地收，收到桌面上再没有牌为止。

收完之后，要读出三样东西：

一、他一共推过来几张牌；
二、所有牌面数字加起来是多少；
三、最大的一张牌。

若一张牌也没有，就记下三个零，不必追问缘由。

另有一条老规矩：牌面虽小，总和却可能大得装不进三十二位的口袋，请用六十四位整数收着。要是你数的是行数，那就数错了——一行里可以并排好几张牌，最后一行也未必以换行收尾。

**人话**：从标准输入一直读到 EOF，统计整数的个数、总和与最大值，分三行输出；输入为空时输出 `0`、`0`、`0`，累加要用 64 位整数。

**输入**：若干行，每行若干个整数，用空格分隔；每个整数的绝对值不超过 `10^9`，总数不超过 `10^5`。

**输出**：三行，依次是：

1. 整数的个数；
2. 所有整数之和；
3. 最大的整数。

输入为空时输出 `0`、`0`、`0`。

### 示例

输入：

```text
1 2
3
4 5
```

输出：

```text
5
15
5
```

### 约束

- 不要把行数当作元素个数：一行里可能有多个整数，最后一行也可能没有换行符。
- 元素总数和单个元素都不大，但总和可能超过 `int`，要用 64 位整数累加。
- 用 `while (std::cin >> value)` 可以读到输入结束。
