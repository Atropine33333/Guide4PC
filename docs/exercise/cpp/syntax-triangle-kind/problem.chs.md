**三角形陈列馆·参观须知**

一、本馆陈列品，均由三条整数边长构成，边长以空格分列于一行。

二、三边之中，任意两边之和须严格大于第三边。两边之和恰好等于第三边的，属下品“退化”之物，本馆不予陈列，标作 `NOT_TRIANGLE`。

三、三边相等者，悬 `EQUILATERAL` 牌；恰有两边相等者，悬 `ISOSCELES` 牌；三边互不相等者，悬 `SCALENE` 牌。

四、悬牌之前，先验第二条。第二条不成立者，第三、第四条自动作废。

五、边长最长可达 `10^9`。若以 32 位整数相加，第二条会给出错误结论——此处请用 64 位。

六、本须知全部为真，只是常识在此处须让位于次序。

**人话**：读入三条整数边长，先判断能否组成三角形（退化情形不算），再按边的相等关系输出四种标签之一：`NOT_TRIANGLE`、`EQUILATERAL`、`ISOSCELES`、`SCALENE`。

**输入**：一行三个整数 `a b c`（`1 ≤ a, b, c ≤ 10^9`）。

**输出**：下面四种之一：

- `NOT_TRIANGLE`：无法组成三角形（包括两边之和恰好等于第三边的退化情况）。
- `EQUILATERAL`：三边相等。
- `ISOSCELES`：恰好有两边相等。
- `SCALENE`：三边互不相等。

### 示例

输入：

```text
3 4 5
```

输出：

```text
SCALENE
```

### 约束

- 任意两边之和都必须严格大于第三边，只检查一对是不够的。
- 边长之和可能超过 `int` 范围，用 64 位整数判断。
- 先判断能否组成三角形，再判断边的相等关系。
