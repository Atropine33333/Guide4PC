乙：今天说一段《两个桶的对话》。甲：等等，桶里装什么？

乙：装键。小写字母拼成的键，长度一到八，各个有各的斤两。甲：桶从哪来？

乙：第一行给一个数 `B`，一到六十四，桶就这么多只，从 0 起编号。甲：键怎么进桶？

乙：把键上每个字符的 ASCII 码加起来，对 `B` 取余，得数就是桶号；`put k v` 连同整数值 `v` 一起放进去。甲：放哪个位置？

乙：那只桶的**头部**。后来的站最前面，先来的往后让一让。同一个键再放一次呢，只换值，位置不动——人家早站好了，不能因为换件衣裳就赶出去。

甲：`get` 呢？乙：`get k` 报出键对应的值；表里没这个键，就报 `none`。甲：不想要了呢？乙：`erase k` 把键摘下来，摘完就走，不吭声；本来没有的键，也只是走一趟。甲：我想看看桶里的光景。乙：`dump` 给 `B` 行，第 `i` 行先出 `i:`，再按链表从头的顺序写键，中间隔一个空格；空桶行尾只剩 `i:`。

甲：说个实在的。乙：`ab` 与 `ba` 的字符码之和都是 195，`B` 为 4 时余 3，二位同行，都落 3 号桶；`a` 单蹦一个 97，落 1 号桶。甲：就这么些？乙：命令不过两千条，键只含小写字母，值的绝对值不超过十亿；`get` 与 `dump` 的结果按命令先后一句一句报，别乱。

**人话**：实现一个链地址法哈希表，按命令操作，并能把每个桶的链表打印出来。第一行是桶数 `B`；`put k v` 在键不存在时插到所属桶链表的**头部**、已存在时只更新值且位置不变；`erase k` 删除键，不存在时什么也不做；`get k` 输出值，缺失输出 `none`；`dump` 输出 `B` 行，第 `i` 行以 `i:` 开头，再按链表从头到尾输出该桶的键，用单个空格分隔。哈希函数固定为所有字符 ASCII 码之和对 `B` 取余。读到 EOF 为止。

### 输入

第一行是桶的数量 `B`。之后每行是一条命令，直到 EOF：

- `put k v`：插入键 `k` 和整数值 `v`。如果 `k` 已存在，只更新值，键在链表中的位置不变；否则插到所属桶链表的**头部**。
- `erase k`：删除键 `k`；不存在时什么也不做。
- `get k`：输出 `k` 对应的值，不存在则输出 `none`。
- `dump`：输出 `B` 行，第 `i` 行先输出 `i:`，然后按链表从头到尾的顺序输出该桶里的键，用单个空格分隔；桶为空时行尾就是 `i:`。

哈希函数固定为：所有字符的 ASCII 码之和对 `B` 取余。

### 输出

对每条 `get` 和 `dump` 命令按顺序输出结果。

### 示例

```
4
put ab 1
put ba 2
put a 5
dump
```

`ab` 与 `ba` 的字符码之和都是 195，落在 3 号桶；`a` 的码是 97，落在 1 号桶。输出：

```
0:
1: a
2:
3: ba ab
```

### 约束

- `1 <= B <= 64`
- 命令总数不超过 2000
- 键只含小写字母，长度 1 到 8
- `|v| <= 1000000000`
