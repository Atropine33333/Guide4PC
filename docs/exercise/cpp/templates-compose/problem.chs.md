惠子谓庄子曰：「吾有二器。下器受一物，变其形而出之；上器受其形，再变而出之。今欲合为一器，可乎？」

庄子曰：「可。子投一物于下器，取其果，复投于上器。所得之果，即二器相继之果也。」

惠子曰：「器可叠乎？」

庄子曰：「器中有器，叠之无量。上器之上更有上器，下器之下更有下器，层层相因，未始有穷。」

惠子曰：「二器之果，其形可异乎？」

庄子曰：「可异。下器出圆，上器受圆而出方，亦无不可。形随器变，道不改。」

惠子曰：「合器之中，二器安在？」

庄子曰：「藏于其中，按值而藏。取之则用，用之则复取，非一用而竭也。」

**人话**：实现函数模板 `compose(F f, G g)`，返回一个可调用对象 `h`，使任意单参数 `x` 满足 `h(x) == f(g(x))`，即先调用 `g`，再把结果交给 `f`。

```cpp
#include <utility>

template <typename F, typename G>
auto compose(F f, G g);
```

返回的可调用对象 `h` 满足：对任意单个参数 `x`，有

```cpp
h(x) == f(g(x))
```

即先调用 `g`，再把结果传给 `f`。

规则：

- 支持普通函数指针、lambda、带 `const operator()` 的函数对象。
- 返回对象按值保存 `f` 和 `g`，可以重复调用，也可以继续参与嵌套组合。
- `f` 和 `g` 的返回类型可以不同；`compose` 的返回类型由编译器推导。
- 不要使用 `std::function` 作为返回类型（允许在测试中传入它）。
- 不要写 `main`，不要修改函数签名。
