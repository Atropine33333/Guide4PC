Read a non-negative integer `n` and print the sum of its decimal digits.

The provided starter compiles but produces wrong answers. Find and fix the bug without changing the input/output format.

**Input**: one integer `n` (`0 ≤ n ≤ 10^18`).

**Output**: one integer, the sum of the digits of `n`.

### Example

Input:

```text
1234
```

Output:

```text
10
```

### Constraints

- The digit sum of `0` is `0`.
- `10^18` has 19 digits: a leading 1 followed by zeros.
- Do not change the input/output format; only fix the bug in the starter.
