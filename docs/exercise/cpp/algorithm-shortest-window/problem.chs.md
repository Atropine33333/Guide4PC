**走廊守则**

本楼走廊尽头有一扇窗，窗里摆着一列数。凡入此廊者，须遵守下列守则：

第一条：窗有两端，右端与左端都只许向右推进，均不得回头。
第二条：右端每推进一格，窗内之和加上该格的数；左端每推进一格，窗内之和减去该格的数。
第三条：当窗内之和不少于 `t` 时，左端必须继续推进，直到和小于 `t` 为止；每次满足条件时的窗宽都要记下，取最小者。
第四条：若右端走到走廊尽头，窗内之和仍不足 `t`，答案记作 `0`。
第五条：窗内之和须用 64 位整数保存。此条在任何情况下都有效。
附则：以上守则仅当窗内诸数全为正数时成立。若出现零或负数，第三条作废，须另寻他法。

**人话**：给定长度 `n` 的正整数序列和目标值 `t`，求“和至少为 `t` 的最短连续非空子段”的长度；不存在这样的子段时输出 `0`。用双指针（滑动窗口）实现，子段和用 64 位整数保存。

**输入**：

- 第一行两个整数 `n t`（`1 ≤ n ≤ 2·10^5`，`1 ≤ t ≤ 10^9`）。
- 第二行 `n` 个正整数 `a[i]`（`1 ≤ a[i] ≤ 10^4`）。

**输出**：一个整数，表示最短长度；不存在这样的子段时输出 `0`。

### 示例

输入：

```text
6 7
2 3 1 2 4 3
```

输出：

```text
2
```

解释：子段 `[4, 3]` 的和是 7，长度为 2。

### 约束

- 子段必须连续且非空。
- 所有元素都是正数，可以用双指针（滑动窗口）：右端扩张、左端收缩，每个元素最多进出窗口一次。
- 子段和要用 64 位整数，`n·a[i]` 最大可到 `2·10^9`，超过 `int`。
