关于队列最小值查询实现方案的通知

各实现单元：

队列一类结构，向来讲究先进先出；而队列之中随时问一句“眼下最小者几何”，亦属常事。为统一实现口径，现将方案通知如下。

第一条　内部存储只准使用 `std::vector`，并且只按栈的方式使用：`push_back`、`back`、`pop_back`，不得按下标随机访问。
第二条　`push` 把元素放到队尾；元素值限定在 `0` 到 `10^9` 之间。
第三条　`front` 返回队首元素，`min` 返回当前队列中的最小值；队列为空时，此二者一并返回 `-1`。
第四条　`pop` 删除队首元素；队列为空时，什么也不做。
第五条　`empty` 与 `size` 如实描述当前元素个数。
第六条　所有操作均须为均摊 `O(1)`；`min` 不得每次扫一遍整个队列。
第七条　补完该类即可，不得自行编写 `main`。

请各实现单元照此办理。

**人话**：用两个栈实现一个队列，并让队列能在 O(1) 时间内报出最小值。内部存储只准用 `std::vector`，且只按栈的方式使用（`push_back` / `back` / `pop_back`）；`push` 入队尾，`pop` 出队首，`front` 与 `min` 在队列为空时都返回 -1，`empty` 与 `size` 描述元素个数。所有操作均摊 O(1)，`min` 不能每次重扫全队列。不读 stdin，不写 stdout，**不要写 `main`**。

```cpp
#include <vector>

class TwoStackQueue {
public:
    void push(int value);
    int front() const;
    void pop();
    bool empty() const;
    int size() const;
    int min() const;
};
```

### 规则

- 内部存储只能用 `std::vector`，并且只按栈的方式使用（`push_back` / `back` / `pop_back`）。
- `push` 把元素放到队尾；元素值在 `0` 到 `10^9` 之间。
- `front` 返回队首元素；`min` 返回当前队列中的最小值；队列为空时两者都返回 `-1`。
- `pop` 删除队首元素；队列为空时什么也不做。
- `empty` 和 `size` 描述当前元素个数。
- 所有操作都应当是均摊 `O(1)`——`min` 不能每次扫一遍整个队列。
- 补完这个类即可，别自己写 `main`。

### 提示

两个栈各自维护一份“从栈底到当前位置的最小值”。元素从一个栈倒进另一个栈时，最小值要跟着重新累积；队列的最小值取两个栈的最小值中较小的那个。
