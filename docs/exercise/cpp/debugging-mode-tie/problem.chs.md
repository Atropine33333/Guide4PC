（帐中烛火摇曳。问卜者把一叠牌摊开，牌面都是整数。）

占卜师：牌面就是这些数。负数是逆位，零是一张空牌。

问卜者：我想知道，哪一张来得最多？

占卜师：来得最多的那张，就是你的答案。可牌摊上常有平局：两张来得一样多，三张也一样多。

问卜者：平局时看什么？

占卜师：看牌面。牌面小的先读。这一条要紧，许多人只数次数，忘了比大小，把后面那张大的留下了。

问卜者：要是每张牌都只来一次呢？

占卜师：那也还是平局，全场一样多。照规矩，读牌面最小的那张。

问卜者：一次摊十万张，蜡烛够用吗？

占卜师：够。先把牌收进册子里，一张一张记数；记完再走一遍，次数多的留下，次数一样就留牌面小的。册子可以用排序，也可以用一张哈希表，随你。

**人话**：读入 `n` 个整数，输出出现次数最多的值；次数相同时输出较小的那个；每张牌都只出现一次时，答案就是最小值。starter 在更新答案时用的是 `>=`，平局会换成后面那张更大的牌，改成 `>` 即可。输入输出格式保持不变，只改 `starter.cpp`。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 10^5`）。
- 第二行 `n` 个整数，绝对值不超过 `10^9`。

**输出**：一行一个整数，表示出现次数最多的值；次数相同时输出较小的那个。

### 示例

输入：

```text
4
1 1 2 2
```

输出：

```text
1
```

### 约束

- 所有值都可能为负数，也可以为 0。
- 出现次数相同的候选可能很多，必须取最小的值。
- 不要改变输入输出格式，不要重写成完全不同的程序。
- 只修改 `starter.cpp`。
