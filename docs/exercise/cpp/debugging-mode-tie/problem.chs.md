下面这段程序想找出一组整数中出现次数最多的值，出现次数相同时应取较小的值；但它对平局和全不相同的输入会选错。请修改 `starter.cpp`。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 10^5`）。
- 第二行 `n` 个整数，绝对值不超过 `10^9`。

**输出**：一行一个整数，表示出现次数最多的值；次数相同时输出较小的那个。

### 示例

输入：

```text
4
1 1 2 2
```

输出：

```text
1
```

### 约束

- 所有值都可能为负数，也可以为 0。
- 出现次数相同的候选可能很多，必须取最小的值。
- 不要改变输入输出格式，不要重写成完全不同的程序。
- 只修改 `starter.cpp`。
