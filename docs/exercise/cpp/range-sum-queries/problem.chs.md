给定一个长度为 `n` 的整数数组，回答 `q` 个区间和查询。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 200000`）。
- 第二行 `n` 个整数，每个数的绝对值不超过 `10^9`。
- 第三行一个整数 `q`（`1 ≤ q ≤ 200000`）。
- 接下来 `q` 行，每行两个整数 `l` 和 `r`（`1 ≤ l ≤ r ≤ n`）。

**输出**：对每个查询输出一行，表示 `a[l] + a[l+1] + … + a[r]`。

### 示例

输入：

```text
5
1 2 3 4 5
3
1 5
2 4
3 3
```

输出：

```text
15
9
3
```

### 约束

- 每次查询都从头累加会超时；预处理前缀和后可以 O(1) 回答。
- 一个区间最多包含 200000 个 `10^9`，总和要用 64 位整数。
