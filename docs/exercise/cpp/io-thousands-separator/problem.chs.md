（深夜两点，第七频道。萨克斯响起。）

“嗨，朋友们，我是罗恩。看这个数字：`1234567`。你能一眼看出它有多大吗？我也不能。”

“但是——等等！看看这个！”

（叮！）

“要你命三千！从右往左，每三位，啪！一个逗号。`1,234,567`，百万，清清楚楚。”

“负号？它待在原地，谁也不许碰它。前导零？要你命三千不搞那一套。零，就是零。”

“心动了吧？商店里买不到。现在拨打电话，只要 19.99 美元——但是等等，还有更多！前十位来电的朋友，再送您一个空格删除器！”

“接线员已经迫不及待！快快拨打 676 - 6767 - 6767 订购吧！”

**人话**：把每个整数格式化成带千位分隔符的写法：从右往左每三位插一个 `,`；负号放在最前面、不参与分组；`-0` 输出 `0`。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 100`）。
- 接下来 `n` 行，每行一个整数 `x`（`-10^15 ≤ x ≤ 10^15`）。

**输出**：`n` 行。每行是 `x` 的十进制表示，从右往左每三位插入一个逗号 `,`。负号放在最前面，不参与分组；`0` 输出 `0`。

### 示例

输入：

```text
3
1234567
-9876543
0
```

输出：

```text
1,234,567
-9,876,543
0
```

### 约束

- 不能使用固定的数字位数，输入可能有 16 位。
- 不要输出前导零；`-0` 应输出 `0`。
- 分组之间不能有空格。
