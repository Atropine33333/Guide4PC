Given a word made of English letters and digits, count its uppercase letters, lowercase letters and digits.

**Input**: one line with a single word without spaces, length between `1` and `1000`, containing only `A`–`Z`, `a`–`z` and `0`–`9`.

**Output**: one line with three integers — uppercase count, lowercase count and digit count — separated by single spaces.

### Example

Input:

```text
Hello123
```

Output:

```text
1 4 3
```

### Constraints

- Do not rely on locale-dependent character classification; compare character ranges directly.
- Do not print trailing spaces.
