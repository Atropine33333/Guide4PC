耶和华晓谕摩西说：

“你要数点这会众，照着他们的族类，分作三营。凡笔划向上者，归入大写之营；凡笔划向下者，归入小写之营；凡手持数目者，归入数字之营。数点已毕，将三营的数目依次报与我，彼此隔一个空格。”

摩西便召亚伦来，把那一句话交在他手里，说：“这话只由字母与数字写成，其间并无空格，长不过一千。你数清了，再报数目；营中无人，也须报个零。”

**人话**：给定一个只由英文字母和数字组成的单词，统计其中大写字母、小写字母、数字的个数，按这个顺序在一行里输出三个整数，用单个空格分隔。

**输入**：一行，一个不含空格的单词，长度在 `1` 到 `1000` 之间，只包含 `A`–`Z`、`a`–`z` 和 `0`–`9`。

**输出**：一行三个整数，依次为大写字母数、小写字母数、数字个数，用单个空格分隔。

### 示例

输入：

```text
Hello123
```

输出：

```text
1 4 3
```

### 约束

- 不要使用依赖区域设置的字符分类函数；直接比较字符范围即可。
- 输出行末不要有多余空格。
