读入 `n` 个浮点数，每个数输出一行：保留两位小数、四舍五入、右对齐，整行宽度为 10 个字符。不足 10 个字符时在左边补空格；超过 10 个字符时原样输出，不截断。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 100`）。
- 接下来 `n` 行，每行一个浮点数，绝对值不超过 `10^9`。

**输出**：`n` 行，每行一个格式化后的数。

### 示例

输入：

```text
3
1.5
-2.25
3.14159
```

输出（为了看清空格，下面用 `·` 表示一个空格）：

```text
······1.50
·····-2.25
······3.14
```

实际输出中 `·` 是普通空格。

### 约束

- 固定两位小数，即使小数部分全为 0 也要输出 `.00`。
- 四舍五入由输出格式负责，不要手动加 `0.005`。
- 宽度 10 是整行的最小宽度，正负号和小数点都算在宽度内。
- 不要输出制表符；除行尾换行外不要额外空行。
