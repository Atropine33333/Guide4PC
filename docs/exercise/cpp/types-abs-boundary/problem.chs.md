读入若干 64 位有符号整数，逐行输出它们的绝对值。

绝对值在十进制下输出；例如 `-42` 的绝对值是 `42`。注意 `long long` 的最小值 `-9223372036854775808` 的绝对值是 `9223372036854775808`，它超出了 `long long` 能表示的正数范围。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 100`）。
- 第二行 `n` 个整数，相邻整数用一个空格分隔，每个整数都在 `[-2^63, 2^63 - 1]` 内。

**输出**：

- `n` 行，每行一个非负整数，表示对应输入的绝对值。

### 示例

输入：

```text
3
-7 0 9223372036854775807
```

输出：

```text
7
0
9223372036854775807
```

### 约束

- 不能假设绝对值一定能放进 `long long`。
- 对最小负数直接写 `-x` 会触发有符号整数溢出，是未定义行为。
- 输出使用十进制，不要加前导零或正号。
