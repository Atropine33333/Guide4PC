读入一个用空格分隔的逆波兰表达式（后缀表达式），计算它的值。

**输入**：一行，若干 token，用空格分隔。token 要么是一个整数（可能带负号），要么是运算符 `+`、`-`、`*`、`/` 之一。表达式保证合法，除法保证除数为非零。

**输出**：一行一个整数，表达式的值。

### 示例

输入：

```text
7 2 3 * -
```

输出：

```text
1
```

先算 `2 * 3 = 6`，再算 `7 - 6 = 1`。

### 约束

- 除法是整数除法，向零截断：`-10 / 3 = -3`，`7 / -2 = -3`。
- 中间结果和最终结果都在 64 位有符号整数范围内。
- 运算符总是需要两个操作数；操作数顺序是“先入栈的在左”。
- 只使用标准库的栈或数组，不要使用递归下降。
