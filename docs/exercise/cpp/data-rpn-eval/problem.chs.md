（哦，我亲爱的朋友，请坐。桌上摊着一张纸，上面是一串用空格隔开的记号。）

“老天爷，”那位先生把纸推过来说，“这串东西，您瞧，全倒着写：两个数在前，符号在后，像是有人把话说反了。”

我看了看：“您说的是逆波兰表达式，也叫后缀表达式。每个记号要么是一个整数，负号也算在内，要么是 `+`、`-`、`*`、`/` 中的一个。表达式保证合法，除数不会为零，这一点您尽管放心。”

“那就拜托您了，亲爱的，”他把手一摊，“这一叠纸，我只要一个数。”

“用栈就是了，”我说，“读到数就压上去；读到符号就取下两个，先入栈的算左边，算完再压回去。最后栈里剩下的那一个，就是答案。除法嘛，是整数除法，往零那边截断，委屈不了您。”

**人话**：读入一行用空格分隔的逆波兰表达式（后缀表达式），计算并输出它的值。记号可以是可能带负号的整数，也可以是 `+`、`-`、`*`、`/` 之一；表达式保证合法，除数非零。用一个栈：遇到数就入栈，遇到运算符就弹出两个操作数，先入栈的是左操作数，算完把结果压回，最后栈顶就是答案。整数除法向零截断，中间结果与最终结果都在 64 位有符号整数范围内。只使用标准库的栈或数组，不要用递归下降。

**输入**：一行，若干 token，用空格分隔。token 要么是一个整数（可能带负号），要么是运算符 `+`、`-`、`*`、`/` 之一。表达式保证合法，除法保证除数为非零。

**输出**：一行一个整数，表达式的值。

### 示例

输入：

```text
7 2 3 * -
```

输出：

```text
1
```

先算 `2 * 3 = 6`，再算 `7 - 6 = 1`。

### 约束

- 除法是整数除法，向零截断：`-10 / 3 = -3`，`7 / -2 = -3`。
- 中间结果和最终结果都在 64 位有符号整数范围内。
- 运算符总是需要两个操作数；操作数顺序是“先入栈的在左”。
- 只使用标准库的栈或数组，不要使用递归下降。
