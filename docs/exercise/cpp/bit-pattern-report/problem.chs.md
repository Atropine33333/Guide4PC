把一个非负整数看成 32 位的二进制图案，报告三项信息：

1. 有多少位是 `1`（population count）；
2. 最高位的 `1` 代表的数值（如果所有位都是 `0`，输出 `0`）；
3. 把这 32 位按二进制补码解释成有符号 32 位整数后的值。

**输入**：一行，一个整数 `x`，满足 `0 ≤ x ≤ 4294967295`。

**输出**：一行三个整数，依次为置位数、最高置位的权值、有符号解释值，用单个空格分隔。

### 示例

输入：

```text
4294967295
```

输出：

```text
32 2147483648 -1
```

### 约束

- `x` 可能大于 `int` 能表示的范围，读入时不要用 `int`。
- 第 3 项可以先用 64 位中间值计算：若最高位为 `1`，结果为 `x - 4294967296`。
