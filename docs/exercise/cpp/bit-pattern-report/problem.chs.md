关于开展非负整数位级情况报送工作的通知

各承办科室：

为全面掌握非负整数的位级状况，现就三十二位图案报送工作通知如下。

一、报送口径。将输入整数视为三十二位的二进制图案，逐项报送三项内容。
二、第一项，置位个数，即图案中 `1` 的个数（population count）。
三、第二项，最高置位权值。若全部位为零，此项报 `0`。
四、第三项，按二进制补码把这 32 位解释成有符号 32 位整数所得的数值。
五、填报方式。三项用单个空格分隔，报于一行。
六、器具要求。输入值最高可达 `4294967295`，已超出 `int` 表示范围，读取时一律不得使用 `int`。

**人话**：读入一个整数 `x`，把它的低 32 位当作二进制图案，输出三个整数：`1` 的个数、最高位 `1` 的权值、以及这 32 位按补码解释成的有符号值。

**输入**：一行，一个整数 `x`，满足 `0 ≤ x ≤ 4294967295`。

**输出**：一行三个整数，依次为置位数、最高置位的权值、有符号解释值，用单个空格分隔。

### 示例

输入：

```text
4294967295
```

输出：

```text
32 2147483648 -1
```

### 约束

- `x` 可能大于 `int` 能表示的范围，读入时不要用 `int`。
- 第 3 项可以先用 64 位中间值计算：若最高位为 `1`，结果为 `x - 4294967296`。
