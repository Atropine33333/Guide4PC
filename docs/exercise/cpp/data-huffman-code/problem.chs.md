对一行只含小写字母的文本构造哈夫曼编码，并输出编码后的比特串和每个字符的码字。

### 输入

一行文本，只包含小写字母 `a` 到 `z`，长度不超过 1000。输入可能为空。

### 输出

第一行为编码后的比特串（只含 `0` 和 `1`，可以为空）。

接下来每行输出一个出现过的字符及其码字，格式为 `<字符> <码字>`，按字符的 ASCII 码从小到大排列。

### 构造规则

必须使用以下确定性的哈夫曼构造方式，否则相同频率时答案可能不同：

- 每个叶子结点保存 `(频率, 子树中最小字符)`。
- 用最小堆按 `(频率, 最小字符)` 的字典序取出两个结点；先取出的是左孩子，后取出的是右孩子。
- 新内部结点的频率为两者之和，最小字符为左孩子的最小字符（左孩子的键不大于右孩子的键）。
- 从父结点到左孩子的边记为 `0`，到右孩子的边记为 `1`。
- 若整棵树只有一个叶子结点，该字符的码字为 `0`。

### 示例

输入：

```text
aabbbcccc
```

输出：

```text
1010111110000
a 10
b 11
c 0
```

### 约束

- 空输入时只输出一个空行。
- 只使用标准库，不要使用文件、异常或线程。
