天国又好像一个称字的匠人。他手上有一行小写字母，从 `a` 到 `z`，有的常来，有的只来一回。匠人把每个字母按出现的次数放上秤：次数少者轻，次数多者重。

他每次都从秤上取下最轻的两件，合为一件，新的重量是二者之和。秤上若有两件一般轻，他就先取子树里字母更小的那件放在左边，另一件放在右边。合了又合，直到秤上只剩一件。

然后他给这件东西挂上绳子：从父到左孩子的绳记 `0`，到右孩子的绳记 `1`。每个字母的码字，就是从顶上顺着绳子走下来，一路见到的 `0` 与 `1`。若秤上自始至终只有一个字母，它的码字就是 `0`。天国里记账，一轻一重都算得明白。

**人话**：读入一行只含小写字母的文本（可能为空），用哈夫曼编码压缩。先统计每个字符的出现次数；再用最小堆按 `(频率, 子树中最小字符)` 反复取出最小的两个结点合并，先取出的当左孩子，后取出的当右孩子，直到只剩一个根；左孩子的码字加 `0`，右孩子加 `1`。输出编码后的比特串，再按 ASCII 码升序输出每个出现过的字符及其码字，格式为 `<字符> <码字>`。频率相同时的取法由下面的构造规则唯一确定，必须照做。

### 输入

一行文本，只包含小写字母 `a` 到 `z`，长度不超过 1000。输入可能为空。

### 输出

第一行为编码后的比特串（只含 `0` 和 `1`，可以为空）。

接下来每行输出一个出现过的字符及其码字，格式为 `<字符> <码字>`，按字符的 ASCII 码从小到大排列。

### 构造规则

必须使用以下确定性的哈夫曼构造方式，否则相同频率时答案可能不同：

- 每个叶子结点保存 `(频率, 子树中最小字符)`。
- 用最小堆按 `(频率, 最小字符)` 的字典序取出两个结点；先取出的是左孩子，后取出的是右孩子。
- 新内部结点的频率为两者之和，最小字符为左孩子的最小字符（左孩子的键不大于右孩子的键）。
- 从父结点到左孩子的边记为 `0`，到右孩子的边记为 `1`。
- 若整棵树只有一个叶子结点，该字符的码字为 `0`。

### 示例

输入：

```text
aabbbcccc
```

输出：

```text
1010111110000
a 10
b 11
c 0
```

### 约束

- 空输入时只输出一个空行。
- 只使用标准库，不要使用文件、异常或线程。
