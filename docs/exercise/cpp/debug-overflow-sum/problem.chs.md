这里的每一条规矩都是真的。房间不骗人，它只是先把你话里的“整数”换掉。

规矩一：本间的 `int` 只有三十二位，能安放的数止于 2147483647。你手里那笔和可以到 2 × 10^14，它放不下。

规矩二：有人报过 `-1294967296` 这个和。那是 3000000000 换了一件旧外套，从 2147483647 那一头绕回来的。请把它认成那个很大的数。

规矩三：规矩二只在本间成立。换一本六十四位的账，外套就脱了；中途把账换回 `int`，外套又穿回去。

规矩四：账本只写一行。第一个数记上，才轮到第二个，次序不许改。

规矩五：门从外面开。输入照原样读，输出照原样写，只许动账本的类型。

如果你发现自己开始觉得 `-1294967296` 挺亲切，请回到开头，重读第一句。

**人话**：读入 `n` 个整数，求它们的和。和的绝对值可到 2 × 10^14，要用 `long long` 累加；starter 把和存成了 `int`，溢出后回绕成负数。改掉这一处，输入输出格式保持不变。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 200000`）。
- 第二行 `n` 个整数，每个数的绝对值不超过 `10^9`。

保证所有数的和 `S` 满足 `-2 × 10^14 ≤ S ≤ 2 × 10^14`。

**输出**：一行一个整数，即所有数的和。

### 示例

输入：

```text
3
1000000000 1000000000 1000000000
```

正确输出：

```text
3000000000
```

初始代码会输出一个与正确答案不符的负数。请只修改必要的地方，不要改变输入输出格式。
