下面的程序本应输出所有整数的和，但它在部分测试数据上给出了错误答案。请找出并修复这个 bug。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 200000`）。
- 第二行 `n` 个整数，每个数的绝对值不超过 `10^9`。

保证所有数的和 `S` 满足 `-2 × 10^14 ≤ S ≤ 2 × 10^14`。

**输出**：一行一个整数，即所有数的和。

### 示例

输入：

```text
3
1000000000 1000000000 1000000000
```

正确输出：

```text
3000000000
```

初始代码会输出一个与正确答案不符的负数。请只修改必要的地方，不要改变输入输出格式。
