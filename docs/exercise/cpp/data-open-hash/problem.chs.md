开放寻址表使用须知

请读完以下各条，再开始填写本表。本表规矩全部属实，只是常识不完全管用。

一、本表不读 stdin，也不往 stdout 写任何东西。你不要写 `main`。
二、本表没有链表。一个槽位只放一个键值对；键与值都是 `int`，键可以为负。负数进门，照样安排座位。
三、同一个键反复 `put`，只改它的值，元素个数不变。
四、`get` 找到时，把值写进 `out`，返回 `true`。找不到时返回 `false`，并且**一个字节也不要动** `out`。你说你没写，检查的人会知道。
五、`erase` 删掉键，返回 `true`；键本来就不在，返回 `false`，别的什么都不会发生。
六、`size()` 数的是当前键值对的数量，数错一个都不行。
七、删除之后，那个槽位会留下一个“已删除”的印记。探测走到这里，**不许停**，要继续往后走；只有遇到从未被占用的空槽，才可以断定“没有这个键”。谁在这里停下，谁的键就会在某一天消失。
八、元素多到快坐满时，换一张更大的表，把所有仍被占用的槽位重新安排进去。带印记的槽位，不必再请。

**人话**：用开放寻址法（线性探测）实现一个整数哈希表 `OpenHashMap`，不读 stdin、不写 stdout，测试在隐藏的 harness 里。`put` 写入或更新键值，重复 `put` 同一键不增加元素个数；`get` 命中时把值写入 `out` 并返回 `true`，未命中返回 `false` 且不修改 `out`；`erase` 删除键返回 `true`，键不存在返回 `false`；`size` 返回键值对数量。槽位有三种状态：空、占用、已删除（墓碑），探测遇到墓碑要继续往后找，遇到真正的空槽才停止；负载升高时扩容，把仍占用的槽位重新插入。**不要写 `main`**。

```cpp
#include <vector>

class OpenHashMap {
public:
    void put(int key, int value);
    bool get(int key, int& out) const;
    bool erase(int key);
    int size() const;
};
```

### 规则

- 键和值都是 `int`，键可以为负数。
- 同一个键重复 `put` 时更新它的值，不增加元素个数。
- `get` 找到时把值写入 `out` 并返回 `true`；找不到返回 `false`，且**不修改** `out`。
- `erase` 删除键并返回 `true`；键不存在时返回 `false`。
- `size` 返回当前键值对数量。
- 必须使用开放寻址（线性探测）；删除后留下的空位不能让后续探测提前终止。
- 不要写 `main`。

### 提示

每个槽位可以记录三种状态：空、占用、已删除（墓碑）。探测时遇到墓碑继续往后找，遇到真正的空槽才停止。元素变多时按需扩容并重新插入所有仍占用的槽位。
