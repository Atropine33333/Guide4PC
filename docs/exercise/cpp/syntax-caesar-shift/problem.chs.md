“还在用明文写信吗？”

深夜的电视里，主持人举起一枚铜盘：“凯撒加密盘！古罗马将军用了两千年，今天只要 19.99 美元！把每个字母往后推 `k` 位：`z` 推过就回 `a`，`Z` 推过就回 `A`；空格、标点、数字，一概不动。”

“But wait, there's more! 负数 `k` 就是往前推，一亿也是推，`k` 再大也不怕——先对 26 取模便是。整行照原样读进来，别拿 `std::cin >> word` 只叼走一个词！”

“数量有限，售完为止。写信、记账、给心上人递条子，一盘在手，万无一失。”

**人话**：读入位移量 `k` 和一行文本，把其中每个英文字母在各自的大小写范围内循环后移 `k` 位，非字母字符原样保留，输出整行。

**输入**：

- 第一行一个整数 `k`（`-10^9 ≤ k ≤ 10^9`），负数表示向前移动。
- 第二行一行文本，长度不超过 100，字符的 ASCII 码在 32 到 126 之间（含空格和标点）。

**输出**：一行，位移后的文本。行首、行尾和行内的空格都必须原样保留。

### 示例

输入：

```text
3
Attack at dawn!
```

输出：

```text
Dwwdfn dw gdzq!
```

### 约束

- 只有 `a`–`z` 和 `A`–`Z` 会改变。
- 位移量可能远大于 26，先对 26 取模；负数取模后仍要得到非负的位移量。
- 必须用 `std::getline` 读整行，不能只用 `std::cin >> word`。
