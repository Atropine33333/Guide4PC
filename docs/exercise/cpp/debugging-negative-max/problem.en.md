The program below reads `n` integers and prints the maximum, but it returns a wrong answer for some inputs. Find and fix the bug.

**Input**:

- The first line contains an integer `n` (`1 ≤ n ≤ 1000`).
- The second line contains `n` integers whose absolute values are at most `2·10^9`.

**Output**: one integer, the maximum of the `n` values.

### Example

Input:

```text
3
-5 -2 -9
```

Output:

```text
-2
```

### Hint

- What should the initial value of the maximum be if every number is negative?
- Do not change the input/output format or rewrite the whole exercise; fix the logic bug in `starter.cpp`.
