庄子与惠子游于濠梁之上。

惠子曰：「请言算。」

庄子曰：「式有文法。一曰数，数者，十进之字也。二曰因子，因子者，数也，或括号之式也，或负号加于因子之前也。三曰项，项者，因子相乘也。四曰式，式者，项相加减也。括号之内，复为一式。」

惠子曰：「负号居前，算者径以其数为零，可乎？」

庄子曰：「不可。一尺之棰，日取其半，万世不竭。递归者，割而复合；割之不尽，则式未终。遇 `-` 于因子之前，取其后者而反其数，斯可矣。负而又负，则复其正，如棰之再割。」

惠子曰：「加与乘，先后如何？」

庄子曰：「乘先于加，加减居其末；同为加减者，自左而右，不相颠倒。空格可居于任意两记号之间，不足为病。」

惠子曰：「善。请书其文法于后，以为后世算者之准。」

**人话**：实现 `eval_expression(text)`，对只含整数、`+`、`-`、`*`、括号与一元负号的表达式求值，按递归下降解析：`expression` 拆成 `term`，`term` 拆成 `factor`。starter 遇到一元负号时直接返回 `0`，把它改成“吃掉 `-`，对后面的因子取负”即可。不写 `main`。

```cpp
#include <string>

int eval_expression(const std::string& text);
```

文法（`expression` 是入口）：

```text
expression := term (('+' | '-') term)*
term       := factor ('*' factor)*
factor     := number | '(' expression ')' | '-' factor
number     := 一个或多个十进制数字
```

约定：

- 运算符都是左结合的：`10 - 3 - 2` 等于 `5`，`2 * 3 * 4` 等于 `24`。
- 一元负号可以出现在任意因子位置，可以嵌套：`-5`、`2 * -3`、`--4`、`-(-3)`、`-(1 + 2)`。
- 空格可以出现在任意两个记号之间（包括数字前），不影响结果。
- 输入保证是合法表达式，且结果在 `int` 范围内。
- 不要写 `main`。

### 示例

`2 * -3 + (4 - 1)` 的结果是 `-3`。

### 提示

检查 `factor` 的解析逻辑：遇到 `'-'` 时应当跳过它，并对后面的 `factor` 取负；只返回 `0` 的做法不对。
