这一题不读 stdin。求值只包含整数、`+`、`-`、`*`、括号和一元负号的算术表达式。

```cpp
#include <string>

int eval_expression(const std::string& text);
```

文法（`expression` 是入口）：

```text
expression := term (('+' | '-') term)*
term       := factor ('*' factor)*
factor     := number | '(' expression ')' | '-' factor
number     := 一个或多个十进制数字
```

约定：

- 运算符都是左结合的：`10 - 3 - 2` 等于 `5`，`2 * 3 * 4` 等于 `24`。
- 一元负号可以出现在任意因子位置，可以嵌套：`-5`、`2 * -3`、`--4`、`-(-3)`、`-(1 + 2)`。
- 空格可以出现在任意两个记号之间（包括数字前），不影响结果。
- 输入保证是合法表达式，且结果在 `int` 范围内。
- 不要写 `main`。

starter 的解析器能处理二元 `+ - *` 和括号，但没有正确处理一元负号；请修好它。

### 示例

`2 * -3 + (4 - 1)` 的结果是 `-3`。

### 提示

检查 `factor` 的解析逻辑：遇到 `'-'` 时应当跳过它，并对后面的 `factor` 取负，而不是只返回 `0`。
