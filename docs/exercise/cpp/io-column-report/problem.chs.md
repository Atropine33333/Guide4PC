甲：您给说说，这报账的名册该怎么排？

乙：简单。名字在左，占十二个字符，不够就往右补空格；紧跟着一根竖线 `|`，左右一点空都不留。

甲：那分数呢？

乙：分数在右，占八个字符，不够往左补空格。名字写满十二、分数写满八的，一个空格也别添；名册每行的末尾不许拖着空格尾巴。

甲：要是名字超过十二个字符呢？

乙：本题名字最长十个，您就别操那份心。可分数能到 `-999999`，七个字符，还在八个里头。

甲：竖线左右也容不得空格？

乙：容不得。补位空格就是全部的间隔，您手一抖多添一个，行末便多出空格，判题的就该找您了。

**人话**：读入 `n` 行“名字 分数”，每行按格式输出：名字左对齐占 12 个字符，紧接一个 `|`，分数右对齐占 8 个字符，行末不留多余空格。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 100`）。
- 接下来 `n` 行，每行一个名字和一个整数分数，用一个空格分隔。名字只含小写字母，长度 `1` 到 `10`；分数在 `-999999` 到 `999999` 之间。

**输出**：`n` 行，顺序与输入一致。每一行的格式是：

- 名字左对齐，占 12 个字符，不足补空格；
- 紧接着一个竖线 `|`；
- 分数右对齐，占 8 个字符，不足在左边补空格。

### 示例

输入：

```text
2
alice 120
bob -42
```

输出（为了看清空格，下面用 `·` 表示一个空格）：

```text
alice·······|·····120
bob·········|·····-42
```

实际输出中 `·` 是普通空格。

### 约束

- 名字和分数之间、分数和竖线之间都不要额外加空格，补位空格就是全部间隔。
- 名字或分数正好填满列宽时不要再补空格。
- 竖线只有一个，左右不留固定空格。
- 行末不要有多余空格。
