读入一个整数 `n`，把它写成大写罗马数字。

**输入**：一行一个整数 `n`（`1 ≤ n ≤ 3999`）。

**输出**：一行，`n` 的罗马数字表示，只包含大写字母 `I`、`V`、`X`、`L`、`C`、`D`、`M`。

### 示例

输入：

```text
1994
```

输出：

```text
MCMXCIV
```

### 约束

- 符号值为 `I=1`、`V=5`、`X=10`、`L=50`、`C=100`、`D=500`、`M=1000`。
- 4、9、40、90、400、900 使用减法记法：`IV`、`IX`、`XL`、`XC`、`CD`、`CM`。
- 同一个符号最多连续出现三次（`M` 在本题范围内最多三次）。
- 输出不要有前导或尾随空格。
