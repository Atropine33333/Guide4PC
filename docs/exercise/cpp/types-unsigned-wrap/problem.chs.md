《无符号减法须知》

一、`a` 与 `b` 均为无符号 64 位整数，取值 `0` 到 `18446744073709551615`。
二、要求输出 `a - b` 与 `b - a`，一行两个，用单个空格分隔。
三、减法按模 `2^64` 进行。数学结果为负时，加 `2^64`。
四、示例：`a = 3`，`b = 5`，则 `a - b` 为 `18446744073709551614`，`b - a` 为 `2`。
五、第 3 条对两个输出同时生效。输出里没有「负数」这一项。
六、若你用有符号整数保存中间结果，第 2 条对你作废：你会得到负数，或者更糟。
七、两个结果都以十进制输出，不补零，不加前缀。

**人话**：读入两个无符号 64 位整数 `a`、`b`，输出 `a - b` 和 `b - a` 的模 `2^64` 结果，用单个空格分隔。减法不会出现负数，只会回绕。

**输入**：一行两个整数 `a`、`b`，范围都是 `0` 到 `18446744073709551615`。

**输出**：一行两个整数，用单个空格分隔：先是 `a - b`，再是 `b - a`。

### 示例

输入：

```text
3 5
```

输出：

```text
18446744073709551614 2
```

`3 - 5` 在无符号 64 位中等于 `2^64 - 2`。

### 约束

- 两个结果都用十进制输出，不需要补零或加前缀。
- 不要用有符号整数保存中间结果，那会得到负数或发生未定义行为。
- `a` 与 `b` 都是无符号的，读取时请使用 `unsigned long long`。
