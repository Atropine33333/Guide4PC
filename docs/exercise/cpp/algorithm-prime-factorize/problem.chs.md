**第一章**

起初，数为一，混沌空虚，渊面黑暗。

耶和华晓谕摩西说：

“你取这整数 `n`，将它尽数分与质数之民，不可剩一。质数者，除了一和自身，再不可分。你要从小分起，不可越过；每民所得之份，记其指数。分到不可再分，若还剩一个大于一的数，那也是质数，也要分给它。”

摩西便照耶和华所吩咐的行了。

**人话**：把 `n` 分解成质因数的乘积，按质因数从小到大输出形如 `p^e` 的项；指数为 1 时也要写成 `p^1`。

**输入**：一行一个整数 `n`（`2 ≤ n ≤ 10^12`）。

**输出**：一行若干形如 `p^e` 的项，相邻项用一个空格分隔，其中 `p` 是质数、`e` 是它的指数。

### 示例

输入：

```text
12
```

输出：

```text
2^2 3^1
```

### 约束

- 质因数按从小到大排列。
- 每个质因数只出现一次，指数用十进制写出，不加前导零。
- `n` 本身是质数时输出一项 `n^1`。
- 直接逐个试除到 `sqrt(n)` 即可；注意判断剩余部分是否大于 1。
