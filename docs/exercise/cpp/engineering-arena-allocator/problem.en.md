В целях дальнейшего упорядочения использования ресурсов памяти, а также решительного устранения переполнений, смещений и повторного занятия Администрация по ресурсам памяти приняла решение провести специальную проверку линейных аллокаторов (arena) в своей зоне ответственности. Ниже излагаются обязательные требования. Отступление не допускается.

**Обязательный интерфейс:**

```cpp
class Arena {
public:
    explicit Arena(int capacity);  // 1 <= capacity <= 256

    Arena(const Arena&) = delete;
    Arena& operator=(const Arena&) = delete;

    // Выделить size байт с выравниванием по alignment.
    // Вернуть nullptr, если size <= 0 или места недостаточно, не меняя used().
    void* allocate(int size, int alignment);

    int used() const;      // занятые байты, включая отступ на выравнивание
    int capacity() const;  // ёмкость, заданная при создании
    void reset();          // освободить всё пространство
};
```

**Обязательные правила:**

1. `alignment` является степенью двойки и не превышает 16. Каждый возвращённый адрес обязан удовлетворять условию `адрес % alignment == 0`. Нарушившие это условие несут ответственность за смещение.

2. Внутри используется настоящий буфер фиксированного размера. Вызов `new` и использование `std::vector` для каждого выделения запрещаются. Каждое выделение обязано обходиться без обращения к куче, как и подобает плановому хозяйству.

3. Перед резервированием `size` байт смещение округляется вверх до границы выравнивания. Отступ на выравнивание учитывается в `used()`. Отступ не является потерей: он есть планомерная подготовка к размещению.

4. Если `size <= 0` или места недостаточно, вернуть `nullptr`, не изменяя `used()`. Частичное занятие и откат не допускаются. Учёт должен оставаться честным до последнего байта.

5. `reset()` освобождает всё пространство. `used()` и `capacity()` обязаны сообщать истинные значения. Сокрытие истинного значения `used()` рассматривается как искажение отчётности.

6. `main` не писать. Скрытый harness проверяет использование памяти извне. Внешний контроль осуществляется в установленном порядке.

7. Не добавлять и не удалять функции-члены. Интерфейс утверждён. Отступление не допускается.

**Формула выравнивания:** `(offset + alignment - 1) / alignment * alignment`. Если `alignment` — степень двойки, подойдут и битовые операции.
