**日期校勘处值夜守则**

欢迎接任夜班校勘员。以下守则条条属实，请逐条遵守。

```cpp
#include <string>

struct Date {
    int year;
    int month;
    int day;
};

bool parse_iso_date(const std::string& text, Date& out);

std::string format_short_date(const Date& date);
```

**守则一（形状）** 只受理形状恰为 `YYYY-MM-DD` 的字符串。长度必须正好是 10；第 5 个和第 8 个字符必须是 `-`；其余位置必须都是 ASCII 数字。少一位、多一位、挪一位，一概不受理。

**守则二（范围）** 年份在 1 到 9999 之间，月份在 1 到 12 之间，日期必须真实存在。这看上去是常识，请记住：常识只在守则没有开口时有效。

**守则三（闰年）** 关于闰年有两句话。能被 4 整除、且不能被 100 整除的年份是闰年；能被 400 整除的年份也是闰年。第二句恰好补在第一句失效之处。二月在闰年有 29 天，平年 28 天。

**守则四（抽屉）** 解析成功，把年月日写入 `out`，返回 `true`。解析失败，返回 `false`，并且**不要修改** `out`。失败的夜里，抽屉里的东西必须保持原样。

**守则五（短格式）** `format_short_date` 返回 `DD/MM/YYYY`，日、月各两位，不足补 `0`，年份四位；例如 `2024-02-09` 变成 `09/02/2024`。可以假定传入的日期已经合法。

**守则六（签字）** 不要写 `main`，不要修改结构体和函数签名。

**人话**：实现 `parse_iso_date` 与 `format_short_date`。前者按形状、范围与闰年守则严格解析 ISO 日期，失败时原样保留 `out`；后者把合法日期输出成 `DD/MM/YYYY`。
