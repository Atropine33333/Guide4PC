给定一个整数序列和一系列位置交换操作，输出全部操作结束后的序列。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 200`）。
- 第二行 `n` 个整数，绝对值不超过 `10^9`。
- 第三行一个整数 `m`（`0 ≤ m ≤ 200`）。
- 接下来 `m` 行，每行两个整数 `i` 和 `j`（`1 ≤ i, j ≤ n`），表示交换第 `i` 个和第 `j` 个元素。

**输出**：一行 `n` 个整数，为最终序列，相邻两个数之间用一个空格分隔。

### 示例

输入：

```text
5
1 2 3 4 5
2
1 5
2 4
```

输出：

```text
5 4 3 2 1
```

### 提示

初始代码已经写好了完整的读入、调用与输出，只差交换函数本身。注意：函数参数写成值传递时，函数里换的只是副本，调用者的数组不会改变。
