《塔罗·洗牌》

问卜者落座，牌阵已经摊开。占卜师说：「牌面就是这些数字，一张不多，一张不少。你只须照牌上写的两处位置，把那里的两张牌对调。」

问卜者抽出「一」与「五」，两牌易位；又抽出「二」与「四」，再易位。占卜师不看牌面，只记位置，说：「洗牌之道，在于原处互换，另有副本，便不算数。」

「若两处指的是同一张牌呢？」

「那便原地不动，牌数不减。」

「若一张也没抽呢？」

「牌阵照旧，一张不动。」

问卜者点头，把牌推回去：「那么，请把最后的牌阵念给我听。」

**人话**：读入 `n`、`n` 个整数、`m` 对位置，把每一对位置上的两个元素对调，输出最终序列。位置从 1 开始编号，`m` 可以为 0，一对位置里的 `i` 与 `j` 也可以相等。初始代码已写好读入、调用与输出，只差交换函数本身：形参要按引用传递，按值传递只会换掉函数里的副本。

### 输入

- 第一行一个整数 `n`（`1 ≤ n ≤ 200`）。
- 第二行 `n` 个整数，绝对值不超过 `10^9`。
- 第三行一个整数 `m`（`0 ≤ m ≤ 200`）。
- 接下来 `m` 行，每行两个整数 `i` 和 `j`（`1 ≤ i, j ≤ n`），表示交换第 `i` 个和第 `j` 个元素。

### 输出

一行 `n` 个整数，为最终序列，相邻两个数之间用一个空格分隔。

### 示例

输入：

```text
5
1 2 3 4 5
2
1 5
2 4
```

输出：

```text
5 4 3 2 1
```

### 提示

初始代码已经写好了完整的读入、调用与输出，只差交换函数本身。注意：函数参数写成值传递时，函数里换的只是副本，调用者的数组不会改变。
