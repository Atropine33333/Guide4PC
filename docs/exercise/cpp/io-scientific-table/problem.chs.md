读入若干浮点数，把每个值按科学计数法格式化成固定宽度的一行。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 8`）。
- 第二行 `n` 个浮点数，相邻值用一个空格分隔；每个值都是有限数，且 `|x| ≤ 10^300` 或 `x = 0`。

**输出**：

- `n` 行，对应输入的每个值。
- 每行使用科学计数法：小数点前一位非零数字，小数点后恰好三位数字，指数部分带符号且至少两位数字。
- 整行右对齐到宽度 `12`，左侧用空格补齐。

例如 `1234` 输出 `  1.234e+03`（共 12 个字符，前面有 3 个空格）。

### 示例

输入：

```text
2
1234 0.03125
```

输出：

```text
  1.234e+03
  3.125e-02
```

### 约束

- 使用 C++ 的默认科学计数法格式，不要自己拼接指数。
- `0` 输出 `0.000e+00`，正零与负零都按 `0.000e+00` 处理。
- 行内除左侧补空格外不能有其他空格。
