读入若干行配置，合并后按关键字字典序输出。

**输入**：若干行，直到文件结束。每行是以下三种之一：

- 空行，或只含空白字符的行：忽略；
- 去掉首尾空白后以 `#` 开头的行：注释，忽略；
- `key=value` 形式：`key` 是配置名，`value` 是配置值。

允许 `key` 和 `value` 两侧有空格或制表符；值本身可以包含等号（只按第一个 `=` 分割）。键区分大小写，值可以为空。若同一个键出现多次，后出现的值覆盖先出现的值。

**输出**：每个键一行，格式为 `键=值`，按键的字典序（ASCII 升序）排列。行内不要输出多余空格；空值也要输出 `键=`。

### 示例

输入：

```text
# settings
b=2
a=1
b=3
```

输出：

```text
a=1
b=3
```

### 约束

- 配置行数不超过 200，每行长度不超过 200；
- 不要假设输入已经按关键字排序；
- 使用 `std::getline` 读整行，使用 `std::map` 保持键有序。
