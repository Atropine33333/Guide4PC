（深夜，一间堆满打印纸的办公室。电话铃响。）

“哦，我亲爱的，你总算打来了。桌上有一摞配置，从第一行读到最后一行，读到文件结束为止。”

“每一行长什么样？”

“三种。空行，或者只有空格和制表符的行——老天爷，别管它。去掉首尾空白后以 `#` 开头的——那是批注，也别管它。剩下的就是 `键=值`，就这么简单。”

“键和值两边有空格呢？”

“允许，我亲爱的，空格和制表符都允许。值里面还可以有等号，按第一个等号切开就好。键区分大小写，值可以是空的。”

“同一个键写了两回？”

“后面那个说了算。记住，后面那个。”

“那输出呢？”

“每个键一行，`键=值`，按键的字典序从小到大排，行里不要添油加醋。值是空的也要写成 `键=`。就这些，亲爱的，别搞砸了。”

**人话**：读若干行配置直到文件结束，忽略空行与 `#` 注释行，按第一个 `=` 拆出键和值并去掉两侧空白，同键后者覆盖前者，最后用 `std::map` 按键的 ASCII 升序输出 `键=值`。

### 输入

若干行，直到文件结束。每行是以下三种之一：

- 空行，或只含空白字符的行：忽略；
- 去掉首尾空白后以 `#` 开头的行：注释，忽略；
- `key=value` 形式：`key` 是配置名，`value` 是配置值。

允许 `key` 和 `value` 两侧有空格或制表符；值本身可以包含等号（只按第一个 `=` 分割）。键区分大小写，值可以为空。若同一个键出现多次，后出现的值覆盖先出现的值。

### 输出

每个键一行，格式为 `键=值`，按键的字典序（ASCII 升序）排列。行内不要输出多余空格；空值也要输出 `键=`。

### 示例

输入：

```text
# settings
b=2
a=1
b=3
```

输出：

```text
a=1
b=3
```

### 约束

- 配置行数不超过 200，每行长度不超过 200；
- 不要假设输入已经按关键字排序；
- 使用 `std::getline` 读整行，使用 `std::map` 保持键有序。
