读入 `n` 个 32 位无符号整数，分别输出它们的二进制表示中 `1` 的个数。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 20`）。
- 第二行 `n` 个整数 `v`（`0 ≤ v ≤ 4294967295`）。

**输出**：`n` 行，每行一个整数，表示对应值的二进制中 `1` 的位数（popcount）。

### 示例

输入：

```text
2
0 4294967295
```

输出：

```text
0
32
```

### 提示

`<bit>` 头文件里的 `std::popcount` 可以直接完成这件事；也可以自己写循环逐位统计。输入值超出了 32 位有符号 `int` 的正数范围，建议先读入 `unsigned long long`，再转换成 `std::uint32_t`。
