凌晨两点，电视里只剩一个声音，背景是蓝得发假的渐变。

「朋友们，你还在为 `printf("%X", 7)` 只吐出一个 `7` 而彻夜难眠吗？看看这个——两位大写十六进制！`00`、`0F`、`FF`，一个不少，前导零永远在位！不管你的字节是 `0` 还是 `255`，它都稳稳占满两个字符！」

「而这还只是开始！现在下单，附赠大写字母表 `A` 到 `F`，绝不小写！每行一个值，干净利落！只要 19.99！」

**人话**：读入 `n` 个字节值 `v`，把每个值输出成恰好两位大写十六进制，一行一个；小于 `16` 的值前面补 `0`。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 256`）。
- 第二行 `n` 个整数 `v`（`0 ≤ v ≤ 255`）。

**输出**：`n` 行，每行恰好两个大写十六进制字符。小于 `16` 的值要补一个前导 `0`。

### 示例

输入：

```text
5
0 15 16 127 255
```

输出：

```text
00
0F
10
7F
FF
```

### 约束

- 输出的字母必须大写。
- 每行必须是两位，不能把 `0` 输出成空行或单个字符。
- 值始终在 `0`–`255` 内，可以用 `unsigned char` 保存。
