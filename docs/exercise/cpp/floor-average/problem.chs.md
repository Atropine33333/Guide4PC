甲：我考考您，`-15 / 2` 得多少？

乙：这还用问？`-7` 啊，计算机都这么算。

甲：计算机算的，是「向零取整」。可数学上还有个「向下取整」，结果是 `-8`。

乙：得，差一位数，至于吗？

甲：至于！正数的时候二位一样，一沾负数、一除不尽，立马差 1。您要是把这两个平均搅成一锅，报出来的数就冤了。

乙：那怎么办？

甲：把总和攒在 64 位整数里，除完看看有没有余数；余数不为零，商又是负的，那就再减一。

乙：合着就是余数说了算。

甲：对了，余数说了算。别拿浮点数凑，凑不出来。

**人话**：读入 `n` 个有符号整数，输出两个平均数：C++ 里 `sum / n` 的截断平均（向零取整），以及数学意义上的向下平均 `⌊sum / n⌋`。两者在整除时相同，仅在总和为负且除不尽时相差 1。

**输入**：第一行一个整数 `n`（`1 ≤ n ≤ 1000`）。第二行 `n` 个整数，每个数的绝对值不超过 `10^9`。

**输出**：一行两个整数，依次为截断平均和向下平均，用单个空格分隔。

### 示例

输入：

```text
2
-7 -8
```

输出：

```text
-7 -8
```

`-15 / 2` 在 C++ 里是 `-7`，而向下取整是 `-8`。

### 约束

- 总和用 64 位整数保存。
- 不要用浮点数计算平均值。
