读入 `n` 个有符号整数，分别报告它们的两种平均数：

- **截断平均**：C++ 中 `sum / n` 的结果，向零取整；
- **向下平均**：数学意义上的 floor，向下取整（`⌊sum / n⌋`）。

当 `sum` 能被 `n` 整除时两者相同；只有当 `sum` 为负数且除不尽时，二者才相差 1。

**输入**：第一行一个整数 `n`（`1 ≤ n ≤ 1000`）。第二行 `n` 个整数，每个数的绝对值不超过 `10^9`。

**输出**：一行两个整数，依次为截断平均和向下平均，用单个空格分隔。

### 示例

输入：

```text
2
-7 -8
```

输出：

```text
-7 -8
```

`-15 / 2` 在 C++ 里是 `-7`，而向下取整是 `-8`。

### 约束

- 总和用 64 位整数保存。
- 不要用浮点数计算平均值。
