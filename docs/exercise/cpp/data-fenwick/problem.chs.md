维护一个长度为 `n` 的数列，初始全为 0，支持单点加与区间求和。请用树状数组（Fenwick tree）实现，使得每次操作都是 `O(log n)`。

### 输入

第一行两个整数 `n` 和 `q`。接下来 `q` 行，每行一条命令：

- `add i x`：把第 `i` 个位置加上 `x`（`x` 可以为负）。
- `sum i`：输出前 `i` 个位置的和。
- `range l r`：输出第 `l` 到第 `r` 个位置的和，保证 `l <= r`。

位置从 1 开始编号。

### 输出

对每条 `sum` 和 `range` 命令按顺序输出一行，答案用 64 位整数保存。

### 示例

```
8 5
add 3 5
sum 3
add 1 2
sum 4
sum 8
```

输出：

```
5
7
7
```

### 约束

- `1 <= n, q <= 200000`
- `|x| <= 1000000000`
- 所有答案在 64 位有符号整数范围内。
