今有数列一列，长 `n` 位，其初空无一物，各位皆零。吏日操二事，交错而至：一曰“加”，于第 `i` 位增 `x`，损则以负数为之；二曰“问和”，问自首位至第 `i` 位共几何。又有问区间者，问自第 `l` 位至第 `r` 位共几何。问者、加者，各以万计。

术曰：置木一具，刻 `n` 位，谓之树状数组。凡行“加”，自第 `i` 位起，每次都取其最低有效位而加之（`i += i & -i`），木上经过之位皆记其数。凡问自首位至第 `i` 位之和，自 `i` 起，每次去其最低有效位（`i -= i & -i`），取木上诸位相加。若问 `l` 至 `r`，则以前 `r` 位之和减前 `l - 1` 位之和。如此，一加一问，皆不过 `O(log n)` 步。

**人话**：维护一个长度为 `n` 的数列，初始全为 0，支持单点加 `x`（可为负）与前缀和、区间和查询，答案用 64 位整数保存。读入 `n` 和 `q`，按顺序执行 `q` 条命令，对每条 `sum` 和 `range` 输出一行。请用树状数组（Fenwick tree）实现，使每次操作都是 `O(log n)`。

### 输入

第一行两个整数 `n` 和 `q`。接下来 `q` 行，每行一条命令：

- `add i x`：把第 `i` 个位置加上 `x`（`x` 可以为负）。
- `sum i`：输出前 `i` 个位置的和。
- `range l r`：输出第 `l` 到第 `r` 个位置的和，保证 `l <= r`。

位置从 1 开始编号。

### 输出

对每条 `sum` 和 `range` 命令按顺序输出一行，答案用 64 位整数保存。

### 示例

```
8 5
add 3 5
sum 3
add 1 2
sum 4
sum 8
```

输出：

```
5
7
7
```

### 约束

- `1 <= n, q <= 200000`
- `|x| <= 1000000000`
- 所有答案在 64 位有符号整数范围内。
