话说这一日，说书人案上摆着一块六十四位的铜牌，牌面刻度从 0 到 63，0 在右手边，算最低位。铜牌初时一片空白，64 个格子全是 0。

列位看官，台下递上来 `n` 张纸条，每张写一道号令。说书人照单全收，来一道办一道：

- `set i`：把第 `i` 格翻成 1。
- `reset i`：把第 `i` 格抹成 0。
- `flip i`：把第 `i` 格翻个面，0 变 1，1 变 0。
- `test i`：报一声第 `i` 格如今是 0 还是 1。
- `count`：数一数牌上有几个 1。
- `first`：报最低的亮格号码；全暗就报 `-1`。
- `last`：报最高的亮格号码；全暗也报 `-1`。
- `any`：只要亮着一格就报 `1`，全暗报 `0`。
- `fill`：把 64 格全部点亮。

且住：只有 `test`、`count`、`first`、`last`、`any` 这五道会出声，其余四道只管动手，不许回话。命令与下标之间恰好一个空格。

**人话**：维护一个初值全 0 的 64 位标志寄存器，按顺序执行 `n` 条命令。`set`、`reset`、`flip`、`test` 带下标 `i`（`0 <= i < 64`，第 0 位是最低位）；`test` 输出该位值，`count` 输出 1 的个数，`first` 输出最低的 1 位下标，`last` 输出最高的 1 位下标，`any` 输出是否存在 1，`fill` 全部置 1。没有 1 时 `first` 与 `last` 都输出 `-1`；只输出结果，不回显命令。可以用 `std::bitset<64>`，也可以自己维护一个 64 位无符号整数。

### 输入

第一行一个整数 `n`（`1 <= n <= 1000`），表示命令数。

接下来 `n` 行，每行一条上述命令。

### 输出

对每条会输出结果的命令，按执行顺序各输出一行。`test`、`count`、`first`、`last`、`any` 有输出；`set`、`reset`、`flip`、`fill` 没有输出。

### 示例

输入：

```text
8
set 0
set 63
test 0
test 63
test 1
count
first
last
```

输出：

```text
1
1
0
2
0
63
```

### 约束

- 命令和下标之间恰好一个空格。
- 可以使用 `std::bitset<64>`，也可以自己维护一个 64 位无符号整数。
- 只输出结果，不要回显命令。
