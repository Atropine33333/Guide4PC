耶和华晓谕摩西说：你按会众的支派数点他们，凡 `n` 人，各归本家，各立旗号。起初各人自为一族，族数共 `n`。

摩西便召了众长老来，对他们说：若有二人同宗，就要把他们并作一族；并族之时，记一人为族长，族数减一。若二人本来已在一族，就不可再减族数。有人问某人属哪一族，就报出他那一族的族长；又问二人是否同宗，就照族长判断。会众之中，还要随时报出如今共有几族。

耶和华又晓谕说：数点之时，凡引路的，都当把沿路的族谱压平，叫人人直指族长，免得日后绕远路。摩西就照耶和华的吩咐行。

**人话**：实现并查集（disjoint-set union）。`DisjointSet(int n)` 让编号 `0..n-1` 的元素各自成组，`n` 为 0 也行；`find(x)` 返回所在组的代表元；`unite(a, b)` 只有在两组不同时才合并并返回 `true`，本来同组返回 `false`、组数不变；`connected(a, b)` 判断是否同组；`components()` 返回当前组数。调用参数保证在 `[0, n)` 内。建议路径压缩加按秩合并，正确性第一。不要写 `main`。

实现：

```cpp
class DisjointSet {
public:
    explicit DisjointSet(int n);   // 元素编号 0..n-1，n 可以为 0
    int find(int x);               // 返回 x 所在组的代表元
    bool unite(int a, int b);      // 合并成功返回 true，本来同组返回 false
    bool connected(int a, int b);
    int components() const;        // 当前组数
};
```

要求：

- 初始时每个元素各自成组，组数为 `n`；
- `unite` 只在两组确实不同时减少组数；
- 调用参数保证在 `[0, n)` 范围内；
- 建议使用路径压缩和按秩合并，但正确性是第一位的。

不要写 `main`。
