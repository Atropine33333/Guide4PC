《九章算术·余数》

今有甲乙二数，甲为被除，乙为除数，乙不为零。问：C++ 取余几何？又，欲令余数落于零与乙之绝对值之间，当得几何？

术曰：以乙除甲，商向零截断；以商乘乙，甲减之，所得为余。余之符号随甲，此本法也。若余为负，则加乙之绝对值，复加至非负而后止；所得必小于乙之绝对值，而甲减之必为乙所整除。

答曰：先书截断之余，次书归正之余，中隔一空。

**人话**：读入两个整数 `a` 与 `b`，输出两样东西，用单个空格隔开：一是 C++ 表达式 `a % b` 的结果，二是把余数规范到 `0 ≤ r < |b|` 之后的 `r`。`b` 可以是负数，但不会为零；全程用整数运算，别碰浮点。

### 输入

一行两个整数 `a` 和 `b`（`b ≠ 0`，`|a| ≤ 10^9`，`|b| ≤ 10^9`）。

### 输出

一行两个整数：

- 第一个是 C++ 表达式 `a % b` 的值。结果非零时，符号与被除数 `a` 相同。
- 第二个是满足 `0 ≤ r < |b|` 且 `a - r` 能被 `b` 整除的余数 `r`。

### 示例

输入：

```text
-7 3
```

输出：

```text
-1 2
```

`-7 / 3` 向零取整得到 `-2`，所以 `-7 % 3` 是 `-1`；要落到非负区间，还需要加一个 `|b|`。

### 约束

- `b` 可以是负数，但不会是 0。
- 不要使用浮点数计算余数。
