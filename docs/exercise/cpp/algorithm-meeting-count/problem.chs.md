话说天下大势，分久必合，合久必分。这一日，某公司会议室门前，排起长队，各部门都来抢这一间屋子。

列位看官，且听我道来：每场会都有起止时辰。前一场散了，后一场方能进去；首尾相接——前一辰散、后一辰开——不算冲突。也允许开了就散，不占时辰，可也算一场。

问一天下来，最多能排几场？

**人话**：给出 `n` 个区间 `[s, e]`，选最多互不重叠的区间，输出个数。

### 输入

第一行一个整数 `n`。接下来 `n` 行，每行两个整数 `s` 和 `e`，表示一场会议从 `s` 开始、到 `e` 结束。允许 `s == e`，这样的会议不占用时间，但仍算安排了一场。

### 输出

一个整数，表示最多能安排的会议数量。

### 示例

```
3
1 2
2 3
3 4
```

输出：

```
3
```

三场会议首尾相接，可以全部安排。

### 约束

- `1 <= n <= 100000`
- `0 <= s <= e <= 1000000000`
