会议室只有一间，你拿到了 `n` 场会议申请，每场用开始时间和结束时间表示。只要前一场的结束时间不晚于后一场的开始时间，两场就可以都安排。求最多能安排多少场。

### 输入

第一行一个整数 `n`。接下来 `n` 行，每行两个整数 `s` 和 `e`，表示一场会议从 `s` 开始、到 `e` 结束。允许 `s == e`，这样的会议不占用时间，但仍算安排了一场。

### 输出

一个整数，表示最多能安排的会议数量。

### 示例

```
3
1 2
2 3
3 4
```

输出：

```
3
```

三场会议首尾相接，可以全部安排。

### 约束

- `1 <= n <= 100000`
- `0 <= s <= e <= 1000000000`
