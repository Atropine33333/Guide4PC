哦，我亲爱的，瞧瞧这段程序。

它想数两样东西：非空的行，和全部的词。可它把每个换行都当成一行，把每一个空格都当成一个词——连成一串的空格，它就数出一串空词来。老天爷，那一小段里明明只有三个词，它偏要数出五个。

要知道，词与词之间隔着的是空白：空格也好，制表符也好，一个或一连串，都算一道墙。行的开头与结尾若有空白，那不算词。空行，也就是只剩空白的行，不算行。

至于循环，一行一行读下去，读到末尾为止。每读一行，先看这行里有没有非空白字符，有才记一行；词呢，按空白切开，切出几段就记几个。

哦，还有一件事，我亲爱的：输出只有一行，两个整数，用单个空格隔开。别多写，也别少写。

**人话**：读入若干行直到 EOF，统计非空行数与单词总数。单词以任意空白（空格或制表符）分隔，一段连续的空白只分隔一次；只含空白的行不计入行数。修好 starter 中按空格个数计词、按行数计行的写法，输出一行两个整数。

下面的程序应当统计输入中有多少个非空行，以及一共有多少个单词。单词之间用任意空白字符（空格或制表符）分隔，空行不计入行数。

```cpp
#include <iostream>
#include <string>

int main() {
    int lines = 0;
    int words = 0;
    std::string line;
    while (std::getline(std::cin, line)) {
        ++lines;
        words += 1;
        for (char ch : line) {
            if (ch == ' ') ++words;
        }
    }
    std::cout << lines << ' ' << words << '\n';
    return 0;
}
```

这份代码在连续空格、制表符、空行和首尾空白下都会给出错误结果。请修好它，使输出符合要求。

### 输入

若干行文本，直到 EOF。每行不超过 1000 个字符，总字符数不超过 100000。

### 输出

一行两个整数：非空行数与单词总数。

### 示例

输入：

```text
first line

second
```

输出：

```text
2 3
```

### 约束

- 单词与行都以空白字符为界，空行（只含空白字符的行）不计入行数。
- 输出只包含一行。
