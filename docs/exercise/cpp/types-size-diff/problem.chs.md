读入两个非负整数，计算“剩余量”：较大者减较小者；如果第一个数较小，结果为 0。

**输入**：一行两个整数 `a b`（`0 ≤ a, b ≤ 10^19`）。

**输出**：一行一个整数，表示 `max(a - b, 0)`。

### 示例

输入：

```text
9 4
```

输出：

```text
5
```

输入：

```text
4 9
```

输出：

```text
0
```

### 约束

- 两个数都可能达到 `10^19`，超过 `long long` 的正数上限，必须用 `unsigned long long` 读入和输出。
- 如果先写 `a - b` 再判断，`a < b` 时会得到巨大的回绕值；要先比较大小。
- `10^19` 仍在 `unsigned long long` 的范围内（上限约 `1.8·10^19`）。
