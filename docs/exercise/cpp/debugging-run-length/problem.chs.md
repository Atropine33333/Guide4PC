读入一行由小写字母组成的非空字符串，按游程编码输出：把每一段连续相同的字符写成“字符 + 该字符出现的次数”，各段直接相连，不添加分隔符。

给定的 starter 能编译，但答案不正确。请找出并修正错误，保持程序的输入输出格式不变。

**输入**：一行仅含小写字母的字符串，长度在 1 到 200 之间。

**输出**：一行游程编码结果。

### 示例

输入：

```text
aaabbc
```

输出：

```text
a3b2c1
```

### 约束

- 每个字符最多连续出现 200 次，次数写成普通十进制，不带前导零。
- 最后一段也必须输出，不能遗漏。
- 不要改变输入输出格式，只修掉 starter 中的错误。
