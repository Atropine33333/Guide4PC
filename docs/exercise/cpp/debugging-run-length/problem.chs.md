话说这一行小写字母，排得整整齐齐，忽而三个 `a`，忽而两个 `b`，末尾还单着一个 `c`。

列位看官，今日这段书，说的叫游程编码。怎么个编法？同一段里相同的字，合成一处，先写这个字，再写它连着出现的次数。几段相连，中间不加标点。`aaabbc` 这么一段，说成 `a3b2c1`。

有人编到此处，把最后一段给忘了。您想，书说到结尾，最后一句最要紧；末了一段，也得报上数来。程序里头那个计数，只在字换了的时候才往外写，走到末了便收了笔，末尾这一段就没了踪影。

另有一处要留神：计数写成十进制，不带前导零；一段里最多 200 个字，次数也就到 200 为止，三位数到头。

闲话少说，入的是一行字母，出的是一行编码。

**人话**：读入一行小写字母，做游程编码：把每段连续相同字符写成“字符 + 次数”，各段直接相连，不加分隔符。最后一段也要输出；次数用普通十进制，不带前导零。starter 在循环结束后漏了写最后一段，补上即可。输入输出格式不变，只改 `starter.cpp` 里那段循环。

**输入**：一行仅含小写字母的字符串，长度在 1 到 200 之间。

**输出**：一行游程编码结果。

### 示例

输入：

```text
aaabbc
```

输出：

```text
a3b2c1
```

### 约束

- 每个字符最多连续出现 200 次，次数写成普通十进制，不带前导零。
- 最后一段也必须输出，不能遗漏。
- 不要改变输入输出格式，只修掉 starter 中的错误。
