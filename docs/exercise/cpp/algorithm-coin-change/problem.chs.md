**第十八章**

天国好像一个王要和他仆人算账。那仆人欠他 `target` 枚银子，王说：“你且用最少的钱币还清。”

仆人便取出 `m` 种钱币，每种面额都可以用无数次。他先抓大的，王摇头；他再换小的，王仍摇头。原来贪心不能使他还得最少。

王又说：“凡还不清的，就把他交给掌刑的，等他还清了所欠的债。”那还不清的，便输出 `-1`。

**人话**：给定 `m` 种面额和一个目标金额 `target`，每种硬币可用任意多次，求凑出 `target` 的最少硬币数；凑不出输出 `-1`，`target = 0` 时输出 `0`。

**输入**：

- 第一行两个整数 `m` 和 `target`（`1 ≤ m ≤ 10`，`0 ≤ target ≤ 5000`）。
- 第二行 `m` 个互不相同的正整数，表示硬币面额，每个不超过 `1000`。

**输出**：

- 一个整数：最少硬币数；如果无法恰好凑出目标金额，输出 `-1`。
- `target = 0` 时输出 `0`。

### 示例

输入：

```text
3 6
1 3 4
```

输出：

```text
2
```

使用两枚面额为 `3` 的硬币；贪心地先拿 `4` 会得到 `4 + 1 + 1`，需要三枚。

### 约束

- 每种硬币数量不限。
- 面额互不相同，但顺序任意。
- 只要求最少枚数，不要求输出方案。
- 无法凑出时输出 `-1`，不要输出 `0` 或很大的哨兵值。
