惠子谓庄子曰：“有一数焉，名曰 `a`；又有指数 `b`，其大不知其几千里也。以 `a` 自乘 `b` 次，其积之巨，不可胜数。今只取其对于 `m` 之余，当何以求之？”

庄子曰：“子不见夫棰乎？一尺之棰，日取其半，万世不竭。指数亦然：折其半而自乘其底，半尽而止。岂在逐次而乘哉？”

惠子曰：“善。”

**人话**：计算 `a^b mod m`。`b` 最大到 `10^18`，逐个相乘会超时，要用二进制快速幂。

**输入**：一行三个整数 `a b m`（`0 ≤ a ≤ 10^9`，`0 ≤ b ≤ 10^18`，`1 ≤ m ≤ 10^9`）。

**输出**：一行一个整数，即 `a^b mod m`。

### 示例

输入：

```text
2 10 1000
```

输出：

```text
24
```

### 约束

- 指数可以达到 `10^18`，逐个相乘会超时，要用二进制快速幂。
- `b = 0` 时结果是 `1 mod m`；`a = 0` 且 `b > 0` 时结果是 0。
- 中间乘积最大约为 `(10^9)^2 = 10^18`，用 `long long` 计算即可；每次乘法后立刻取模。
