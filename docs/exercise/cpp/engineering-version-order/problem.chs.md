今有版本若干，皆以点分之，如 `1.2.3` 之属。问：何以次之？

术曰：自左而右，逐段较其数。段数不足者，以零补之。数大者居后，数小者居前。段段相同，则二版等也，仍依其入列之先后，勿乱其序。

又术曰：版之段数或一或四，每段之数至 `10^9` 而止，书写可带前导之零；前导之零不入比较，只留在纸上。故 `1.2`、`1.2.0`、`1.02.0` 三版相等。

问者曰：若以字比之，何如？答曰：不可。以字比之，`1.10` 反在 `1.2` 之前；须化为数，方得其序。

今有版三：`1.2.3`、`1.10.0`、`1.2.10`。术曰：`1.2.3` 居首，`1.2.10` 次之，`1.10.0` 居末。

**人话**：读入 `n` 个点分版本号（1 到 4 段，每段 0 到 `10^9`，允许前导零），按数值逐段比较并做稳定排序，原样输出字符串。用 64 位整数比较，相等时保持输入顺序。

### 输入

- 第一行一个整数 `n`（`1 ≤ n ≤ 100`）。
- 接下来 `n` 行，每行一个版本号：由 1 到 4 个非负整数用 `.` 连接而成，每个整数在 `0` 到 `10^9` 之间，允许前导零。

### 输出

`n` 行，排序后的版本号，保持它们原来的字符串形式（包括前导零）。

### 排序规则

- 从左到右比较各段数值，第一处不同的段决定大小。
- 段数不同时，缺少的段按 0 处理：`1.2`、`1.2.0`、`1.02.0` 三者相等。
- 相等版本保持输入中的相对顺序（稳定排序）。
- 例如 `1.2.3 < 1.2.10 < 1.10.0`。

### 示例

输入：

```text
3
1.2.3
1.10.0
1.2.10
```

输出：

```text
1.2.3
1.2.10
1.10.0
```

### 约束

- 不能按字符串直接排序，`"1.10"` 会排在 `"1.2"` 前面。
- 前导零只影响输出形式，不影响比较：`01.002` 与 `1.2` 相等。
- 每段最大 `10^9`，用 64 位整数比较更安全。
- 相等时不要用不稳定的 `std::sort` 打乱顺序。
