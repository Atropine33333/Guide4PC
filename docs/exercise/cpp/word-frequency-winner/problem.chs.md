给定若干个小写英文单词，找出出现次数最多的那个。如果出现次数最多的单词不止一个，输出字典序最小的那个。

**输入**：

- 第一行一个整数 `n`（`1 ≤ n ≤ 1000`）。
- 第二行 `n` 个由单个空格分隔的单词，每个单词只含小写字母，长度不超过 20。

**输出**：一行一个单词，即出现次数最多且字典序最小的单词。

### 示例

输入：

```text
5
apple banana apple cherry banana
```

输出：

```text
apple
```

`apple` 和 `banana` 都出现 2 次，`apple` 字典序更小。

### 提示

`std::map<std::string, int>` 会同时帮你完成计数和按字典序排序；遍历时用严格大于来更新答案，就能在并列时保留字典序最小的单词。
