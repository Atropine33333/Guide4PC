The program below counts vowels among `n` characters, but it contains bugs. Find and fix them so that it passes all tests.

The vowels are `a`, `e`, `i`, `o`, `u`, and their uppercase forms.

**Input**:

- The first line contains an integer `n` (`1 ≤ n ≤ 1000`).
- The second line contains `n` space-separated ASCII letters.

**Output**: one integer, the number of vowels.

### Example

Input:

```text
5
H e l l o
```

Output:

```text
2
```

`e` and `o` are vowels.

### Hint

- Check whether the loop examines all `n` characters;
- Check upper and lower case;
- Do not change the input/output format or rewrite the whole exercise; fix the logic bugs in `starter.cpp`.
