（台上两个人，一张桌子，一把扇子。）

甲：今天说个缓存。

乙：说呗。

甲：固定容量，装键和值。装满了再来新的，就得赶走一个。

乙：赶谁？

甲：赶最久没碰过的那个。这叫 LRU。

乙：那 `get` 一下呢？

甲：取到值，顺手把这个键记成“刚用过”；取不到，就说什么也没有，返回 `false`。

乙：`put` 呢？

甲：键在，改值，也记成“刚用过”；键不在，插进去。要是满了，先赶人，再安顿新来的。

乙：那容量是零呢？

甲：哎，问得好。容量零，`put` 什么也不干，`get` 一律 `false`，`size()` 一直是零。

乙：听着不难。

甲：难处就在“刚用过”这三个字。取一次算用，改一次算用，插一次也算用。你少记一笔，赶走的就是错的。

乙：那怎么才算对？

甲：先拿固定种子随机跑一遍，再和参考实现一条一条对照。

**人话**：补完 `LruCache`：`get(key, out)` 命中时写值、标记最近使用并返回 `true`，否则返回 `false`；`put` 插入或覆盖，满了先淘汰最久未使用的键，容量为 0 时什么也不做；`size()`、`capacity()` 如实返回。

```cpp
class LruCache {
public:
    explicit LruCache(int capacity);

    bool get(int key, int& out);
    void put(int key, int value);

    int size() const;
    int capacity() const;
};
```

### 规则或约定

- 容量可以是 `0`。
- `get` 命中时把值写入 `out`，把该键标记为最近使用，返回 `true`；不存在返回 `false`。
- `put` 插入或覆盖：键已存在时更新值并标记为最近使用；缓存已满且要插入新键时，先淘汰最久未使用的键。容量为 0 时什么也不做。
- `size` 返回当前键的数量；`capacity` 返回构造时的容量。
- 不要写 `main`。
