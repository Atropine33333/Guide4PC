读入两条长度相同的 DNA 字符串，统计它们的汉明距离，并输出第一条字符串的反向互补链。

互补规则是 `A` 与 `T` 配对、`C` 与 `G` 配对。反向互补链就是先把原串倒过来，再把每个字符换成它的互补字符。

### 输入

两行，每行一个 DNA 字符串。两个字符串长度相同，只包含大写字母 `A`、`C`、`G`、`T`。

### 输出

- 第一行：两个字符串在相同位置上不同字符的个数。
- 第二行：第一条字符串的反向互补链。

### 示例

输入：

```text
AACG
TAGC
```

输出：

```text
3
CGTT
```

### 约束

- 字符串长度在 1 到 100 之间。
- 两个字符串长度一定相同。
- 只使用标准库，不要输出多余的空格或空行。
