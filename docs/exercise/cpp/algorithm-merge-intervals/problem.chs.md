**第七章**

以色列人出埃及地，各支派在旷野安营。每一支派自 `left` 扎到 `right`；有的两支彼此搭界，营帐便连成一片。

耶和华晓谕摩西说：“你要数点各支派的营地。凡彼此搭界的，并作一处；仅止相邻、并不搭界的，各归各营。并完之后，按起营之处，自小至大，一一记下。不可漏掉一支，也不可把一处并作两处。”

摩西便照耶和华所吩咐的行了。

**人话**：实现函数 `merge_intervals`，把若干闭区间合并成互不相交的列表，按左端点升序返回。不要写 `main`。

先定义结构体：

```cpp
struct Interval {
    int left;
    int right;
};
```

实现：

- `std::vector<Interval> merge_intervals(std::vector<Interval> intervals)`：合并所有相交的闭区间，返回按 `left` 升序排列、互不相交的区间列表。

两个闭区间 `[a, b]` 和 `[c, d]` 相交当且仅当 `c ≤ b`（排序后）。端点相接的区间 `[1, 2]` 与 `[2, 3]` 要合并；仅仅相邻的 `[1, 2]` 与 `[3, 4]` 不合并。输入中的每个区间都满足 `left ≤ right`。
