哦，我亲爱的，总算来了一位懂行的。请坐，别客气——就当这是你自己的剪辑室。

您瞧，这台老机器收到的台词本上，反斜杠是个爱管闲事的家伙。它一露面，后头那个字母就得改口：`n` 念作换行，`t` 念作制表，`r` 念作回车；要是再来一个反斜杠跟它肩并肩，就合成一个孤零零的反斜杠。老天爷，这行当的规矩可真是多。

它后头跟着别的字符呢？那就原样留着，两个都留，谁也不许动。要是它站在台词本的最末尾，后头一个人也没有，那也由它去——就留它一个反斜杠站在那儿。空格、数字、标点，统统照抄。

还有，亲爱的，别自己写 `main`。

**人话**：实现 `expand_escapes(const std::string& input)`，从左到右扫描，把 `\n`、`\t`、`\r`、`\\` 展开成对应字符；未知转义与末尾孤立的反斜杠原样保留。

```cpp
std::string expand_escapes(const std::string& input);
```

规则：

- `\n` 变成一个换行符（`'\n'`）。
- `\t` 变成一个制表符（`'\t'`）。
- `\r` 变成一个回车符（`'\r'`）。
- `\\` 变成一个反斜杠。
- 反斜杠后面跟着其他字符时，保留反斜杠和那个字符，不做特殊处理。
- 输入结尾单独一个反斜杠时，原样保留这个反斜杠。
- 其他字符原样复制，包括空格、数字和标点。
- 不要写 `main`。

### 提示

从左到右扫描。遇到反斜杠时先看它后面是否还有字符：没有就输出反斜杠；有就根据下一个字符决定输出什么，并跳过这两个字符。未知转义要输出反斜杠和下一个字符。
