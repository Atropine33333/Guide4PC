（帐中烛火摇曳。问卜者洗牌，抽牌，把一叠数字牌摊在桌上。牌可以重复。）

问卜者：我想问“第 `k` 小”的那张牌。

占卜师：先别急。牌是一张一张进来的。你说 `add x`，我就把 `x` 放进牌堆；你说 `erase x`，我就从牌堆里抽走一张 `x`，只抽一张；牌堆里没有 `x`，我就不动。

问卜者：那 `kth k` 呢？

占卜师：我把牌从小到大排开，数到第 `k` 张。`k` 从 1 起算。若 `k` 小于 1，或者大过牌堆现有的张数，牌面写 `none`。问一次，答一次。

问卜者：重复的牌怎么算？

占卜师：同名的牌有几张算几张。`erase` 只收走其中一张，余下的仍留在牌堆里。

问卜者：牌堆最多两千张，我若每次都从头数呢？

占卜师：那是笨办法，倒也算数。想快，就用能排序、能按值删除、能按次序取第 `k` 个的容器。命里有时终须有，命里无时写 `none`。

**人话**：维护一个允许重复的整数多重集合，按输入顺序处理 `q` 条操作：`add x` 插入一个 `x`；`erase x` 删除一个等于 `x` 的元素，不存在则什么也不做；`kth k` 查询当前第 `k` 小的元素，`k < 1` 或 `k` 大于当前元素个数时输出 `none`。每个 `kth` 输出一行，其他操作不输出。`q ≤ 2000`，`|x| ≤ 10^9`。

**输入**：

- 第一行一个整数 `q`（`1 ≤ q ≤ 2000`），表示操作数。
- 接下来 `q` 行，每行是下面三种之一：
  - `add x`：插入一个 `x`（`|x| ≤ 10^9`）；
  - `erase x`：删除一个等于 `x` 的元素；如果不存在，什么也不做；
  - `kth k`：查询第 `k` 小的元素（`k` 是普通整数，可能小于 `1` 或大于当前元素个数）。

**输出**：

- 对每个 `kth` 操作输出一行：第 `k` 小的元素；如果 `k < 1` 或 `k` 大于当前元素个数，输出 `none`。
- 其他操作不产生输出。

### 示例

输入：

```text
6
add 5
add 1
add 5
kth 1
erase 5
kth 2
```

输出：

```text
1
5
```

### 约束

- 集合中可能有重复值，`erase` 只删掉其中一个。
- 查询之间没有嵌套，按输入顺序依次处理。
- `kth` 查询的 `k` 也可能是 `0` 或负数。
- 输出只用小写字母和十进制数字。
