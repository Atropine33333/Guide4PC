话说有一个数，姓考名拉兹，脾气古怪：

遇着偶数，便折半；遇着奇数，便三倍再加一。如此反复，不管起始是几，最后总要落到 1 上。江湖上至今没人证得出这个理，也还没人找出反例。

列位看官，今日不问它为何落下来，只问它落了多久、路上最高爬到几。起始的那个数算在路程之内，末尾的 1 也算。

**人话**：读入一个正整数 `n`，按 Collatz 规则反复变换直到得到 1，输出变换次数与过程中出现过的最大值（含初始的 `n` 和最后的 1），用单个空格隔开。

**输入**：一行一个整数 `n`（`1 ≤ n ≤ 10^6`）。

**输出**：一行两个整数，用单个空格分隔：变换次数与过程中的最大值。

### 示例

输入：

```text
6
```

输出：

```text
8 16
```

序列是 `6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1`，共 8 次变换，最大值为 16。

### 约束

- `n = 1` 时不需要变换，次数为 0，最大值为 1。
- 中间值可能超过 32 位整数范围，请用 64 位有符号整数保存。
- 输出只包含两个十进制整数和一个空格。
