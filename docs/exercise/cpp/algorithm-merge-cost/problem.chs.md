一排石堆，第 `i` 堆有 `piles[i]` 块石头。每次只能把相邻的两堆合并成一堆，代价是两堆石头总数，合并后的新石堆留在原来的位置。把所有石堆合并成一堆，求最小总代价。

需要实现的接口（不要写 `main`）：

```cpp
long long min_merge_cost(const std::vector<int>& piles);
```

### 输入

无。

### 输出

无。函数返回最小总代价，答案用 `long long` 保存。

### 示例

```cpp
min_merge_cost({1, 2, 3}) == 9
```

先合并 `1` 和 `2`，代价 3，剩下 `{3, 3}`；再合并这两堆，代价 6；总代价 9。若先合并 `2` 和 `3`，总代价是 5 + 6 = 11，更差。

### 约束

- `0 <= piles.size() <= 100`
- `0 <= piles[i] <= 1000000`
- 空数组返回 0。
- 用固定种子生成小规模数据，并与穷举所有合并顺序的结果比较。
