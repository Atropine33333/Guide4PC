## 二、小技巧

### 2.1 右键 Windows 徽标键（Win + X）

在屏幕左下角的开始按钮上点右键，或者按 `Win + X`，会弹出一个菜单。里面的东西都是系统自带的管理工具，比你去控制面板翻来翻去快得多。

| 菜单里的选项 | 是干什么的 |
|--------------|------------|
| 应用和功能 | 卸载不需要的程序 |
| 移动中心 | 调亮度、音量、投屏 |
| 电源选项 | 改睡眠时间、电源计划 |
| 事件查看器（Event Viewer） | 看系统日志，蓝屏原因常在这里 |
| 系统 | 看电脑配置（CPU、内存、Windows版本） |
| 设备管理器（Device Manager） | 查看和更新驱动 |
| 网络连接 | 看网卡、手动填 IP 地址 |
| 磁盘管理（Disk Management） | 给硬盘分区 |
| 计算机管理（Computer Management） | 整合了好几个管理工具 |
| Windows PowerShell / 终端（Terminal） | 打开命令行 |
| 任务管理器（Task Manager） | 看进程、看性能、关掉卡死的程序 |

这个菜单里的东西大部分需要管理员权限。平时排查问题的时候，这里是最快的入口。

### 2.2 文件资源管理器的选中技巧

在文件资源管理器（File Explorer，就是打开“此电脑”后看到的那个窗口）里，选中文件的时候有两个很常用的方式：

- **按住 `Ctrl` 再点文件**：可以一个一个挑着选。比如你先点了一个文件，按住 Ctrl 再点另一个，两个都会被选中；再点一次其中某个，可以把它从选中里取消。适合“我要挑这几个，不要那一个”的情况。

- **先点一个文件，然后按住 `Shift` 再点另一个文件**：会把这两个文件之间的所有文件（包括中间的那些）一次性全选中。适合“我要从 A 到 B 这一整段”的情况。

这两个可以配合用。比如先按 Shift 选一段连续的范围，再按住 Ctrl 选中几个分散的。

### 2.3 任务管理器里能看到 PID

打开任务管理器（Task Manager，`Ctrl + Shift + Esc`），点“进程（Process）”，你会看到一列表格。在表头那一行（显示“名称”“CPU”“内存”的那一行）上点右键，可以勾选更多列。其中有一个叫 **PID**。

**PID（Process Identifier，进程标识符）**：系统给每个正在运行的程序（进程）分配的一个编号，每个程序都不一样。

**有什么用**：有时候一个程序卡死了，但任务管理器里有好几个同名的，你分不清该结束哪一个。这时候看 PID 就能区分。另外有些命令行工具（比如 `taskkill`）也需要用 PID 来指定要关掉哪个进程。

勾选方法：任务管理器 → 详细信息 → 右键点击表头 → 选择列（Select columns）→ 勾选“PID”。

### 2.4 Windows Terminal 与 PowerShell 7

**Windows Terminal**：一个现代的命令行窗口程序。比起传统的 CMD 黑窗口，它支持多标签页、可以分屏、字体渲染更清晰，还能自定义主题。附录七里介绍过，装好之后把它固定在任务栏，以后所有命令行操作都从这里进。Windows Terminal 本身只是一个“壳”，里面可以跑 CMD、PowerShell 或者任何其他命令行工具。

**PowerShell 7**：一个命令行工具。和 Windows 系统自带的 Windows PowerShell（版本 5.x）是两个版本，可以共存。它的命令更统一，功能更强，还能跨平台（Windows、Mac、Linux 都能用）。普通用户不一定需要装，但如果你以后写脚本或者跟着某些教程操作，可能会用到。

两者的关系：Windows Terminal 是“窗户”，PowerShell 7 是“窗户里坐着的那个人”。你打开 Windows Terminal，在里面可以新建一个标签页跑 PowerShell 7。

### 2.5 环境变量

**环境变量（Environment Variable）**：可以理解成系统里的一些“全局小纸条”。每张小纸条上写着一个名字和对应的值，任何程序运行的时候都可以看这些小纸条，知道去哪里找东西。

常见的有：
- **PATH**：记录了一堆文件夹路径。你在命令行里敲 `notepad`，系统会挨个去这些文件夹里找 `notepad.exe`。你安装 Python 或者 FFmpeg 之后想在命令行里直接运行，本质上就是把它们的安装路径加到了 PATH 里。
- **TEMP**：临时文件放在哪里。
- **USERNAME**：当前登录的用户名。

**怎么改**：右键“此电脑”→ 属性 → 高级系统设置（Advanced system settings）→ 环境变量（Environment Variables）。分“用户变量（User variables）”（只对当前用户生效）和“系统变量（System variables）”（对所有用户生效）。

**你不需要现在就会改**。但如果以后你在命令行里敲一个命令，提示“不是内部或外部命令”，你知道可能是 PATH 没配好，往这个方向去搜就行。

### 2.6 注册表

**注册表（Registry）**：Windows 的一个巨型配置数据库。你平时在设置里改的东西——桌面壁纸、开机启动项、文件夹选项——最终都会写到注册表里。

**怎么打开**：`Win + R`，输入 `regedit`，回车。

**里面长什么样**：左边是“项”（Key，像文件夹），右边是“值”（Value，像文件）。几个最顶层的叫根键（Root Key）：
- `HKEY_CURRENT_USER`：当前用户的设置
- `HKEY_LOCAL_MACHINE`：整台电脑的全局设置
- `HKEY_CLASSES_ROOT`：文件关联（比如 `.txt` 默认用记事本打开）

**一个重要警告**：改错注册表可能会让软件出问题，严重的时候系统都开不了机。动手改之前，一定记得备份：右键点你要改的那个项 → 导出（Export），存一个 `.reg` 文件。万一改坏了，双击那个文件就能恢复。

**你不需要现在就会改**。但以后你在网上搜到某个教程说“改注册表可以解决某某问题”，你知道注册表是干什么的，也知道改之前要先备份，这就够了。

### 2.7 组策略

**组策略（Group Policy）**：你可以把它理解成“注册表的图形化开关”。组策略把一堆相关的注册表修改打包成了一个个选项，你只需要选“启用（Enabled）”或者“禁用（Disabled）”，系统自动帮你改注册表，不用自己去翻。

**怎么打开**：`Win + R`，输入 `gpedit.msc`，回车。（注意：Windows 家庭版默认没有这个功能。）

**举个例子**：你想禁用 USB 存储设备，防止别人插 U 盘拷你的文件。在组策略里找到“可移动存储访问”，选“拒绝所有权限”，启用了就行。如果让你自己去注册表里找对应的位置，可能找半天。

家庭版用户想用组策略的话，可以搜一下“gpedit-enabler”这种工具，但不保证稳定，也不一定要折腾。

### 2.8 内存管理相关

以下三个概念在任务管理器的“性能（Performance）”标签页里可以看到。

**页面文件（Page File）**

页面文件是硬盘上的一个隐藏文件（通常叫 `pagefile.sys`）。它还有一个名字叫 **SWAP（交换文件）**。当你的物理内存（RAM）不够用的时候，系统会把内存里暂时用不到的数据挪到这个文件里，把空出来的内存给当前需要运行的程序用。

可以理解成：你的桌子（内存）太小，放不下所有东西，就把暂时不用的资料先收到抽屉（硬盘）里，要用的时候再拿出来。硬盘比内存慢得多，所以如果系统频繁使用页面文件，电脑会明显变卡。

C 盘空间不足的时候，页面文件无法正常扩展，电脑就会卡顿。这也是为什么附录二里反复强调不要把 C 盘塞满。

**已提交（Commit）**

任务管理器里显示的“已提交”是一个总量，表示“系统已经承诺分给所有程序的内存总和”。这个数字可以大于你的物理内存——因为有一部分承诺是通过页面文件来兑现的。

打个比方：你手头只有 100 块钱现金（物理内存），但你的信用卡有 200 块钱额度（页面文件的空间）。你能“承诺”花掉的钱可以超过 100 块，只要最终从信用卡里补上就行。

当“已提交”的总量超过了物理内存 + 页面文件的总和，系统就会提示“内存不足”，甚至可能强制关掉一些程序。

**分页缓冲池（Paged Pool）与非分页缓冲池（Nonpaged Pool）**

Windows 内核（Kernel，系统的核心部分）会给自己留一块内存，专门放一些关键数据。这块内存分为两种：

- **非分页缓冲池（Nonpaged Pool）**：永远呆在物理内存里，不会被挪到页面文件。因为有些关键数据（比如处理硬件中断的）必须随时能用，不能等从硬盘读回来。
- **分页缓冲池（Paged Pool）**：可以被挪到页面文件。里面放的是那些“需要的时候能等一下”的内核数据。

普通用户不需要关心这两个池的具体数值。但在任务管理器的性能页面看到它们的时候，知道“分页的可以挪到硬盘，非分页的必须留在内存”就够了。

### 2.9 硬件编解码器

**硬件编解码器（Hardware Encoder/Decoder）**：显卡（GPU）里面有一块专门的电路，用来做视频的编码或者解码。这块电路和显卡跑游戏的流处理器是分开的。

- **硬件解码（Hardware Decoding）**：播放视频的时候，用显卡里这块专门电路来解码。CPU 几乎不用干活，功耗低，发热小，播放高码率 4K 视频也不会卡。
- **硬件编码（Hardware Encoding）**：录屏、直播、导出视频的时候，用这块电路来压缩视频。速度快，对游戏帧数影响小。

**软件编解码器（Software Encoder/Decoder）**：用 CPU 来做这些事。CPU 虽然也能干，但效率比硬件电路低很多。播放 4K 视频或者导出视频的时候，CPU 容易跑满，电脑变卡，发热也大。

**你实际会遇到的情况**：
- 用 OBS 录游戏，编码器选 NVENC（NVIDIA 硬件编码）或者 QSV（Intel 核显硬件编码），就是让显卡硬件编码。对游戏帧数影响小。
- 播放一个高码率 4K 视频，CPU 占用很高，说明播放器没用上硬件解码。去播放器设置里找“硬件解码”或者“DXVA”选项，打开它。

任务管理器的“性能”页面里，GPU 那一栏通常会有“Video Encode”“Video Decode”两个小图，显示硬件编解码器的占用率。

### 2.10 磁盘性能相关

**IOPS（Input/Output Per Second，每秒输入输出次数）**

衡量硬盘处理“零散小文件”的能力。比如你打开一个有很多小图的文件夹、在游戏里加载场景、开虚拟机，这些场景下 IOPS 比顺序速度更重要。

- 机械硬盘（HDD）：几十到一百多 IOPS
- 普通 SATA SSD：几千到几万 IOPS
- 好一点的 NVMe SSD：几十万甚至上百万 IOPS

这也是为什么把操作系统装在固态硬盘上，开机速度、打开软件的速度会快那么多——不是因为顺序读写有多快，而是 IOPS 比机械硬盘高了几百上千倍。

**MB/s 与 Mbps**

这两个单位经常被弄混，尤其在测网速的时候。

- **MB/s（Megabyte per second，兆字节每秒）**：你复制文件时看到的那个速度。1 MB/s 就是一秒传 1 兆字节的数据。
- **Mbps（Megabit per second，兆比特每秒）**：宽带套餐里说的那个速度。比如 100 兆宽带，指的是 100 Mbps。

**换算关系**：1 MB/s = 8 Mbps。所以 100 兆的宽带，理论最快下载速度是 100 ÷ 8 = 12.5 MB/s。

记住了：小写的 b 是比特（bit），大写的 B 是字节（byte），1 字节 = 8 比特。网速除以 8，才是你看到的下文件的速度。

**MB/s 和 IOPS 的关系**：这两个不是一回事。MB/s 是“一秒能传多少数据”，IOPS 是“一秒能处理多少个请求”。拷贝一个大电影文件，考验的是 MB/s；同时打开一千张小图片，考验的是 IOPS。一块好硬盘，两项都应该好，但价格也更贵。

### 2.11 留下印象即可

环境变量、注册表、组策略、页面文件这几个东西，你现在不需要会改，更不要乱动。但“留个印象”很重要：

- 以后装软件时命令行提示“不是内部或外部命令”——你知道可能是 PATH 的问题。
- 以后网上教程说“改注册表”——你知道那是什么，改之前要备份。
- 以后系统报“内存不足”——你知道可能是物理内存或者页面文件空间不够了。
- 以后电脑突然变卡，C 盘又红了——你知道可能是页面文件受影响。
- 以后播放视频卡顿或者 CPU 占用很高——你知道可能是没用上硬件解码。
- 以后测网速看到数字和下载速度对不上——你知道 Mbps 和 MB/s 要除以 8。

知道大概是什么东西、出了问题往哪个方向查，已经比绝大多数用户强了。

## 三、名词表

### 3.1 进程

**进程（Process）**：一个正在运行的程序。你打开一个浏览器、一个游戏、一个记事本，系统就给你创建了一个进程。每个进程有自己的内存空间，互不干扰。

在任务管理器里结束一个卡死的程序，本质就是杀掉它的进程。注意不要随便结束名字看起来像系统进程的东西（比如 `svchost.exe`），可能让电脑出问题。

### 3.2 线程

**线程（Thread）**：一个进程可以有多个线程。线程是真正干活的人。

打个比方：进程是一个工厂，线程是工厂里的工人。一个工厂可以只有一个工人（单线程），也可以有多个工人同时干活（多线程，Multithreading）。多线程的好处是能同时做几件事——浏览器一边下载文件一边渲染网页，就是多线程的功劳。

任务管理器里的 CPU 占用率，其实是所有线程占用率的和。一个高负载的程序往往有好几十甚至上百个线程。

### 3.3 句柄

**句柄（Handle）**：一个整数编号，Windows 用它来指代某个资源（比如一个打开的文件、一个窗口、一个线程）。你打开一个文件，系统给你返回一个句柄；以后对这个文件的操作（读、写、关闭）都要通过这个句柄。

**句柄泄漏（Handle Leak）**：程序用完资源之后忘了关闭句柄，导致这个资源一直被占用。最常见的症状就是：你想删一个文件，系统提示“文件被占用”，但你已经关掉了所有可能打开它的程序。很可能就是某个进程的句柄没关掉。

可以用 Process Explorer 或者 LockHunter 这类工具查看是哪个进程占着不放。
