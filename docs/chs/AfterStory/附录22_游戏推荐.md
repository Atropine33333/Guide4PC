# 附录二十二：游戏推荐

> 这里收录我喜欢的游戏，分类别列出来。纯粹个人口味，仅供参考。  
> 我不玩竞技类游戏，新出的大作配置要求太高也带不动，所以这份清单只覆盖我能玩、玩过、并且真心喜欢的作品。如果你的口味跟我差不多，可以参考；如果不一样，那当个了解就好。

## VN（视觉小说）

**Ever17 -the out of infinity-**

KID开发、打越钢太郎编剧的悬疑科幻名作。玩家被困于海底主题公园“LeMU”，必须在119小时崩溃倒计时中逃脱。游戏采用双主角视角（少年/武）交替推进，前四条角色线二十余小时的漫长铺垫，换来的是可可线最后那几分钟震撼到头皮发麻的伏笔回收。

**9-nine- 全系列**

PALETTE出品的异能战斗恋爱AVG，分四部加一个新章。故事发生在地震后出现圣遗物的白巳津川市，主角新海翔在追寻能力者事件真相的过程中逐步揭开幕后黑手。前两部是标准的萌系异能战斗，第三部开始剧情急速起飞，到第四部雪色雪花雪余痕时，编剧用一种朴实到极致的方式将玩家本人拽进了故事里。文字游戏的第四面墙被击穿，而你甚至没注意到它什么时候立起来的。

**ATRI -My Dear Moments-**

Aniplex.EXE发行的短篇全年龄视觉小说。海平面上升后的末日世界，少年夏生从海底打捞起一个机器人少女亚托莉。“高性能萝卜子”元气满满地喊出“主人”，在海边小镇的日常中填满了温暖与欢笑。但三本日记本揭示了真相——所有快乐的日常都是在为最后的告别做铺垫。八小时的流程，讲完了相遇、陪伴、告别，以及时间跨度数十年的重逢。

**Summer Pockets REFLECTION BLUE**

Key社出品的泣系长篇全年龄AVG。将背景搬到濑户内海的鸟白岛，男主角鹰原羽依里在整理祖母遗物时与岛上的少女们相遇。“暑假”“乡愁”“记忆”构成了整个故事的核心母题。Reflection Blue版追加了四条新路线和大量CG，体量远超初版，是Key社后期集大成之作。

**eden\***

minori出品的全年龄视觉小说。没有选项，只有一条直线到底的故事。地球即将毁灭，超级兵器"Felix"少女诗音用毕生心血送出最后的移民船，而军方的逃离命令下达后，男主角亮选择留在即将死去的星球上，陪她走完最后的旅程。全宽屏电影化演出，天门作曲，关于“告别”这件事做到了极致的纯粹与浪漫。


## 3A

**GTA5**

不需要介绍了吧，洛圣都。线下模式的三主角叙事（麦克、崔佛、小富）将相爱相杀刻画到极致，线上模式则构建了一个可供数千小时挥霍的犯罪帝国。

**GTA6**

R星母公司Take-Two确认，2026年11月19日发售，登陆PS5和Xbox Series。

**荒野大镖客2**

开放世界叙事的天花板之一。1899年的美国西部，亚瑟·摩根在帮派存亡与自我救赎之间的挣扎。节奏慢，细节多，沉进去就是几百小时。R星联合创始人Dan Houser称这是“他参与过的最佳作品”。

**赛博朋克2077**

首发灾难，两年后涅槃重生。夜之城的密度和沉浸感在开放世界里独一份。2.0版本和《往日之影》DLC把底子彻底翻了一遍，现在是它当初承诺的样子。如果你刚入坑，建议先玩本体再看衍生剧《边缘行者》，后劲很大。


## 独立游戏

**极乐迪斯科**

没有任何传统战斗，全靠对话和技能检定推进的侦探RPG。你扮演一个失忆的警探，在褴褛飞旋旅馆调查一具吊尸。检定点数分配到“内陆帝国”“能工巧匠”“博学多闻”——每项技能都是你脑子里的一个声音，它们会吵架。推荐啃生肉，先了解东欧、北欧文化和背景，还有各种意识形态。剧本拿过雨果奖，是唯一获此殊荣的游戏。记得多存档，否则很容易死在奇怪的地方。

**雨世界**

你是一只蛞蝓猫，在生态完备的废墟世界里求生。所有的生物都有自己的行为逻辑——它们捕食你、被更顶层的捕食者捕食、迁徙、睡觉、打架，不在乎你。上手极难，学习曲线垂直，但一旦跨过那道坎，你会发现这是关于从“猎物”变成“捕食者”最深刻的作品。最初Metacritic评分仅59，但开发团队持续更新七年，如今Steam好评率94%，还有大型扩展《倾盆大雨》和2025年新DLC《The Watcher》。

**Öoo**

一只毛毛虫被大鸟吞进了肚子，必须在被消化之前逃出去。核心道具是一颗会无限再生的炸弹，炸路、炸机关、炸开隐藏通道，甚至利用爆炸的气浪把自己弹到更高的地方。流程大约两到三小时，全程没有任何文字。由三位日本独立开发者合作完成，美术风格类似《动物井》，Steam发售一周就拿下了压倒性好评。

**Noita**

每个像素都有独立的物理属性——燃烧、融化、爆炸、导电。你在随机生成的洞穴里捡法杖，然后把法术像编程一样组合：子弹分裂、触发延时、投射物修正……几乎任何组合都能跑通，包括自杀。无存档，一条命，死回起点。

**脑叶公司**

Project Moon的第一作。你扮演脑叶公司的主管，负责收容管理从人类集体潜意识中诞生的“异想体”，从它们身上抽取能源。每只异想体都有自己的出逃机制和应对逻辑，你的员工会死，而且死得很惨。世界观从这里起步，通向一个非常庞大的都市世界。

**废墟图书馆**

承接脑叶公司结局。安吉拉在废墟上建立图书馆，邀请“宾客”前来，战败则化作书。卡牌战斗的核心是“情感等级”——不是抽到什么打什么，而是在对拼中积累情绪，每回合重新洗牌。Project Moon的故事在这里彻底放开了。

**Limbus Company**

Project Moon第三作，也是他们第一款全平台游戏。你扮演巴士管理人，带着12个罪人（全是脑叶公司时代的熟面孔）在都市里回收金枝。回合制战斗，带实时拼点判定。还在更新。

**osu!**

开源社区驱动型音乐节奏游戏。四种模式（标准、太鼓、接水果、钢琴），玩家自制谱面是核心。入门门槛低但精度天花板极高，一个谱面刷几百遍是常态。

**Casualties: Unknown**

一款残酷的洞穴探险生存游戏。你作为俘虏被派到异星找回丢失的货物，探索11层洞穴。核心特色是全面的肢体与心血管模拟系统——受伤需要包扎、控制感染、管理失血；情绪会影响生存几率，过度悲观会让处境更艰难。有3名玩法各异的角色，300种可发现物品，可在主菜单调整战利品掉率和危险程度。  
现在还在demo阶段，不过已经很好玩了，难度很大，推荐感兴趣的人试一试

**星际拓荒**

很好玩。很感动。很治愈。一辈子只能玩一次的游戏。

## 模组

很多游戏都可以加模组，可以去 Nexus Mods 搜索，那是一个全球最大的游戏模组分享平台，几乎所有热门游戏都能在上面找到玩家制作的模组。免费的，注册账号就能下载，不过免费下载速度比较慢。
