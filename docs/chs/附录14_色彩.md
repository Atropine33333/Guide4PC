# 附录十四：色彩

> 这个附录介绍色彩的基本概念——色域、色彩空间、色准、校色。如果你只是自己用电脑看视频、打游戏、修修自己拍的照片，这些知识其实不太用得上。但如果你开始做设计、修图、剪视频，并且需要把作品发给别人看或者打印出来，那了解一下会有帮助。

## 14.1 先说你最需要知道的一句话

**如果不涉及稿件交付（比如发给客户、打印、投稿），只是自己用——玩游戏、看视频、修自己拍的照片——那你屏幕的颜色“准不准”根本不重要。你觉得舒服就行。**

色彩管理是一个无底洞。除非你靠颜色吃饭（平面设计、修图师、视频调色、印刷），否则不必深究。万一以后需要了，知道有这回事、知道往哪个方向查，就够了。

## 14.2 色域与色彩空间

### 14.2.1 什么是色域

**色域（Gamut）** 是一个设备（显示器、打印机、投影仪）或者一个色彩标准能表现出来的所有颜色的范围。人眼能看到的颜色很多，不同设备只能覆盖其中的一部分。

常见的色域标准有：

| 色域 | 覆盖范围（相对人眼） | 主要用途 | 一句话说明 |
|------|----------------------|----------|------------|
| **sRGB** | 约 35% | 网页、普通显示器、Windows 默认 | 最通用的“保险色”。几乎所有设备都能正确显示。 |
| **DCI-P3** | 约 45% | 数字影院、苹果设备、HDR 视频 | 比 sRGB 更广，红和绿更鲜艳。 |
| **Display P3** | 约 45% | 苹果显示器 | 基于 DCI-P3，但白点改成和 sRGB 一样，兼容性更好。 |
| **Adobe RGB** | 约 50% | 专业摄影、印刷 | 加强了青绿色，为了覆盖 CMYK 印刷色域。 |
| **Rec. 709** | 和 sRGB 基本相同 | 高清电视（HDTV） | sRGB 的“电视版”，白点、伽马略有不同。 |
| **Rec. 2020** | 约 75% | 4K/8K 超高清电视（UHDTV） | 目前最大的色域标准之一，几乎没有消费级显示器能完全覆盖。 |

### 14.2.2 三个名字，基本一样的范围

**sRGB、Rec.709、Rec.601** 这三个色域的实际颜色范围几乎相同，差别在于：

- **sRGB**：用于电脑显示器、网页、消费级数码相机
- **Rec.709**：用于高清电视（HDTV），白点和 sRGB 一样，伽马曲线略有不同
- **Rec.601**：标清电视（SDTV）的标准，已经被 Rec.709 取代

对于普通用户，可以把它们理解为同一个东西——都是“最通用的那个小色域”。你在网上看到的绝大多数图片和视频都是 sRGB 或 Rec.709。

### 14.2.3 OKLAB：为什么需要它

传统的色彩空间（如 sRGB、P3）在数学上不够“均匀”。什么意思呢？在 sRGB 里，数值变化 10，在暗部可能变化很大，在亮部可能看不出区别。OKLAB 是一种较新的色彩模型，它的设计目标是：**数值变化相同的量，人眼感知到的变化也基本相同**。

OKLAB 主要用于颜色转换算法（比如把一张 sRGB 图片转成 P3，怎么转才不偏色）。普通用户不需要直接接触它，但你可以记住：以后看到某个软件支持 OKLAB，说明它对颜色的处理更科学。

### 14.2.4 为什么有这么多色域

不同的行业有不同的需求。印刷需要覆盖 CMYK（青、品红、黄、黑），所以有 Adobe RGB；电影院需要更大的动态范围和鲜艳的红绿色，所以有 DCI-P3；电视从标清到高清到超高清，就有了 Rec.601、Rec.709、Rec.2020。

对普通用户来说，**sRGB 是最安全的**。你在广色域显示器上设计了一张很鲜艳的图，发给朋友（他用普通 sRGB 显示器），看到的颜色会变淡。反过来，别人发给你一张 sRGB 的图，你用广色域显示器看，如果不做色彩管理，颜色会被错误地“拉伸”，变得过艳。这就是为什么很多设计师在修图时会把显示器切换到 sRGB 模式。

## 14.3 显示器的色域覆盖

买显示器的时候，参数里会写“覆盖 99% sRGB”“覆盖 95% DCI-P3”。这些数字怎么理解？

- **色域覆盖**：这台显示器能显示出某个色域里百分之多少的颜色。99% sRGB 意味着 sRGB 这个三角形里 99% 的颜色都能显示，剩下 1% 显示不出来。
- **色域容积**：显示器颜色范围的“面积”和某个色域的面积之比。有可能出现“120% sRGB 容积”——但颜色不准，因为超出了 sRGB 的部分可能偏到哪里去了。

**对普通用户**：覆盖 100% sRGB 的显示器，日常用已经很好了。更高的色域（P3、Adobe RGB）不是必须的，除非你有明确需求（比如剪 HDR 视频、做印刷设计）。

## 14.4 色准：ΔE（Delta E）

**ΔE（Delta E，读作“德尔塔 E”）** 是衡量颜色“准不准”的数值。ΔE 越小，显示出来的颜色和标准颜色之间的差异越小。

| ΔE 范围 | 含义 |
|----------|------|
| ΔE < 1 | 人眼几乎无法分辨差异（专业级） |
| ΔE < 2 | 很准，只有专业人员仔细对比才能看出 |
| ΔE < 3 | 普通用户可以接受 |
| ΔE > 5 | 肉眼明显能看出偏色 |

显示器的 ΔE 通常标的是“平均 ΔE”。比如“平均 ΔE < 2”，意思是大部分颜色都挺准，但个别颜色（比如深蓝色）可能偏差大一些。

**对普通用户**：不用纠结 ΔE。你打游戏的时候不会在乎“这个红色是不是标准的 sRGB 红色”。只要不偏得太离谱（比如白色看起来是粉色），就没问题。

## 14.5 校色仪与校色

如果你真的需要颜色准（比如你接了个设计活，客户要求颜色不能偏），那就需要**校色（Calibration）**。

### 14.5.1 什么是校色仪

**校色仪（Colorimeter 或 Spectrophotometer）** 是一个像鼠标大小的硬件，贴在屏幕上，测量屏幕实际显示的颜色，然后生成一个“颜色配置文件（ICC Profile）”给操作系统。Windows 加载这个配置文件后，会调整输出信号，让屏幕显示得更准。

常见的校色仪品牌：

- **Datacolor Spyder（蜘蛛）**：常见型号 Spyder X、Spyder 5，适合普通用户和摄影爱好者。
- **Calibrite（原 X-Rite）**：更专业，比如 ColorChecker Display、i1Display Pro。很多工作室用这个。

### 14.5.2 校色步骤

1. 把校色仪接上电脑，安装配套软件（或者用开源的 DisplayCAL）。
2. 让显示器预热至少 30 分钟（颜色稳定下来）。
3. 在软件里设置目标：色温（通常选 D65，即 6500K）、亮度（普通室内选 120 cd/m²）、伽马（sRGB/Rec.709 选 2.2）。
4. 把校色仪挂在屏幕中央，运行测量。软件会显示一系列颜色，校色仪逐个读取。
5. 测量完成后，软件生成 ICC 配置文件，并让 Windows 加载它。
6. 这仅供参考，我搜的资料，我也没用过，如果你真的需要，还是咨询店家吧。

### 14.5.3 什么时候需要校色

- **刚买的新显示器**：出厂校色不一定准，而且用久了会衰减。专业用户每 1~2 个月校一次。
- **换了显卡或重装系统**：系统自带的颜色配置可能丢了。
- **发现两个屏幕颜色不一样**：比如笔记本屏幕和外接显示器明显不同。
- **要交付印刷品**：印刷对颜色要求高，不校色可能印出来偏得离谱。

### 14.5.4 什么时候不需要校色

- **只玩游戏、看视频**：不需要。
- **用笔记本自带的屏幕**：笔记本屏幕的硬件素质有限，校色也提升不了多少，不值得花这个钱。
- **偶尔修图，只发朋友圈**：不需要。朋友圈照片没人拿色卡对比。
- **你没有校色仪**：租一个（淘宝上可以租，几十块一天），或者找朋友借。自己买一个几百到上千，如果你只是用一次，不划算。

## 14.6 色彩管理的重要性和非必要性

### 14.6.1 什么时候必须重视色彩管理

- **交给客户的设计稿**：你觉得好看的蓝色，客户那边显示成紫色，你的尾款就悬了。
- **打印/印刷**：屏幕和纸张是完全不同的介质。不经过色彩管理，打出来的东西和你屏幕上看的完全两回事。
- **视频调色并交付给平台（B站、YouTube 等）**：如果颜色空间没设置对，平台再转一次码，颜色全变了。
- **产品摄影（淘宝、电商）**：衣服的颜色不准，买家收到货发现色差，退货率高。

### 14.6.2 什么时候可以不用管

- **自己玩玩游戏**：不需要。
- **看视频、看电影**：不需要。视频本身已经是调好的颜色，你看到的就是导演想让你看到的（只要显示器不太差）。
- **修自己拍的照片，只发朋友圈或存手机**：不需要。你的朋友们用各种品牌的手机，每个屏幕颜色都不一样——你校得再准，到别人手机上照样偏。放松点。
- **写代码、写文档、上网课**：颜色和内容无关，不需要。

### 14.6.3 一句话总结

**如果你不涉及交付，只是自娱自乐，那就别折腾色彩管理。把精力花在内容上，比花在颜色上值。**

## 14.7 Windows 的色彩管理：为什么比 Mac 麻烦

这里简单提一下。很多人说“Mac 颜色准，Windows 颜色乱”，原因在于两套系统设计不同：

- **macOS**：系统级强制色彩管理。无论什么程序（哪怕是不支持色彩管理的老软件），macOS 都会在系统层面把颜色数据映射到当前屏幕的色域。配合苹果出厂校色的屏幕，开箱即准。
- **Windows**：应用自己管自己。支持色彩管理的程序（Photoshop、Lightroom、Chrome/Edge）会正确处理颜色；不支持的程序（老游戏、老截图工具、部分看图软件）直接把颜色数值丢给屏幕。如果你的屏幕是广色域，这些程序里的颜色就会过饱和。

**这个差异不影响普通用户**。但如果你需要颜色准，并且不想折腾，Mac 确实是更省心的选择。

# 补充阅读

> 以下内容涉及色彩空间的数学计算和更深层原理，难度较高。建议先快速扫一眼，以后需要时再回来看。

## 补充1：CIE 1931 色度图

1931 年，国际照明委员会（CIE）定义了 **CIE 1931 XYZ 色彩空间**，这是所有现代色度学的基础。  

![CIE 1931 LAB](/img/CIE-1931_diagram_in_LAB_space.svg)  

它是一个马蹄形的人眼颜色感知图，x 轴和 y 轴表示色度（颜色，不含亮度）。任何色域都可以在这个马蹄形里画出一个三角形——三角形的三个顶点是该色域的红、绿、蓝三基色坐标。sRGB、DCI-P3、Rec.2020 都是这个马蹄形里不同大小的三角形。


## 补充2：色域覆盖率与容积率的数学区别

- **覆盖率**：显示器色域与参考色域的重叠面积，除以参考色域的面积（百分比）。覆盖率不可能超过 100%。
- **容积率**：显示器色域的总面积，除以参考色域的面积（百分比）。容积率可以超过 100%（意味着显示器颜色比参考色域更广）。

一个显示器可能宣称“120% sRGB 容积”，但如果那多出来的 20% 颜色位置是偏移的，实际显示 sRGB 内容时仍然不准。所以容积率高不一定好，覆盖率更反映显示sRGB内容的准确性。

## 补充3：CIE Lab 与 OKLAB 的对比

**CIE Lab**（也叫 CIELAB、L*a*b*）是 CIE 在 1976 年定义的色彩空间，设计目标是“感知均匀”——但后来发现它在蓝色区域仍然不够均匀。**OKLAB**（2020 年提出）在此基础上改进了均匀性，尤其改善了蓝色和青色区域。OKLAB 是目前颜色转换算法（比如从 P3 转 sRGB）中效果较好的色彩空间。Adobe Photoshop、Blender、OpenColorIO 等软件已经开始支持 OKLAB。

## 补充4：白点与色温

白点（White Point）决定了“白色”在色度图上的坐标。常见的白点：

- **D65**：6500K，对应正午阳光。sRGB、Rec.709、Display P3 都用 D65。
- **D50**：5000K，偏黄。印刷行业标准（因为印刷用的纸张本身不是纯白）。
- **DCI-P3 原版白点**：6300K，和 D65 略有差异。Display P3 为了兼容 sRGB，把白点改成了 D65。

色温单位是开尔文（K），越低越偏黄/红（暖色），越高越偏蓝（冷色）。电视的“暖色”“标准”“冷色”模式，调的就是白点。

## 补充5：校色仪的数据存储

校色仪生成的 ICC 配置文件是一个包含颜色转换表（CLUT，Color Lookup Table）的文件。Windows 加载后，显卡在输出信号时会根据这张表做转换：`真实颜色 = 显卡输出颜色 × 色彩转换矩阵`。这个过程需要显卡和操作系统支持，部分老游戏可能会绕过色彩管理，导致校色不生效。

## 补充6：广色域显示器的日常使用

如果你买了广色域显示器（例如覆盖 95% DCI-P3），但主要用 Windows，建议：

1. 在显示器 OSD 菜单里切换到 **sRGB 模式**。这样显示器内部会把广色域压缩到 sRGB，所有程序（包括不支持色彩管理的）颜色都正常。
2. 如果你需要用到广色域（比如剪 HDR 视频），在修图/剪辑软件里打开色彩管理，日常使用再切回 sRGB 模式。
3. 或者，只在你确信需要的时候才开广色域。平时当 sRGB 用，不折腾。
