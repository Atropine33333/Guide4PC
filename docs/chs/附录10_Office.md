# 附录十：Office

> 这个附录介绍 Microsoft Office 三个主要组件（Word、Excel、PowerPoint）的核心功能。大学期间写论文、做报告、处理数据都离不开它们。  
> 我仅介绍 Microsoft Office ，以 Office 365 为例， WPS 写法类似，细节上有差别。我建议使用 Office365 ，当然，如果你的老师规定要用 WPS 写论文——虽然这很少见，你最好乖乖听话，因为 MSOffice 和 WPS 的格式处理是有差别的，并且比较玄学。用 WPS 打开 MSOffice 文档，或者反过来，页边距、行距、字体渲染可能出现偏差。提交最终版论文前，建议用老师指定的软件打开检查一遍格式。  
> 下一个附录我会介绍 `LaTeX` 它在论文排版上更为强大，一般地，大学基本都会提供毕业论文的LaTeX模板。

## 第一部分：Word

Word 是文档编辑工具。写论文、做简历、交作业都用它。下面介绍几个真正会用到的功能。

### 1.1 样式

**样式（Style）** 是一套预先设置好的格式方案，包含字体、字号、加粗、颜色、段落间距等。

很多人写文档的习惯是：选中文字 → 手动调字号 → 手动加粗 → 手动调行距。一篇论文几十页，标题就有好几级，一个个手动调费时费力，改起来更是灾难。

正确做法：先定义样式，再套用。

Word 里预置了“标题1”“标题2”“正文”等样式。右键点击某个样式 → 修改，可以设置字体、字号、行距、段前段后间距。修改完后，所有套用该样式的文字会自动更新。

**好处**：
- 格式统一，不会出现“这个标题是宋体三号，那个标题是黑体小三”的情况
- 改格式快：只需要修改样式定义，全文自动更新
- 配合后面的“引用”功能，可以自动生成目录

### 1.2 分页与换行

写论文时经常需要另起一页（比如每一章从新的一页开始）。很多人会狂按回车直到翻到下一页。这样做的坏处是：前面内容增减一点，后面的页就全乱了。

正确做法：

- **`Ctrl + Enter`**：插入分页符（Page Break）。光标后面的内容会被推到下一页。无论前面怎么改，分页的位置不会变。
- **`Shift + Enter`**：换行但不分段（Line Break）。按回车是分段，段与段之间有空隙；按 `Shift + Enter` 只是换行，不产生新段落，行距不变。适合写地址、诗歌这类需要换行但不希望有空隙的地方。

### 1.3 布局

**布局（Layout）** 选项卡里控制页面整体的外观：

- **页边距（Margins）**：文档四周的空白区域。毕业论文通常有页边距要求（比如上2.5cm、下2.5cm、左3cm、右2cm）。可以在“自定义页边距”里精确设置。
- **纸张方向（Orientation）**：纵向（Portrait）和横向（Landscape）。表格太大放不下时，可以把那一页单独设成横向（需要在“页面设置”里选择“应用于本节”）。
- **分栏（Columns）**：把一页分成多栏。适合 Newsletter、 pamphlet 之类的文档。

### 1.4 引用

**引用（References）** 选项卡是写论文的核心工具。

**目录（Table of Contents）**：只要你用了样式（标题1、标题2等），点一下“目录”就能自动生成。目录上的页码会随着文档修改自动更新。如果新增或删除了标题，点“更新目录”即可。

**脚注（Footnote）与尾注（Endnote）**：
- 脚注：在当前页底部显示注释。插入位置在正文右上角，注释内容在页面底端。适合对某句话做补充说明。
- 尾注：在文档末尾显示注释。适合参考文献（有些人用尾注格式）。

**引文与书目（Citations & Bibliography）**：
- 点击“插入引文” → “添加新源”，填入作者、标题、年份等信息。Word 会自动帮你格式化引文。
- 在文档末尾点“书目”，可以自动生成参考文献列表。
- 不同期刊/学校要求的引文格式不同（APA、MLA、Chicago 等），在“样式”下拉框里选即可。

**题注（Caption）**：插入了图片、表格、公式后，选中图片，点“插入题注”，可以给图片编号（图1、图2、表1、表2）。配合“交叉引用”，可以在正文里写“如图1所示”，点一下就能跳转到图。如果中间又插入了一张新图，后面的编号会自动更新。

### 1.5 审阅

**审阅（Review）** 选项卡里的功能，大学期间经常用到——尤其是老师批改论文的时候。

**批注（Comment）**：选中一段文字，点“新建批注”，会在页面右侧出现一个气泡。老师可以在气泡里写“这里逻辑不通”“补充参考文献”之类的意见。学生看到后修改，修改完成后可以“答复”或“解决”该批注。

**修订（Track Changes）**：打开“修订”后，你对文档的任何修改（删除、添加、移动）都会以彩色标记显示。老师可以看到你改了哪里，你也可以看到老师帮你改了什么。接受或拒绝修订后，标记才会消失。

**比较（Compare）**：交了两个版本的论文，想知道改了哪里？点“比较”，选择原文档和修改后的文档，Word 会生成一个对比结果，把所有改动标出来。

### 1.6 Word 选项里的重要设置

点击“文件” → “选项”，会打开 Word 选项窗口。下面几个设置建议了解一下：

**常规 → 用户界面选项**：配色方案可以改成“深灰色”或“黑色”，长时间写论文眼睛没那么累。

**显示**：
- 始终在屏幕上显示这些格式标记：建议勾选“制表符”“空格”“段落标记”。打开后，你会看到灰色的点（空格）和弯箭头（回车）。排版排不齐的时候，看这些标记能帮你找到问题。
- **切勿更改文档页面颜色**：有些人喜欢把 Word 背景改成护眼绿色或深色模式。但文档的最终读者（比如老师、期刊审稿人）看到的还是默认的白纸黑字。如果你在彩色背景上调了字体颜色（比如用了浅灰色），换到白色背景上可能看不清。建议保持默认，或者改完背景后检查一下。

**保存**：
- **保存自动恢复信息**：默认是 10 分钟。写重要文档时可以改短一些，比如 5 分钟。
- **默认保存格式**：建议选 `Word 文档（*.docx）`。`.doc` 是旧版格式，兼容性差。
- **嵌入字体**：如果文档里用了特殊字体（不是 Windows 自带的），发给别人时对方电脑没有这个字体，会用默认字体替代，排版会乱。勾选“在文件中嵌入字体”，Word 会把字体文件打包进文档。注意：部分字体有版权限制，不允许嵌入。

**高级**：
- **图片保真度**：默认情况下 Word 会压缩插入的图片以减小文档体积。如果你需要打印或提交高质量文档（比如带高清图的论文），在“图像大小和质量”里把“默认分辨率”改成“高保真”。
- **剪切、复制和粘贴**：从网页复制一段文字到 Word，经常带格式（背景色、奇怪的字体）。可以在“从其他程序粘贴”那里选“只保留文本”，粘贴进来的就只有纯文字，不带任何格式。
- **显示文档内容**：有“在页面视图中显示背景色和图像”等选项。

**加载项（Add-ins）**：用来扩展 Word 功能。比如 Zotero（文献管理工具）会在这里装一个加载项，让你在 Word 里直接插入引用。如果某个加载项导致 Word 变慢或报错，可以在这里禁用。

### 1.7 DOTM 模板

**.dotm** 是 Word 启用宏的模板文件格式。普通文档是 `.docx`，模板是 `.dotx`，带宏的模板是 `.dotm`。

**模板（Template）** 像一个模具。你做一个简历模板，设置好页边距、样式、页眉页脚，另存为 `.dotx`。以后每次新建文档时双击这个模板文件，它会生成一个新文档，继承所有设置，而原模板不会被修改。

有些学校提供毕业论文的 `.dotm` 模板，里面预置了格式要求，还可能包含自动化脚本（比如一键检查图表编号）。如果是 `.dotm` 格式，打开时会提示“启用宏”，需要允许才能使用全部功能。

**把模板放到哪里**：Word 模板默认保存在 `C:\Users\你的用户名\Documents\自定义 Office 模板`。放进去后，在“文件” → “新建” → “个人”里就能看到。

### Word 延伸阅读

#### 延伸1：样式与目录的联动

生成目录时，Word 默认只抓取“标题1”“标题2”“标题3”。如果你用了自定义样式（比如“一级标题”），需要在“引用” → “目录” → “自定义目录” → “选项”里手动指定层级。

#### 延伸2：分节符

**分节符（Section Break）** 比分页符更强大。插入分节符后，每一节可以独立设置页边距、页眉页脚、纸张方向。比如：论文的前言和目录用罗马数字页码，正文用阿拉伯数字页码，中间就需要插一个分节符。

插入方法：布局 → 分隔符 → 下一页（分节符）。

#### 延伸3：文档页面颜色

Word 选项里的“切勿更改文档页面颜色”是针对那些用深色模式写论文的人。Windows 11 的深色模式会影响 Office，Word 会变成黑底白字。但文档的实际背景还是白色。如果有人在深色模式下把字体改成了亮色（比如浅灰色），发到老师那里（白色背景）就可能看不清。保持默认最安全。

## 第二部分：Excel

Excel 是表格工具，用来处理数据、做计算、画图表。很多人只会往格子里打字，遇到公式就头疼。这一节不讲复杂的函数，只介绍大学期间真正会用到的。

### 2.1 基础操作

**单元格（Cell）** 是表格里最小的单位，用列号（字母）和行号（数字）定位，比如 `B3` 表示第2列第3行。

**区域（Range）** 是一组连续的单元格，用左上角单元格和右下角单元格表示，中间用冒号。例如 `A1:C10` 表示从 A1 到 C10 这个矩形区域。

**常用快捷操作**：

| 操作 | 方法 |
|------|------|
| 选中整行 | 点击行号 |
| 选中整列 | 点击列标 |
| 选中整个表格 | 点击左上角三角（A 列和 1 行交汇处） |
| 填充相同内容 | 选中单元格，拖动右下角的小方框（填充柄） |
| 序列填充 | 按住 `Ctrl` 再拖动填充柄（或先输入两个值让 Excel 识别规律） |
| 调整列宽/行高 | 双击列标之间的分割线（自动适应内容宽度） |

### 2.2 公式与函数

公式以 `=` 开头。例如在单元格里输入 `=1+2`，回车后显示 `3`。

**常用函数**

| 函数 | 作用 | 示例 |
|------|------|------|
| `SUM` | 求和 | `=SUM(A1:A10)` |
| `AVERAGE` | 平均值 | `=AVERAGE(B2:B20)` |
| `COUNT` | 统计数字个数 | `=COUNT(C1:C100)` |
| `COUNTA` | 统计非空单元格个数 | `=COUNTA(D:D)` |
| `MAX` / `MIN` | 最大值 / 最小值 | `=MAX(E2:E50)` |
| `IF` | 条件判断 | `=IF(F2>=60, "及格", "不及格")` |

**重要概念：相对引用 vs 绝对引用**

写公式时，`A1` 是相对引用，向下拖动公式时会自动变成 `A2`、`A3`；`$A$1` 是绝对引用，拖动时保持不变。混合引用 `$A1`（列固定、行可变）和 `A$1`（行固定、列可变）也有各自用途。

按 `F4` 键可以快速切换这四种引用模式。

**示例**：要计算每个销售额占总销售额的比例。假设销售额在 `B2:B10`，总销售额在 `B11`。比例公式为 `=B2/$B$11`，把 `$B$11` 锁死，向下拖动时总销售额单元格不会变。

### 2.3 查找与引用函数

这部分是 Excel 的核心能力：根据一个值去另一张表找对应的数据。

**VLOOKUP（垂直查找）**

语法：`=VLOOKUP(要找什么, 去哪里找, 在第几列, 0)`

示例：有一张学生成绩表，A 列是学号，B 列是姓名，C 列是成绩。你想根据学号找成绩：
`=VLOOKUP(F2, A:C, 3, 0)`
- F2：要查找的学号
- A:C：在 A 到 C 列这个区域里找（第一列必须是学号）
- 3：找到后，返回该行的第 3 列（即 C 列的成绩）
- 0：精确匹配

**注意事项**：
- 查找值必须在查找区域的第一列
- `VLOOKUP` 只能从左往右查，不能返回查找列左边的数据
- 最后一个参数写 `0` 或 `FALSE` 表示精确匹配，不要省略

**XLOOKUP（Office 365 独占）**

`XLOOKUP` 是 `VLOOKUP` 的升级版，解决了很多痛点。语法更简单，可以向左查，还可以自定义找不到时显示什么。

语法：`=XLOOKUP(要找什么, 去哪里找, 返回哪一列, "没找到")`

示例：`=XLOOKUP(F2, A:A, C:C, "无此学号")`

**注意区分版本**：
- Office 2021 和 Office 365 支持 `XLOOKUP`、`FILTER`、`SORT` 等新函数
- Office 2019 及更早版本不支持这些函数。如果发给别人的文件里用了 `XLOOKUP`，对方打开会显示 `#NAME?` 错误

**INDEX + MATCH（万能组合，所有版本通用）**

`INDEX` 返回某个区域里第几行第几列的值。`MATCH` 找某个值在列表里的位置。两者结合可以实现双向查找。

示例：根据姓名和科目名查成绩
`=INDEX(成绩区域, MATCH(姓名, 姓名列, 0), MATCH(科目名, 科目行, 0))`

### 2.4 文本与日期处理

**文本函数**

| 函数 | 作用 | 示例 |
|------|------|------|
| `LEFT(文本, 数字)` | 取左边几个字符 | `=LEFT("2024001", 4)` → "2024" |
| `RIGHT(文本, 数字)` | 取右边几个字符 | `=RIGHT(A2, 6)` |
| `MID(文本, 起始位, 字符数)` | 取中间一段 | `=MID("2024-09-01", 6, 2)` → "09" |
| `&` 运算符 | 连接文本 | `=B2 & " " & C2` |
| `TEXT(数值, 格式)` | 格式化数字或日期 | `=TEXT(A2, "yyyy-mm-dd")` |

**日期函数**

| 函数 | 作用 | 示例 |
|------|------|------|
| `TODAY()` | 当前日期 | 每天自动更新 |
| `NOW()` | 当前日期和时间 | |
| `YEAR(日期)` | 提取年份 | `=YEAR(A2)` |
| `MONTH(日期)` | 提取月份 | |
| `DAY(日期)` | 提取日 | |
| `DATEDIF(开始, 结束, "单位")` | 计算两个日期的差 | `=DATEDIF(A2, TODAY(), "y")` 计算年龄 |

### 2.5 条件统计

| 函数 | 作用 | 示例 |
|------|------|------|
| `COUNTIF(范围, 条件)` | 按条件计数 | `=COUNTIF(B:B, ">=60")` |
| `SUMIF(条件范围, 条件, 求和范围)` | 按条件求和 | `=SUMIF(A:A, "销售部", B:B)` |
| `AVERAGEIF(条件范围, 条件, 平均范围)` | 按条件求平均 | `=AVERAGEIF(C:C, ">0", C:C)` |

### 2.6 数据透视表

**数据透视表（Pivot Table）** 是 Excel 里最强大的数据分析工具。几千行数据，点几下就能生成汇总报表。

**场景**：你有一张全校学生成绩表，包含“班级”“姓名”“科目”“成绩”四列，共 5000 行。你想知道每个班的平均分、每个科目的最高分、各班各科的分数分布——用数据透视表只需几秒钟。

**操作步骤**：
1. 选中整个数据区域
2. 点击“插入” → “数据透视表”
3. 在弹出的窗口里，选择“新工作表”
4. 在右侧“数据透视表字段”面板里，把字段拖到不同区域：
   - “行”区域：要按什么分组（如“班级”）
   - “列”区域：要交叉对比什么（如“科目”）
   - “值”区域：要计算什么（如“成绩”，默认是求和，点“值字段设置”可改“平均值”或“计数”）

### 2.7 图表制作

选中数据 → “插入” → “图表”。常用类型：
- **柱形图**：比较不同类别的数值
- **折线图**：展示数据随时间的变化趋势
- **饼图**：展示各部分占总体的比例（不要超过 5 个部分，否则看不清楚）

建议添加标题、数据标签、坐标轴说明。右键点击图表可以修改图表类型、调色板、添加趋势线等。

### 2.8 条件格式

**条件格式（Conditional Formatting）** 让单元格根据数值自动变色。

选中数据 → “开始” → “条件格式”。常用规则：
- 突出显示单元格规则：大于某个值的标红、重复值标黄
- 色阶：用颜色深浅表示数值高低（绿色最高、红色最低）
- 数据条：在单元格里画一条长度代表数值大小的条形（不需要额外占空间）
- 图标集：用红绿灯、箭头表示好坏

### 2.9 数据验证

**数据验证（Data Validation）** 可以限制单元格里能填什么内容，防止输错。

选中单元格 → “数据” → “数据验证” → “设置” → “允许”选“序列”，在“来源”里输入选项（用英文逗号隔开，如 `是,否`）。这个单元格就变成了下拉菜单。

**常用限制**：
- 序列 → 下拉菜单
- 整数 → 限制数字范围（比如 0 到 100）
- 日期 → 限制日期范围
- 文本长度 → 限制字符数（比如手机号必须是 11 位）

### 2.10 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + 方向键` | 跳到数据区域的边缘 |
| `Ctrl + Shift + 方向键` | 选中连续区域 |
| `Alt + =` | 快速求和（自动输入 SUM 公式） |
| `F4` | 重复上一步操作（如重复插入行、重复设置格式） |
| `F2` | 编辑当前单元格（不用双击） |
| `Ctrl + D` | 向下填充（复制上方单元格） |
| `Ctrl + R` | 向右填充 |
| `Ctrl + 1` | 打开单元格格式设置 |
| `Ctrl + Shift + L` | 开启/关闭筛选 |

### Excel 延伸阅读

#### 延伸1：Office 2021 与 Office 365 的函数差异

| 函数 | Office 2021 | Office 365 | 说明 |
|------|-------------|------------|------|
| `XLOOKUP` | ✅ | ✅ | 2021 也支持 |
| `FILTER` | ❌ | ✅ | 365 独占，自动筛选并返回结果 |

## 延伸：VBA 宏

**VBA（Visual Basic for Applications）** 是 Office 内置的编程语言。它可以写脚本来自动化重复操作。

**打开 VBA 编辑器**：`Alt + F11`

### VBA 能做什么

**批量处理 Word 文档**：把文件夹里所有 Word 文档的页边距统一改成 2.5cm。手动操作需要打开每一个文档，点几十次鼠标；写一段 VBA 脚本，点一下运行，几百个文档一次性改完。

**Excel 自动化**：把 12 个月的数据表合并成一张总表。写一个循环，自动打开每个文件、复制数据、粘贴到汇总表。

**PowerPoint 批量操作**：给 200 页 PPT 的每一页右上角都加上公司 Logo。

### 录制宏

最简单的方法：点击“开发工具”选项卡 → “录制宏” → 正常操作一遍（比如设置页边距、改字体）→ “停止录制”。Excel 会自动把刚才的操作转换成 VBA 代码。之后可以一键重放。

**注意**：录制宏生成的代码比较啰嗦（会把你的每一步操作都记下来，包括你可能不需要的）。但这是一个很好的学习方式——录一遍，看看自动生成的代码长什么样，再动手改改。

### 安全性

`.docm`、`.xlsm`、`.pptm` 是启用了宏的文件。打开这类文件时 Office 会提示“文件中包含宏”。只打开来源可靠的文件（比如学校发的、同事发的），不要打开不明来源的宏文件。宏可以删除文件、格式化硬盘，本质上是小型的可执行程序。

**查看和编辑宏**：`Alt + F11` 打开 VBA 编辑器，可以看到所有模块和代码。不懂编程没关系，能看懂基本逻辑（比如“打开文件”“复制”“粘贴”这种英语单词）就行。
