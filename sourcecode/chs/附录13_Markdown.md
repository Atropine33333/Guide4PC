# 附录十三：Markdown

> 这个附录介绍 Markdown 是什么、怎么用。Markdown 是一种轻量级的标记语言，让你用纯文本写文档，然后转换成格式整洁的 HTML。它比 Word 简单得多，比记事本好看得多。本附录只介绍最基本的语法，更详细的教程请访问 `markdown.com.cn`。

## 13.1 什么是 Markdown

**Markdown** 是一种纯文本格式的标记语言。你不需要用鼠标去点“加粗”按钮，只需要在文字两边加几个符号，就能表示格式。例如：

```markdown
这是 **加粗** 文字，这是 *斜体* 文字。
```

Markdown 文件的后缀通常是 `.md`。你可以用任何文本编辑器（记事本、VS Code）打开和编辑。写好之后，可以转换成 HTML、PDF、Word 等格式。

**Markdown 能做什么**：
- 写 README（你在 GitHub 上看到的项目介绍，基本都是 Markdown）
- 写博客（很多静态博客系统如 Hexo、Hugo、VuePress 都用 Markdown）
- 写笔记（Obsidian、Typora、Notion 都支持 Markdown）
- 写技术文档（很多开源项目的文档就是 Markdown）
- 实际上，这个网站的所有内容都是使用 Markdown 编写的

它最大的特点是 **纯文本**——在任何电脑上都能打开，不会像 `.docx` 那样排版错乱。而且语法极其简单，十分钟就能学会。

## 13.2 基本语法

以下是最常用的 Markdown 语法。更完整的内容请查阅 [markdown.com.cn](https://markdown.com.cn) 的“基本语法”章节。

### 13.2.1 标题

用 `#` 表示标题，几个 `#` 就是几级标题。`#` 后面要加一个空格。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

### 13.2.2 段落与换行

段落之间用空行分隔。如果只想换行（不产生新段落），在行末加两个空格然后回车。

```markdown
这是第一段。

这是第二段。

这是第一行··（两个空格）
这是同一段落里的第二行。
```

### 13.2.3 强调

```markdown
*斜体* 或 _斜体_
**加粗** 或 __加粗__
***加粗斜体*** 或 ___加粗斜体___
```

### 13.2.4 列表

**无序列表**：用 `-`、`*` 或 `+`，后面加空格。

```markdown
- 苹果
- 香蕉
- 橙子
```

**有序列表**：用数字加英文句点，后面加空格。数字不必连续，Markdown 会自动排序。

```markdown
1. 第一项
2. 第二项
3. 第三项
```

### 13.2.5 链接

```markdown
[链接文字](https://example.com)
```

### 13.2.6 图片

```markdown
![替代文字](图片地址)
```

### 13.2.7 引用

用 `>` 表示引用块。可以嵌套（`>>`）。

```markdown
> 这是一段引用。
> 
> > 这是嵌套引用。
```

### 13.2.8 代码

行内代码：用反引号（键盘上 `Tab` 键上方、`1` 左边的那个键）包裹。

```markdown
这是 `printf("hello")` 函数。
```

代码块：用三个反引号包裹，可以指定语言（用于语法高亮）。

~~~markdown
```python
def hello():
    print("Hello, world!")
```
~~~

### 13.2.9 分隔线

三个或更多的 `-`、`*` 或 `_` 单独占一行。

```markdown
---
```

### 13.2.10 表格

用 `|` 分隔单元格，用 `-` 分隔表头。

```markdown
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
```

### 13.2.11 任务列表

用 `- [ ]` 表示未完成，`- [x]` 表示已完成。

```markdown
- [x] 写完了第一章
- [ ] 写完了第二章
- [ ] 找别人校对
```

## 13.3 扩展语法

标准 Markdown 的功能比较基础。**扩展语法** 增加了更多实用功能：删除线、自动链接、脚注、定义列表、Emoji、高亮、下标、上标等。但不是所有 Markdown 渲染器都支持扩展语法。

常用扩展语法示例：

```markdown
~~删除线~~

:joy: （Emoji，用 `:joy:` 表示 😂）

这是一个脚注。[^1]

[^1]: 脚注的内容。
```

详细的扩展语法请访问 `markdown.com.cn` 的“扩展语法”章节。

## 13.4 用什么工具写

- **VS Code**：安装 `Markdown All in One` 插件，可以预览、生成目录、导出 HTML。
- **Typora**：一款专门写 Markdown 的编辑器，“所见即所得”——你写语法，它实时显示渲染结果。界面干净，适合新手。
- **Obsidian**：支持 Markdown 的知识管理工具，适合做个人笔记库。
- **任何文本编辑器**：记事本也能写，只是没有预览功能。

## 13.5 最后一句

Markdown 不是 Word 的替代品——复杂的图文混排、精确的页边距、论文参考文献，还是用 Word 或 LaTeX。但日常的笔记、文档、README、博客，用 Markdown 写是最省事的。

你不需要背下所有语法。记住 `#` 标题、`**` 加粗、`[链接]()`、`![图片]()` 这几个就够了。剩下的，用到的时候再查。
