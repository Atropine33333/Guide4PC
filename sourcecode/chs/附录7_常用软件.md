# 附录七：有用的软件

> 本附录介绍几款日常使用频率较高的软件，涵盖压缩、播放、下载、编辑、系统增强等方面。

## 7.1 压缩软件：NanaZip / WinRAR

Windows 自带解压只支持 `.zip` 格式，遇到 `.rar`、`.7z` 等就无法处理。需要安装第三方压缩软件。

**[NanaZip](https://nanazip.org/)**：开源，基于 7‑Zip 开发，界面适配 Windows 11 现代风格，支持深色模式。可从微软商店安装，也提供 `.msixbundle` 直接下载。功能完整，解压和压缩都够用。

**[WinRAR](https://www.win-rar.com/)**：经典压缩软件，支持创建 `.rar` 格式（商业算法）。安装后有 40 天试用提示，但可继续使用。如果需要向他人发送加密或分卷压缩包，用 WinRAR 或 7‑Zip 均可。

两款都可以满足日常使用，选一个装就行。

## 7.2 视频播放器：PotPlayer

Windows 自带的“电影和电视”播放器解码能力有限，很多格式（如 `.mkv`、`.flv`、`.mov`）无法打开。[PotPlayer](https://potplayer.tv/) 启动快、解码全，几乎不用设置就能播放绝大多数视频文件。

**说明**：PotPlayer 并非技术上的最佳选择。更专业的用户可能会选择 MPV 配合自编译解码器，或者使用特定版本以支持杜比视界和 HDR 映射。但 PotPlayer 对普通用户来说足够稳定且易于使用。如果您已经能够自行配置复杂播放环境，本推荐对您无效，您的技术水平已超出本附录的受众范围。

## 7.3 BT 下载工具：qBittorrent

下载 BT 种子或磁力链接，推荐 **[qBittorrent](https://www.qbittorrent.cn/)**。开源、无广告、功能完整。支持搜索插件、顺序下载、速度限制、IP 过滤等。

**几种常见的下载链接类型**：
- **种子文件（.torrent）**：一个小文件（通常几十到几百 KB），里面记录了要下载的资源的元信息（文件名、分块哈希、Tracker 地址等）。下载软件打开种子后，根据其中的信息去连接其他用户下载数据。
- **磁力链接（magnet:?xt=urn:btih:...）**：种子的“升级版”，不需要先下载 .torrent 文件。软件直接根据链接中的哈希值在 DHT 网络中查找资源。复制整段链接到 qBittorrent 即可添加任务。
- **ed2k 链接（ed2k://...）**：电驴（eMule）协议的链接，用于老式 P2P 网络。现在资源较少，部分老资源库仍在使用。qBittorrent 不支持 ed2k，需要使用 eMule 或支持该协议的下载器。

**几个设置建议**：
- 添加公共 Tracker 列表（参考 `trackerslist.com`），可提高连接成功率。
- 限制上传速度（例如设为 1 MB/s），避免抢占带宽导致网络卡顿。
- 下载完成后做种一段时间（上传量达到 1:1 或 24 小时），这是 BT 分享精神的体现。

## 7.4 代码与纯文本编辑器：VS Code

即使不写代码，**[VS Code](https://code.visualstudio.com/)** 也是一款值得安装的纯文本编辑器。它比记事本强在：语法高亮（打开 `.json`、`.xml`、`.md` 等文件时自动着色）、多标签、正则搜索、插件扩展（Markdown 预览、拼写检查等）。

安装后可以做两件小事：
1. 设置字体：在设置中搜索 `Font Family`，填入 `'JetBrains Mono', Consolas, monospace`，并开启 `editor.fontLigatures` 以支持连字。
2. 安装中文语言包：在扩展商店搜索“Chinese (Simplified)”。

以后打开任何配置文件、日志文件、脚本或笔记，都可以用 VS Code 查看编辑。

## 7.5 苹果设备图像扩展：HEIF / HEVC

iPhone 拍摄的照片可能是 `.heic` 格式（HEIF），视频是 `.hevc` 格式（HEVC/H.265）。Windows 默认无法打开或显示缩略图。

需要在 **Microsoft Store** 安装两个官方扩展：
- HEIF 图像扩展（免费）
- HEVC 视频扩展（来自设备制造商的版本，免费）

安装后即可在文件资源管理器中直接查看苹果设备拍的照片和视频。

## 7.6 终端增强：Windows Terminal

CMD 和 PowerShell 自带的窗口较简陋：不支持多标签、字体渲染一般、复制粘贴别扭。**[Windows Terminal](https://apps.microsoft.com/detail/9n0dx20hk701?hl=zh-CN&gl=CN)** 是微软官方推出的现代终端，支持：
- 多标签页，可拆分窗格
- GPU 加速渲染，字体清晰
- 自定义主题、背景图片、透明度
- 同时打开 PowerShell、CMD、WSL 的任意组合

安装后把它固定在任务栏，以后所有命令行操作都从这里进。

# 补充阅读

> 以下内容涉及相关软件的技术细节和替代方案，难度中等。可根据兴趣选择性阅读。

## 补充1：7‑Zip 命令行用法

7‑Zip 的核心是命令行版本 `7z.exe`。很多自动化脚本（如批量解压、压缩备份）都依赖它。常用命令：
- 解压：`7z x archive.7z -oC:\target`
- 压缩：`7z a archive.7z C:\source`
- 测试完整性：`7z t archive.7z`

NanaZip 安装后不默认提供命令行版本，如需使用可以从 7‑Zip 官网下载独立命令行程序。

## 补充2：PotPlayer 与硬件解码

PotPlayer 默认使用内置解码器，在播放 4K HDR 内容时可能占用较高 CPU。可以切换为显卡硬件解码：
- 右键画面 → 选项 → 滤镜 → 视频解码器 → 内置解码器 → 硬件解码（DXVA2 / D3D11）设为“自动”。
- 如果显卡支持，可开启“HDR 直通”（需要显示器支持）或“像素着色 HDR 转换”。

## 补充3：qBittorrent 搜索插件

qBittorrent 内置搜索功能，需要先安装 Python 并下载搜索插件（从官方 GitHub 仓库获取）。安装后可在程序内直接搜索各大资源站（需自行添加插件，默认不提供）。此功能涉及版权问题，使用需遵守当地法律。

## 补充4：VS Code 常用插件推荐

- **PDF Viewer**：在 VS Code 内浏览 PDF 文件。
- **Remote - SSH**：通过 SSH 连接远程服务器编辑文件。

## 补充5：Windows Terminal 的配置文件位置

Windows Terminal 的设置保存在 `settings.json` 中（可通过下拉菜单 → 设置 → 左下角“打开 JSON 文件”）。可以直接编辑该文件以添加自定义配色方案、背景图片等。社区有很多现成的主题配置（如 `catppuccin`、`dracula`）。

## 补充6：HEVC 视频扩展的两种版本

Microsoft Store 中有两个 HEVC 扩展：
- **HEVC 视频扩展（付费）**：售价 7 元，由官方发布。
- **来自设备制造商的 HEVC 视频扩展**：免费，但可能需要满足特定硬件条件（如安装了厂商提供的驱动）。绝大多数笔记本预装 Intel 核显驱动后会附带此扩展，可直接搜索安装。

如果安装免费版时提示“不符合安装条件”，可以尝试直接搜索“HEVC 视频扩展 设备制造商”的商店链接（通过搜索引擎获取）强行安装，通常也能成功。
