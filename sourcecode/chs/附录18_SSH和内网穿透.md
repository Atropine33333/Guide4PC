# 附录十八：SSH 与内网穿透

> 这个附录介绍 SSH 是什么、怎么用，以及当你的电脑没有公网 IP 时，怎么从外面访问它（内网穿透）。不深入原理。  
> 主要作用是防止你对如何连上学校机房跑仿真一头雾水。

## 18.1 SSH 是什么

**SSH（Secure Shell，安全外壳协议）** 是一种加密的网络协议，用于安全地远程登录另一台电脑。

**为什么需要 SSH**：以前人们用 telnet 远程登录，但 telnet 所有数据（包括密码）都是明文传输。谁在中间一抓包，你的密码就没了。SSH 把整个通信过程加密了，中间的人看到的是一堆乱码。

**SSH 能干什么**：
- 远程登录服务器（取代 telnet）
- 安全传输文件（SFTP、SCP）
- 隧道转发（把其他不安全协议的流量塞进 SSH 加密通道）
- 跑远程命令（`ssh user@host "ls -la"`）

**大学里什么时候会用上**：
- 连接学校实验室的 Linux 服务器做作业、跑实验
- 连接学校提供的计算集群（超算中心）
- 连接树莓派、NAS 等设备
- 从宿舍连接实验室的电脑（配合内网穿透）

## 18.2 SSH 和其他协议的区别

| 协议 | 加密 | 典型用途 |
|------|------|----------|
| **Telnet** | 明文 | 老式远程登录（现在已经不推荐用了） |
| **SSH** | 加密 | 远程命令行、文件传输 |
| **RDP** | 加密 | Windows 远程桌面（图形界面） |
| **VNC** | 可选 | 远程桌面，默认不加密 |
| **VPN** | 加密 | 整个网络流量都走隧道 |
| **HTTP** | 明文 | 网站 |
| **HTTPS** | 加密 | 网站（加密版） |

**简单记**：命令行远程用 SSH，图形界面 Windows 远程桌面用 RDP，整台电脑的网络都走隧道用 VPN。

## 18.3 Windows 自带的 OpenSSH

Windows 10/11 已经内置了 OpenSSH 客户端，不需要装 PuTTY 之类的第三方软件。

**检查是否已安装**：设置 → 系统 → 可选功能 → 搜索“OpenSSH 客户端”。没有的话点“添加功能”。

**基本用法**（在 CMD、PowerShell 或 Windows Terminal 里）：

```bash
ssh 用户名@服务器地址
# 例如：ssh root@192.168.1.100
# 例如：ssh ubuntu@example.com -p 2222
```

第一次连接时，会提示你确认服务器的指纹（公钥）。输入 `yes` 回车，之后就不会再问了。

**常用参数**：
- `-p` 指定端口（默认 22）
- `-i` 指定私钥文件（免密登录用）

**退出 SSH 连接**：输入 `exit` 或按 `Ctrl + D`。

## 18.4 免密登录（SSH 密钥）

输密码太麻烦，而且自动化脚本需要人输密码。可以配免密登录。

**在本地电脑生成密钥对**：

```bash
ssh-keygen -t ed25519
```

一路回车（建议设置一个密码保护私钥）。会在 `~/.ssh/` 目录下生成两个文件：
- `id_ed25519`：私钥（别给别人）
- `id_ed25519.pub`：公钥（放到服务器上）

**把公钥上传到服务器**：

```bash
ssh-copy-id 用户名@服务器地址
# 例如：ssh-copy-id root@192.168.1.100
```

输一次密码后，以后连接就不用再输了。

**为什么用 ed25519**：比 RSA 更快、更安全、密钥更短。老系统可能不认识，那就用 `-t rsa -b 4096`。

## 18.5 别名与配置文件

连多台服务器，每次输入 `ssh ubuntu@123.456.789.0 -p 2222 -i /path/to/key` 很烦人。可以在 `~/.ssh/config` 里配别名。

```bash
# 编辑配置文件
notepad ~/.ssh/config
```

示例内容：

```
Host myvps
    HostName 123.456.789.0
    User ubuntu
    Port 2222
    IdentityFile ~/.ssh/id_ed25519

Host jumpserver
    HostName jump.example.com
    User admin
```

之后只需要 `ssh myvps` 就能连上了。

## 18.6 内网穿透：没有公网 IP 怎么办

大多数家庭宽带没有公网 IPv4 地址。**大学里的实验室、宿舍网络**通常也是内网——你的电脑没有独立的公网 IP，外面的人直接连不上你。

**什么是内网穿透**：内网穿透（NAT traversal）是指让外网能够访问内网设备的技术。原理是你的电脑主动连上一个有公网 IP 的服务器（中转站），外面的人通过这个服务器访问你的电脑。

**大学场景举例**：
- 你在宿舍，想从外面（家里、实验室、实习公司）连回宿舍电脑拿文件
- 你在实验室，想从宿舍连回实验室的服务器跑代码
- 你做了一个网页，想临时给同学看看，但不想买服务器

**FRP** 是目前最流行的自建穿透工具。开源免费，Go 语言写的，支持 TCP、UDP、HTTP、HTTPS。但需要自己有一台有公网 IP 的服务器（VPS）来搭服务端。

如果不想自己买服务器，可以用公共服务。推荐两个：

- **Openfrp**：有免费套餐（限速 12 Mbps，隧道数 2），支持 TCP/UDP/TLS/HTTPS。适合游戏联机、远程桌面、网站临时测试。
- **cpolar（极点云）**：功能强大，场景适配广，支持 HTTP/HTTPS/TCP。免费版每日更换域名，适合临时调试。

其他公共服务（Ngrok、Natapp、SAKURA FRP 等）也可以，开箱即用，不需要自己有服务器。

> **注意**：国内公共服务很多要求实名认证，要花钱，这是合规要求。

## 18.7 大学实验室的 SSH 跳板机

很多学校的实验室或超算中心不允许直接公网 SSH 登录，而是需要先登录一台**跳板机（Jump Server / Bastion Host）**，再从跳板机登录内网的服务器。

典型流程：
1. `ssh 学号@gateway.sjtu.edu.cn`（跳板机）
2. 在跳板机上 `ssh 192.168.1.100`（内网服务器）

嫌两步麻烦，可以在 `~/.ssh/config` 里配置 `ProxyJump`：

```
Host jumpserver
    HostName gateway.sjtu.edu.cn
    User 学号

Host labserver
    HostName 192.168.1.100
    User ubuntu
    ProxyJump jumpserver
```

之后直接 `ssh labserver` 就可以一步登入实验室服务器。

## 18.8 小结

| 场景 | 推荐方案 |
|------|----------|
| 服务器远程管理 | SSH 密钥免密登录 + config 别名 |
| 同局域网内的电脑互访 | 直接用 SSH 内网 IP |
| 从外网访问没有公网 IP 的设备 | openfrp / cpolar / FRP 自建 |
| Windows 远程桌面（图形界面） | SSH 隧道转发 RDP，或直接用内网穿透工具转发 3389 端口 |
| 大学跳板机 | config 配置 ProxyJump |

SSH 本身功能远不止于此，还支持端口转发、代理跳转等高级用法。不过对日常使用来说，学会 `ssh user@host`、配好免密登录、知道内网穿透怎么搞，已经够用了。
