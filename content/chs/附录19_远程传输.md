# 附录十九：远程传输

> 这个附录介绍手机和电脑之间传文件的方法。不用数据线，不用看手机文件管理里乱七八糟的文件夹，几种方式各取所需。

## 19.1 为什么传个文件这么麻烦

手机和电脑之间传文件，常见的方法各有各的烦：

- **微信/QQ**：要压缩画质，大文件不让传，还得登录同一个账号
- **数据线**：要找线，插上还要选模式，手机文件管理里一堆看不懂的文件夹名
- **蓝牙**：慢，容易断
- **网盘**：要先上传再下载，绕远路，限速

其实有更好的办法。下面按推荐程度排序。

## 19.2 Snapdrop：最省事的方案

**Snapdrop** 是一个网页版的局域网传输工具。不需要安装任何软件，不需要登录账号，只要手机和电脑连在同一个 Wi-Fi 下，打开浏览器就能传。

**怎么用**：
1. 手机和电脑连同一个 Wi-Fi
2. 手机和电脑都打开浏览器，访问 `snapdrop.net`
3. 页面会自动发现同一网络下的其他设备，显示为圆形图标
4. 点击对方的图标，选择文件，对方点击“保存”即可接收 

**优点**：
- 什么都不用装，打开网页就能用
- 文件不经过任何服务器，只在设备之间点对点传输，安全 
- 支持任何设备（iPhone 用 Safari，安卓用 Chrome，电脑用 Edge 都行）

**缺点**：
- 必须在同一个 Wi-Fi 下（不能跨网络）
- 单文件太大可能会慢，建议 100MB 以内 

**一句话**：临时传几张照片、一个小文档，Snapdrop 最快。

## 19.3 KDE Connect：功能最全的方案

**KDE Connect** 是一个开源的全能型跨设备通信工具。原本是 Linux 上的 KDE 桌面环境的配套工具，现在已经支持 Windows、macOS、Android、iOS 。

**除了传文件还能干什么**：
- 手机和电脑共享剪贴板（手机上复制，电脑上 Ctrl+V 粘贴）
- 手机通知同步到电脑（电脑上查看微信消息，不用拿手机）
- 手机当电脑遥控器（控制音乐播放、PPT 翻页）
- 找手机（让手机响铃）
- 设备间双向传文件

**安装方法**：
- **Windows**：Microsoft Store 搜索“KDE Connect”安装 
- **Android**：Google Play 或 F-Droid 搜索“KDE Connect” 
- **iOS**：App Store 搜索“KDE Connect”
- **电脑端不需要登录任何账号**，手机和电脑在同一个 Wi-Fi 下就能配对

**配对步骤**：
1. 手机和电脑连同一个 Wi-Fi
2. 打开两边的 KDE Connect，手机会自动发现电脑
3. 点击“配对”，电脑上确认 

**一句话**：如果你经常在手机和电脑之间切换工作，装了 KDE Connect 会爽很多。

## 19.4 共享文件夹（SMB）

Snapdrop 和 KDE Connect 都需要两边都操作（一个发、一个收）。如果你只是想“在手机上随时翻电脑里的文件”，最好的办法是在电脑上开一个共享文件夹，手机当网络硬盘挂载。

**电脑端设置**（Windows）：
1. 右键要共享的文件夹 → 属性 → 共享 → 高级共享
2. 勾选“共享此文件夹”，权限里添加 `Everyone` 或 `Guest`，给“读取”权限 
3. 记下电脑的局域网 IP：Win+R 输入 `cmd`，再输入 `ipconfig`，找“IPv4 地址”（如 `192.168.1.100`）

**手机端访问**：

**安卓**：推荐用 **CX 文件管理器**（Play 商店或官网下载）
1. 打开 CX → 网络 → 远程存储 → SMB
2. 输入电脑 IP（如 `192.168.1.100`），用户名和密码（如果电脑设了的话）
3. 连上后就能直接浏览电脑里的文件，像操作本地文件一样

**iOS**：用自带的“文件”App 就够了 
1. 打开“文件”App → 右上角 `...` → 连接服务器
2. 输入 `smb://192.168.1.100`（注意是 `smb://` 开头）
3. 输入电脑的用户名和密码（Windows 登录账号）
4. 连上后共享文件夹会出现在“共享”列表里

**优点**：
- 一次配好，以后随时能用
- 手机可以直接看电脑里的视频、文档，不用先下载
- 支持多台设备同时访问

**缺点**：
- 只有局域网能用（离开 Wi-Fi 范围就连不上了）

## 19.5 FTP / HTTP 文件服务器

如果你只是偶尔从手机下载电脑上的文件，不需要反过来上传，可以在电脑上开一个临时的 HTTP 或 FTP 服务器。手机上用浏览器就能访问。

**Windows 快速开 HTTP 服务器**（不装软件）：
1. 在要共享的文件夹里，在地址栏输入 `cmd` 回车
2. 输入 `python -m http.server 8000`（需要装 Python）
3. 手机上浏览器访问 `http://电脑IP:8000`，就能看到文件夹里的文件列表，点击直接下载

**用 FTP**（适合需要上传）：
- 下载一个小巧的 FTP 服务器软件（如 Quick'n Easy FTP Server），5 分钟配好 
- 手机用 CX 文件管理器或浏览器（`ftp://电脑IP`）连接

## 19.6 总结

**简单选择**：
- 临时传文件 → Snapdrop
- 想深度打通手机和电脑 → KDE Connect
- 想随时访问电脑上的所有文件 → 开共享文件夹 + CX/iOS 文件

以上所有方法都**不走互联网**（在同一个 Wi-Fi 下），不消耗流量，也不用担心隐私泄露。离开家/宿舍就没法用了——那是内网穿透的事，附录十八讲过了。
