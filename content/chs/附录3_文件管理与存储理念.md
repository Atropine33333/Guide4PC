# 附录三：文件管理与存储理念

> 本章只介绍最核心的文件管理和存储操作。更深入的技术讨论请见后面的“补充阅读”。

## 3.0 新电脑到手第一件事：关掉 BitLocker

**BitLocker 是 Windows 的全盘加密功能**。它会加密你的硬盘数据，只有输入正确的恢复密钥才能解密。听起来很安全，但对个人用户而言，它带来的麻烦远大于好处：

- 你几乎用不上它。BitLocker 主要面向企业或政府场景，防止设备丢失后数据被读取。个人电脑丢失概率很低，而且大多数人的数据并没有那么高的保密价值。
- 一旦系统崩溃、主板损坏或你忘记备份恢复密钥，所有数据将永远无法恢复。微软也不会帮你解密。
- 它会略微降低硬盘性能（尤其是读写小文件时）。

**数据无价。我建议你直接关掉它，避免将来无法恢复数据的风险。**

**如何检查并关闭：**

1. 打开“设置” → “隐私和安全性” → “设备加密”（或搜索“BitLocker”）。如果显示“关闭”，则无需操作。
2. 如果显示“开启”，请以**管理员身份**打开 PowerShell 或命令提示符，输入以下命令并回车：
   ```powershell
   manage-bde -off C:
   ```
3. 等待解密完成。可在同一命令行中输入 `manage-bde -status` 查看进度。解密可能需要几十分钟到几小时，期间可以正常使用电脑，但建议插电并保持开机直到完成。

**不要听信任何“保留 BitLocker”的建议。对你来说，关闭它是更明智的选择。**

## 3.1 硬盘分区：C 盘和 D 盘分开

新电脑通常只有一个 C 盘。把所有文件（系统、文档、下载）都塞进 C 盘，一旦系统崩溃重装，所有数据都会丢失。因此建议将硬盘分成两个区。

**举例**：你的笔记本是 1TB 固态硬盘。可以给 C 盘留 300GB，剩下的约 650GB 给 D 盘。

- **C 盘（系统盘）**：只放 Windows 系统、驱动程序、以及少数必须装在 C 盘的软件。除此之外，什么都不要往里放。
- **D 盘（数据盘）**：存放你的文档、照片、视频、下载的安装包、Steam 游戏库、项目代码等。

**好处**：系统崩溃重装时，你只需要格式化 C 盘，D 盘上的所有文件完好无损。重装 Steam 后，在设置中添加 D 盘的 Steam 库文件夹，无需重新下载游戏。

**操作方法**：使用系统自带的“磁盘管理”（右键“此电脑” → 管理 → 磁盘管理），右键点击 C 盘选择“压缩卷”，压缩出所需大小，然后新建简单卷并分配盘符 D。如果不确定，可以在 B 站搜索“硬盘分区”，跟着视频做一次。

## 3.2 文件分类：用数字前缀建立秩序

在 D 盘里，不要直接堆文件夹。建议按“类别 + 编号”的方式组织，例如：

```
D:\
├── 01_Work
│   ├── 2026_resume.docx
│   └── lab_reports
├── 02_Study
│   ├── textbooks
│   ├── course_notes
│   └── projects
├── 03_Media
│   ├── photos
│   ├── music
│   └── videos
├── 04_Downloads
│   └── （临时存放，定期清理）
└── 05_Archive
    └── old_files_backup
```

- **01_Work**：实习、兼职、社团相关文档。
- **02_Study**：课程资料、论文、电子书。
- **03_Media**：个人照片、音乐、电影。
- **04_Downloads**：浏览器下载的缓存文件。每周或每月清理一次，有用的移到其他分类，没用的删除。
- **05_Archive**：已经用不上但舍不得删的东西（如毕业设计旧版本）。

为什么加数字前缀？ Windows 默认按字符排序，`01_` 会排在最前面，`02_` 其次。这样打开 D 盘时，重要的文件夹总是第一眼看到。
为什么用纯英文+数字+字符？ 一些软件显示非英文文字会乱码

## 3.3 游戏存储：通关即删，保留云存档

Steam、Epic 上的游戏越来越大（50–100GB）。一般来讲同时玩的游戏一般不超过两三个。通关后不会再碰的游戏，留着只会占空间。

**做法**：只保留正在玩的游戏。通关或确定近期不玩的，先确认云存档已同步（Steam 默认开启），然后从 Steam 卸载。想重温时再下载。

## 3.4 备份策略：321 原则（简化版）

321 备份原则是数据安全的基本共识：

- **3** 份副本（一份原始数据 + 两份备份）
- **2** 种不同的存储介质（例如本机硬盘 + 外置机械硬盘）
- **1** 份异地备份（例如云盘）

**对学生来说，可以简化为：**

1. **原始数据**：放在笔记本 D 盘。
2. **本地备份**：每两周或一个月，将 D 盘中最重要的文件夹（文档、照片、代码项目）复制到一块外置机械硬盘。
3. **异地备份**：使用百度网盘、OneDrive 或阿里云盘，将重要资料同步一份。

> 千万不要用杂牌 U 盘作为唯一备份！杂牌 U 盘可能用几次就坏。如果需要 U 盘，买正规品牌（如闪迪 CZ74）。更详细的机械硬盘选购和备份技巧，请见补充阅读。

## 3.5 云存储的简单选择

- **有条件尽量用国外服务**：OneDrive（购买 Office 365 附带的 1TB）、Dropbox。客户端稳定，对隐私保护相对更好。
- **国内选择**：百度网盘（速度受限但可做增量备份）、阿里云盘（目前限速较少）。
- **极度敏感的数据**（如身份证扫描件、密码备份）：不要直接上传任何云盘。先用开源加密软件（如 VeraCrypt）或 7‑Zip 带密码的 AES‑256 加密压缩包，再将加密后的文件上传。

## 3.6 让电脑时间精准：更换 NTP 服务器

如果电脑时间总是不对（例如开机后慢几分钟），是因为 Windows 默认的时间服务器在国外，连接延迟大。

**手动同步方法：**

1. 右键任务栏右下角的时间 → “调整日期/时间”。
2. 在“同步时间”区域，点击“立即同步”。如果失败，则点击“添加不同时区的时钟” → 切换到“Internet 时间”选项卡 → “更改设置”。
3. 在“服务器”框中输入以下任一地址：
   - `ntp.tencent.com`（腾讯，推荐）
   - `ntp.aliyun.com`（阿里云）
4. 点击“立即更新”，稍等几秒显示成功。

如果你是高校学生，可以搜索“你的学校 + ntp 服务器”获取校内地址（如清华的 `ntp.tuna.tsinghua.edu.cn`），延迟更低。

设置好后，电脑时间会自动定期同步，不再出错。

## 补充1：BitLocker 的适用场景（你不需要了解）

BitLocker 对于极少数需要极高安全性的场景（如处理商业机密、法律敏感信息）才有意义。如果你不是这类人，忽略即可。记住：关掉它。

## 补充2：分区操作的详细指南

使用系统自带磁盘管理分区时，注意：

- 新电脑 C 盘通常有大量空闲空间，“压缩卷”能压缩出的最大容量就是空闲空间。
- 压缩后出现黑色未分配区域，右键选择“新建简单卷”，按向导分配盘符 D，文件系统选 NTFS。
- 如果不小心删除了系统分区，不要慌张，搜索“Windows 安装介质修复引导”。

推荐视频教程：B 站搜索“硬盘分区 教程”。

## 补充3：游戏存档手动备份技巧

虽然 Steam 等平台提供云存档，但某些老游戏或盗版游戏不会自动同步。存档通常位于：

- `C:\Users\你的用户名\Documents\My Games`
- `C:\Users\你的用户名\AppData\Local` 或 `Roaming`（AppData 是隐藏文件夹，需要在文件管理器地址栏直接输入路径）

建议每通关一个游戏后，手动将其存档文件夹复制到 D 盘的 `GameSaves` 目录下。

## 补充4：机械硬盘选购与备份指南（深度版）

如果你需要一块机械硬盘专门做冷备份（不经常通电读写），以下经验值得参考。

**最前面的话: 机械硬盘工作时怕震动，不要边用边移动，也不要磕碰。**

**CMR vs SMR：我的个人选择**

CMR（传统磁记录）随机写入性能稳定，数据恢复成功率较高，即使局部损坏也通常不影响其他区域。SMR（叠瓦式磁记录）通过磁道重叠提升存储密度（同尺寸下可比CMR多约25%容量），单位成本更低，价格通常比同容量CMR低10%-20%。对于纯粹的冷数据顺序写入场景，SMR在技术上是够用的。

**但我自己就是讨厌叠瓦盘**——它随机写入性能差（IOPS下降超50%），局部损坏可能波及关联数据，恢复难度大。所以我个人只推荐CMR盘。目前家用级硬盘中，西数红盘 Pro、希捷 IronWolf Pro 等通常是CMR，购买前搜索“型号 + CMR”确认即可。

**SSD能否做冷备份？**

不推荐。固态硬盘依靠电荷存储数据，长期不通电（2-3年）电荷会逐渐流失导致数据损坏。如果温度较高，数据保存时间会进一步缩短（30°C环境下约一年，55°C环境下仅剩半年）。重要冷数据放机械硬盘更稳妥——当然，最好在任何地方都保留多份副本。

**利用闲置固态硬盘：M.2 硬盘盒**

如果你手头有闲置的M.2 SSD，可以买一个M.2硬盘盒把它变成高速移动硬盘。目前我了解的性价比不错的品牌是 **ITGZ**（也叫IGTZ），全金属外壳、支持9210B主控、兼容2230/2242/2280多种尺寸，价格大约49-70元。购买时注意——硬盘盒本身不贵，但没有闲置M.2硬盘的话，现在固态价格偏高，专门买一块来当移动硬盘不太划算。

**B Key 与 M Key 区分（给恰好需要的人）**

M.2接口有三种缺口类型：

- **M Key**：支持PCIe x4通道（高性能NVMe SSD），缺口在右侧，带宽可达32Gbps。
- **B Key**：主要支持SATA和PCIe x2通道，缺口在左侧，带宽较低。
- **B+M Key**：两种缺口都有，兼容两种插槽，但实际传输协议取决于插槽本身。

**定期通电：对任何电子产品都适用**

无论机械硬盘还是固态硬盘，长期不通电都可能出问题。机械硬盘的电机轴承需要定期转动润滑；固态硬盘虽无机械结构，但JEDEC标准规定数据保存期限是在特定温度条件下测量的，超过期限数据可能丢失。建议每3-6个月通电一次，让硬盘运行几分钟，顺便检查健康状态。

**易驱线与安全弹出**

如果用易驱线连接3.5英寸机械硬盘，务必选择带独立12V电源的版本——仅靠USB供电可能无法驱动，或导致识别异常。

需要拔掉时，务必先在Windows右下角点击“安全删除硬件”图标，确认弹出后再拔线。最稳妥的做法是直接关机——关机时系统会自动让磁头归位。**绝对不要在硬盘灯还在闪烁时直接拔USB线**，这极易造成磁头撞击盘片，产生物理坏道。

**SATA 接口插拔寿命提醒**

SATA 接口的插拔寿命有限（通常约 50-100 次），不要拔着玩。如果你用的是易驱板（SATA 转 USB 的裸板），可以把硬盘一直插在易驱板上，只拔 USB 线，这样 SATA 接口就不会磨损。如果你用的是易驱线（SATA 转 USB 的一根线），也建议整个连在一起放置，不要反复插拔 SATA 端。

**数据线推荐**

给硬盘盒或移动设备配 Type-C 数据线时，可以关注 **立讯精密**（Luxshare）的代工线。这家公司是苹果供应链核心企业，也是高速线缆领域的龙头。闲鱼上可以买到立讯精密的散装 240W PD 3.1 USB-C 快充线，价格不到 20 元，做工和电气性能远超同价位杂牌线，很适合搭配硬盘盒或给笔记本充电。另外，“科学捡漏”这个渠道也可以关注一下，有时能淘到大厂代工的好东西。

## 补充5：云存储加密实战

对于敏感文件（身份证扫描件、财务记录、密码备份），上传前必须加密。

**方法一：VeraCrypt**

- 下载 [VeraCrypt](https://veracrypt.io/en/Downloads.html)，创建一个加密卷（相当于一个虚拟硬盘）。
- 把敏感文件拖进去，关闭后生成一个 `.hc` 文件。把这个文件上传到云盘。
- 解密时需要 VeraCrypt 和密码，云盘服务商无法读取内容。

**方法二：7‑Zip 加密**

- 右键要加密的文件/文件夹 → 7‑Zip → 添加到压缩包。
- 设置密码，加密算法选 AES‑256。
- 将生成的 `.7z` 或 `.zip` 上传。注意：压缩包内文件名也会被加密（需勾选“加密文件名”选项）。

## 补充6：NTP 时间同步原理

NTP（网络时间协议）用于通过互联网校准电脑时钟。电脑主板上有 CMOS 电池维持时间，但电池会耗尽（一般 3–5 年）。如果你的电脑每次开机时间都重置到 1970 年，说明 CMOS 电池没电了，更换纽扣电池（CR2032）即可。

更换国内 NTP 服务器可以大幅提高同步成功率。除了腾讯和阿里，还可以尝试：

- `time.edu.cn`（教育网ntp服务器）
