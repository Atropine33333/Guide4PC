# 附录二：系统调优与杀毒软件

> 本章只介绍最核心的维护原则和操作。更深入的技术讨论请见后面的“补充阅读”。

## 2.1 核心原则：不懂就不要动

Windows 操作系统默认配置已经经过了大量测试，足以满足绝大多数使用场景。网上有很多“优化教程”教你关闭某些系统服务来释放内存，但这样做常常会导致一些功能无法使用（例如关闭打印服务后连不上打印机），而你可能早已忘记是自己关掉的。

唯一安全的原则：**如果你不清楚某个设置的具体作用，就不要改动它。** 正常使用、不乱调整，就是最好的优化。

## 2.2 杀毒软件：系统自带就够用

Windows 自带的 **Microsoft Defender** 已经足够强大，病毒库更新及时，与系统深度融合，不额外消耗过多资源。对于绝大多数个人用户，不需要安装任何第三方杀毒软件。

## 2.3 第三方安全软件的处理

### 2.3.1 国产安全软件：一般不需要
360、腾讯电脑管家、金山毒霸等国产软件，通常不建议安装。它们往往带有弹窗广告、捆绑推广，占用后台资源，甚至自身可能存在安全漏洞。

### 2.3.2 预装的迈克菲（McAfee）：建议卸载
很多品牌笔记本电脑（如华硕、戴尔的部分型号）会预装迈克菲，并赠送两年授权。考虑到迈克菲历史上曾曝出过安全漏洞，且运行在内核驱动层面，出现问题影响较大，**建议将其卸载**。卸载方法：搜索“McAfee 官方卸载工具”，下载运行即可彻底清除。

## 2.4 笔记本厂商预装软件：只保留控制中心

品牌笔记本会预装不少软件。其中唯一建议保留的是硬件控制中心，例如：
- 联想的 Lenovo Vantage
- 华硕的 Armoury Crate
- 戴尔的 Dell Power Manager

这些软件可以调节性能模式、风扇转速、电池充电阈值等。其余预装软件（如各类 AI 助手、音乐播放器、应用商店推荐、试用版软件等）都可以安全卸载。

## 2.5 C 盘不要塞满（最重要的优化）

保持 C 盘剩余空间不低于 **20%**（即占用率不超过 80%）。如果 C 盘空间不足，电脑会明显变慢，因为系统需要用硬盘作为临时内存（SWAP）。一旦 C 盘接近写满，请立即清理不需要的文件，或将“文档”“下载”“桌面”等用户文件夹移动到 D 盘。具体操作方法可以搜索“Windows 更改用户文件夹位置”。

## 2.6 良好习惯是最好的安全措施

- 只从官方网站或 Microsoft Store 下载软件。
- 不点无关弹窗广告，尤其是不点击“你的电脑已中毒”之类的提示。
- 不随意插入来历不明的 U 盘。
- 安装任何软件时，不要无脑狂点“下一步”。慢一点，看清楚每一步有没有“安装XX浏览器”、“设为首页”、“装到C盘”（可能想装到D盘）这样的选项，把不需要的勾去掉。

养成这些习惯后，Windows Defender 已经足够应对剩余的安全风险。

## 2.7 第一次进入系统后马上做的事

1. 连接网络后，打开 **“设置” → “Windows 更新”**，点击“检查更新”，安装所有补丁（可能需要重启多次）。
2. 打开 **“设置” → “应用”**，卸载不需要的预装软件（包括迈克菲）。
3. 重启电脑。
4. 在右下角任务栏确认 Windows Defender 的小盾牌图标存在且正常。

## 2.8 Windows 更新：请不要关闭

很多老教程会建议你“关闭 Windows 更新”，理由是更新会占用后台带宽、可能导致系统重启。**这个建议在今天已经完全不适用了。**

Windows 更新不仅仅是修复安全漏洞，它还会：

- 自动更新许多 Microsoft 软件，例如 Office 套件、运行库等；
- 更新硬件驱动（显卡、网卡、声卡等），避免因驱动过旧导致的蓝屏或性能问题；
- 更新 Windows Defender 的病毒库，确保你的电脑能防御最新的威胁。

如果你担心更新时电脑突然重启打断工作，可以这样做：

- 打开 **“设置” → “Windows 更新” → “高级选项” → “使用时段”**。
- 设置你通常使用电脑的时间段（例如 08:00 到 02:00）。Windows 在此期间不会自动重启。
- 其他时间如果有更新需要重启，Windows 会在闲置时进行，你也可以手动选择重启时间。

**不更新 Windows 并不会让你的系统更稳定。** 相反，长期不更新会累积大量未修复的漏洞和驱动 bug，反而可能导致蓝屏、卡顿甚至被恶意软件攻击。保持自动更新，合理设置使用时段，是更明智的做法。

# 补充阅读

> 以下内容为详细的技术讨论和进阶知识，每段独立成篇。你可以单独阅读任意段落，不需要依赖必须阅读部分。

## 补充1：为什么不要乱动注册表和组策略

注册表是 Windows 的配置数据库，记录了硬件、软件、用户等几乎所有设置。组策略是批量配置注册表的一种图形界面工具。错误的修改可能导致系统无法启动、某些功能永久失效。例如，有人为了“省内存”关闭了 Print Spooler 服务，结果几个月后需要打印时怎么也打不了，查了很久才想起是自己关的。如果你不知道这些工具是做什么的，就完全不要碰它们。

## 补充2：Windows Defender 与常见国产杀毒软件的对比

Windows Defender 没有广告、不会弹窗、不收集个人使用习惯数据，资源占用小。而国内一些安全软件（如 360、腾讯电脑管家）虽然提供了额外的小工具（如软件管家、网络测速），但代价是频繁的弹窗推广、捆绑安装、后台上传数据。在各大国际安全评测中，Defender 的病毒查杀率长期保持在第一梯队。因此，对于不做特殊高危操作的个人用户，Defender 是更稳妥的选择。

## 补充3：迈克菲（McAfee）的卸载说明

迈克菲之所以建议卸载，除了历史上出现过远程代码执行等安全漏洞外，还因为它的卸载并不容易——常规的“添加/删除程序”往往残留大量驱动和服务。推荐使用官方提供的“[McAfee Consumer Product Removal](https://www.mcafee.com/support/s/article/000001616)”工具，可以在迈克菲官网搜索获得。运行后会自动检测并彻底清理。如果你的笔记本是刚买的、还没有激活迈克菲，可以直接在设置中卸载，残留影响更小。

## 补充4：厂商预装软件的详细分类

- **必须保留**：硬件控制中心（调性能模式、风扇、电池阈值）。一旦卸载，你可能无法调节屏幕亮度、键盘背光或限制充电电量。
- **可以卸载**：厂商自带的“AI 助手”“电脑管家”“应用商店”“音乐/视频试用版”“云存储推广”等。它们大多是第三方的定制版，体验一般且占用资源。
- **视情况保留**：厂商的驱动更新工具（如联想驱动管理）。一般地，Windows更新会自动更新厂商的驱动，可以酌情判断是否要保留

## 补充5：SWAP（虚拟内存）机制详解

操作系统使用一种称为 SWAP（页面文件）的机制。当物理内存（RAM）不够时，系统会把一部分暂时不用的数据从内存移动到硬盘上的 `pagefile.sys` 文件中，从而释放内存给当前活跃的程序。即便物理内存足够，Windows 也可能会预先交换一些数据，以优化内存布局。这个 SWAP 文件默认存放在 C 盘。如果 C 盘剩余空间很少，页面文件无法正常扩展，或者扩展出来的空间不连续、散落在磁盘各处，系统频繁读写硬盘就会使电脑变得非常卡顿。这也解释了为什么 C 盘不能塞满。

## 补充6：固态硬盘的 SLC 缓存与写入原理

现代消费级固态硬盘大多使用 TLC（每单元 3 位）或 QLC（每单元 4 位）颗粒。为了提升写入速度，SSD 内部会划出一部分空间作为 SLC 缓存（每单元 1 位模式，写入快）。当写入数据量超过缓存大小时，就会切换到 TLC/QLC 直写模式，速度大幅下降。

当 SSD 占用率超过一定值时，主控会逐渐减少甚至关闭 SLC 缓存，强制进入 TLC 直写。更严重的是，剩余空间往往不是一整块连续区域，而是散布着已删除文件的逻辑痕迹。此时写入新数据，SSD 需要先读取原有数据块，在内存中修改后再写回（称为“读‑改‑写”），这会进一步降低性能并增加写入放大，缩短硬盘寿命。因此，保持 C 盘足够空闲不仅是为了虚拟内存，也是为了维持 SSD 的高速写入能力。

## 补充7：Malware-Patch 等辅助工具

Malware-Patch 是一个开源小工具（项目地址：[https://github.com/the1812/Malware-Patch](https://github.com/the1812/Malware-Patch)）。它不主动杀毒，而是通过 UAC（用户账户控制，即安装软件时弹窗询问权限的机制）拦截常见流氓软件的安装行为。当你双击安装某些“全家桶”软件时，它会弹出提醒。对于新手来说，这是一个温和的辅助手段，但不是必需的。如果你已经养成了只从官方渠道下载软件的习惯，就不需要它。

## 补充8：关于“让你的电脑飞起来”的优化视频

网上有很多视频声称通过修改几处设置就能大幅提升电脑性能。大多数这类“优化”要么是心理安慰，要么是牺牲稳定性换取微小提升，甚至可能关闭了重要的安全机制。真正能让电脑保持流畅的做法只有三点：
- 保持 C 盘有足够的剩余空间；
- 确保散热正常（清灰、垫高机身）；
- 不要安装明显拖慢系统的软件（如某些杀毒全家桶）。

除此之外，Windows 自己会管理好内存和后台进程。相信默认配置，把时间用在真正的工作和娱乐上，就是最好的优化。

## 补充9：关于“关闭 Windows 更新”的误解

网络上曾经流行一种观点：关闭 Windows 更新能提升性能、避免强制重启。这种观点源自 Windows 早期版本（如 Windows 7/8）更新体验较差、重启控制不佳的时期。但从 Windows 10 开始，微软对更新机制做了大量改进：

- 绝大多数更新在后台静默下载，不占用前台资源；
- “使用时段”功能给予用户足够的控制权；
- 驱动更新通过 Windows Update 分发，避免了用户自行寻找驱动的麻烦。

事实上，许多长期不更新的电脑遇到的问题（随机蓝屏、无法安装新软件、外设不兼容等），在安装完所有 Windows 和驱动更新后往往自动消失。因此，保持 Windows 更新开启，并定期检查，是维护系统健康最简单有效的手段之一。
