# 附录一：笔记本电脑入门

> 本章只介绍最核心的概念和操作。如果你完全没用过电脑，请先读这一部分。更深入的讨论请见后面的“补充阅读”。

## 1.1 硬件基础

### 1.1.1 什么是 CPU

CPU（中央处理器）是电脑的运算和控制核心，负责解释指令、处理数据、协调各个部件工作。你可以把它理解为电脑的“大脑”。

### 1.1.2 什么是 GPU

GPU（图形处理器）专门处理图像和并行计算任务。笔记本电脑中的 GPU 有两种形态：

- **核显（集成显卡）**：与 CPU 封装在同一芯片内，没有自己的显存，借用一部分系统内存。
- **独显（独立显卡）**：单独的芯片，有自己的显存。

### 1.1.3 什么是内存（RAM）

内存是 CPU 直接读写数据的临时仓库。速度快，但断电后数据全部丢失。打开程序时，系统会把数据从硬盘复制到内存中。

### 1.1.4 什么是硬盘（存储）

硬盘是长期保存数据的设备，断电后数据不丢失。现代笔记本电脑几乎全部使用固态硬盘（SSD）。

### 1.1.5 内存与硬盘的区别

用厨房的台面和冰箱来打比方：

- **内存是砧板（台面）**：你正在切和准备的食材就摆在手边，方便随时取用。台面空间有限，当你做完饭（断电）后，台面上剩下的食材就被扔掉了。
- **硬盘是冰箱**：所有食材长期存放在那里，需要时再取出来放到台面上处理。

## 1.2 核显与独显（基本概念）

- **核显**：功耗低、发热小，适合日常办公、网页浏览和轻度游戏。
- **独显**：性能强，适合大型游戏、3D 建模、视频剪辑等重负载工作。

核显的实际游戏表现受散热和功耗限制，详见补充阅读。

## 1.3 触控板（必须了解的类型）

2026 年的高端轻薄本大多使用以下两种触控板：

- **压感触控板**：不通电时按不下去，通电后通过压力传感器识别力度，用震动马达模拟按压反馈。手感好坏完全取决于厂商调校。
- **全域机械触控板**：整个板面都可以按下去（不像传统触控板只有下半部分可以按），但很多 Windows 机型上下区域按压力度不一致。

**强烈建议**：先到苹果体验店试一下 **MacBook Pro 的压感触控板**（这是压感触控板的标杆）和 **MacBook Neo 的全域机械触控板**（这是全域机械的标杆）。记住那种均匀、跟手的感觉，再回来试 Windows 阵营的同类产品，你就能判断自己能接受什么程度的手感了。

## 1.4 笔记本电脑分类

- **轻薄本**：便携、长续航、安静。使用低功耗 CPU，无独显，厚度约 15mm，重量 1.3kg 以下。适合办公、学习、轻娱乐。
- **游戏本**：高性能，配备标压 CPU 和中高端独显，散热厚重，重量常超过 2kg。适合大型游戏、专业视频剪辑等。
- **全能本**：介于两者之间，有一定便携性（约 1.8kg），配备入门级或中端独显，能兼顾办公和轻度游戏。

## 1.5 选购参考：笔吧评测室

笔吧评测室是国内较权威的笔记本电脑评测媒体。关注其微信公众号或 B 站账号（抖音和小红书也有）。微信公众号每周会发布不同价位的机型推荐列表，介绍非常详细。你可以先看推荐文章锁定几款候选机型，再去搜索详细评测和用户反馈。

## 1.6 购买建议（2026 年）

- **价格偏高**：2026 年笔记本电脑价格处于历史高位。如果不是刚需（比如现有电脑还能用），可以等等，价格可能会回落。
- **刚需购买**：在当前行情下，轻薄本性价比较高。现代高端轻薄本的核显性能已经足够运行不少游戏和日常软件。
- **国家补贴**：许多省份提供 10‑20% 的消费补贴。如果你有条件，可以考虑到有补贴的省份购买。具体政策请搜索“省份名 + 家电补贴”。

## 1.7 从开箱到激活：验机流程（核心步骤）

收到笔记本电脑后，请按以下步骤操作。**未激活前可无条件退换货**，发现问题立刻退货，不要自己修。

1. **检查外包装和外观**
   
   - 确认封条无拆开痕迹。
   - 检查笔记本顶盖（A面）和底面（D面）有无划痕、磕碰。
   - 检查电源适配器、充电口有无使用痕迹。
   - 轻轻掀开屏幕，来回转动，听有无异响。
   - 检查触控板：对于机械式（传统下沉结构），轻轻拨动边缘看是否晃动，按压四角看力度是否一致；对于压感触控板，开机进入系统后再测试不同区域的按压反馈。
   - 轻轻按压键盘各区域，感受是否稳固。
   
   发现异常，拍照留证，对不能接受的问题，可以直接联系客服退换。
2. **运输模式测试**
   不要接通电源，直接按一下开机键。
   
   - **无法开机** → 正常，继续下一步。
   - **直接开机进系统** → 说明被使用过，直接退货。
3. **第一次开机设置（跳过联网）**
   开机后有登录界面时，**千万不要连 Wi-Fi**。
   跳过 Windows 11 强制联网的方法：
   
   - 在区域选择界面按 `Shift + F10` 调出命令提示符。
   - 输入 `OOBE\BYPASSNRO` 回车，电脑自动重启。
   - 重启后走到联网界面，选择“我没有 Internet 连接” → “继续执行有限设置”。
   - 使用本地账户进入系统（用户名用英文数字）。
4. **屏幕检查**
   
   - 进入桌面后，右键点击“个性化”→“背景”→“纯色”，依次改为纯白、纯黑、纯红、纯绿、纯蓝，仔细观察是否有坏点（不该出现的亮点或暗点）。
   - 纯黑画面下看漏光：IPS 屏幕边缘微微发白是正常的，但如果某个角落明显发亮，可考虑退货。
5. **确认配置**
   
   - 按 `Win + X` 点击“任务管理器”→“性能”，确认 CPU 型号和内存容量。
   - 下载一个硬盘检测工具（如 CrystalDiskInfo），确认 SSD 品牌和型号与评测一致。
   - [CrystalDiskInfo官方下载界面](https://crystalmark.info/en/download/#CrystalDiskInfo): [https://crystalmark.info/en/download/#CrystalDiskInfo](https://crystalmark.info/en/download/#CrystalDiskInfo)
   - 你也可以使用`winget`来下载 `winget install -e --id CrystalDewWorld.CrystalDiskInfo`
6. **操作手感测试**
   
   - 单手端起笔记本时，有无异响。
   - 插上 U 盘、鼠标等，确认所有接口正常。
   - 充满电后，用电池轻度使用一小时，排除异常掉电。
7. **七天无理由退货**
   如果发现以下任何问题：屏幕坏点（尤其是正中间）、漏光影响观看、触控板回弹异常、电池损耗明显、网上有该批次通病——**直接选择退货（不是换货）**，重新购买一台或换一个品牌。
8. **注册微软账号并激活**
   
   - 访问 [signup.live.com](https://signup.live.com) 创建免费账号。
   - 登录后激活预装 Office（30 天内，否则失效）。
   - 以后重装系统可用数字许可证自动激活。
9. **最后联网**
   所有检查完成后，再连接 Wi‑Fi，Windows 和 Office 会自动激活。

# 补充阅读

> 以下内容为详细的技术讨论和进阶知识，每段独立成篇。你可以单独阅读任意段落，不需要依赖必须阅读部分。

## 补充1：CPU 型号与性能

2026 年主流轻薄本使用的 CPU 包括 Intel Core Ultra 5 338H、Ultra X7 358H、Ultra X9 388H 等型号；主流游戏本则常见 Intel Ultra 7 356H 搭配 NVIDIA RTX 5060 或 5070 独立显卡。需要注意的是，笔记本电脑 CPU 的命名规则较为混乱，同一架构可能衍生出多个型号，例如 AMD 的 8845H 实际上是 7840H 的马甲（规格几乎相同，仅名称不同，甚至8845H性能更差一点）。因此，在购买前建议搜索具体型号的性能评测，不要仅凭数字大小判断强弱。

## 补充2：核显游戏的性能期待与实际体验

有些宣传提到“ Intel Arc B390 GPU 性能接近 3050 Ti”，但实际使用中需要留意：笔记本电脑的核显没有独立显存，需要借用系统内存，而且 CPU 和核显共享同一套散热模组。在长时间游戏时，CPU 和核显会相互竞争功耗和散热资源，导致实际表现可能不如跑分数据那么理想。如果你打算用核显本玩 3A 大作，建议先观看笔吧评测室等媒体的核显游戏实测视频，再决定是否购买。

## 补充3：睡眠状态（S0ix 与 S3）

Windows 定义了多种电源睡眠状态。S3 是传统的“挂起到内存”——CPU 和大部分硬件断电，仅保留内存刷新，唤醒速度很快（约 1‑2 秒）。S0ix（现代待机，又称 S2idle）是微软从 Windows 8 开始推广的低功耗空闲状态，允许系统像手机一样待机时仍能联网更新，但有时会带来发热、电池耗电快、唤醒不可靠等问题。自 Intel Meteor Lake（第 12 代酷睿）之后，微软要求硬件厂商放弃对 S3 的完整支持，导致许多新笔记本只支持 S0ix。即使安装 Linux，由于 ACPI 表被厂商裁剪，同样无法使用 S3。如果你对睡眠可靠性有较高要求，购买前可以查询社区反馈——部分商务本（如某些 ThinkPad 型号）仍保留 S3 选项。

## 补充4：触控板调校差异

即使同为压感触控板，不同厂商的震动反馈手感差异也很大。例如小米和荣耀的调校风格就完全不同。因此，亲自去实体店触摸体验是很值得的。如果你不确定自己是否喜欢某种手感，可以先试苹果 MacBook Pro 的压感触控板（业界公认的标杆），再试 MacBook Neo 的全域机械触控板（同样标杆级），然后对比 Windows 机型，你就能清楚判断 Windows 机型的表现是否可以接受。

## 补充5：硬盘选型

### 颗粒厂与组装厂

固态硬盘的核心是 NAND 闪存颗粒。能自行生产颗粒的厂商称为“颗粒厂”或 IDM。目前仍在量产的主要颗粒厂有：三星（Samsung）、SK 海力士（SK hynix，含收购的 Intel 闪存业务，现为 Solidigm）、美光（Micron）、铠侠（Kioxia）、西部数据（Western Digital）以及中国的长江存储（YMTC）。长江存储的 Xtacking 架构（如 X4‑9040 颗粒）在性能和成本上较有竞争力。

主控芯片是 SSD 的“小 CPU”，负责管理数据读写、磨损均衡、垃圾回收等。知名的零售主控厂商有：慧荣（Silicon Motion）、群联（Phison）、联芸（Maxio）、英韧（InnoGrit）。

### TLC 与 QLC

- **TLC（Triple-Level Cell）**：每单元存储 3 位数据，写入寿命和速度较好。
- **QLC（Quad-Level Cell）**：每单元存储 4 位数据，密度高、成本低，但写入寿命和写入速度明显弱于 TLC。

对于系统盘或频繁写入的场景，一般不建议使用 QLC。Solidigm P41 Plus 是少数通过优秀固件策略缓解了 QLC 先天缺陷的产品。

### 原厂固态与副厂固态

- **原厂固态**：颗粒厂自己设计、封装和销售的 SSD，例如三星、西部数据、铠侠、致态等。
- **副厂固态**：从颗粒厂购买晶圆后自行封装、测试、组装的品牌，例如金士顿、威刚等。

副厂质量取决于其封装能力。有能力自行封装并严格测试的副厂（如 UMIS 出品的忆联盘的OEM）可以接受。对于没有任何封装能力、只会贴片的杂牌，由于颗粒来源不明，存在掉盘丢数据的风险，建议谨慎。

### OEM 盘与零售盘

OEM 盘与零售盘的硬件完全相同，零售版有官方质保和驱动支持，OEM 版只能通过渠道商保修，价格更低。OEM 盘通常从二手渠道流通，购买时建议核实店家的售后承诺。

### 个人推荐（仅供参考）

优先推荐原厂固态，如致态 TiPro 9000 等。OEM 盘中，以下三款值得考虑：

- **PVC10（SK 海力士）**
- **PCB01（SK 海力士）**
- **AM6C1（忆联，UMIS 旗下）**

三星 PM9A1 等型号曾出现过 0e 错误（不可恢复的数据错误，导致数据永久丢失），建议避开。任何白片、黑片或杂牌 SSD 也应避免。

硬盘存储着你的重要数据——论文、照片、代码、游戏存档。一块质量不可靠的硬盘可能突然损坏，数据恢复费用高昂且不一定能成功。为节省少量预算而承担这种风险，并不值得。

### 笔记本加装硬盘的注意事项

给笔记本加装硬盘前，建议确认以下几点：

- **空硬盘位**：搜索你机型的主板照片或拆机视频，确认有无空余 M.2 插槽。不同机型的第二硬盘位可能只支持短尺寸（如 2242 或 2230），强行安装 2280 可能无法固定。
- **M.2 尺寸规格**：常见规格有 2230（30mm 长）、2242（42mm 长）和 2280（80mm 长）。2280 最为常见。2242 规格中，PVC10 和 PC411 是两个值得考虑的选择。
- **功耗与掉盘风险**：笔记本电脑的供电和散热能力不如台式机。选购时确认该型号在满载下的功耗水平，功耗过高的硬盘在轻薄本上容易出现高温掉盘甚至损坏。
- **推荐评测来源**：B 站 UP 主“前进的四火”和“HOMOLAB”的硬盘评测质量较高，他们使用 fio 等专业工具做严谨的稳态测试，而非只看峰值跑分。
- **当前时机**：2026 年硬盘价格处于高位，如果不是刚需，可以等价格回落再入手。

## 补充6：屏幕选型

屏幕好坏因人而异，建议去线下实体店亲自观看对比。

### 个人偏好

部分用户更喜欢高素质的 LCD 屏幕（尤其是 IPS 或 MiniLED 背光），因为 LCD 没有 OLED 烧屏风险，全屏亮度更高，文字显示更锐利。

### 分辨率与刷新率

相比高刷新率（如 120Hz），高分辨率（如 2560×1600 或 3840×2160）能带来更细腻的文字和图像，对办公、编程、阅读提升明显。60Hz 对非竞技游戏用户基本够用。预算有限时，可以优先考虑高分辨率。

### 色准与色域覆盖

色准（常用 Delta E 衡量）和色域覆盖同样重要。色准影响你对色彩的判断——例如你用手机拍一张照片，放到电脑上用 Lightroom 调色，如果屏幕色准较差，调出来的颜色在别人眼中可能完全不同。即便不从事专业调色，日常修图、看电影也希望颜色尽量真实。色域覆盖决定屏幕能显示多少颜色，常见标准有 sRGB、DCI-P3 等。对于大多数用户，覆盖 100% sRGB 是及格线。

### 关于出厂校色与校色仪

现代轻薄本对屏幕色准的控制普遍不错，但“出厂校色”往往只针对少量样品，报告中的 Delta E 是在特定亮度和模式下测得，不保证你拿到的机器同样准确。如果你确实对色准有要求（如果你不知道“色准”这个概念，说明现阶段可能并不需要它），最可靠的方法是租一个校色仪（如 Spyder 或 Calibrite），按照教程校准屏幕，生成 ICC 配置文件并加载。每年校一次即可。

## 补充7：游戏本与全能本选购原则

对于游戏本，一个常用的核心原则是：在性能释放合格、屏幕过得去的前提下，选择价格更低的型号。不同品牌的同配置机型，性能释放（CPU 和 GPU 在长时间负载下能维持的功耗水平）可能差别很大。建议查看笔吧评测室等机构的实际烤机测试，确认散热和性能释放不缩水后再比价格。

全能本同样建议线下体验，因为不同模具的机身厚度、散热、风扇噪音差异较大。
